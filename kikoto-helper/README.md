# Kikoto Helper (Legacy)

[English](#english) | [简体中文](#简体中文) | [日本語](#日本語)

## English

Kikoto Helper is developed in its own repository:
<https://github.com/yexca/kikoto-helper>. Releases, documentation, and issues
live there. The helper deploys and manages Kikoto on Windows and runs local
speech recognition and translation for it.

This folder holds the legacy PowerShell helper. It receives no new features.
It stays in place because existing `kikoto-helper.cmd` launchers download their
language script and check for updates from this folder.

For a new installation, follow the
[Kikoto Helper README](https://github.com/yexca/kikoto-helper/blob/main/README.md).

## 日本語

Kikoto Helper は独立したリポジトリで開発されています：
<https://github.com/yexca/kikoto-helper>。リリース、ドキュメント、Issue は
そちらにあります。Kikoto Helper は Windows 上で Kikoto をデプロイ・管理し、
Kikoto のためにローカルの音声認識と翻訳を実行します。

このフォルダーには旧版の PowerShell ヘルパーが入っています。新しい機能は
追加されません。既存の `kikoto-helper.cmd` がこのフォルダーから言語スクリプトを
ダウンロードし、更新を確認するため、フォルダーを残しています。

新しくインストールする場合は
[Kikoto Helper の日本語 README](https://github.com/yexca/kikoto-helper/blob/main/docs/readme/README.ja.md)
に従ってください。
