Kikoto v0.4.1 adds durable voice-catalog discovery and stable per-session
recommendations, while refining creator, Library, and Android mobile flows.

## Library And Work Detail

- Favorites now contains only works the user explicitly favorited or added to a
  favorite list. Listening marks and playback cursors alone no longer add a
  work to Favorites.
- Work cards show a compact playback-history indicator when a persisted Resume
  cursor exists, without adding another row to shared collection cards.
- Recommendation ordering is materialized per browser-tab or native-app client
  session. Navigation, pagination, filters, card updates, and reshuffling keep
  their current generation stable; changed listening or favorite inputs affect
  placement in a later session.
- Refined mobile Library controls: search opens from a compact action, recently
  played is hidden while a search or status filter is active, and directory
  actions move into an accessible overflow menu on narrow screens.
- Maintenance now supports an ordered DLsite metadata language priority. Sync
  tries the configured languages in order before falling back to DLsite's
  default response.

## Creators And Catalogs

- Added durable Voice catalog discovery. Voice actor pages retain compatible
  remote-source discoveries independently from imported works, so remote
  catalog results do not create a second work identity.
- Added explicit First pull and refresh actions for voice catalogs, with
  incremental and full catalog or metadata scopes and selected remote sources.
  Catalog visits remain read-only; refresh runs are visible and recoverable as
  workflows.
- Voice catalog refresh follows source pagination with bounded concurrency,
  preserves prior observations after failed sources, and only synchronizes
  metadata for known canonical work families.
- Added creator catalog sync states and configurable freshness. Circle cards
  now show one canonical available-work summary, while Circle and Voice mobile
  pages use focused action and options surfaces.

## Appearance And Mobile

- Header account actions open in a viewport-bounded mobile sheet, keeping
  account, Activity, and appearance controls usable on compact screens.
- Appearance style previews now reflect the selected color palette.
- Android no longer requests activity resize for the software keyboard. The
  frontend continues to size text-entry surfaces against the visual viewport,
  preventing severe viewport compression while the keyboard is shown.

## Operations And Reliability

- Added migration `026` for revision-tracked recommendation generations and
  client-session bindings.
- Added migration `027` for persisted voice catalog items, source observations,
  and refresh state.
- Updated mobile browser regression coverage to follow the current accessible
  search and directory-action flows.
