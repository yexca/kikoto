Kikoto v0.5.0 adds a release-versioned fresh-install database baseline while
preserving the immutable numbered migration path for existing libraries.

## Library And Accounts

- Favorites distinguish the system Marked list from ordinary user-created
  lists, preserving existing explicit favorites during the upgrade.
- Accounts can store an interface-language preference independently from the
  browser default.

## Metadata And Maintenance

- DLsite metadata retains the provider-declared edition language separately
  from the request locale, with a queryable localized title and tag projection.
- Local media cleanup records its workflow association and preserves older
  local-root information as explicit folder locations.

## Workflows And Operations

- Availability Watch is now one instance-level workflow with a shared target
  pool and a safe migration path for prior per-user configurations.
- New installations use `baseline/032_v0.5.0.sql`; existing databases continue
  through numbered migrations `028` through `032` without reconstructing user
  data from the baseline.
