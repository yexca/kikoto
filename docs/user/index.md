# User Guide

This section is for people who run Kikoto and listen to their own library. It
covers installation, first-time setup, library organization, playback, remote
sources, and the settings visible in the application.

## Start here

- [Getting started](../getting-started.md): install Kikoto, start the container,
  and perform the first library scan.
- [Library](../product/library.md): understand Local, Tracked, and remote
  library views.
- [Sources](../product/sources.md): browse, track, cache, and fetch remote
  files.
- [Playback](../product/playback.md): use the player, queues, progress, and
  compatible media playback.
- [Settings](../product/settings.md): configure personal and instance options.
