# 订阅
[English](../en/subscriptions.md) · [简体中文](../zh-Hans/subscriptions.md) · [繁體中文](../zh-Hant/subscriptions.md) · [日本語](../ja/subscriptions.md) · [한국어](../ko/subscriptions.md)

订阅页面汇集你所订阅的社团、系列和声优的新作，以及可用性监视在远程来源上发现的作品。

## 订阅

- 社团、系列和声优页面在**收藏**旁边都有一个铃铛。订阅与收藏是分开的：收藏记录的是偏好，订阅则会把新作加入订阅动态。订阅属于个人。
- 订阅以目录当前的状态为起点：目录中已有的作品永远不会被算作新作。如果目录最近拉取过，订阅会立即开始。否则订阅时会先询问：可以同步元数据的账号可以立即拉取目录，拉取成功后订阅开始；其他账号，或选择**下次刷新时拉取**的账号，则等待下一次计划刷新。在此之前，铃铛显示**已订阅，正在等待首次拉取目录**。
- 社团订阅包含该社团的系列。已订阅社团的系列上的铃铛不可用；订阅一个社团时，会先列出它将取代的系列订阅，然后再移除它们。
- 声优的目录来自远程来源，因此订阅声优需要一个已启用且兼容的远程来源。
- 再次选择铃铛，可以开启或关闭**监视可用性**、打开**管理订阅**，或**取消订阅**。开启**监视可用性**后，如果你的账号可以编辑监视池，该订阅的新作也会被加入可用性监视。

## 新作

- **新作**按作品进入动态的日期分组，最新的一天在前，每个作品族一张卡片。每天另起一行，标题显示日期和当天的作品数量。每张卡片上方显示发生了什么以及通过哪个订阅。事件有：
  - **新作**：订阅的目录中出现了新作品。
  - **新版本**：很久以前发行的作品出现了新的语言版本，例如翻译版。
  - **现已可用**：可用性监视在远程来源上找到了该作品。所有可以打开工作流的账号都会收到这类条目。
  有多个事件的作品族只保留一张卡片，显示在其最新事件当天。
- 卡片与媒体库一致。**显示选项**包含每行的卡片数、媒体库和其他作品集合共用的**卡片**选择（**完整**、**紧凑**或**极简**），以及每页包含的天数：5、10（默认）或 15。没有新作品的日子会被跳过，因此每页包含的是有作品的这么多天。一天从**设置 → 账户 → 时区**中所选时区的午夜开始；选择**自动**时使用设备的时区。
- 元数据已知该作品时，卡片显示该作品；在此之前显示目录中的标题、社团和编号。打开卡片可以进入该作品、将它加入收藏列表、打开 DLsite，或将它加入可用性监视。
- 自你上次打开动态以来新增的卡片带有圆点标记。导航会显示其数量，打开动态后计数清零。一次刷新如果向你的动态添加了条目，还会发送一条通知。
- 发行时间早于你的订阅开始时间 30 天以上的作品不会显示，因此日后拉取目录中较早的部分不会给动态添加任何内容。

## 订阅设置

右上角的设置图标（**订阅设置**）会从屏幕右侧打开一个抽屉，在手机上则打开一个底部面板，其中有**订阅**和**可用性监视**两个标签页。点击 `×`、按 Esc 键或点击抽屉外侧即可关闭。

- **订阅**列出你的社团、系列和声优订阅，以及它们的状态（**生效中**或**等待首次拉取**）、目录上次拉取的时间和**监视可用性**选项。
- **刷新计划**由所有账号共用。一次刷新会对每个已订阅的目录各拉取一次，同步新作品的元数据，把它们加入订阅者的动态，然后检查可用性监视。最近六小时内拉取过的目录（例如通过详情页刷新）不会再次拉取，并且一次刷新最多同步 60 部新作品；其余的等待下一次刷新。
- 可以同步元数据的账号可以开启或关闭**自动刷新**，选择**刷新间隔**（1 小时到 7 天；默认 24 小时），选择每次刷新是否检查可用性监视，并**立即刷新**。**查看最近一次运行**会在“活动”中打开该次刷新。

## 可用性监视

- 设置抽屉的**可用性监视**标签页保存共用的监视池及其配置：远程来源、作品变为可用时的操作，以及可选的 Fetch 扩展名排除项；监视运行如何检查作品族，参见[工作流](workflows.md)。它向可以打开工作流的账号显示。
- 订阅刷新会按其计划运行监视；**运行**会立即检查监视池。工作流页面保留监视的运行历史，并链接到这里。
