# 社团
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社团页面呈现制作者、社团以及相关主体的目录状态。

## 当前行为

- 以服务端分页的方式列出已知主体，每张卡片都带有目录状态和可用性状态。
- 提供搜索、筛选、由 URL 保存的分页、收藏状态、用户标签、评分和备注。
- 搜索、一键切换视图的筛选标签和每页数量操作位于同一行可换行的工具栏。筛选标签为 `全部社团`、`收藏`、`已标记`、`可用`、`本地`、`远程`、`缺失` 和 `需要注意`，处于按下状态的标签即当前视图。在手机上，搜索框独占一行，每页数量位于其旁边，筛选标签在下方横向滚动。
- 每个社团显示为封面磁贴：社团的封面（没有封面时显示 `无封面` 占位）、封面上的收藏控件、名称、最新发行日期和个人标签。磁贴在宽屏布局中铺满整行，在手机上为两列。
- 以已知的最新 DLsite 作品的本地缓存封面作为社团的封面。详情页**更多**菜单中的**更换封面…**会列出该社团的作品并提供搜索，所选作品的封面会成为该社团在磁贴和详情摘要上的封面。同一对话框中的**最新作品**可恢复为随每次新发行更新的封面。该选择归做出选择的账户所有；若所选作品已不在该社团的目录中，则改用最新作品的封面。
- 每个社团磁贴概括其同步状态、统一的 `可用 N/total` 数量和一条可用性条：实心段表示有本地副本的作品，较浅的段表示只有远程来源持有的作品，空白轨道表示其余作品。
- 按外部 ID 显示社团详情。
- 社团目录作品由服务器分页。目录总数保持完整，搜索、可用性和系列筛选以及所选排序在分页前执行；批量选择仅覆盖当前已加载的页面。
- 目录作品可按**发行日期**、**代码**、**标题**、**评分**或**销量**升序或降序排列，默认按发行日期从新到旧。没有评分或销量的作品无论升序还是降序都排在最后。排序方式和每页数量（24、48 或 96）按账号记在当前设备上，并适用于每个社团。
- 支持以增量或完整模式刷新目录。
- 目录条目与已导入的作品分开存储。
- 为目录中的作品显示本地、缓存和远程来源的可用性标签。
- 以与媒体库相同的响应式网格和作品卡片呈现作品结果。这同时适用于社团详情和社团系列；单独的社团列表保留自己的控件。在作品卡片上选择 DLsite 标签或个人标签，会打开针对该标签的本地媒体库搜索。
- 社团详情摘要显示在带封面色调的面板上，并列出该社团的别名和个人标签。其中的**可用**、**本地**、**远程**和**不可用**数量位于可用性条旁，描述整个目录，不受下方作品筛选条件的影响。从未拉取过的社团会说明仅列出媒体库已知的作品；否则摘要会显示目录上次同步的时间。系列卡片带有同样的可用性条。
- 常用的刷新操作位于详情摘要中：尚未拉取过的社团显示**首次拉取**，之后是**刷新社团**，它同时会检查远程来源。只有当目录作品仍缺少元数据时才会出现**重试元数据**，并且只补全这些作品。每个操作都会排队一个不带筛选或标签的“同步社团目录”运行并立即返回；在该运行结束前，按钮显示**正在刷新**，运行情况可在“活动”中查看。
- “收藏”旁边的铃铛用于订阅该社团的新作，系列的 DLsite 链接旁边的铃铛用于订阅该系列；参见[发现](discover.md#订阅)。已订阅社团的系列已包含在内。
- **更多**菜单中有**更换封面…**和**同步此社团的目录…**，即已填入当前社团的“同步社团目录”预制工作流，用于目录刷新、筛选、元数据、标签和来源检查的其他各种组合。若要刷新该社团作品已有的元数据，请使用社团范围运行元数据同步。
- 在移动端缩短常用的详情操作，仅有图标的“收藏”、“更多”和 DLsite 控件仍可通过名称访问，并把 DLsite 放在最后。
- 在宽屏布局中使用与媒体库一致的作品工具栏：左侧是“作品/系列”切换和有长度限制的搜索，右侧依次是显示当前排序方式的排序按钮、显示选项、可用性筛选和选择。显示选项包含与媒体库共用的**卡片**选项（**完整**、**紧凑**、**极简**）、列数以及每页数量；新选择的卡片模式从其[预设](library.md#当前行为)开始。共用的合集分页位于网格上方和下方。
- 在移动端，作品控件仅保留“作品/系列”切换（旁边是排序按钮）、搜索和一个“目录选项”操作。可用性、卡片模式、移动端列数、每页数量和选择模式都放在该面板里；宽屏布局保留内联控件。系列概览列出系列，不提供排序。
- 在移动端，详情页的返回控件相当于“上一级”，指向最近一次按服务器和用户记录的社团列表位置，即使该详情是从媒体库打开的也一样。宽屏布局则保留可识别来源的历史返回标签和目的地。
- 确认后可以移除过期的目录条目。

## 边界

社团目录只说明某个主体发布过什么。在来源同步或 Fetch 创建媒体位置之前，它们不会产生具体的播放位置。

## 刷新行为

增量刷新应优先读取最新的目录条目，遇到已知条目时停止。完整刷新可以遍历更多提供方的分页，但不应自动删除旧的目录条目。
