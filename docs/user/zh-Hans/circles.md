# 社团

[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社团页面表示创作者及其目录状态。

## 主要内容

- 支持搜索、筛选和分页浏览社团。
- 管理收藏、个人标签、评分和备注。
- 显示 DLsite 代码、封面、同步状态和 `Available N/total`。
- 目录行与 Work 分开保存，作品结果使用与 Library 相同的网格。

目录说明社团发布过什么；只有 Sync 或 Fetch 创建媒体位置后才有可播放位置。
