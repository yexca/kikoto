# 社团
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社团页面呈现制作者、社团以及相关主体的目录状态。

## 当前行为

- 以服务端分页的方式列出已知主体，每张卡片都带有目录状态和可用性状态。
- 提供搜索、筛选、由 URL 保存的分页、收藏状态、用户标签、评分和备注。
- 采用与媒体库一致的首行工具栏：搜索位于左侧，每页数量和社团筛选操作（默认为 `全部社团`）位于右侧；窄屏布局会把搜索收进工具栏操作中。
- 在紧凑的响应式创作者卡片中显示已知的最新 DLsite 作品编号和本地缓存的封面，没有封面时显示 `无封面` 占位。
- 每张社团卡片概括其同步状态，并用统一的 `可用 N/total` 徽章取代分开的本地和远程数量。
- 按外部 ID 显示社团详情。
- 支持以增量或完整模式刷新目录。
- 目录条目与已导入的作品分开存储。
- 为目录中的作品显示本地、缓存和远程来源的可用性标签。
- 以与媒体库相同的响应式网格和作品卡片呈现作品结果。这同时适用于社团详情和社团系列；单独的社团列表保留自己的控件。在作品卡片上选择 DLsite 标签或个人标签，会打开针对该标签的本地媒体库搜索。
- 在社团详情中，用户自定义标签旁显示一个 `可用 N` 徽章。社团界面不再显示重复的统计磁贴和社团别名。
- 常用的刷新操作位于详情摘要中：尚未拉取过的社团显示**首次拉取**，之后是**刷新社团**，它同时会检查远程来源。只有当目录作品仍缺少元数据时才会出现**重试元数据**，并且只补全这些作品。每个操作都会排队一个不带筛选或标签的“关注社团”运行并立即返回；在该运行结束前，按钮显示**正在刷新**，运行情况可在“活动”中查看。
- **更多**菜单中有**关注此社团…**，即已填入当前社团的“关注社团”预制工作流，用于目录刷新、筛选、元数据、标签和来源检查的其他各种组合。若要刷新该社团作品已有的元数据，请使用社团范围运行元数据同步。
- 在移动端缩短常用的详情操作，仅有图标的“收藏”、“更多”和 DLsite 控件仍可通过名称访问，并把 DLsite 放在最后。
- 在宽屏布局中使用与媒体库一致的作品工具栏：左侧是“作品/系列”切换和有长度限制的搜索，右侧是列数、每页数量、可用性筛选和选择，均为低调的图标操作。共用的合集分页位于网格上方和下方。
- 在移动端，作品控件仅保留“作品/系列”切换、搜索和一个“目录选项”操作。可用性、移动端列数和选择模式都放在该面板里；宽屏布局保留内联控件。
- 在移动端，详情页的返回控件相当于“上一级”，指向最近一次按服务器和用户记录的社团列表位置，即使该详情是从媒体库打开的也一样。宽屏布局则保留可识别来源的历史返回标签和目的地。
- 确认后可以移除过期的目录条目。

## 边界

社团目录只说明某个主体发布过什么。在来源同步或 Fetch 创建媒体位置之前，它们不会产生具体的播放位置。

## 刷新行为

增量刷新应优先读取最新的目录条目，遇到已知条目时停止。完整刷新可以遍历更多提供方的分页，但不应自动删除旧的目录条目。
