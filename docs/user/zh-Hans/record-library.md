# 记录

[English](../en/record-library.md) · [简体中文](record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](../ja/record-library.md) · [한국어](../ko/record-library.md)

记录是用于个人视频、图片和音频文件的独立媒体库。它使用 `/record` 挂载点，不会把文件加入音频媒体库或任何作品。

## 设置

记录默认关闭，需由管理员开启。将主机目录挂载到 `/record`，然后在**系统 → 媒体库**的**记录**部分开启**记录媒体库**，并选择**初始化根目录**。Kikoto 会写入 `.kikoto-record` 标记；只有显式初始化后才会开始扫描。记录关闭时，侧边栏对所有账户都会隐藏它；关闭后会保留它的文件夹、观看位置和缩略图，重新开启后即可继续使用。生产环境的默认挂载如下：

```yaml
volumes:
  - ./record:/record
```

目录可以使用任意深度，页面浏览的是同一棵目录树：

```text
record/
├── artist1/
│   ├── folder-a/
│   └── folder-b/
└── artist2/
    └── folder-c/
```

## 浏览

记录页面一次显示一个文件夹。顶部路径栏标出当前文件夹并可返回包含它的任一上级文件夹，右侧提供**继续观看**和**扫描**（没有扫描权限的账户则显示**刷新**）。地址会保留当前打开的文件夹，因此浏览器的后退、前进和刷新都会回到同一位置；按 Backspace 键也可以返回上一级。

文件夹内的项目按名称自然顺序排列，依次为子文件夹、视频、照片，最后是文件夹中的其他文件；当同一文件夹包含多种类型时才会显示分组标题。子文件夹显示为方形磁贴，展示其海报；没有海报时展示背景图，两者都没有时显示文件夹图标；视频显示为宽幅磁贴，附带视频中的一帧、已知的时长，以及一条表示观看进度的进度条；照片显示为方形缩略图。缩略图在文件夹首次显示时生成，因此较大的文件夹第一次打开时可能需要稍等片刻。文件夹的 artwork 图片保持隐藏。

**文件**列出文件夹中的其他所有内容，每项一行，显示其类型和大小：音频文件附带时长和一条表示收听进度的进度条，另外还有字幕、元数据及任何其他文件。选择音频文件即可播放。

在任意文件夹中打开右上角的**继续观看**，都会按最近观看的顺序列出你看到一半停下的视频和音频文件，并标出每个视频所在的文件夹。选择其中一个会从停下的位置开始播放，关闭播放器后返回打开时的文件夹。

## 扫描和 artwork

选择路径栏右上角的**扫描**；这需要资料库写入权限。悬停按钮可查看根目录上次扫描的时间；开始扫描后，还会显示扫描是已排队、正在运行还是已完成。扫描会作为持久工作流排队，并与正在运行的扫描合并。它按扩展名索引普通文件，跳过链接和 Kikoto 事务目录；根目录离线或扫描部分完成时会保留已有记录。只有完整扫描才会将已移除的目录和文件标记为缺失。扫描还会读取每个新增或已更改视频的时长和大小，以及每个新增或已更改照片的大小；无法读取的文件不会记录时长，并会在其更改后重新读取。

文件夹 artwork 使用以下图片名：`folder`、`poster` 或 `cover` 用作海报，`backdrop`、`fanart` 或 `background` 用作背景。支持的视频扩展名包括 `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v` 和 `.ts`；支持的音频扩展名包括 `.mp3`、`.m4a`、`.aac`、`.flac`、`.wav`、`.ogg`、`.opus`、`.wma`、`.aiff` 和 `.mka`；支持的图片扩展名包括 `.jpg`、`.jpeg`、`.png`、`.webp` 和 `.avif`。

## 观看视频和照片

选择视频后会在全屏播放器中打开，播放器会让画面及其控件适应屏幕，并提供与[作品的视频播放器](work-detail.md#当前行为)相同的屏幕控件、触摸手势、**字幕**菜单和键盘快捷键；在电脑上，顶部的键盘按钮会列出这些快捷键。在手机上，视频开始播放时会切换为全屏，宽度大于高度的视频会让屏幕转为横屏，直到退出全屏；在 iPhone 和 iPad 上，**全屏**会打开系统播放器。如果你上次看到一半停下，Kikoto 会询问是从该时间**继续**还是**从头开始**。浏览器无法直接播放的视频，例如 MPEG-TS（`.ts`）录像，或在不支持 HEVC 的浏览器中的 HEVC 视频，会按媒体库中视频的方式播放：浏览器能解码其画面时，服务器无需重新编码即可重新封装，否则会转换。与视频同名的 `.vtt` 或 `.srt` 文件会作为其字幕显示；`.srt` 文件必须为 UTF-8 编码。视频内嵌的文本字幕同样可选。上一个和下一个按钮可在该文件夹的视频之间切换，返回或 Esc 关闭播放器。

耳机按钮（**仅音频**）会只播放视频的声音：播放器只加载其声音，并显示视频的一帧画面或文件夹的海报。切换后会从同一时刻继续，且此设备会记住该选择，用于下一个视频。音频文件在同一播放器中打开，可在该文件夹的音频文件之间切换，并像视频的声音一样直接播放或经转换后播放。

播放位置按账户保存，约每十秒一次，并在暂停、播放结束和关闭播放器时保存；保存位置需要资料库写入权限。视频或音频文件开始播放时会暂停全局音频播放器，关闭播放器后音频仍保持暂停。

选择照片可全屏查看。使用箭头按钮、方向键或左右滑动在该文件夹的照片之间切换，用返回或 Esc 关闭。照片打开时适应屏幕，点击显示实际大小，再次点击恢复适应屏幕；鼠标滚轮、触控板或双指捏合，以及 `+`、`-`、`0` 键可以缩放到实际大小 8 倍以内的任意比例，放大后拖动可以平移。
