# 记录

[English](../en/record-library.md) · [简体中文](record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](../ja/record-library.md) · [한국어](../ko/record-library.md)

记录是用于个人视频和图片的独立媒体库。它使用 `/record` 挂载点，不会把文件加入音频媒体库或任何作品。

## 设置

将主机目录挂载到 `/record`，打开**记录**，然后选择**初始化根目录**。Kikoto 会写入 `.kikoto-record` 标记；只有显式初始化后才会开始扫描。生产环境的默认挂载如下：

```yaml
volumes:
  - ./record:/record
```

目录可以使用任意深度，页面浏览的是同一棵目录树：

```text
record/
├── artist1/
│   ├── folder-a/
│   └── folder-b/
└── artist2/
    └── folder-c/
```

## 浏览

记录页面一次显示一个文件夹。上方的路径标出当前文件夹，并可返回包含它的任一上级文件夹。地址会保留当前打开的文件夹，因此浏览器的后退、前进和刷新都会回到同一位置。

带有背景 artwork 的文件夹打开时会显示横幅，展示其海报、名称以及视频和照片的数量，并提供用于播放第一个视频的**播放**，或从你上次观看的视频停下的时间继续的**从 … 继续**。其他文件夹则以普通标题显示相同的信息。

工具栏可切换显示**全部**、**视频**或**照片**，并可按名称正序或倒序排序。子文件夹显示为方形磁贴，展示其海报；没有海报时展示背景图，两者都没有时显示文件夹图标；视频显示为宽幅磁贴，附带视频中的一帧、已知的时长，以及一条表示观看进度的进度条；照片显示为方形缩略图。缩略图在文件夹首次显示时生成，因此较大的文件夹第一次打开时可能需要稍等片刻。字幕、元数据及其他文件保持隐藏，文件夹的 artwork 图片也同样隐藏。**刷新**会重新读取该文件夹。

在顶层，**继续观看**按最近观看的顺序列出你看到一半停下的视频，并标出每个视频所在的文件夹。选择其中一个会从停下的位置开始播放，关闭播放器后返回顶层。

## 扫描和 artwork

在工具栏中选择**扫描**；这需要资料库写入权限。旁边会显示根目录上次扫描的时间；开始扫描后，还会显示扫描是已排队、正在运行还是已完成。扫描会作为持久工作流排队，并与正在运行的扫描合并。它按扩展名索引普通文件，跳过链接和 Kikoto 事务目录；根目录离线或扫描部分完成时会保留已有记录。只有完整扫描才会将已移除的目录和文件标记为缺失。扫描还会读取每个新增或已更改视频的时长和大小，以及每个新增或已更改照片的大小；无法读取的文件不会记录时长，并会在其更改后重新读取。

文件夹 artwork 使用以下图片名：`folder`、`poster` 或 `cover` 用作海报，`backdrop`、`fanart` 或 `background` 用作背景。支持的视频扩展名包括 `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v` 和 `.ts`；支持的图片扩展名包括 `.jpg`、`.jpeg`、`.png`、`.webp` 和 `.avif`。

## 观看视频和照片

选择视频后会在全屏播放器中打开。如果你上次看到一半停下，Kikoto 会询问是从该时间**继续**还是**从头开始**。与视频同名的 `.vtt` 或 `.srt` 文件会作为其字幕显示；`.srt` 文件必须为 UTF-8 编码。上一个和下一个按钮可在该文件夹的视频之间切换，返回或 Esc 关闭播放器。播放位置按账户保存，约每十秒一次，并在暂停、播放结束和关闭播放器时保存；保存位置需要资料库写入权限。视频开始播放时会暂停全局音频播放器，关闭播放器后音频仍保持暂停。

选择照片可全屏查看。使用箭头按钮、方向键或左右滑动在该文件夹的照片之间切换，用返回或 Esc 关闭。
