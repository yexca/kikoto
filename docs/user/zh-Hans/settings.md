# 设置

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

设置管理保存在服务器、用户和浏览器中的行为。

## 主要内容

- 设置界面语言、主题、显示密度和作品网格列数。
- 保存播放速度、跳转时间和兼容播放范围。
- 管理服务器连接、来源、元数据语言、扫描、watcher 和 `Follow-up run`。
- 按用户保存个人标签、收藏和播放状态。

## 维护

Maintenance 标签单行横向排列，窄屏可横向滚动。Overview 已移除；Library 整合本地扫描、远程来源和只读存储路径，作为来源管理员的默认页。Users 整合用户管理及仅超级管理员可用的实例访问设置；只有用户管理权限时默认进入 Users。旧 Paths 和 Access 链接分别转到 Library 和 Users。

远程来源以精简列表展示健康状态、主机、健康检查和可立即保存的启用开关。**添加来源** 只需输入一个地址：Kikoto 会依次探测原地址、其源站和常见的 `api.` 子域名，自动填入 API URL、公开网站和名称；未检测到时会展开 **连接详情** 供手动填写。端点、优先级以及网络与存储选项默认折叠。Cache & Fetch 只保留配置项，缓存内容改在 **清理** 标签页管理。推荐设置下新增折叠的 **我的推荐活动**，只统计当前用户过去 30 天的推荐数据。

## 清理

**清理** 是设置中位于 Cache & Fetch 之后的管理员标签页（`/settings?tab=cleanup`）；缓存部分需要 `downloads:manage`，数据库部分需要 `sources:write`。页面包含转码缓存与托管媒体缓存的用量和清理，以及数据库记录清理：磁盘上已确认不存在的作品文件夹和本地文件（连同由此变空的曲目条目和本地可用状态）、孤立元数据快照、未使用的来源标签、过期会话、已关闭通知、超过 90 天的工作流历史和推荐信号、不再使用的推荐快照。个人标签、带审阅、Fetch 记录或元数据问题的运行以及每个工作流的最新运行都会保留；清理需要确认并写入审计日志，不会删除媒体文件。过期会话和符合条件的旧工作流运行也会按相同规则每天自动删除一次。数据文件夹缺失或为空时会暂停路径检查。**没有任何来源的作品** 链接到元数据的 **无可用来源** 视图；**压缩数据库** 会把空闲页归还给磁盘；它作为显示在活动中的工作流运行在后台执行，同一时间只能有一个压缩在排队或运行。

## 元数据

侧边栏的 **元数据** 位于 **工作流** 下方。横向分类为 **全部**、**需要注意**、**元数据问题** 和 **无可用来源**。全部包含所有已保存的作品系列，包括没有待处理问题的记录；其他分类按注意原因筛选。各分类共用搜索、分页、封面、选择和受影响版本详情。**声优别名** 视图（需要 `metadata:sync`）列出声优及其已确认的别名，可在弹窗中添加或删除别名、合并重复人物并撤销合并。

顶部将分类、搜索和列表操作放在同一行。宽屏时搜索框位于分类右侧；窄屏时收起为右侧的搜索图标，点击后在该行下方展开搜索框。其后依次为刷新、每页数量、**重试元数据**、**检查来源** 和 **元数据设置** 齿轮。列表上下的分页与媒体库一致。元数据设置以悬浮框打开，将鼠标悬停或聚焦在信息图标上即可查看各项说明，关闭后保留列表和筛选条件。元数据同步请在 Workflows 中运行。

选择作品后点击**重试元数据**，按钮显示适用数量；也可在详情中重试指定版本，包括此前被报告为不可用的作品。失败时保留已有资料和人工覆盖内容。**检查来源**只处理所选无来源作品；**删除本地信息**仅在「无可用来源」筛选中提供，需要确认，服务端重新检查来源状态并保留媒体文件。

Activity 和 Workflows 保留原有功能。**前往元数据待处理列表**会打开作品维护并筛选该次运行尚未解决的元数据问题，**显示全部待处理作品**可取消运行筛选。恢复不会修改其他用户的 Activity 审核。元数据处理需要 `metadata:sync`；来源检查、删除以及来源和语言设置需要 `sources:write`。**元数据设置** 悬浮框集中管理语言优先级、来源请求语言和目录新鲜度。此页面不重复同步工作流的配置和运行操作。旧 Maintenance 链接会跳转到此页。

元数据页面的正式地址为 `/metadata`。旧 `/work-management` 链接仍可使用，并保留筛选或设置上下文。首次同步失败及存在待处理元数据问题的结果入口会打开元数据问题列表；没有工作流权限的用户进入不限定运行的列表。运行诊断仍可在 Workflows 的 Activity 中查看。

Settings 现在仅有 Account、Playback 和 Recommendation。Playback 内的目录偏好和推荐配置按账号保存到服务器，可跨设备使用；没有个人覆盖时沿用现有实例默认配置。保存推荐设置会更新当前页面的推荐会话，其他已打开页面保留原快照。Maintenance 仅保留 Library、Cache & Fetch、Users，全站推荐统计位于 Library 的折叠区域。外观设置只保留右上角入口，地球图标表示跟随浏览器或设备语言。Demo 模式不能修改账号偏好；管理标签页（Library、Cache & Fetch、Cleanup、Users）仍可查看，但无法修改。
