# 设置

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

设置管理保存在服务器、用户和浏览器中的行为。

## 主要内容

- 设置界面语言、主题、显示密度和作品网格列数。
- 保存播放速度、跳转时间和兼容播放范围。
- 管理服务器连接、来源、元数据语言、扫描、watcher 和 `Follow-up run`。
- 按用户保存个人标签、收藏和播放状态。

## 作品管理

侧边栏 **作品管理** → **待处理作品**集中显示需要关注的已有作品，可筛选**全部待关注**、**元数据问题**或**无可用来源**。共用搜索、分页、封面和选择功能；每个作品家族只占一行，可同时显示多个原因，展开后查看受影响的版本和提供方。元数据更新成功只清除对应问题，无可用来源的作品仍留在列表。

选择作品后点击**重试元数据**，按钮显示适用数量；也可在详情中重试指定版本，包括此前被报告为不可用的作品。失败时保留已有资料和人工覆盖内容。**检查来源**只处理所选无来源作品；**删除本地信息**仅在「无可用来源」筛选中提供，需要确认，服务端重新检查来源状态并保留媒体文件。

Activity 和 Workflows 保留原有功能。**前往元数据待处理列表**会打开作品维护并筛选该次运行尚未解决的元数据问题，**显示全部待处理作品**可取消运行筛选。恢复不会修改其他用户的 Activity 审核。元数据处理需要 `metadata:sync`；来源检查、删除以及来源和语言设置需要 `sources:write`。**元数据设置** 标签集中管理语言优先级、来源请求语言和目录新鲜度。**打开元数据同步**是通往现有 Workflows 的快捷入口，不重复工作流配置。旧 Maintenance 链接会跳转到此页。
