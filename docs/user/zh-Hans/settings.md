# 设置

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

设置管理保存在服务器、用户和浏览器中的行为。

## 多语言标题

使用第一个拥有专属手动标题或 DLsite 版本的首选元数据语言，依次采用该语言手动标题、全语言手动标题、该版本的标题。全语言标题只替换标题文字，默认版本、简介和标签与没有这个标题时相同。`Origin` 对应原版明确声明的语言；语言不明时不推测。均不匹配时使用原版标题。社团、系列和声优的手动覆盖仍为全语言共享。未声明的原版语言始终视为未知，不根据元数据请求语言推测；此时语言标签只显示**原始**。语言专属手动标题用于明确声明的对应语言，或在该手动语言被明确列为首选、手动选中时生效。语言菜单只列实际版本和拥有专属手动标题的语言；全语言标题应用于已有选项，不会新增语言。

## 主要内容

- 设置界面语言、主题、显示密度和作品网格列数。
- 保存播放速度、跳转时间和兼容播放范围。
- 管理服务器连接、来源、元数据语言、扫描、watcher 和 `Follow-up run`。
- 按用户保存个人标签、收藏和播放状态。

## 维护

Maintenance 标签单行横向排列，窄屏可横向滚动。Overview 已移除；Library 整合本地扫描、远程来源和只读存储路径，作为来源管理员的默认页。Users 整合用户管理及仅超级管理员可用的实例访问设置；只有用户管理权限时默认进入 Users。旧 Paths 和 Access 链接分别转到 Library 和 Users。

远程来源以精简列表展示健康状态、主机、健康检查和可立即保存的启用开关。**添加来源** 只需输入一个地址：Kikoto 会依次探测原地址、其源站和常见的 `api.` 子域名，自动填入 API URL、公开网站和名称；未检测到时会展开 **连接详情** 供手动填写。端点、优先级以及网络与存储选项默认折叠。Cache & Fetch 只保留配置项，缓存内容改在 **清理** 标签页管理。推荐设置下新增折叠的 **我的推荐活动**，只统计当前用户过去 30 天的推荐数据。

Library 中的 **创作者目录** 包含 **目录新鲜度天数**（1 到 365，默认 30），通过单独的 **保存目录设置** 按钮保存：社团或声优目录距上次刷新超过该天数后会标记为需要注意。旧的 `/settings?tab=metadata` 链接会打开 Library。实例不再设置元数据语言：每位用户自己的选择在右上角头像的账号菜单中，远程来源的回退语言在其来源设置中。

## 清理

**清理** 是设置中位于 Proxy 之后的管理员标签页（`/settings?tab=cleanup`）；缓存部分需要 `downloads:manage`，数据库部分需要 `sources:write`。页面包含转码缓存与托管媒体缓存的用量和清理，以及数据库记录清理：磁盘上已确认不存在的作品文件夹和本地文件（连同由此变空的曲目条目和本地可用状态）、孤立元数据快照、未使用的来源标签、过期会话、已关闭通知、超过 90 天的工作流历史和推荐信号、不再使用的推荐快照。个人标签、带审阅、Fetch 记录或元数据问题的运行以及每个工作流的最新运行都会保留；清理需要确认并写入审计日志，不会删除媒体文件。过期会话和符合条件的旧工作流运行也会按相同规则每天自动删除一次。数据文件夹缺失或为空时会暂停路径检查。**没有任何来源的作品** 链接到元数据的 **无可用来源** 视图；**压缩数据库** 会把空闲页归还给磁盘；它作为显示在活动中的工作流运行在后台执行，同一时间只能有一个压缩在排队或运行。

## 元数据

**元数据** 左栏分为 **作品**（全部、需要注意、元数据问题、无可用来源）和 **条目**（标签、社团、声优）。宽屏可以展开分组和视图名称，手机为可横向滚动的图标行。作品表格保留搜索、分页、选择和手动刷新，铅笔按钮打开与作品详情相同的编辑器。admin 和 super_admin 拥有 `library:write`，可编辑元数据、封面、元数据链接，取消追踪来源，并管理共享标签和社团身份。

**标签**（`/metadata?view=tags`）每行以共享标签 **ID** 为准，按 ID 排序，因此列表不受任何语言设置影响。ID 单元格在标签 ID 下方显示 DLsite 类型 ID（如有），仅当标签已隐藏或已合并时再在其下显示 **已隐藏** 或 **已合并**；正常标签不显示状态。列依次为 ID、日语、简体中文、繁体中文、英语、韩语、**其他名称**、作品数、管理。每个语言列显示该语言实际显示的名称，优先顺序为：该语言的手动名称、全语言手动名称（以弱化样式显示）、DLsite 词典名称、远程来源的名称；都没有时显示「—」。**其他名称** 将其余已知名称各列出一次：被手动名称替换的名称（附语言）、没有语言的名称，以及没有名称记录的已存储名称。搜索匹配名称（包括远程来源的名称），纯数字查询还会匹配标签 ID 或 DLsite 类型 ID。窄屏时表格在自己的框内横向滚动，管理按钮始终固定在右侧。管理对话框可设置通用或各语言手动名称、全局隐藏、选择合并目标并取消合并映射。**社团**（`?view=circles`）每行以 DLsite maker id（RG 编号）为准，按编号排序；合并带来的 maker id 显示在主编号下方，仅由远程来源得知的社团排在最后，以 Kikoto 编号显示。列依次为编号、名称（旁附最新作品封面）、已知名称、作品数、管理，搜索也匹配 maker id。管理对话框支持不会被来源刷新覆盖的手动名称、已确认别名，以及可审阅的合并：作品、maker id、目录、快照、系列和个人社团数据一起迁移。撤销按最近合并优先，受影响数据有后续编辑时会拒绝覆盖。**声优** 每行以 Kikoto 编号为准，按编号排序，列依次为编号、名称（旁附最新作品封面）、别名、作品数、状态（目录同步）、管理；别名与重复人物管理仍要求 `metadata:sync`，保留 `/metadata?view=aliases&voice=<id>` 深链。Demo 可查看这些界面，修改控件禁用。

条目列表和元数据页面使用相同的访问条件：登录并拥有 `library:write`、`metadata:sync`、`sources:write` 或 `system:admin` 中至少一项权限。匿名只读访问不包含这些管理列表。Demo 只显示与演示作品相关的标签和社团，作品数也只计算这个范围，并且不公开社团合并记录。

标签是否显示只看最终合并目标。隐藏已经合并的标签，是保存它取消合并后的隐藏设置；合并到隐藏目标会隐藏最终标签。合并后原名称仍可搜索，取消合并恢复原身份和搜索名称。

旧封面迁移和标签回填在核心启动工作流之后独立后台运行。单个封面失败不会阻止其他文件，失败会记入日志并在下次启动重试。

顶部将分类、搜索和列表操作放在同一行。宽屏时搜索框位于分类右侧；窄屏时收起为右侧的搜索图标，点击后在该行下方展开搜索框。其后依次为刷新、每页数量、**重试元数据**、**检查来源** 和 **元数据设置** 齿轮。列表上下的分页与媒体库一致。元数据设置以悬浮框打开，将鼠标悬停或聚焦在信息图标上即可查看各项说明，关闭后保留列表和筛选条件。元数据同步请在 Workflows 中运行。

选择作品后点击**重试元数据**，按钮显示适用数量；也可在详情中重试指定版本，包括此前被报告为不可用的作品。失败时保留已有资料和人工覆盖内容。**检查来源**只处理所选无来源作品；**删除本地信息**仅在「无可用来源」筛选中提供，需要确认，服务端重新检查来源状态并保留媒体文件。

Activity 和 Workflows 保留原有功能。**前往元数据待处理列表**会打开作品维护并筛选该次运行尚未解决的元数据问题，**显示全部待处理作品**可取消运行筛选。恢复不会修改其他用户的 Activity 审核。元数据处理需要 `metadata:sync`；来源检查、删除以及来源和语言设置需要 `sources:write`。**元数据设置** 悬浮框提供 **DLsite 代理** 快捷开关：与 `设置 -> 代理 -> 代理作用范围` 中 DLsite 的开关和代理选择相同，修改立即保存；**管理代理** 会打开该处以添加代理或调整顺序。其下的 **目录新鲜度** 打开 `设置 -> Library`，**远程元数据回退** 打开元数据同步工作流，该设置位于其 **配置** 中。此页面不重复同步工作流的配置和运行操作。旧 Maintenance 链接会跳转到此页。

共享标签名称逐个尝试首选语言：该语言的手动名称 > 所有语言手动名称 > 提供方名称。详情页的语言切换也遵循此顺序。

隐藏、合并和取消合并会立即保存状态，相关作品在后台持续更新。标签管理显示整个实例剩余的待更新作品数，包括等待重试的作品；刷新列表可查看进度。失败作品会自动重试，不阻塞其他作品，重启后继续处理。

### 首选语言的标签名称

首选元数据语言由每位登录用户在账号菜单中选择。未选择的用户和匿名访客看到每部作品的原语言（**原版**）；存储的标题和标签名、后台同步、目录刷新、远程元数据回退和活动文本也始终使用每部作品的原语言。任何语言下标签都来自原作版本，按标题排序则遵循显示的标题。请求远程来源时先使用查看者的语言，最后使用来源设置中的 **回退语言**；保持 **原版** 的用户、匿名访客以及抓取、下载、回退查询等后台任务只使用回退语言。

即使作品只有日文版，DLsite 也会按请求的语言返回类型名称。任一用户的首选元数据语言不是日语时，**学习标签名称** 工作流会在后台补全缺失的标签名称：每种语言都挑一个包含最多缺失标签的作品请求一次，所以请求数取决于缺失的标签数量，而不是作品库的大小。它在启动时、元数据同步后和修改语言后运行，使用与元数据同步相同的请求间隔和 DLsite 代理，重启后会接着做。进度、结果和失败显示在活动中。它只保存标签名称，不使用标题或简介；DLsite 没有给出名称的标签不会反复请求。

### 远程元数据回退

**远程元数据回退** 在元数据同步工作流（`工作流 -> 同步作品元数据`）的 **配置** 中设置，拥有 `sources:write` 的管理员会在 **运行** 旁看到该按钮；默认关闭。开启后，刷新作品元数据时如果 DLsite 明确返回找不到作品，会按列表顺序查询所选远程来源；超时等临时的 DLsite 错误不会触发查询。列表只显示在来源设置中开启了 **提供作品元数据** 的来源。每个来源只请求一次，第一个返回该作品的来源补全标题、发售日、社团、标签和封面（仅在没有封面时）。回退不会新建作品，也不会补全 DLsite 缺少的语言。开启期间，没有 DLsite 数据的作品的标签会并入共享标签，与已有标签匹配的远程标签会复用该标签。之后一旦有了 DLsite 数据，总是改用 DLsite。

即使开关关闭，列表顺序也决定多个远程来源描述同一作品时使用哪个来源的值。关闭开关后不再发起新的查询，远程标签会移出共享标签；已补全的标题、日期、社团和封面会保留，直到被 DLsite 或手动值替换。元数据待处理列表会注明补全 DLsite 缺失作品的来源。

### 购买特典

**将购买特典关联到原作品** 在同一元数据同步工作流的 **配置** 中设置，默认开启。早期购买特典（`【早期購入特典】`）等购买特典是 DLsite 不标明所属作品的免费作品。元数据同步保存这类作品时，会先在媒体库中同一社团的作品里查找原作品，找不到再读取社团的 DLsite 页面（最多 10 页），检查与特典编号最接近的 5 个作品。只有恰好一个作品与特典的标题读音相同，或发售日及特典标记中引用的标题相符时才会关联。媒体库中已有的特典会在下一次元数据同步时检查。没有找到原作品的作品，在作品详情中刷新元数据时会再次检查。关闭开关会停止新的检测，已有关联保留；关联带来的变化见[购买特典](work-detail.md#购买特典)。
