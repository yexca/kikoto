# 设置

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

设置管理保存在服务器、用户和浏览器中的行为。

## 主要内容

- 设置界面语言、主题、显示密度和作品网格列数。
- 保存播放速度、跳转时间和兼容播放范围。
- 管理服务器连接、来源、元数据语言、扫描、watcher 和 `Follow-up run`。
- 按用户保存个人标签、收藏和播放状态。
