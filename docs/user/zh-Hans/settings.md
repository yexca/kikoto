# 设置
[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

“设置”包含账户控制、个人播放、历史、推荐和标签偏好，对管理员而言还包含实例管理。外观位于页眉的外观菜单中；界面语言和优先元数据语言位于头像后面的账户菜单，或位于**登录**之后。

## 标签页

“设置”使用账户、播放、历史、推荐和标签这几个标签页，以图标显示：悬停或聚焦某个图标可查看其名称，手机上还会显示当前标签页的名称。管理员以及演示模式还会在一条分隔线之后看到管理标签页（媒体库、缓存与获取、代理、清理和用户），使高权限的范围保持独立。宽屏会把图标显示为设置旁边的一列；手机上则显示为可横向滚动的一行。该列下方的**展开标签页名称**按钮会展开它，为每个标签页显示名称，“设置”会记住这个选择。

`/maintenance`、`/users`、`/cleanup`、`/history`、`/tags` 和 `/user-data` 链接会打开对应的“设置”标签页。

## 账户

- 更新已认证用户的显示名称。
- 在验证当前密码并确认新密码后，更改由账户管理的用户的密码。
- 用户名和角色可见，但为只读。
- 账户末尾的**我的数据**用于导出和导入个人数据；参见[个人数据](personal-data.md)。

更改密码会保留当前会话，并撤销该用户的其他会话。管理员在“设置 -> 用户”中重置密码，会撤销目标用户的所有会话。角色、启用状态、用户名和用户生命周期管理不属于自助的账户设置。

每个账户（包括最初的管理员）都在这里更改自己的密码。例外是环境 root 账户模式下的 root 账户，其密码来自 `KIKOTO_ROOT_PASSWORD`。忘记的管理员密码需要在服务器主机上重置；参见[管理员初始化与恢复](../../operations/security.md#administrator-setup-and-recovery)。

## 播放、历史与推荐

- **播放**包含向后和向前的拖动间隔、**播放来源**以及**目录偏好**。拖动间隔默认为 10 秒和 30 秒，接受 1 到 300 的整数秒数。Android 和 iOS 应用还会显示**本设备隐私**，详见[睡眠与耳机隐私](playback.md#睡眠与耳机隐私)。
- **播放来源**：**快速切换来源**会让“正在播放”的来源标签变成菜单，用来为当前音轨选择另一个位置；**失败时切换其他来源**则让失败的位置从该音轨的下一个可用位置继续。两者默认都关闭，并立即生效。
- **目录偏好**包含有序的文件夹匹配和排除规则。保存会更新之后的目录选择，而不会停止播放器。
- **历史**显示收听报告（30 天、12 个月或全部时间）以及折叠起来的完整收听历史。
- **推荐**以**我的推荐活动**报告开头，涵盖已登录用户自己最近 30 天的情况（展示如何转化为打开和播放、给出的标记和重新洗牌，以及亲和度得分的分布），然后是推荐预设、徽章阈值、变化幅度、发现加成和高级评分。保存会为当前标签页创建一个新的推荐会话；其他已打开的标签页会保留各自的快照，直到创建新的会话。

目录偏好和推荐设置按已认证账户存储在服务器上，并在各设备间共享；更改它们绝不会改变其他账户。没有自己的值的账户以及匿名浏览，使用实例默认值。保存失败时会保留草稿和已持久化的值。

## 语言与外观

外观只能从页眉菜单中设置，界面语言只能从页眉的账户菜单中设置。地球图标选项跟随浏览器或设备的语言；它的工具提示和无障碍名称会标明这是自动选择。每位已登录用户还会在界面语言的正下方看到**优先展示 metadata 语言**。这是个人选择：它决定该用户看到哪个标题版本、简介和标签名称，按这些标题对标题排序，并且在 Kikoto 为该用户查询远程来源时被最先询问。选项有**原版**、日语、英语、简体中文、繁体中文和韩语。没有选择时显示**原版**，即每部作品的原始语言，选择**原版**会清除该偏好；没有所选语言的版本会回退为 `原版`。共享的标签名称在相同的语言优先顺序下使用手动名称和已学习的词典，而不论该语言是否有对应的版本。所有语言显示的标签都相同：它们来自原始版本。匿名访客看到原始语言。所有存储或共享的内容，例如已存储的标题和标签名称、后台同步、创作者目录刷新、远程元数据回退和“活动”文字，始终使用每部作品的原始语言，因此一位用户的选择绝不会改变其他人看到的内容。

### 多语言标题

Kikoto 使用第一个拥有自己的手动标题或 DLsite 版本的优先元数据语言。该语言专属的手动标题优先，其次是全语言手动标题，然后是该版本的标题。全语言标题只替换文字：默认版本、简介和标签与没有它时保持一致。`原版` 使用原始版本所声明的语言；未知的语言不会被猜测。如果没有任何匹配，则使用原始标题。社团、系列和声优的覆盖设置在各语言间共享。未声明的原始语言在任何地方都保持未知，与元数据请求的区域设置无关；它的语言标签只显示**原始**。语言专属的手动标题，对其声明的语言生效，或在该手动语言被显式设为优先或被选中时生效。语言菜单只包含已有的版本和拥有自己手动标题的语言；全语言标题应用于已有的选项，而不会新增语言。

## 演示模式

演示模式会让依赖账户的“设置”保持只读。管理标签页、历史、推荐和标签这几个标签页，以及账户中的“我的数据”部分，即使演示身份不是管理员，也仍然可见以供查看，并且其中的所有更改都被禁用。外观和播放控件仍然可用，因为主题模式、样式、颜色、拖动间隔和播放来源选项都是浏览器本地的偏好，不会修改演示服务器的数据。播放偏好按服务器身份和已认证用户隔离；启用匿名访问时，则按匿名主体隔离。

## 管理

### 媒体库

“媒体库”整合了媒体库存储、本地扫描设置、创作者目录、已配置的远程来源和只读的存储路径。

- **媒体库存储**显示媒体库模式（普通或存储池）、带有在线或离线徽章的每个存储池，以及 Fetch 池。可以添加存储池，或者在存储池不含任何作品时将其移除；一旦媒体库含有本地作品，模式本身就固定不变。**重新连接**会在操作员确认正确的磁盘已挂载到那里之后，再次标记一个现有的文件夹。
- **扫描深度**不能设置得低于 Fetch 保存作品的层级；扫描总是至少到达该层级，因此 Fetch 得到的作品绝不会因为扫描止步于它们之上而被报告为缺失。
- **创作者目录**包含**目录新鲜度天数**（1 到 365，默认 30），通过它自己的**保存目录设置**按钮保存。社团或声优目录的上次刷新一旦比该值更早，就会被标记为“需关注”。
- 远程来源以紧凑的列表显示：健康状况、主机、健康检查操作，以及一个立即保存的启用开关。健康检查的结果会通过与自动探测相同的来源健康状态持久化。
- **添加来源**从一个地址开始。Kikoto 会探测按输入的原样地址、其源站（origin）以及约定俗成的 `api.` 同级域名，看是否有兼容 Kikoeru 的作品 API，然后填入 API URL、公共站点和名称。什么都没有检测到时，**连接详情**会打开以供手动输入。端点字段、优先级以及网络/存储选项保持在折叠的分组中。
- **回退语言**是最后询问的，排在查看者的优先元数据语言之后，因为来源可能并未用每种语言描述作品。保留**原版**的查看者、匿名访客，以及爬取、下载和远程元数据回退这类后台任务，只会用回退语言询问。它默认为日语。上游仍可能忽略该请求，或返回混合语言的元数据。
- 远程来源默认使用兼容的公共存储主机。来源配置可以启用**限制出站主机**，仅允许 API、公共站点、回退，以及一个可编辑的、由精确匹配或 `*.example.invalid` 形式的公共主机模式组成的列表。
- 存储路径默认折叠，为只读，并显示解析后的数据根目录、缓存根目录、默认的缓存/保存预览，以及每个来源的保存预览。远程来源配置显示同样解析后的示例，而不是路径模板编辑器。

没有实例级别的元数据语言：每位用户自己的选择位于页眉的账户菜单中，远程来源的回退语言位于其来源设置中。

### 缓存与获取

“缓存与获取”只包含配置：播放缓存策略、传输安全，以及折叠起来的下载节奏，并带有一个在发生更改后才可用的保存操作。缓存的内容在“清理”标签页中管理。

- 单文件的远程媒体限制默认为 100 GB；失败或取消的 Fetch 运行所遗留的未发布暂存数据，默认保留七天。
- 转码缓存的限制是独立的，范围为 1 到 4096 GB，默认为 5 GB。这个可重建的缓存位于 `/cache/transcodes` 下，不会改变托管的远程媒体缓存限制。

### 代理

- **代理**标签页按优先级顺序列出出站代理。请求从顶部开始尝试，并使用第一个能够连接的代理。**添加代理**可选择**本机**或**其他地址**。本机代理运行在 Kikoto 的托管位置：对话框会显示服务器访问它所用的地址（例如容器中的 `host.docker.internal`），但不允许编辑，因此只需设置协议、端口以及可选的用户名和密码。其他代理还需要填写地址。协议有 HTTP、HTTPS、SOCKS5 和 SOCKS5h。已保存的密码不会再次显示；字段留空即可保留原密码。每项更改都会立即保存。
- **代理作用范围**选择代理应用于何处：**DLsite**（元数据、封面和创作者目录）、**远程来源**（浏览、播放和下载）以及**其他**（更新检查；个人 Kikoeru 账户导入始终直接连接）。**全部**会同时切换这三项。每个范围可以按优先级使用所有代理，或使用选定的某一个代理。每个远程来源可以跟随远程来源的范围、直接连接，或使用它自己的代理选择。
- **保底直连**默认关闭。关闭时，如果某个请求的所有代理都无法连接，该请求会失败，而不是直接连接。开启时，在所有代理都尝试过之后，该请求会不经代理再重试一次。

### 清理

**清理**（`/settings?tab=cleanup`）的缓存部分需要 `downloads:manage`，数据库部分需要 `sources:write`。

- **转码缓存**显示相对于其限制的用量，并提供需确认的清除操作。
- **托管媒体缓存**报告磁盘上的、被引用的、符合条件的和受保护的文件，并按来源分组清理孤立缓存或按作品划分的缓存。清理是分两步的破坏性操作，作为工作流运行排队执行。
- **数据库记录**列出可以移除的记录类型，每种都带有当前数量：缺失的作品文件夹和已确认在磁盘上不存在的本地文件（连同它们遗留下来的空音轨条目和本地可用性）、孤立的元数据快照、未使用的来源标签、已过期的会话、已关闭的通知、超过 90 天的已结束工作流运行、超过 90 天的推荐信号，以及未使用的推荐快照。个人标签、带有审阅、Fetch 记录或元数据问题的运行，以及每个工作流的最新一次运行都会保留。所选任务在确认后移除，并记入审计日志；媒体文件绝不会被删除。已过期的会话和符合条件的旧工作流运行，也会按同样的规则每天自动移除一次。
- 当数据文件夹缺失或为空时，路径检查会暂停，因此未挂载的媒体库绝不会被当作已删除。
- **没有任何来源的作品**链接到“元数据”的**无可用来源**视图，用于审阅和删除。
- **压缩数据库**会重写 SQLite 文件，把空闲页归还给磁盘。它作为工作流运行在后台执行并显示在“活动”中，同一时间只能有一个压缩处于排队或运行中。

### 用户

“用户”用于管理账户。生产环境和开发环境中的超级管理员还会在这里看到**实例访问**。匿名的媒体库浏览和播放默认禁用；更改该开关会应用到生产环境的访问边界，并创建一条审计记录。开发环境会以 root 身份认证每个请求，因此该设置在那里可见且可编辑，而不会创建匿名的开发会话。

## 元数据

“元数据”使用 `/metadata`；`/work-management` 链接会连同其筛选或设置上下文重定向到那里。

**元数据**图标栏把**作品**（全部、需要注意、元数据问题、无可用来源）和**条目**（标签、社团、声优）分组。宽屏可以展开分组和视图的名称；手机显示可滚动的一行图标。作品表格提供搜索、分页、选择和手动刷新，铅笔图标打开与作品详情相同的编辑器。Admin 和 super_admin 获得 `library:write`，用于元数据、封面、元数据链接、取消来源跟踪、共享标签编辑和社团身份编辑。

**标签**（`/metadata?view=tags`）按共享标签的**ID**列出共享概念，并按 ID 排序，因此列表绝不依赖语言设置。ID 单元格在有 DLsite 类型 ID 时，会将其显示在标签 ID 下方，再往下只有在标签被隐藏或被合并时才会显示**已隐藏**或**已合并**；处于活动状态的标签不显示状态。各列依次为 ID、日语、简体中文、繁体中文、英语、韩语、**其他名称**、作品数和管理。每个语言列都显示该语言所展示的名称：它自己的手动名称，其次是全语言手动名称（以弱化样式显示），再次是 DLsite 词典名称，然后是远程来源的名称，都没有时则显示“—”。**其他名称**会列出其他每个已知的名称各一次：被手动名称取代的名称（带有其语言）、没有语言的名称，以及没有名称记录的已存储名称。搜索会匹配名称（包括远程来源的名称），数字查询还会匹配标签 ID 或 DLsite 类型 ID。在窄屏上，表格在自己的框内横向滚动，而“管理”按钮固定在其右边缘。“管理”会打开针对所有语言或某个区域设置的手动名称、全局隐藏、合并目标选择，以及合并映射的撤销。**社团**（`?view=circles`）按 DLsite 厂牌 ID（RG 编号）列出社团，并按编号排序；合并时带过来的厂牌 ID 显示在主 ID 之下，仅由远程来源得知的社团排在其后，以其 Kikoto ID 显示。各列依次为编号、名称（位于最新已知作品的封面旁）、已知名称、作品数和管理，搜索也会匹配厂牌 ID。“管理”支持在提供方刷新后仍保留的手动名称、已确认的别名，以及会迁移作品、厂牌 ID、目录、快照、系列和个人社团数据的、经过审阅的合并。撤销会先处理最近一次合并，并拒绝覆盖对受影响记录所做的后续编辑。**声优**（`/metadata?view=aliases`，附加 `&voice=<id>` 可打开某一个人）按 Kikoto ID 列出人物并按 ID 排序，各列依次为 ID、名称（位于最新作品的封面旁）、别名、作品数、状态（目录同步）和管理；别名和重复项管理需要 `metadata:sync`。演示模式允许查看，而更改仍被禁用。

条目列表遵循对元数据页面的访问权限：需要登录，并至少拥有 `library:write`、`metadata:sync`、`sources:write` 或 `system:admin` 之一。匿名的读取权限不包括这些管理列表。演示模式只显示与演示作品相关的标签和社团，只统计这些作品，并且不公开社团的合并历史。

标签的可见性遵循最终的合并目标。隐藏一个已合并的标签，会保存它的隐藏设置以便撤销之后使用；合并到被隐藏的目标，会隐藏合并后的标签。原始名称在合并期间仍可被搜索，撤销会恢复原始的身份和搜索名称。

封面布局迁移和标签回填会在核心启动工作流之后，于后台独立运行。某个封面文件失败不会阻止其他文件。修复失败会记入日志，并在下次启动时重试。

页眉把分类、搜索和列表控件保持在一行。在宽屏上，搜索框位于分类旁边；在较窄的屏幕上，它会折叠为右侧的搜索图标，点击后在该行下方打开搜索框。随后依次是刷新、每页行数、**重试元数据**、**检查来源**和**元数据设置**齿轮。列表上方和下方的分页与媒体库一致。元数据设置在弹出层中打开；悬停或聚焦信息图标可查看某项设置的说明，关闭弹出层会保留当前的列表和筛选。元数据同步请从“工作流”启动。

选择作品族并点击**重试元数据**；其数量只包含符合条件的所选项。你也可以从详情中重试受影响的版本，包括被报告为不可用的商品。重试失败会保留现有的元数据和手动覆盖。**检查来源**适用于没有来源的所选作品族。需确认的本地信息删除只能在**无可用来源**视图中进行；服务器会重新检查可用性，并保留媒体文件。

“活动”中的**前往元数据待处理列表**会打开按该运行的未解决元数据问题筛选的“元数据”；**显示全部待处理作品**会移除该运行筛选。首次同步的失败和待处理的元数据结果会打开元数据问题；没有工作流权限的操作员会看到未限定范围的问题列表。运行诊断位于“工作流”的“活动”中。恢复操作绝不会改变其他用户的“活动”审阅。元数据恢复需要 `metadata:sync`，而来源检查、删除以及来源/语言设置需要 `sources:write`。**元数据设置**弹出层只包含设置；本页面不会重复同步工作流的配置或运行控件。

元数据设置有一个 **DLsite 代理**快捷方式：与 `设置 -> 代理 -> 代理作用范围` 下 DLsite 范围相同的开关和代理选择，立即保存。**管理代理**会打开该部分，用于添加代理或调整代理顺序。其下方的**目录新鲜度**会打开 `设置 -> 媒体库`，**远程元数据回退**则会打开元数据同步工作流，其**配置**中包含该设置。

共享的标签名称会依次尝试每种优先语言：该语言的手动名称、全语言手动名称，然后是提供方名称。详情页的语言切换遵循同样的优先顺序。

隐藏、合并和撤销会立即保存其状态。相关作品会在后台持续更新；标签管理器会显示整个实例中剩余的工作数量，包括等待重试的作品。刷新列表可以查看进度。失败的作品会自动重试，而不会拖延其他作品，并且更新在重启后会继续。

### 以优先语言显示标签名称

DLsite 会以所请求的语言命名类型，即使作品只有日语版本。当任何用户的优先元数据语言不是日语时，**学习标签名称**工作流会在后台补全缺失的标签名称：对每种语言，它向 DLsite 询问一次能覆盖最多未命名标签的那部作品，因此请求的数量取决于缺失的标签，而不是媒体库的大小。它在启动、元数据同步和语言更改之后运行，使用与元数据同步相同的请求节奏和 DLsite 代理，并在重启后继续。进度、结果和失败会显示在“活动”中。它只存储标签名称，绝不存储标题或简介，并且对 DLsite 没有给出名称的标签不会再次询问。

### 远程元数据回退

**远程元数据回退**是每次 DLsite 元数据同步运行及其间隔触发器的一个选项，默认关闭。启用它，并按请求顺序选择最多 16 个提供作品元数据的已启用来源。只有 DLsite 明确的“未找到”结果才会触发回退；超时和临时故障则不会。请求只描述已有的作品，并使用共享的有界传输。补全的元数据会在运行结束后保留。这些选择不会改变已存储的远程值在整个实例范围内的排序，也不会改变手动/DLsite 的优先级。

### 购买特典

**将购买特典关联到原作品**是 DLsite 的一个运行选项，默认开启，也会保存在触发器中。它控制该次运行的自动检测。检测会先检查已存储的作品，然后最多检查 10 个社团页面和 5 个候选商品。检测关闭时，已有的关联仍然适用；参见[购买特典](work-detail.md#购买特典)。
