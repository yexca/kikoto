# 媒体库
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒体库是浏览作品的主界面。

## 当前行为

- 显示本地、已跟踪以及已配置的远程来源标签页。
- 对大型结果集使用服务端分页。
- 在加载当前页之前，先搜索规范化后的标题、编号、语言版本别名、社团、标签、声优信息和制作人员信息。提供方声明的版本编号仍可被搜索，而无需创建额外的作品，也不必在媒体库请求期间扫描原始元数据快照。
- 按字面匹配搜索文本，并忽略全角/半角、字母大小写和假名字形：`100%` 和 `a_b` 不是通配符，全角的 `ＡＢＣ` 能找到 `abc`，片假名也能找到用平假名书写的同一个词。在词前加上 `tag: 癒し`、`circle:`、`va:` 或 `mytag:` 这类子句，即可只搜索某一个字段。`staff:` 搜索 DLsite 的全部制作人员，`author:`、`scenario:` 和 `illust:` 搜索某一种制作人员角色，`creator:` 搜索声优。在 `tag:`、`mytag:`、`circle:`、`va:` 或制作人员子句前加 `-` 可排除匹配的作品；用引号括起短语（如 `"calm night"` 或 `circle:"Example Circle"`）则按整个短语匹配。
- DLsite 标签也会匹配 Kikoto 已获取到的该标签在各语言中的名称：当请求英文版本的作品把显示为 `癒し` 的标签报告为 `Healing` 时，`tag: healing` 可以同时找到两者。标签、标题、社团、声优信息或制作人员信息与搜索词完全相同的结果，会排在部分匹配的结果之前，所选排序则分别作用于每一组。
- 搜索框中的 `+` 按钮会打开一个浮动编辑器，用于编辑结构化的搜索条件。选择某个条件徽章，会在同一个弹出层中编辑它，而不会移动结果。
- 显示封面、标题、编号、单行省略显示的“社团 / 系列”、声优元数据、本地可用性、来源标签，以及（如有）快速收听标记。
- 将提供方标签测量后最多排成两行卡片内容。`+N` 徽章会在弹出层中显示被隐藏的标签；个人标签仍是单独的、由用户拥有的一行。
- 在同一个指标行中显示精简的 DL 销量，以及由五段组成的非数字评分对比。存在已保存的播放进度游标时，会出现播放历史图标。
- 作品的音轨有歌词时显示歌词图标：在**管理歌词**中指定的歌词文件，或按名称匹配到音轨的歌词文件。其他文本文件（例如 readme 或台本）不计入。自身没有音轨的作品沿用其他版本的状态。
- 当有规范化的商业元数据时，显示当前价格，并将零价格的作品标为“免费”。
- 在统一的作品卡片和详情中，将已登录用户的作品标签与元数据标签分开显示。`mytag:` 用于筛选个人标签，不会改变提供方 `tag:` 搜索的含义。
- 在视觉上将来源可用性与元数据标签区分开。
- 在作品卡片上的社团名称旁显示已知的年龄分级，同时在作品详情中保留完整的年龄元数据。
- 媒体库、收藏、社团详情和声优详情等界面的作品合集都使用同一套响应式网格。列数选项是共享的，而不是在每个页面各自重新实现。
- 在本地保存所选的作品合集列数设置，并将其应用于媒体库、收藏、社团的作品合集和声优的作品合集。
- 支持稳定的带种子随机排序。种子能保持分页一致；重新洗牌会生成新的种子，而不是把顺序反过来。
- 新建媒体库视图默认使用个性化推荐排序，并保留恢复的浏览选择。规范化 URL 保留查询和非默认收听状态，也读取显式浏览参数。正在听和想听优先，未标记是主要发现池，重听和已完成有限插入，零槽位状态后置。每种状态先显示有界推荐候选，再按稳定的带种子探索顺序显示其他所有匹配作品。精确搜索仍优先，总数包含全部匹配，修改每页数量不改变顺序。该顺序不表示全部结果严格按个人亲和度排列。
- 亲和度使用收藏、标签、声优和社团证据，扣除候选自己的反馈；正向证据最多强化至五部支持作品，常见标签权重较低。收藏和重听是正向证据，单独已完成是中性的。发现加成、扰动和创作者多样性影响候选排序，徽章保持真实亲和度。普通排序只为当前页打分；候选外作品的解释也显示真实亲和度，排序调整只在适用的推荐查询上下文内显示。上下文过期时，解释保留原会话的亲和度，省略排序调整。
- 每个浏览器标签页或原生应用启动，将偏好画像、收听状态槽位和共享元数据版本冻结在一个推荐代中。导航、筛选、分页、卡片变更和重新洗牌复用画像。实时收藏和收听变化立即显示在卡片上，并在新会话影响排序。共享特征由后台更新，新会话使用最新完整发布的版本，可能稍晚于元数据编辑。重新洗牌只改变种子。可浏览成员和筛选仍是实时的：作品增删、可用性、权限和个人筛选可能移动页边界，相同可见数据的顺序保持确定且完整。
- 首次推荐索引期间，普通浏览和播放保持可用。可选徽章失败时保留卡片并提供独立重试；推荐准备失败时在已加载卡片旁提供重试。这些失败不打断全局播放器。
- 远程推荐徽章也会为尚未导入的作品打分，使用已知的本地化标签和创作者别名。开启徽章后，会在一个批次中为当前页打分，而不会重新加载远程来源，然后逐步显示徽章（遵循减少动态效果的设置）。每个已打分的作品都会显示得分；达到你设定的高亮阈值的得分会突出显示，较低的得分以弱化样式显示。打分失败时作品仍可使用，并提供“重试”。远程得分使用同一份冻结的会话偏好画像，不会导入任何作品。
- 提供最近播放的作品，按用户排序，依据每个逻辑作品族拥有的唯一游标，并包含最新的音轨位置。宽屏上，工具栏中的历史按钮会打开该列表。手机上，排序行的“继续收听”按钮会在其下方打开一条可横向滚动的最近播放封面条，在任何页面和来源下都可使用。
- 手机上，媒体库以始终可见的搜索框开头，旁边的来源按钮显示当前来源，并在菜单中列出所有来源。其下的排序行以决定结果的排序按钮和标记筛选按钮开头，以推荐徽章、“继续收听”和显示选项这些附加功能与显示操作结尾。标记筛选和“继续收听”各自显示或隐藏下方的一行，依次是快速标记筛选按钮行和“继续收听”条。两行默认都隐藏；设置标记筛选时，其按钮会显示对应的标记。再次点选当前选中的按钮会清除该筛选。
- 排序按钮显示当前顺序，并在弹出层中打开各种排序和方向。“推荐”和“随机”排序会在它旁边加上一个刷新按钮。
- 显示选项以**卡片**开头，可在**完整**、**紧凑**和**极简**中选择，该选择与列数设置一起保存，手机和宽屏分别保存。**完整**为默认值。宽屏的自动列数在一行中最多容纳 5 张完整卡片、6 张紧凑卡片或 7 张极简卡片，窗口较窄时更少。选择其他模式会把其余显示选项重置为该模式的起始值，之后可以再调整：每种模式都使用自动的宽屏列数，**完整**和**紧凑**使用每页 24 部作品和自动的封面来源标记，**极简**使用每页 48 部作品，不显示封面来源标记。手机列数保留自己的设置。**紧凑**在手机单列时将每部作品显示为一行：封面旁依次是代码、标题、社团和声优名称、评分、销量和价格，然后是一行标签（个人标签在前），有上次收听位置时一并显示。手机双列和宽屏则显示简短的方块卡片，价格显示在封面上，不显示标签行。**极简**只显示封面和最多两行标题，不显示代码、参与人员、标签、评分、价格、推荐分数或操作行，手机上的自动列数每行显示两个封面。封面来源标记在每种模式下都遵循各自的显示选项，卡片在每种模式下打开作品的方式都相同。该选择适用于媒体库中的本地、已跟踪和远程来源，包括远程加载占位。
- 在本地、已跟踪和已配置的远程来源之间使用同一个查询。每个来源保留各自的分页、排序和滚动状态，而网格列数设置仍是共享的。用户在别处清除查询词后，来源不会恢复过时的查询文本。
- 将当前本地、已跟踪或远程来源的每页数量放在工具栏的显示选项中。本地、已跟踪和远程来源每页都可选 24、48 或 96 部作品。宽屏顶部显示紧凑的分页，包含结果上下文和翻页。手机上，作品上方以说明文字显示结果数量和当前页，翻页则通过底部的分页进行。底部分页列出首页、末页、当前页及其相邻页；页码之间的省略号可打开输入框，输入页码后跳转到该页。
- 数据库清理不在媒体库中进行。“元数据 -> 无可用来源”为没有可用来源或媒体位置的逻辑作品族提供分页搜索、来源检查，以及需确认的本地信息删除。
- `/no-source` 和 `/library/no-source` 链接会打开“元数据 -> 无可用来源”；`/library/all` 和 `/library/remote` 链接则打开媒体库。
- 当 `KIKOTO_MODE=demo` 时，后端的列表、详情和媒体响应只允许适合所有年龄段且永久免费的作品。本地作品使用规范化的商业元数据，未知元数据和临时免费促销都会被排除。模拟的 Remote Kikoeru 来源只会重新发布已获准的本地作品。演示会话可以播放已获准的完整媒体，但不能修改媒体库、设置或工作流状态。推荐分数是模拟随机值，解释标注“演示分数，随机生成”。每部作品的分数在同一演示会话中保持稳定，重新洗牌不改变分数，也不显示偏好贡献或排序调整。

在每个合集界面上，作品卡片都使用同一个摘要模型，已知的声优信息也包含在内。紧凑卡片最多显示两个声优名称，并概括其余的参与人员，不会让元数据无限撑大卡片。

收藏只在规范化 URL 中保留实体/搜索意图。它所选的列表、收藏筛选、排序、种子、分页、选择和作品锚点，会从当前历史记录条目中恢复，并以按用户划分的会话作为后备。`全部收藏`汇总带有快速标记的作品以及你加入任一列表的作品。`标记`是固定的系统列表，只包含快速标记不为“未标记”的作品；其成员由推导得出，不能作为列表编辑。其他列表由用户创建，并保留显式的成员关系。作品卡片或作品详情上的“添加到列表”带搜索框列出你的列表，每勾选或取消一个列表都会立即保存；输入一个尚无列表使用的名称，即可新建该列表并把作品加入其中。按规则包含该作品的动态列表会注明这一点，取消勾选则把作品排除在该列表之外。在收藏中选中作品后的“更改列表”会显示每个列表将发生的变化（例如会加入多少部作品），并一次性应用；只包含部分作品的列表除非你改动，否则保持不变。在手机上两者都以底部面板打开。

动态列表会根据标签自动收录作品。新建列表时选择**动态列表**，再把共享的元数据标签和你自己的标签分成三组：作品必须全部带有的**必须包含**、至少带有其中一个的**至少包含其一**，以及一个都不能带有的**排除**。空的分组会被忽略，但“必须包含”或“至少包含其一”中至少要有一个标签；编辑器会随着你的选择显示匹配的作品数量。匹配的作品会出现在列表中，但不会因此成为收藏。你仍可手动加入其他作品，它们会像在任何列表中一样成为收藏；移除某个匹配的作品后，它会一直被排除在列表之外，直到你再次加入。列表只会收录媒体库中已有的作品。之后有作品开始匹配时，书架会显示新作品的数量，并给这些作品标上**新**，直到你选择**全部标为已看**；**只看新作品**则只显示这些作品。**转为普通列表**会把列表当前显示的作品保留为普通列表，将它们全部设为收藏，并移除规则。之后被隐藏或删除的标签会带删除线保留在规则中，不再匹配任何作品。

切换列表时，在结果加载期间完整的收藏列表行保持稳定，“已搁置”是收听状态选项中的最后一项。仅有播放游标永远不会把作品加入收藏。资源筛选按卡片上显示的可用状态限定收藏的作品：“可用”（本地、缓存或远程）、“本地”、“远程”或“缺失”。文件属于其他语言版本的作品，会连同该版本一起判定。筛选读取已保存的可用状态，不会请求实时的远程刷新。

在宽屏上，结果旁边的书架栏会列出全部收藏、标记、你的列表，以及关注的社团和声优及其数量。与“工作流”和“设置”的侧栏一样，它可以隐藏名称而只保留图标，这个选择会记在该设备上。每个用户列表可以显示一个在其编辑器中选定的图标，图标栏中正是靠它来区分各个列表；该列表图标也会出现在“添加到列表”菜单里。手机上则把相同的书架显示为一行可滚动的内容。打开的书架带有标题，其中有封面拼贴、数量、已完成的作品数，以及你正在听的作品。显示选项可以让作品在卡片和更紧凑、附带每部作品续播位置的列表之间切换。

书架中的“添加列表”和列表书架上的“编辑列表”会打开单个列表的编辑器：带图标的名称、可选的描述、动态列表的规则，以及“删除列表”。与其他列表重名时会给出提示，但仍可保存。“管理列表”显示全部列表；“上移”和“下移”会立即调整顺序，且不会离开当前打开的书架；在那里打开某个列表进行编辑后，可用“返回”回到全部列表。

## 身份

媒体库卡片代表统一的作品，而不是按来源划分的副本。远程卡片可以在作品拥有本地文件之前就对其进行跟踪或同步，但由此产生的状态会附着在同一个统一的作品身份上。“跟踪”还会保存所选的来源目录树，并在“已跟踪”中打开该来源。

一个远程来源可能收录同一作品的多个语言版本。当媒体库已经知道该作品的版本家族时，远程标签页会把来源返回的这些版本合并为一张卡片。卡片展示其中一个版本：搜索中指定的编号；没有时，选来源拥有的、在你的元数据语言中排在最前的版本；再没有时，选家族自身编号的版本。卡片上的编号、标题、封面、DLsite 链接、跟踪和 Fetch 都属于该版本。来源返回多个版本时，卡片底部的语言按钮会列出它们，并打开你选择的版本。媒体库尚不知道的家族，其各个版本会显示为各自独立的卡片。结果能放在一页内时，计数为卡片数；跨多页时，计数为来源的条目数。

## 来源标签页

来源标签页应当帮助用户回答“这部作品可以从哪里播放或获取”。它们不是各自拥有元数据所有权的独立媒体库。本地、已跟踪、缓存和远程的各项事实，都指向同一个作品模型。
