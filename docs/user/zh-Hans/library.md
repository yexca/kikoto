# 媒体库

[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒体库是浏览作品的主界面。

## 主要内容

- 显示 Local、Tracked 和远程来源标签页。
- 支持搜索标题、代码、语言版本、社团、标签和声优。`%` 和 `_` 按字面匹配，不区分全角/半角、大小写以及片假名/平假名。可以用 `tag: 癒し` 这样的条件限定搜索字段。
- DLsite 标签也能用 Kikoto 抓取过的其他语言名称匹配：如果某个以英文请求的版本把 `癒し` 返回为 `Healing`，`tag: healing` 就能同时找到两者。标签、标题、社团或声优与搜索词完全一致的结果排在部分匹配之前，各组内部仍按所选排序。
- 搜索框中的 `+` 按钮会打开浮动编辑器来添加结构化搜索条件；点击已有条件标签会在同一浮层中编辑，不会推移结果列表。
- 卡片显示封面、可用性、个人标签和播放状态。
- Library、Favorites、社团和声优页面共用响应式作品网格。
- Favorites 的收藏架侧栏可以像 Workflows 一样收起名称、只显示图标；自定义列表可以在「编辑列表」中选择图标。
- `KIKOTO_MODE=demo` 只返回全年龄且永久免费的作品。

卡片代表统一的 Work，而不是按来源复制的条目。Track 保存来源目录树并在 Tracked 中打开；来源标签表示可播放或获取的位置。
