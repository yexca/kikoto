# 作品详情

[English](../en/work-detail.md) · [简体中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

作品详情显示一个 Work 的元数据、版本、文件树、来源可用性和播放操作。

## 编辑元数据

admin 和 super_admin 拥有 `library:write`，可以编辑作品元数据。保存只提交相对初始值改动的字段；只换封面不会冻结自动标题、社团、系列或声优。清空字段只重置该字段的手动覆盖。升级会删除与同一作品系列某个 DLsite 标题去掉首尾空白后完全相同的冻结标题覆盖，社团、系列和声优覆盖保留。

标签区可以搜索共享元数据标签，为当前作品添加或移除，也能新建自定义标签；没有 DLsite 元数据的作品也可使用。恢复 DLsite 标签会清除当前作品的标签增删。共享名称按配置的元数据语言优先级选择手动名称和已学到的 genre 名称，因此只有日文版的作品也能显示已知的中文标签名。后台更新完成后，全局隐藏的标签不会出现。「我的标签」仍是独立的个人标签。Demo 中编辑器只供查看。

新建的自定义标签名称先保留为草稿，保存时才在同一事务中创建或复用共享标签并关联当前作品。取消编辑不会留下共享条目。去掉首尾空白、忽略大小写后，与任一语言的已知名称完全相同时会复用已有标签，重复点击或同名输入不会创建重复概念。

切换元数据语言版本时，优先使用该版本语言的手动名称或字典名称，没有时按配置的语言优先级回退；手动增删、最终目标的隐藏状态和合并关系继续生效。默认版本选择与作品投影使用相同的来源版本。只有快照标签的作品，在自身投影完成前保留标签显示；手动移除全部标签后则保持为空。

补全建议将已合并的旧名称显示为最终目标标签。名称命中隐藏标签（包括合并到隐藏目标）时会标明并禁止添加；请先在元数据管理中取消隐藏。标签名称遵循[设置](settings.md)中说明的语言优先顺序。

后台更新完成前，作品保留上次保存的标签集合，包括空集合，刷新元数据也不会让已移除的标签重新出现。远程标签与手动添加的共享标签一起显示。

## 主要内容

- 显示作品代码、封面、标题、社团、标签、评分、声优和 DLsite 链接。
- 分开显示语言版本、目录版本和 Origin。
- 汇总 Local、Cache、Tracked 和远程可用性。
- 分阶段加载元数据、本地目录树和来源信息，远程错误不会阻塞本地详情。
- 目录以文件夹浏览器呈现：宽屏时固定的文件夹栏位于所选文件夹内容旁，窄屏时用「文件夹」按钮打开同一导航。标出推荐文件夹和正在播放的文件夹；内容分组为子文件夹、音轨列表、图片集、文档和其他文件，音轨显示作品的续播位置。
- 预览以文件查看器打开，可用标题栏按钮、方向键、手机滑动或图片缩略图条切换同一文件夹内的同类文件。图片可适应窗口或以点击位置为中心查看实际尺寸并拖动平移；LRC、WebVTT 和 SRT 以带时间戳的行显示，解析方式与播放器歌词一致。
- 提供 Resume、Quick 状态、收藏、个人标签、Sync、Track、Cache 和 Fetch。
- 可以在元数据编辑器中把作品的元数据关联到另一个 DLsite 编号，例如特典版停售后普通版以新编号销售时。之后刷新元数据会读取关联编号，并把其元数据、标签和封面保存到当前作品；关联编号不会成为单独的作品。作品自身编号没有记录时，元数据不可用提示会直接打开编辑器。
