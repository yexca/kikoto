# 声优
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

声优页面呈现已持久化的人物和参与人员数据。

## 当前行为

- 根据本地提供方的参与人员信息和用户维护的人物数据列出声优，每张创作者卡片上都带有“本地”和“远程”可用性徽章。
- 使用服务端分页、由 URL 保存的列表搜索和筛选，配合更短的响应式创作者卡片、动态的用户标签行、与媒体库一致的分页，以及已知参与作品的最新封面。
- 采用与媒体库一致的首行工具栏：搜索位于左侧，每页数量和现有的声优筛选操作（默认为 `全部声优`）位于右侧；窄屏布局会把搜索收进工具栏操作中。用户标签仍然可见且可搜索，但列表暂时不提供标签筛选。
- 显示收藏、评分、备注和用户标签状态。
- 在详情标题下方显示已确认的别名。别名审核、重复项合并和合并撤销位于“元数据”页面的**声优**视图；对于拥有 `metadata:sync` 的用户，详情页的**更多**菜单会链接到那里。
- 没有提供方声优信息的作品归入 `unknown` 分组。
- 在声优详情中，先显示“本地”和“远程”可用性徽章，再显示用户标签。缓存仍可用于播放和筛选数据，但不会显示为“本地”。
- 以与媒体库相同的响应式网格和共用作品卡片呈现已知作品和远程作品。在作品卡片上选择 DLsite 标签或个人标签，会打开针对该标签的本地媒体库搜索。
- 人物详情、已知作品和远程匹配结果相互独立地加载。远程来源搜索使用有限的并发，声优数量和用户标签则分批汇总。
- 详情摘要中保留“收藏”、常用的刷新操作和**更多**菜单。**首次拉取**或**刷新**会排队一个“关注声优”运行，只针对所有兼容的远程来源获取已知作品的元数据；只有当已知作品仍缺少元数据时才会出现**重试元数据**。在该运行结束前，按钮显示**正在刷新**。同步状态旁的警告会统计上次运行失败的远程来源，并在“活动”中打开该运行。**更多**中包含**关注此声优…**（打开已选中当前声优的预制工作流，用于选择来源、筛选、元数据和标签）以及**管理别名**。作品工具栏与媒体库一致：左侧是有长度限制的搜索，右侧是列数、每页数量、可用性筛选和选择，均为低调的图标操作，共用的合集分页位于网格上方和下方。移动端的作品搜索保持一行，并通过单独的选项面板打开筛选、列数和选择控件。
- 在移动端，详情页的返回控件相当于“上一级”，指向最近一次按服务器和用户记录的声优列表位置，即使该详情是从媒体库或收藏打开的也一样。宽屏布局则保留可识别来源的历史返回。

## 边界

DLsite 仍然是已知作品的元数据提供方。Kikoto 不会把对 DLsite 的关键词爬取当作可靠的声优目录。

## 审核行为

别名和合并工具应当保留用户状态，并在合并重复的人物记录时保持合并撤销入口可见。
