# 声优
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

声优页面呈现已持久化的人物和参与人员数据。

## 当前行为

- 根据本地提供方的参与人员信息和用户维护的人物数据，以封面磁贴的形式列出声优，每个磁贴带有“本地”和“远程”数量以及一条可用性条：实心段表示有本地副本的作品，较浅的段表示只有远程来源持有的作品，空白轨道表示其余作品。
- 使用服务端分页、由 URL 保存的列表搜索和筛选。每个磁贴显示声优的封面（封面上有收藏控件）、名称、别名、最新发行日期和动态的用户标签行，并配有与媒体库一致的分页。磁贴在宽屏布局中铺满整行，在手机上为两列。
- 以已知参与作品的最新封面作为声优的封面。详情页**更多**菜单中的**更换封面…**会列出该声优的作品并提供搜索，所选作品的封面会成为该声优在磁贴和详情摘要上的封面。同一对话框中的**最新作品**可恢复为随每次新发行更新的封面。该选择归做出选择的账户所有；若所选作品已不再是该声优的作品，则改用最新作品的封面。
- 搜索、一键切换视图的筛选标签和每页数量操作位于同一行可换行的工具栏。筛选标签为 `全部声优`、`收藏`、`已标记`、`可用`、`本地`、`远程` 和 `缺失`，处于按下状态的标签即当前视图。在手机上，搜索框独占一行，每页数量位于其旁边，筛选标签在下方横向滚动。用户标签仍然可见且可搜索，但列表不提供标签筛选。
- 显示收藏、评分、备注和用户标签状态。
- 在详情标题下方显示已确认的别名。别名审核、重复项合并和合并撤销位于“元数据”页面的**声优**视图；对于拥有 `metadata:sync` 的用户，详情页的**更多**菜单会链接到那里。
- 没有提供方声优信息的作品归入 `unknown` 分组。
- 在带封面色调的声优详情摘要中，先显示“本地”和“远程”可用性徽章，再显示用户标签。缓存仍可用于播放和筛选数据，但不会显示为“本地”。
- 以与媒体库相同的响应式网格和共用作品卡片呈现已知作品和远程作品。在作品卡片上选择 DLsite 标签或个人标签，会打开针对该标签的本地媒体库搜索。
- 作品可按**发行日期**、**代码**、**标题**、**评分**或**销量**升序或降序排列，默认按发行日期从新到旧。没有所选依据数据的作品无论升序还是降序都排在最后。排序方式和每页数量（24、48 或 96）按账号记在当前设备上，并适用于每位声优。
- 声优的作品由服务器分页。已知作品与远程目录合并为一个列表，搜索、可用性筛选以及所选排序在分页前执行；批量选择仅覆盖当前已加载的页面。搜索与媒体库的普通搜索一样，按代码、标题、社团、声优、标签或个人标签匹配作品；只存在于远程目录的作品则按其代码、标题、社团或标签匹配。同一作品的各个版本只算作一部作品，任一版本可用即视为可用。人物详情和远程来源的目录状态分别加载。远程来源搜索使用有限的并发，声优数量和用户标签则分批汇总。
- 详情摘要中保留“收藏”、常用的刷新操作和**更多**菜单。**首次拉取**或**刷新**会排队一个“同步声优目录”运行，只针对所有兼容的远程来源获取已知作品的元数据；只有当已知作品仍缺少元数据时才会出现**重试元数据**。在该运行结束前，按钮显示**正在刷新**。同步状态旁的警告会统计上次运行失败的远程来源，并在“活动”中打开该运行。“收藏”旁边的铃铛用于订阅该声优的新作；参见[订阅](subscriptions.md)。**更多**中包含**更换封面…**、**同步此声优的目录…**（打开已选中当前声优的预制工作流，用于选择来源、筛选、元数据和标签）以及**管理别名**。作品工具栏与媒体库一致：左侧是有长度限制的搜索，右侧依次是显示当前排序方式的排序按钮、显示选项、可用性筛选和选择，共用的合集分页位于网格上方和下方。显示选项包含列数、与媒体库共用的**卡片**选项（**完整**、**紧凑**、**极简**）以及每页数量。手机上排序按钮位于作品上方，搜索、筛选、列数、卡片模式、每页数量和选择则通过单独的选项面板打开。
- 在移动端，详情页的返回控件相当于“上一级”，指向最近一次按服务器和用户记录的声优列表位置，即使该详情是从媒体库或收藏打开的也一样。宽屏布局则保留可识别来源的历史返回。

## 边界

DLsite 仍然是已知作品的元数据提供方。Kikoto 不会把对 DLsite 的关键词爬取当作可靠的声优目录。

## 审核行为

别名和合并工具应当保留用户状态，并在合并重复的人物记录时保持合并撤销入口可见。
