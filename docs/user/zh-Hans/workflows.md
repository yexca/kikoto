# 工作流

[English](../en/workflows.md) · [简体中文](../zh-Hans/workflows.md) · [繁體中文](../zh-Hant/workflows.md) · [日本語](../ja/workflows.md) · [한국어](../ko/workflows.md)

工作流让后台处理过程可查看。

## 主要内容

- 在 Workflows 管理定义和触发器，在 Activity 查看执行状态。
- 本地扫描、元数据 Sync、远程 Sync、Cache、Fetch 和清理是独立运行。
- 消失的文件夹标记为 `missing`，重复代码保留在 Review。
- 每个 canonical Work 只保留一个排队或运行中的 Fetch，Activity 显示传输字节数、实测速度和预计剩余时间。
- 运行详情显示开始与结束时间、耗时、触发方式、步骤，以及默认折叠的诊断日志。
- 只有声明支持恢复的工作流才支持检查点和重试。
- 关注社团、关注系列、关注声优是预制工作流。目标、筛选、动作、Fetch 上限和标签模板直接显示在工作流标题下方的运行选项中，点击标题右侧的 **Run** 即可运行。触发器默认使用上方参数；勾选“自定义运行选项”后可单独覆盖。仅同步元数据不需要来源；Track 和 Fetch 需要已启用的兼容远程来源，Fetch 还需要下载管理权限并给出明确的文件数、体积和剩余空间上限。“仅新作品”会跳过媒体库中已有的作品，标签模板留空则不打标签。自动运行只支持已存储或增量的社团目录刷新，完整刷新仅限手动。
- “关注社团”和“关注声优”带有可选的作品元数据刷新（仅缺失的或全部作品），社团还可选择检测远程来源。声优目标为选定的一位声优，并在勾选的远程来源中刷新其目录。关闭 **关注新作品** 后只运行刷新步骤，详情页的刷新即以这种方式运行。
- 用户自建的自定义工作流、DAG 编辑器、斜杠命令和定义运行对话框已移除。升级时会删除既有的用户定义及其触发器，运行记录仍保留在 Activity 历史中。

Workflows 右上角的 Activity 打开桌面面板或手机底部面板。运行中的任务显示在上方，下方分为 **Needs attention** 和 **History**。待处理候选项、元数据问题和未确认失败进入前者；已解决的元数据运行提示自动解除，其他失败可按用户确认。History 保留原始执行状态。元数据集中处理作品问题和元数据设置，并提供同步工作流快捷入口。

Activity 仅显示当前工作流的任务和计数，切换工作流会更新列表。点击 Recent runs 或记录即可在同一面板查看详情、事件和候选项。独立 Full Activity 页面已移除，旧链接和通知会打开所属工作流的 Activity。
