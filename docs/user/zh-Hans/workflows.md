# 工作流

[English](../en/workflows.md) · [简体中文](../zh-Hans/workflows.md) · [繁體中文](../zh-Hant/workflows.md) · [日本語](../ja/workflows.md) · [한국어](../ko/workflows.md)

工作流让后台处理过程可查看。

## 主要内容

- 在 Workflows 管理定义和触发器，在 Activity 查看执行状态。
- 本地扫描、元数据 Sync、远程 Sync、Cache、Fetch 和清理是独立运行。
- **刷新本地作品文件**排在本地扫描之后（第二个）。它为扫描已发现的本地作品文件夹索引其中的媒体文件，避免打开作品时才临时索引大型文件夹。**增量**（默认）只处理从未索引过文件的文件夹；**完整**会重新索引所有可用的本地作品。同一时间只有一个排队或运行中的任务，再次启动会返回当前任务。支持保存模式的 Startup 和间隔触发器，默认不带触发器。
- 消失的文件夹标记为 `missing`，重复代码保留在 Review。
- 每个 canonical Work 只保留一个排队或运行中的 Fetch，Activity 显示传输字节数、实测速度和预计剩余时间。
- Fetch 运行详情列出其文件：正在下载的文件置顶并带有单独进度条，完整列表标出已完成、等待中，以及运行失败或暂停时所在的文件。
- 运行详情显示开始与结束时间、耗时、触发方式、步骤，以及默认折叠的诊断日志。
- 只有声明支持恢复的工作流才支持检查点和重试。
- 关注社团、关注系列、关注声优是预制工作流。运行选项分为三部分：**输入**（目标与目录刷新：增量或完整）、**筛选**（发售日期范围与作品上限）和**动作**（同步元数据、标签模板，社团还可检测远程来源），点击标题右侧的 **Run** 即可运行。触发器默认使用上方参数；勾选“自定义运行选项”后可单独覆盖。同步元数据针对缺少元数据的目录作品（包括尚未入库的作品），筛选和标签作用于这些作品。所有筛选默认关闭；没有发售日期范围或作品上限时，每次运行会同步所有缺少元数据的目录作品。标签模板同样默认关闭，开启后才会为同步的作品打标签。保存没有筛选的自动运行时，触发器弹窗会提示并建议开启筛选。关闭同步元数据后，关注社团和关注声优只刷新目录（以及检测来源）。Track 和 Fetch 不再是关注的动作。自动运行只支持增量目录刷新，完整刷新仅限手动。
- 声优目标为选定的一位声优，并在勾选的远程来源中刷新其目录。系列读取已存储的作品，没有目录刷新。升级后，之前保存的关注触发器会被停用并提示需要重新配置；打开触发器、确认运行选项并保存，然后重新开启即可。元数据同步刷新媒体库中已有的作品：运行选项可选择**作品**（全部作品、某个社团、某位声优）和**刷新内容**（缺失或过期，或全部元数据），间隔触发器也保存同样的选择。
- 用户自建的自定义工作流、DAG 编辑器、斜杠命令和定义运行对话框已移除。升级时会删除既有的用户定义及其触发器，运行记录仍保留在 Activity 历史中。

Workflows 右上角的 Activity 打开桌面面板或手机底部面板。运行中的任务显示在上方，下方分为 **Needs attention** 和 **History**。待处理候选项、元数据问题和未确认失败进入前者；已解决的元数据运行提示自动解除，其他失败可按用户确认。History 保留原始执行状态。元数据集中处理作品问题和元数据设置，并提供同步工作流快捷入口。

Activity 仅显示当前工作流的任务和计数，切换工作流会更新列表。点击 Recent runs 或记录即可在同一面板查看详情、事件和候选项。独立 Full Activity 页面已移除，旧链接和通知会打开所属工作流的 Activity。
