# 工作流

[English](../en/workflows.md) · [简体中文](../zh-Hans/workflows.md) · [繁體中文](../zh-Hant/workflows.md) · [日本語](../ja/workflows.md) · [한국어](../ko/workflows.md)

工作流让后台处理过程可查看。

## 主要内容

- 在 Workflows 管理定义和触发器，在 Activity 查看执行状态。
- 本地扫描、元数据 Sync、远程 Sync、Cache、Fetch 和清理是独立运行。
- **刷新本地作品文件**排在本地扫描之后（第二个）。它为扫描已发现的本地作品文件夹索引其中的媒体文件，避免打开作品时才临时索引大型文件夹。**增量**（默认）只处理从未索引过文件的文件夹；**完整**会重新索引所有可用的本地作品。同一时间只有一个排队或运行中的任务，再次启动会返回当前任务。支持保存模式的 Startup 和间隔触发器，默认不带触发器。
- 消失的文件夹标记为 `missing`，重复代码保留在 Review。
- 每个 canonical Work 只保留一个排队或运行中的 Fetch，Activity 显示传输字节数、实测速度和预计剩余时间。
- Fetch 运行详情列出其文件：正在下载的文件置顶并带有单独进度条，完整列表标出已完成、等待中，以及运行失败或暂停时所在的文件。
- 运行详情显示开始与结束时间、耗时、触发方式、步骤，以及默认折叠的诊断日志。
- 只有声明支持恢复的工作流才支持检查点和重试。
- 关注社团、关注系列、关注声优是预制工作流。运行选项分为三部分：**输入**（目标与目录刷新：增量或完整）、**筛选**（发售日期范围与作品上限）和**动作**（同步元数据、标签模板，社团还可检测远程来源）；宽屏时三部分并排成三列。点击运行选项底部的 **Run** 即可运行。触发器默认使用上方参数；勾选“自定义运行选项”后可单独覆盖。同步元数据针对缺少元数据的目录作品（包括尚未入库的作品），筛选和标签作用于这些作品。所有筛选默认关闭；没有发售日期范围或作品上限时，每次运行会同步所有缺少元数据的目录作品。标签模板同样默认关闭，开启后才会为同步的作品打标签。保存没有筛选的自动运行时，触发器弹窗会提示并建议开启筛选。关闭同步元数据后，关注社团和关注声优只刷新目录（以及检测来源）。Track 和 Fetch 不再是关注的动作。自动运行只支持增量目录刷新，完整刷新仅限手动。
- 声优目标为选定的一位声优，并在勾选的远程来源中刷新其目录。系列读取已存储的作品，没有目录刷新。升级后，之前保存的关注触发器会被停用并提示需要重新配置；打开触发器、确认运行选项并保存，然后重新开启即可。元数据同步刷新媒体库中已有的作品：运行选项可选择**作品**（全部作品、某个社团、某位声优）和**刷新内容**（缺失或过期，或全部元数据），间隔触发器也保存同样的选择。拥有 `sources:write` 的管理员还会在 **运行** 旁看到 **配置**：它设置整个实例的[远程元数据回退](settings.md#远程元数据回退)，并且只保存这一项设置。
- 用户自建的自定义工作流、DAG 编辑器、斜杠命令和定义运行对话框已移除。升级时会删除既有的用户定义及其触发器，运行记录仍保留在 Activity 历史中。

页面顶部的状态条显示正在运行的任务及进度、需要处理的运行数量和下一次计划运行。点击前两格或状态条右端的 Activity 会打开桌面面板或手机底部面板；点击下一次计划运行会选中对应的工作流。运行中的任务显示在上方，下方分为 **Needs attention** 和 **History**。待处理候选项、元数据问题和未确认失败进入前者；已解决的元数据运行提示自动解除，其他失败可按用户确认。History 保留原始执行状态。元数据集中处理作品问题和 DLsite 代理快捷开关，并提供同步工作流快捷入口。

Activity 显示所有工作流的任务和计数，切换工作流不会改变它。点击 Recent runs 或记录即可在同一面板查看详情、事件和候选项。独立 Full Activity 页面已移除，旧链接和通知会打开所属工作流的 Activity。

- 工作流列表按类别分组列出所有工作流：基础（本地扫描、本地文件、元数据同步）、收集（热门收集）、关注（预制关注工作流）和远程（Availability Watch 与 Fetch 记录），顺序固定。每一项显示最近一次运行的状态和时间，小图标标出已启用的 Startup 触发器、计划或文件夹监听。宽屏时列表位于所选工作流旁边，列表下方的「收起标签页名称」可将其收起为图标，每个图标仍以小圆点标出最近一次运行的状态，「展开标签页名称」可再次展开，此页面会记住这一选择；手机上先显示列表，点击工作流打开详情，用顶栏返回按钮或浏览器后退回到列表。
- 所选工作流汇总最近 20 次运行：上次运行、已完成运行的成功率、典型（中位数）耗时，以及下次自动运行的时间（计划、下次服务启动、文件夹变化或仅手动）。下方的柱状图按从旧到新显示这些运行的耗时；正常成功显示为中性色，失败和部分完成会突出显示。悬停柱子查看详情，点击打开该运行。
- 有运行参数的工作流在汇总下方显示 **运行选项**。表单底部的栏中有 **Run**；无法运行时会在旁边说明原因（例如缺少必填项）。表单较长时，这一栏会停留在屏幕底部，位于手机导航栏和播放器上方。没有运行参数的工作流将 **Run** 放在标题右侧。表单之后依次是最近一次运行的阶段与日志、触发器和最近运行。
