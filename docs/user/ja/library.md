# ライブラリ

[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

ライブラリは作品を閲覧するためのメイン画面です。

## 主要内容

- Local、Tracked、リモートソースをタブで表示します。
- タイトル、コード、言語版、サークル、タグ、声優を検索します。
- カバー、可用性、個人タグ、再生状態をカードに表示します。
- Library、Favorites、サークル、声優で同じレスポンシブグリッドを使います。
- `KIKOTO_MODE=demo` では全年齢かつ恒久的に無料の作品だけを表示します。

カードはソース別の複製ではなく統合された一つの Work です。Track はソースのツリーを保存し、Tracked で開きます。ソースタブは再生または取得できる場所を示します。
