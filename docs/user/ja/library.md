# ライブラリ

[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

ライブラリは作品を閲覧するためのメイン画面です。

## 主要内容

- Local、Tracked、リモートソースをタブで表示します。
- リモートのおすすめは未取り込みの作品にも対応し、既知の多言語タグ名と制作者の別名から好みを判定します。有効にすると現在のページを一括採点し、バッジを順に表示します。動きを減らす設定に従い、個人のしきい値を満たすスコアだけ表示します。ソースの一覧は再取得せず、採点の失敗だけ再試行でき、作品を取り込みません。
- おすすめは繰り返しの肯定的な評価を重視し、一般的なタグの重みを抑えます。探索は情報の少ない作品を優先し、順位では同じ制作者の集中を少し緩和します。視聴状態ごとの枠数とセッション内の好みは安定し、カードのスコアと順位調整は別です。
- タイトル、コード、言語版、サークル、タグ、声優を検索します。`%` や `_` は文字どおりに一致し、全角・半角、大文字・小文字、カタカナ・ひらがなの違いは区別しません。`tag: 癒し` のように項目を指定して検索できます。
- DLsite のタグは、Kikoto が取得したことのある各言語の名前でも一致します。英語で取得した版が `癒し` を `Healing` と返していれば、`tag: healing` で両方が見つかります。タグ・タイトル・サークル・声優が検索語と完全に一致する結果は部分一致より前に表示され、各グループ内は選択した並び順に従います。
- 検索欄の `+` ボタンは、構造化された検索条件を追加するフローティングエディターを開きます。条件バッジを選ぶと同じポップオーバーで編集でき、検索結果の位置は動きません。
- カバー、可用性、個人タグ、再生状態をカードに表示します。
- Library、Favorites、サークル、声優で同じレスポンシブグリッドを使います。
- Favorites の棚レールは Workflows と同じように名前を隠してアイコンだけにでき、ユーザーリストには「リストを編集」で選んだアイコンを表示できます。
- `KIKOTO_MODE=demo` では全年齢かつ恒久的に無料の作品だけを表示します。

カードはソース別の複製ではなく統合された一つの Work です。Track はソースのツリーを保存し、Tracked で開きます。ソースタブは再生または取得できる場所を示します。
