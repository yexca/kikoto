# ライブラリ
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

ライブラリは、作品を閲覧するための主要な画面です。

## 現在の動作

- ローカル、追跡済み、および設定済みのリモートソースのタブを表示します。
- 大きな結果セットにはサーバー側のページ分割を使用します。
- 現在のページを組み立てる前に、正規化したタイトル、コード、言語版の別名、サークル、タグ、
  声優クレジットを検索します。プロバイダーが宣言した版のコードは、ライブラリのリクエスト中に
  余分な作品を作成したり生のメタデータスナップショットをスキャンしたりすることなく、
  引き続き検索できます。
- 検索テキストは文字どおりに照合し、全角・半角、英字の大文字小文字、かな文字種の違いを
  無視します。`100%` や `a_b` はワイルドカードではなく、全角の `ＡＢＣ` で `abc` が見つかり、
  カタカナで書かれた語はひらがなで書かれた同じ語にも一致します。1 つのフィールドだけを
  検索するには、語の前に `tag: 癒し`、`circle:`、`va:`、`mytag:` などの句を付けます。
- DLsite のタグは、Kikoto がそのタグについて取得したすべての言語での名称にも一致します。
  英語で要求した版が `癒し` として表示されているタグを `Healing` と報告する場合、
  `tag: healing` はどちらも見つけます。タグ、タイトル、サークル、声優クレジットが検索語と
  完全に一致する結果は部分一致より前に表示され、選択した並べ替えが各グループを順序付けます。
- 検索フィールドの `+` ボタンは、構造化された検索条件を編集するフローティングエディターを
  開きます。条件のバッジを選択すると、結果を動かすことなく同じポップオーバーで編集できます。
- 利用できる場合は、カバー、タイトル、コード、1 行に省略表示された サークル / シリーズ、
  声優のメタデータ、ローカルの利用可能状態、ソースタグ、クイック聴取マークを表示します。
- プロバイダーのタグは最大 2 行のカード行に収まるよう計測します。`+N` バッジはポップオーバーで
  非表示のタグを開き、個人タグはユーザー所有の別の行として残ります。
- DL 販売数と、5 段階で数値を示さない評価の比較を、1 つの指標行にコンパクトに表示します。
  保存された再生位置がある場合は、再生履歴のアイコンが表示されます。
- 言語アイコンは、有効なソースを通じて、利用可能な原版以外の版があることをデータベースが
  把握している場合にのみ表示します。不明な言語やメタデータのみの言語関係では、利用可能とは
  みなしません。
- 正規化された商用メタデータがある場合は現在の価格を表示し、価格がゼロの作品には
  無料のラベルを付けます。
- 統合された作品カードと詳細では、サインインしているユーザーの作品タグをメタデータのタグとは
  別に表示します。`mytag:` はプロバイダーの `tag:` 検索の意味を変えることなく、個人タグで
  絞り込みます。
- ソースの利用可能状態は、メタデータのタグとは視覚的に分けて表示します。
- 既知の年齢区分を作品カードのサークル名の横に表示し、完全な年齢メタデータは作品詳細に保持します。
- 作品コレクションには、ライブラリ、お気に入り、サークル詳細、声優詳細の各画面で同じ
  レスポンシブなグリッドを使用します。列数の選択肢は、ページごとに再実装されるのではなく
  共有されます。
- 選択した作品コレクションの列設定はローカルに保存され、ライブラリ、お気に入り、サークルの
  作品コレクション、声優の作品コレクション全体に適用されます。
- 安定したシード付きのランダム順序に対応します。シードによってページ分割の一貫性が保たれ、
  シャッフルし直すと、順序を逆にするのではなく新しいシードが作成されます。
- 新しいライブラリビューは、パーソナライズされたおすすめ順を既定とし、履歴やセッションから
  復元された閲覧の選択は保持します。正規の URL に残るのは、クエリと既定以外の聴取ステータスだけ
  ですが、リンク内で明示された閲覧パラメーターは引き続き読み取られます。おすすめの配置では、
  聴取の意図と親和性を分けて扱います。再生中と聴きたいには先頭の枠が割り当てられ、未マークが
  引き続き主な発見の対象となり、再聴取と完了には限られた数が差し込まれ、保留は予定された
  状態が出尽くすまで待機します。ステータスを明示したフィルターでは、一致するすべての作品が
  引き続き返されます。各状態の中では、お気に入り、タグ、声優、サークルのシグナルを用いた
  上限付きの親和性スコアが使われ、候補自身を嗜好の履歴として扱うことはありません。肯定的な
  フィードバックが繰り返されると、一致した各シグナルが最大 5 作品の裏付けまで強まり、
  よくあるタグの重みは小さくなります。シード付きの発見ブーストは弱い根拠を優遇し、
  結果のばらつきは現在の状態内の並び順に対してのみその親和性を調整します。また、制作者の
  多様性についての小さな調整も並び順に影響します。バッジとテレメトリには、上限付きの
  親和性スコアが保持されます。再聴取とお気に入りの履歴は肯定的な根拠となり、完了だけでは
  中立です。各ブラウザータブまたはネイティブアプリの起動は不変のおすすめ世代に結び付けられるため、
  ナビゲーション、ページ移動、フィルター、カードの変更、ツールバーでのシャッフルし直しでは
  親和性は再計算されません。お気に入りや聴取の変更はカードにはすぐに反映されますが、配置に
  影響するのは次のクライアントセッションからです。新しいセッションでは、おすすめの入力が
  変更された場合にのみ世代を再構築し、そうでなければ新しい安定したシードで現在の世代を再利用します。
  シードによって、状態の混合と状態内の多様性の両方でページ分割の安全性が保たれ、ツールバーの
  更新操作は現在の世代内でそのシードだけを変更します。
- リモートのおすすめバッジは、取り込まれていない作品についても、既知のローカライズ済みタグと
  制作者の別名を使ってスコアを付けます。バッジをオンにすると、リモートソースを再読み込みせずに
  現在のページを一括でスコアリングし、その後バッジを段階的に表示します（モーションの低減設定が
  尊重されます）。バッジのしきい値を満たすスコアだけが表示されます。スコアリングに失敗しても
  作品は利用可能なままで、再試行が提示されます。リモートのスコアは、同じ固定されたセッションの
  嗜好プロファイルを使用し、作品を取り込むことはありません。
- ライブラリのコントロールの上に、横スクロール可能なコンパクトな最近再生した作品の帯を表示します。
  これはユーザーごとに、各論理的な作品ファミリーが持つ 1 つのカーソルから並べられ、最新の
  トラック位置を含みますが、完全な作品カードのグリッドを置き換えることはありません。
  この帯は折りたたむことができ、その設定はブラウザーに保存されます。
- ローカル、追跡済み、および設定済みのリモートソースで、1 つの共有クエリを使用します。
  各ソースは独自のページ分割、並べ替え、スクロールの状態を保持し、グリッドの列設定は共有
  されたままです。ユーザーが別の場所でクリアしたクエリテキストを、ソースが古い状態から
  復元することはありません。
- 現在のローカル、追跡済み、またはリモートソースのページサイズは 1 行目のアクションツールバーに
  置かれ、上部のコンパクトなページ移動は結果の文脈とページ移動に専念します。
- データベースのクリーンアップはライブラリには含まれません。メタデータ -> 利用可能なソースなし
  では、利用可能なソースもメディアの場所もない論理的なファミリーに対して、ページ分割された
  検索、ソースの確認、確認付きのローカル情報の削除を提供します。
- `/no-source` および `/library/no-source` のリンクはメタデータ -> 利用可能なソースなしを開き、
  `/library/all` および `/library/remote` のリンクはライブラリを開きます。
- `KIKOTO_MODE=demo` の場合、バックエンドの一覧、詳細、メディアのレスポンスは、全年齢向けで
  恒久的に無料の作品のみを許可します。ローカルの作品は正規化された商用メタデータを使用し、
  不明なメタデータや一時的な無料キャンペーンは除外されます。シミュレートされた Remote Kikoeru
  ソースは、許可されたローカルの作品を再公開するだけです。デモのセッションでは、許可された
  完全なメディアを再生できますが、ライブラリ、設定、ワークフローの状態は変更できません。

作品カードは、すべてのコレクション画面で同じサマリーモデルを使用し、既知の場合は声優の
クレジットも含みます。コンパクトなカードには声優名が最大 2 件まで表示され、追加のクレジットは
要約されるため、メタデータによってカードが際限なく大きくなることはありません。

お気に入りは、正規の URL にエンティティと検索の意図のみを保持します。選択中のリスト、
お気に入りのフィルター、並び順、シード、ページ移動、選択、作品のアンカーは、現在の履歴エントリから
復元され、ユーザー単位のセッションにフォールバックします。`すべてのお気に入り` は、クイックマークの
付いた作品と、いずれかのユーザーリストに入っている作品を集約します。`マーク済み` は、クイックマークが
未マークではない作品だけを含む固定のシステムリストで、そのメンバーは導出されるため、リストとして
編集することはできません。その他のリストはユーザーが作成し、明示的なメンバーを保持します。
リストを切り替えても、結果の読み込み中はお気に入りリストの行全体が安定したまま維持され、
保留は聴取状態の最後の選択肢です。再生カーソルだけでは作品がお気に入りに追加されることはありません。
ソースピッカーでは、ソースごとの作品コピーを作成したりライブのリモート更新を要求したりすることなく、
選択した複数の設定済みファイルソースのいずれかにお気に入りの作品を絞り込めます。

広い画面では、結果の横の棚のレールに、すべてのお気に入り、マーク済み、自分のリスト、
フォロー中のサークルと声優が、それぞれの件数とともに並びます。ワークフローや設定のレールと同様に、
名前を非表示にしてアイコンだけにでき、その選択はそのデバイスに記憶されます。各ユーザーリストには
リストを編集で選んだアイコンを表示でき、アイコンのレールではそれによってリストを見分けられます。
リストのアイコンは、リストに追加のメニューにも表示されます。スマートフォンでは、同じ棚が 1 つの
スクロール可能な行として表示されます。開いている棚には、カバーのモザイク、件数、完了した作品の数、
聴取中の作品を示すヘッダーがあります。作品は、カードとして、または各作品の再開位置を示すより
密度の高いリストとして表示できます。

## アイデンティティ

ライブラリのカードは、ソースごとのコピーではなく、統合された作品を表します。リモートのカードは、
ローカルファイルを持つ前でも作品を追跡または同期できますが、その結果の状態は同じ統合された
作品のアイデンティティに紐付けられます。追跡は、選択したソースツリーも保存し、そのソースを
追跡済みで開きます。

## ソースタブ

ソースタブは、作品をどこから再生または取得できるかをユーザーが把握する助けになるべきものです。
それぞれメタデータの所有権が別々のライブラリではありません。ローカル、追跡済み、キャッシュ、
リモートの事実は、すべて同じ作品モデルに紐付けられます。
