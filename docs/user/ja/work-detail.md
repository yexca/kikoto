# 作品詳細

[English](../en/work-detail.md) · [简体中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

作品詳細は一つの Work のメタデータ、版、ファイルツリー、ソース可用性、再生操作を表示します。

## 多言語タイトル

編集画面のタイトルセクションは日本語、簡体字中国語、繁体字中国語、英語、韓国語を先に幅いっぱいの 1 行ずつ並べます。原版の言語には `origin`、現在表示中のメタデータ言語には `current` のバッジが付き、同じ行に両方を表示できます。その下の **タイトルの詳細設定** は既定で折りたたまれ、開くと **全言語共通タイトル** を設定できます。共通タイトルが保存されている場合は自動で開き、編集や解除ができます。ヒントは各言語の提供元タイトルより共通タイトルが優先され、言語別の手動タイトルがあればそちらを優先することを説明します。版や紹介文は変わりません。その行の手動タイトルは直接編集でき、提供元と継承値は灰色のヒントだけで表示されます。変更しないヒントは保存されません。各行は現在の出典を示し、手動または編集済みのタイトルに印を付けます。保存は変更した項目と言語のみを送信します。既存の手動値を空にするか、その行で「元に戻す」を選ぶと保存時にその範囲を解除し、継承ヒントへの入力を消した場合は変更しません。メタデータ → 作品からも同じ編集画面を開けます。

独自の手動タイトルまたは DLsite 版がある最初の優先言語を使います。その言語の手動タイトル、全言語の手動タイトル、その版のタイトルの順に適用します。全言語タイトルは文言だけを置き換え、既定の版、紹介文、タグはこのタイトルがない場合と同じです。`Origin` は原版で宣言された言語に対応し、不明な言語は推測しません。一致しなければ原版タイトルを使います。サークル、シリーズ、声優の上書きは全言語共通です。原版の言語が宣言されていない場合、すべての画面で不明として扱い、メタデータのリクエスト言語から推測しません。このとき言語ラベルは **オリジナル** だけを表示します。言語別の手動タイトルは宣言された対応言語、またはその手動言語を明示的に優先・選択した場合に適用します。言語メニューは実在する版と独自の手動タイトルがある言語だけを表示し、全言語タイトルは既存の選択肢に適用して言語を追加しません。

DLsite に記録がなくリモートソースで補完された作品では、詳細の通知に **リモートソースで補完** と表示され、ソースごとに補完した値が示されます。リモートのタイトルはタイトルの優先順で DLsite の後、作品自身のタイトルの前に使われます。言語を宣言しないため言語の選択肢を増やさず、文言もそのまま表示します。タイトル編集ではそのソース名が表示されます。

作品ファミリーの原版以外は第三者による翻訳を含めて翻訳版として扱います。提供元タイトルの表示では `【简体中文版】` や `【ドイツ語版】` のような DLsite の言語版ラベルを形式で判定し、先頭の一つだけを除きます。`【ASMR】`、途中のラベル、手動タイトルは保持します。各版は未対応言語でもその版自身のタイトルを使い、提供元の原文とスナップショットは変更しません。カード、詳細、言語選択、検索結果、新しい再生キューは同じ表示規則を使い、すべての手動タイトルを検索できます。紹介文はプレーンテキストのまま表示し、選択した版に従います。対応する版がない手動言語は原版の紹介文を使います。

## メタデータの編集

作品上部の **メタデータ** ボタンで編集画面を直接開きます。左下の **メタデータを更新** は従来の DLsite 更新です。有効でメタデータに対応するリモート提供元を設定すると、右の矢印に **〈提供元名〉から** が表示され、その提供元から現在の作品を再取得できます。手動の上書き、DLsite の優先順位、未保存の下書きは保持されます。自動リモート補完を有効にする必要はありません。

**List** メニューの **リストを追加** で新しいリストを作成すると、自動で選択されます。**保存** で既存の選択とともに作品の所属リストを更新します。

admin と super_admin は `library:write` により作品のメタデータを編集できます。保存は初期値から変更した項目だけを送信します。カバーだけを変更しても、自動取得のタイトル、サークル、シリーズ、声優情報は固定されません。空欄はその項目の上書きだけを解除します。アップグレード時には、同じ作品ファミリーの DLsite タイトルと前後の空白を除いて完全一致するタイトル上書きだけを削除し、サークル、シリーズ、声優の上書きは保持します。

編集画面はタイトル、カバー、タグ、クレジット、メタデータ提供元のセクションに分かれます。未保存の変更があるセクションには点が付き、フッターにも一覧が出ます。手動のサークル、シリーズ、声優リスト、カバーを「元に戻す」操作や、メタデータリンクの追加・削除も含め、すべての変更は保存するまで下書きのままなので、セクションを切り替えても編集は失われません。下書きがある状態でキャンセルすると、破棄してよいか確認します。サークル、シリーズ、声優は候補から選ぶと既知の項目にリンクされ、その ID は名前の下に表示され、「ID を編集」で変更できます。カバーは作品のローカル画像のサムネイル一覧から選びます。Ctrl+Enter で保存します。

タグ欄では共有メタデータタグを検索して作品に追加・削除でき、独自タグも作成できます。DLsite メタデータがない作品にも使えます。「DLsite タグに戻す」は作品のタグ追加・削除を解除します。表示名は自分の優先メタデータ言語に従って手動名と取得済みの genre 名から選ぶため、日本語版だけの作品でも既知の中国語タグ名を表示できます。全体で非表示のタグは表示されません。個人のタグはアカウント所有の別のデータです。Demo では閲覧のみです。

タグの言語ボタンを押すと、そのタグの全言語共通の名前と言語別の名前がそれぞれの行で開きます。手動の名前は直接編集でき、提供元や取得済みの名前は灰色のヒントとして表示されます。タグ名は共有されるため、名前を変えるとそのタグを持つすべての作品に反映され、パネルには共有している作品数が表示されます。新しい独自タグは入力した名前を全言語の名前とし、作成前に他の言語の名前も入力できます。名前の変更も他の変更と同じく下書きで、保存時に書き込まれます。

新しい独自タグ名は保存するまで下書きです。保存時に共有タグの作成または再利用と作品への追加を同じトランザクションで行い、キャンセルでは共有項目を残しません。前後の空白と大文字・小文字の違いを除き、どの言語の既知名とも完全一致する場合はそのタグを再利用し、連続操作や同名入力で重複を作りません。

メタデータ言語を切り替えると、その版の言語の手動名または辞書名を優先し、なければ自分の優先メタデータ言語に戻ります。追加・削除、最終統合先の非表示、統合対応は引き続き適用されます。どの版でも原作版のタグを表示するため、切り替えてもタグ名が変わるだけで増減しません。スナップショットだけにあるタグも投影完了まで表示を保ち、すべて手動で削除した場合は空欄になります。

日本語版しかない作品も、バックグラウンドの **タグ名を学習** ワークフローが名前を学習すると、タグを優先言語で表示します。それまでは日本語のタグ名を表示します。タイトルは日本語のままです。

統合済みの名前は最終的な統合先のタグとして候補に表示されます。非表示タグや非表示の統合先に一致する名前は明示され、追加できません。まずメタデータ管理で非表示を解除してください。名前は[設定](settings.md)で説明する言語の優先順に従います。

バックグラウンド更新が完了するまで、メタデータを更新しても最後に保存したタグ集合を表示します。空の集合も保たれます。声優ページのリモート作品一覧では、リモートのタグと手動で追加した共有タグを一緒に表示します。

## 購入特典

早期購入特典（`【早期購入特典】`）などの購入特典は、独自のファイルを持つ別の DLsite 作品ですが、どの作品のものかを DLsite は示しません。メタデータ同期は特典を元の作品に関連付けられ（[購入特典](settings.md#購入特典)を参照）、ライブラリ編集者はエディターのメタデータソースにある **購入特典** で元の作品のコードを入力または解除できます。関連付けた特典は別の作品のままで、タイトル、カバー、ファイル、再生位置、ライブラリのカードはそのままに、足りないタグ、声優、シリーズを元の作品から引き継ぎます。特典の詳細には **特典の対象** として元の作品が表示され、元の作品がライブラリにない場合はコードと DLsite へのリンクが表示されます。元の作品の詳細には、ファミリー内の別の版に関連付けられたものも含め、ライブラリにある **購入特典** が一覧表示されます。元の作品のコードがライブラリの作品になることはありません。関連付けを解除するとその作品の自動検出も止まり、次の更新で引き継いだ値は消えます。

## 主要内容

- 作品コード、カバー、タイトル、サークル、タグ、評価、声優、DLsite リンクを表示します。
- 言語版とディレクトリ版、Origin を分けて表示します。
- Local、Cache、Tracked、リモートの可用性を集約します。
- メタデータ、ローカルツリー、ソース情報を段階的に読み込みます。
- プレビューはファイルビューアーで開き、ヘッダーのボタン、矢印キー、スマートフォンのスワイプ、画像のフィルムストリップで同じフォルダー内の同じ種類のファイルを切り替えます。画像はウィンドウに合わせるか、クリック位置を中心に実寸で表示してドラッグで移動でき、LRC・WebVTT・SRT はプレーヤーの歌詞と同じ方法でタイムスタンプ付きの行として表示します。
- ローカルソースの **歌詞を管理** は、各ローカル音声ファイルと歌詞の選択を一覧表示します。ライブラリの書き込み権限を持つユーザーは、作品内の任意のローカル歌詞ファイル（音声とファイル名が一致しない翻訳歌詞を含む）を指定したり、歌詞フォルダーをトラック番号で（両方のファイル数が同じなら順番で）トラックに揃えたりできます。各行で冒頭の数行をプレビューでき、最後のタイムスタンプがトラックの終了より後なら警告します。指定はすべてのリスナーで共有され「自動」の選択になります。リスナー自身の選択は引き続き優先されます。
- 互換リモートソースを設定している場合、ファイルをダウンロードできるユーザーには **歌詞を管理** に **リモートから取得** タブが表示されます。ソースと作品 family の版を選び（DLsite は通常翻訳版にだけ歌詞を付けるため、翻訳版を先に選択します）、歌詞ファイルを一覧表示して、ダウンロードするファイルと対応するトラックを選び、同じタイミング確認でプレビューできます。ファイルは作品フォルダー内の、版の言語・作品番号・ダウンロード日時を名前にした新しいフォルダー（例: `Lyrics - CHI_HANS - RJ00000001 - 20261008-153012`）に保存されます。既存のファイルやフォルダーは置き換えず、その後作品を再スキャンして選んだ指定を保存します。読み取った版はライブラリに追加されません。
- ディレクトリはフォルダーエクスプローラーとして表示します。広い画面では固定のフォルダー列を選択中フォルダーの内容の横に置き、狭い画面ではフォルダーボタンから同じナビゲーションを開きます。おすすめのフォルダーと再生中のフォルダーを示し、内容はサブフォルダー、トラック一覧、画像ギャラリー、ドキュメント、その他のファイルにまとめます。トラックには作品の再開位置を表示します。
- Resume、Quick、お気に入り、個人タグ、Sync、Track、Cache、Fetch を提供します。
- メタデータ編集で、作品のメタデータを別の DLsite 作品番号にリンクできます。特典付き版の販売が終わり、通常版が別の番号で販売されている場合などに使います。以後のメタデータ更新はリンク先の番号を読み込み、そのメタデータ、タグ、カバーをこの作品に保存します。リンク先の番号は別の作品にはなりません。作品自身の番号に記録がない場合、メタデータを取得できない旨の通知から編集画面を直接開けます。
