# 設定

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定はサーバー、ユーザー、ブラウザに保存される動作を管理します。

## 多言語タイトル

独自の手動タイトルまたは DLsite 版がある最初の優先言語を使います。その言語の手動タイトル、全言語の手動タイトル、その版のタイトルの順に適用します。全言語タイトルは文言だけを置き換え、既定の版、紹介文、タグはこのタイトルがない場合と同じです。`Origin` は原版で宣言された言語に対応し、不明な言語は推測しません。一致しなければ原版タイトルを使います。サークル、シリーズ、声優の上書きは全言語共通です。原版の言語が宣言されていない場合、すべての画面で不明として扱い、メタデータのリクエスト言語から推測しません。このとき言語ラベルは **オリジナル** だけを表示します。言語別の手動タイトルは宣言された対応言語、またはその手動言語を明示的に優先・選択した場合に適用します。言語メニューは実在する版と独自の手動タイトルがある言語だけを表示し、全言語タイトルは既存の選択肢に適用して言語を追加しません。

## 主要内容

- UI 言語、テーマ、表示密度、作品グリッド列数を設定します。
- 再生速度、シーク時間、互換再生範囲を保存します。
- サーバー接続、ソース、メタデータ言語、スキャン、watcher、`Follow-up run` を管理します。
- 個人タグ、お気に入り、再生状態をユーザーごとに保持します。

## メンテナンス

Maintenance のタブは横一列で、狭い画面では横スクロールできます。Overview は廃止し、Library にローカルスキャン、リモートソース、読み取り専用の保存パスをまとめました。ソース管理者は Library、ユーザー管理権限のみの場合は Users が初期画面です。Users にはユーザー管理とスーパー管理者向けのアクセス設定をまとめています。従来の Paths と Access のリンクは、それぞれ Library と Users に移動します。

リモートソースは、状態、ホスト、ヘルスチェック、即時保存される有効スイッチを持つ簡潔な一覧です。**ソースを追加** ではアドレスを 1 つ入力するだけで、入力どおりのアドレス、そのオリジン、一般的な `api.` サブドメインを順に調べ、API URL、公開サイト、名前を自動入力します。検出できない場合は **接続の詳細** が開き、手動で入力できます。エンドポイント、優先度、ネットワークと保存先の設定は折りたたまれています。Cache & Fetch は設定のみになり、キャッシュの内容は **クリーンアップ** タブで管理します。おすすめ設定には、ログイン中のユーザー自身の過去 30 日間の統計を示す折りたたみ式の **あなたのおすすめアクティビティ** を追加しました。

Library の **クリエイターのカタログ** には **カタログの更新日数**（1〜365、既定 30）があり、専用の **カタログ設定を保存** ボタンで保存します。この日数を過ぎて更新されていないサークルや声優のカタログは要確認になります。従来の `/settings?tab=metadata` リンクは Library を開きます。インスタンス全体のメタデータ言語はありません。各ユーザー自身の選択はアカウントメニューに、リモートソースのフォールバック言語はソース設定にあります。

## クリーンアップ

**クリーンアップ** は設定の Proxy の次にある管理者向けタブです（`/settings?tab=cleanup`）。キャッシュ部分には `downloads:manage`、データベース部分には `sources:write` が必要です。トランスコードキャッシュと管理メディアキャッシュの使用量と削除に加え、データベースのレコードを整理できます。対象は、ディスク上に存在しないことを確認した作品フォルダとローカルファイル（空になったトラック項目とローカル可用性を含む）、孤立したメタデータスナップショット、使われていないソースタグ、期限切れセッション、閉じた通知、90 日より前のワークフロー履歴とおすすめシグナル、使われていないおすすめスナップショットです。個人タグ、レビュー・Fetch 記録・メタデータの問題を含む実行、各ワークフローの最新の実行は残ります。整理には確認が必要で監査ログに記録され、メディアファイルは削除されません。期限切れセッションと対象となる古いワークフロー実行は、同じ条件で 1 日 1 回自動的にも削除されます。データフォルダがない、または空の場合はパスの確認を停止します。**ソースのない作品** はメタデータの **利用可能なソースなし** に移動し、**データベースを最適化** は空きページをディスクに返します。最適化はアクティビティに表示されるワークフロー実行としてバックグラウンドで行われ、同時にキューに入る、または実行できるのは 1 件だけです。

## メタデータ

**メタデータ** のレールは **作品**（すべて、要対応、メタデータの問題、利用可能なソースなし）と **項目**（タグ、サークル、声優）に分かれます。広い画面ではグループと表示名を展開でき、スマートフォンでは横スクロールのアイコン行になります。作品表は検索、ページ分割、選択、手動更新を保持し、鉛筆ボタンは作品詳細と同じエディターを開きます。admin と super_admin は `library:write` によりメタデータ、カバー、メタデータリンク、ソース追跡解除、共有タグ、サークルの識別情報を編集できます。

**タグ**（`/metadata?view=tags`）は共有タグの **ID** を行の基準にし、ID 順に並ぶため、一覧は言語設定に左右されません。ID の欄には、DLsite のジャンル ID があればタグ ID の下に表示し、非表示または統合済みのタグに限ってその下に **非表示** または **統合済み** を表示します。有効なタグには状態を表示しません。列は ID、日本語、簡体字中国語、繁体字中国語、英語、韓国語、**その他の名前**、作品数、管理です。各言語の列には、その言語で表示される名前を、その言語の手動名、全言語共通の手動名（薄く表示）、DLsite の辞書の名前、リモートソースの名前の順で表示し、どれもなければ「—」を表示します。**その他の名前** には、それ以外の既知の名前を 1 回ずつ表示します。手動名で置き換えられた名前（言語付き）、言語のない名前、名前の記録がない保存済みの名前が含まれます。検索は名前（リモートソースの名前を含む）に一致し、数字の検索語はタグ ID や DLsite のジャンル ID にも一致します。狭い画面では表は専用の枠内で横にスクロールし、管理ボタンは右端に固定されたままです。管理ダイアログで全言語共通または言語別の手動名、全体の非表示、統合先、統合対応の取り消しを設定します。**サークル**（`?view=circles`）は DLsite の maker id（RG コード）を行の基準にし、コード順に並びます。統合で加わった maker id は主コードの下に表示し、リモートソースだけで知られているサークルは最後に Kikoto の ID で表示します。列はコード、名前（最新作品のカバー付き）、登録済みの名前、作品数、管理で、検索は maker id にも一致します。管理では提供元の更新に上書きされない手動名と確定した別名を管理し、作品、maker id、カタログ、スナップショット、シリーズ、個人のサークル情報をまとめて統合します。取り消しは最新の統合から行い、対象データの後続編集を上書きしません。**声優** は Kikoto の ID を行の基準にして ID 順に並び、列は ID、名前（最新作品のカバー付き）、別名、作品数、状態（カタログ同期）、管理です。別名と重複人物の管理は引き続き `metadata:sync` が必要で、`/metadata?view=aliases&voice=<id>` のリンクも利用できます。Demo は閲覧のみで変更操作は無効です。

項目の一覧はメタデータ画面と同じアクセス条件です。ログインし、`library:write`、`metadata:sync`、`sources:write`、`system:admin` のいずれかが必要です。匿名閲覧には管理一覧を含みません。Demo は対象作品に関連するタグとサークルだけを表示し、作品数もその範囲だけで計算します。サークルの統合履歴は表示しません。

タグの表示状態は最終的な統合先で決まります。統合済みタグの非表示設定は取り消し後に適用され、非表示のタグへ統合すると結果も非表示になります。元の名前は統合後も検索でき、取り消すと元の識別情報と検索名に戻ります。

旧カバーの移動とタグの補完は、基本の起動ワークフローの後に独立したバックグラウンド処理で実行します。一つのカバーで失敗しても他のファイルを続け、失敗はログに記録して次の起動で再試行します。

上部は分類、検索、一覧の操作を 1 行にまとめます。広い画面では検索欄が分類の右に並び、狭い画面では右側の検索アイコンにまとまり、押すと行の下に検索欄を開きます。続いて更新、表示件数、**メタデータを再試行**、**ソースを確認**、**メタデータ設定** の歯車が並びます。一覧の上下のページ分割はライブラリと同じです。メタデータ設定はポップオーバーで開き、各設定の説明は情報アイコンにカーソルを合わせるかフォーカスすると表示されます。閉じても一覧と絞り込みを保持します。メタデータ同期は Workflows から実行します。

作品を選んで**メタデータを再試行**すると、対象件数がボタンに表示されます。詳細から特定の版も再試行でき、取得不可と報告された作品も再確認できます。失敗しても既存情報と手動の上書きは保持されます。ソース確認は選択したソースのない作品だけが対象です。ローカル情報の削除は「利用可能なソースなし」の画面に限定され、確認後にサーバーが利用状態を再検証します。メディアファイルは保持します。

Activity と Workflows は維持します。Activity の問題一覧ボタンは、その実行の未解決メタデータ問題で絞り込んだ作品メンテナンスを開きます。すべての要対応作品を表示すると実行の絞り込みが解除されます。他のユーザーのレビュー状態は変更しません。復旧には `metadata:sync`、ソース確認・削除・ソースと言語の設定には `sources:write` が必要です。**メタデータ設定** のポップオーバーには **DLsite プロキシ** のショートカットがあり、`設定 -> プロキシ -> プロキシの適用範囲` の DLsite と同じスイッチとプロキシの選択をすぐに保存します。**プロキシを管理** はその項目を開き、プロキシを追加・並べ替えます。その下の **カタログの更新日数** は `設定 -> Library` を開き、**リモートメタデータの補完** はその設定を **設定** に持つメタデータ同期ワークフローを開きます。このページは同期ワークフローの設定や実行操作を重複させません。従来の Maintenance リンクもこのページへ移動します。

共有タグ名は優先言語ごとに、言語別の手動名、全言語共通の手動名、提供元の名前の順で選びます。詳細の言語切り替えも同じ順です。

非表示、統合、統合解除は状態をすぐ保存し、関連作品をバックグラウンドで続けて更新します。タグ管理は再試行待ちを含むインスタンス全体の更新待ち作品数を表示します。リスト更新で進捗を確認できます。失敗した作品は他の作品を止めずに自動で再試行し、再起動後も処理を続けます。

### 優先言語のタグ名

優先メタデータ言語は、ログインした各ユーザーがアカウントメニューで選びます。選んでいないユーザーと匿名の訪問者には各作品の原語（**原版**）が使われます。保存されるタイトルとタグ名、バックグラウンドの同期、カタログ更新、リモートメタデータの補完、アクティビティの文言も常に各作品の原語を使います。どの言語でもタグは原作版のものを表示し、タイトル順の並べ替えは表示されるタイトルに従います。リモートソースには閲覧者の言語を先に、ソース設定の **フォールバック言語** を最後に指定してリクエストします。**原版** のままの閲覧者、匿名の訪問者、クロールやダウンロード、補完などのバックグラウンド処理は、フォールバック言語だけを指定します。

DLsite は日本語版しかない作品でも、リクエストした言語でジャンル名を返します。いずれかのユーザーの優先メタデータ言語が日本語以外の場合、**タグ名を学習** ワークフローが不足しているタグ名をバックグラウンドで補います。言語ごとに、名前のないタグを最も多く含む作品を 1 回ずつ問い合わせるため、リクエスト数はライブラリの規模ではなく不足しているタグの数で決まります。起動時、メタデータ同期の後、言語を変更した後に実行され、メタデータ同期と同じリクエスト間隔と DLsite プロキシを使い、再起動後は続きから再開します。進行状況、結果、失敗はアクティビティに表示されます。保存するのはタグ名だけで、タイトルや紹介文は使いません。DLsite が名前を返さなかったタグは再度問い合わせません。

### リモートメタデータの補完

**リモートメタデータの補完** は、メタデータ同期ワークフロー（`ワークフロー -> 作品メタデータを同期`）で `sources:write` を持つ管理者に **実行** の横に表示される **設定** から設定し、既定でオフです。オンにすると、作品のメタデータ更新で DLsite が作品を明確に見つけられなかった場合に、選択したリモートソースへ一覧の順に問い合わせます。タイムアウトなど一時的な DLsite のエラーでは問い合わせません。一覧にはソース設定で **作品のメタデータを提供** がオンのソースだけが表示されます。各ソースへの問い合わせは 1 回で、最初に作品を返したソースがタイトル、発売日、サークル、タグ、表紙（表紙がない場合のみ）を補完します。作品を新たに作ることはなく、DLsite にない言語を補うこともありません。オンの間は DLsite のデータがない作品のタグが共有タグに加わり、既存のタグと一致するリモートのタグはそのタグを使います。DLsite のデータが取得できれば、リモートの値は常に置き換えられます。

一覧の順序は、スイッチがオフでも、複数のリモートソースが同じ作品を返した場合にどの値を使うかを決めます。オフにすると新しい問い合わせは止まり、リモートのタグは共有タグから外れます。補完済みのタイトル、日付、サークル、表紙は DLsite または手動の値に置き換わるまで残ります。メタデータの要対応一覧には、DLsite にない作品を補完したソース名が表示されます。

### 購入特典

**購入特典を元の作品に関連付ける** は、同じメタデータ同期ワークフローの **設定** で切り替え、既定ではオンです。早期購入特典（`【早期購入特典】`）などの購入特典は、どの作品のものかを DLsite が示さない無料の作品です。メタデータ同期がそのような作品を保存すると、ライブラリにある同じサークルの作品から元の作品を探し、見つからなければサークルの DLsite ページを最大 10 ページ読み、特典のコードに最も近い 5 作品を確認します。特典とタイトルの読みが同じ作品、または発売日と特典表記内のタイトルが一致する作品がちょうど 1 つの場合だけ関連付けます。ライブラリにある既存の特典は次のメタデータ同期で確認されます。見つからなかった作品は、作品詳細からメタデータを更新すると再確認します。スイッチをオフにすると新しい検出は止まり、既存の関連付けは残ります。関連付けの効果は[購入特典](work-detail.md#購入特典)を参照してください。

メタデータ画面の正式な URL は `/metadata` です。従来の `/work-management` リンクも絞り込みや設定を保持して移動します。初回同期の失敗や未解決のメタデータ問題はこの画面を開きます。ワークフロー権限がない場合、実行別の絞り込みを付けません。実行の診断は Workflows の Activity で確認できます。

Settings は Account、Playback、「履歴」「おすすめ」「タグ」タブの構成で、タブはアイコンで表示されます。アイコンにカーソルを合わせるかフォーカスすると名前が表示され、スマートフォンでは選択中のタブの名前も表示されます。「データ」のエクスポートとインポートは Account の末尾にあります。「おすすめ」は推薦のアクティビティと推薦設定を表示します。管理者（と Demo）には区切り線の後に管理タブ（Library、Cache & Fetch、Proxy、Cleanup、Users）が表示されます。広い画面ではアイコンが設定内容の左に縦に並び、スマートフォンでは横にスクロールできる 1 行のアイコンになります。縦の列の下にある「タブ名を表示」ボタンで列を広げると、すべてのタブ名が表示されます。この選択は Settings に記憶されます。フォルダーの優先設定と推薦設定はアカウントごとにサーバーへ保存され、端末間で共有されます。未設定時は既存のインスタンス既定値を使用します。推薦設定を保存すると現在のタブだけ新しい推薦セッションを使い、他のタブは既存のスナップショットを保持します。Maintenance は Library、Cache & Fetch、Proxy、Cleanup、Users で構成され、全体の推薦統計は Library 内の折りたたみ領域に残ります。外観は右上のメニュー、UI 言語はアバターのアカウントメニューで設定し、地球アイコンはブラウザーまたは端末の言語への追従を表します。ログインしているすべてのユーザーには UI 言語のすぐ下に「優先表示するメタデータ言語」も表示されます。これは個人の選択で、そのユーザーに表示するタイトルの版、紹介文、タグ名を決めます。選択肢は「原版」、日本語、英語、簡体字中国語、繁体字中国語、韓国語です。選んでいない場合は「原版」と表示され、各作品の原語を使います。「原版」を選ぶと設定が解除されます。選んだ言語の版がない場合は原版を使います。プロキシは Proxy タブで優先度順に追加し、「プロキシの適用範囲」で DLsite、リモートソース（ソースごとの上書きも可能）、その他のリクエストに適用します。「このマシン」のプロキシはコンテナーからホストへ接続するアドレスを表示するだけで編集できず、プロトコル、ポート、任意の認証情報を設定します。「直接接続へのフォールバック」（既定はオフ）をオンにすると、すべてのプロキシに接続できなかったリクエストをプロキシなしで 1 回だけ再試行します。Metadata の設定にある「DLsite プロキシ」は DLsite の適用範囲と同じスイッチです。Demo ではアカウント設定を変更できません。管理タブ（Library、Cache & Fetch、Proxy、Cleanup、Users）と個人データの画面は閲覧用に表示されますが、変更はできません。
