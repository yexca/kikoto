# 設定

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定はサーバー、ユーザー、ブラウザに保存される動作を管理します。

## 主要内容

- UI 言語、テーマ、表示密度、作品グリッド列数を設定します。
- 再生速度、シーク時間、互換再生範囲を保存します。
- サーバー接続、ソース、メタデータ言語、スキャン、watcher、`Follow-up run` を管理します。
- 個人タグ、お気に入り、再生状態をユーザーごとに保持します。

## 作品管理

サイドバーの **作品管理** → **要対応の作品**に、確認が必要な既存作品をまとめます。**要確認のすべて**、**メタデータの問題**、**利用可能なソースなし**で絞り込めます。検索、ページ分割、カバー、選択を共用し、一つの作品ファミリーを一行で表示します。複数の理由を表示でき、詳細を開くと対象の版とプロバイダーを確認できます。更新成功で解消されるのは該当する問題だけで、ソースがない作品は残ります。

作品を選んで**メタデータを再試行**すると、対象件数がボタンに表示されます。詳細から特定の版も再試行でき、取得不可と報告された作品も再確認できます。失敗しても既存情報と手動の上書きは保持されます。ソース確認は選択したソースのない作品だけが対象です。ローカル情報の削除は「利用可能なソースなし」の画面に限定され、確認後にサーバーが利用状態を再検証します。メディアファイルは保持します。

Activity と Workflows は維持します。Activity の問題一覧ボタンは、その実行の未解決メタデータ問題で絞り込んだ作品メンテナンスを開きます。すべての要対応作品を表示すると実行の絞り込みが解除されます。他のユーザーのレビュー状態は変更しません。復旧には `metadata:sync`、ソース確認・削除・ソースと言語の設定には `sources:write` が必要です。**メタデータ設定** タブで言語の優先順位、ソースのリクエスト言語、カタログの鮮度を管理します。同期のショートカットは既存の Workflows を開き、設定を重複させません。従来の Maintenance リンクもこのページへ移動します。
