# 設定

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定はサーバー、ユーザー、ブラウザに保存される動作を管理します。

## 主要内容

- UI 言語、テーマ、表示密度、作品グリッド列数を設定します。
- 再生速度、シーク時間、互換再生範囲を保存します。
- サーバー接続、ソース、メタデータ言語、スキャン、watcher、`Follow-up run` を管理します。
- 個人タグ、お気に入り、再生状態をユーザーごとに保持します。

## メンテナンス

Maintenance のタブは横一列で、狭い画面では横スクロールできます。Overview は廃止し、Library にローカルスキャン、リモートソース、読み取り専用の保存パスをまとめました。ソース管理者は Library、ユーザー管理権限のみの場合は Users が初期画面です。Users にはユーザー管理とスーパー管理者向けのアクセス設定をまとめています。従来の Paths と Access のリンクは、それぞれ Library と Users に移動します。

リモートソースは、状態、ホスト、ヘルスチェック、即時保存される有効スイッチを持つ簡潔な一覧です。**ソースを追加** ではアドレスを 1 つ入力するだけで、入力どおりのアドレス、そのオリジン、一般的な `api.` サブドメインを順に調べ、API URL、公開サイト、名前を自動入力します。検出できない場合は **接続の詳細** が開き、手動で入力できます。エンドポイント、優先度、ネットワークと保存先の設定は折りたたまれています。Cache & Fetch は設定のみになり、キャッシュの内容は **クリーンアップ** タブで管理します。おすすめ設定には、ログイン中のユーザー自身の過去 30 日間の統計を示す折りたたみ式の **あなたのおすすめアクティビティ** を追加しました。

## クリーンアップ

**クリーンアップ** は設定の Cache & Fetch の次にある管理者向けタブです（`/settings?tab=cleanup`）。キャッシュ部分には `downloads:manage`、データベース部分には `sources:write` が必要です。トランスコードキャッシュと管理メディアキャッシュの使用量と削除に加え、データベースのレコードを整理できます。対象は、ディスク上に存在しないことを確認した作品フォルダとローカルファイル（空になったトラック項目とローカル可用性を含む）、孤立したメタデータスナップショット、使われていないソースタグ、期限切れセッション、閉じた通知、90 日より前のワークフロー履歴とおすすめシグナル、使われていないおすすめスナップショットです。個人タグ、レビュー・Fetch 記録・メタデータの問題を含む実行、各ワークフローの最新の実行は残ります。整理には確認が必要で監査ログに記録され、メディアファイルは削除されません。データフォルダがない、または空の場合はパスの確認を停止します。**ソースのない作品** はメタデータの **利用可能なソースなし** に移動し、**データベースを最適化** は空きページをディスクに返します。

## メタデータ

サイドバーの **メタデータ** は **ワークフロー** の直下にあります。横並びの **すべて**、**要対応**、**メタデータの問題**、**利用可能なソースなし** で絞り込みます。すべてには問題のない保存済み作品ファミリーも含まれます。検索、ページ分割、カバー、選択、対象の版とプロバイダーの詳細を共用します。

右上の **メタデータ設定** はダイアログを開き、閉じても一覧と絞り込みを保持します。**メタデータ同期** は既存の同期ワークフローを開き、対象を選んで実行できます。

作品を選んで**メタデータを再試行**すると、対象件数がボタンに表示されます。詳細から特定の版も再試行でき、取得不可と報告された作品も再確認できます。失敗しても既存情報と手動の上書きは保持されます。ソース確認は選択したソースのない作品だけが対象です。ローカル情報の削除は「利用可能なソースなし」の画面に限定され、確認後にサーバーが利用状態を再検証します。メディアファイルは保持します。

Activity と Workflows は維持します。Activity の問題一覧ボタンは、その実行の未解決メタデータ問題で絞り込んだ作品メンテナンスを開きます。すべての要対応作品を表示すると実行の絞り込みが解除されます。他のユーザーのレビュー状態は変更しません。復旧には `metadata:sync`、ソース確認・削除・ソースと言語の設定には `sources:write` が必要です。**メタデータ設定** ダイアログで言語の優先順位、ソースのリクエスト言語、カタログの鮮度を管理します。同期のショートカットは既存の Workflows を開き、設定を重複させません。従来の Maintenance リンクもこのページへ移動します。

メタデータ画面の正式な URL は `/metadata` です。従来の `/work-management` リンクも絞り込みや設定を保持して移動します。初回同期の失敗や未解決のメタデータ問題はこの画面を開きます。ワークフロー権限がない場合、実行別の絞り込みを付けません。実行の診断は Workflows の Activity で確認できます。

Settings は Account、Playback、Recommendation の構成です。フォルダーの優先設定と推薦設定はアカウントごとにサーバーへ保存され、端末間で共有されます。未設定時は既存のインスタンス既定値を使用します。推薦設定を保存すると現在のタブだけ新しい推薦セッションを使い、他のタブは既存のスナップショットを保持します。Maintenance は Library、Cache & Fetch、Users のみとなり、全体の推薦統計は Library 内の折りたたみ領域に残ります。外観は右上のメニューで設定し、地球アイコンはブラウザーまたは端末の言語への追従を表します。Demo ではアカウント設定を変更できません。
