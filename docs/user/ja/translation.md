# 翻訳
[English](../en/translation.md) · [简体中文](../zh-Hans/translation.md) · [繁體中文](../zh-Hant/translation.md) · [日本語](../ja/translation.md) · [한국어](../ko/translation.md)

**翻訳** ページ（`/translation`）は、ライブラリ全体の[AIで翻訳](work-detail.md#aiで翻訳)を追跡します。実行中またはキュー待ちのもの、停止したもの、完了した翻訳が書き込んだもの、そして各言語で作品がどこまで揃っているかを確認できます。ライブラリの書き込み権限を持つアカウントのサイドバーから開き、ワークフローの権限は必要ありません。開けるユーザーには、すべてのアカウントの翻訳が表示されます。各項目は、[結果](work-detail.md#結果)に記載のとおり、完了するとすぐに適用されます。

このページは、AIで翻訳の実行とその項目を表示するビューです。[ワークフロー](workflows.md)のアクティビティは、同じ実行を診断情報とともに一覧します。

## 処理中

**処理中**（`?view=running`）は、このページが最初に開くビューで、翻訳中の実行、次にキュー待ちの実行を、作品ごとに 1 枚のカードで一覧し、各翻訳先の言語を独自の行に、その段階（待機中、完了した項目数とともに翻訳中、完了）とともに表示します。

自分が開始した実行は、ワークフローの権限がなくても **キャンセル** できます。ワークフロー管理者は、ほかのアカウントの実行もキャンセルできます。まだ送っていないものはすべて停止し、すでに送った翻訳のリクエストは結果不明の状態を保ちます。ワークフローの権限を持つアカウントには **アクティビティ** も表示され、その実行の診断情報を開きます。

## 停止

**停止**（`?view=attention`）は、失敗した項目、結果が不明な項目、期限切れになった項目、コンテンツ安全ポリシーがブロックした項目を、作品、言語、カテゴリーごとにグループ化して、それぞれ理由とともに一覧します。**再送信** は、失敗した項目を同じ実行に再びキューに入れます。結果を書き込めなかった項目（たとえばフォルダーがブロックされた歌詞）は、追加のリクエストなしで、保持された結果から書き込まれます。接続の切断、サーバーの停止、キャンセルなどで応答を失ったリクエストは、すでにプロバイダーに課金されている可能性があるため、**再送信** はまず確認を求めます。元のデータ、プロバイダー、コンテンツポリシーが変わった項目は、作品からの新しいリクエストで再び翻訳されます。

## 履歴

**履歴**（`?view=history`）は、完了した項目が書き込んだ内容を新しい順に、作品ごとにグループ化して一覧し、各作品へのリンクが付きます。タイトル、説明、その言語のタグ名または表示名、そして歌詞の項目が作成したファイルです。

## カバレッジ

**カバレッジ**（`?view=coverage`。`&language=` と `&missing=` を付けられます）は、カタログ作品もカスタム作品も含むすべての作品が、1 つの対象言語でどこまで利用できるかを示します。`/metadata?view=translation` のリンクもこのビューを開きます。**対象言語** はインターフェース言語で始まります。**表示** は、何かが足りない作品（初期値）、タイトル・説明・タグ名・ファイル名・歌詞のいずれかが足りない作品、完了した作品、またはすべての作品を一覧します。**タイトル** と **説明** は、その言語のテキストの出どころを示します。**原文** はその言語が作品の原版の言語である場合、**公式版** は作品のその言語の版、**手動** はその言語の手動のタイトルまたは説明、**LLM** は AI 翻訳、**なし** はいずれもない場合です。**タグ** はその言語の名前がある作品の共有タグの数、**ファイル名** はその言語の表示名があるローカルファイルの数、**歌詞** はその言語の歌詞が割り当てられたローカルトラックの数を示します。ダッシュは数える対象がないことを意味し、ファイル名は作品の原語では **原文** と表示されます。チェックは完了したものに付き、足りない部分は注意色になります。行には、その言語への作品の翻訳のうち実行中のものも表示されます。幅の広い画面では各部分が個別の列になり、狭い画面ではタイトルの下に一覧されます。

作品を選んでヘッダーの翻訳ボタンを押すと、選んだモデルで、各作品に足りないもの（タイトル、説明、共有タグ名、ファイル名とフォルダー名）をその言語に翻訳します。カテゴリーは、選んだ作品のいずれかに足りない部分で始まります。足りないものがない作品はスキップされます。歌詞は、各作品自身のAIで翻訳でトラックごとに選びます。結果は **履歴** に表示されます。

ページは、実行が進行中の間は数秒ごとに自動で更新されます。スマートフォンでは、ビューは横にスクロールする 1 行になります。
