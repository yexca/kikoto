# 声優

[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

声優画面は声優カタログと関連 Work の可用性を表示します。

## 主要内容

- 声優を検索し、カタログをページング表示します。
- カタログ更新、詳細表示、お気に入り、個人タグ、評価、メモを提供します。
- 詳細の **初回取得**・**更新**・**メタデータを再試行** は、既知作品のメタデータだけを更新する「声優をフォロー」の実行をキューに追加します。**その他** メニューには声優のフォローと別名の管理があります。
- 関連作品は Library と同じカードで表示し、Local、Cache、Tracked、リモート状態を示します。
- カタログ項目は Work のメタデータや再生位置を直接作成しません。
