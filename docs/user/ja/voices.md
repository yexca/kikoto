# 声優
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

声優のページでは、保存されている人物とクレジットのデータを表示します。

## 現在の動作

- ローカルのプロバイダークレジットとユーザーが管理する人物データから声優を一覧表示し、
  各制作者カードにローカルとリモートの利用可能状態バッジを表示します。
- サーバー側でページ分割され URL に保持される一覧の検索とフィルターを使用します。
  短めでレスポンシブな制作者カード、動的なユーザータグの行、ライブラリと同じ形式のページ移動、
  および最新の既知のクレジット作品のカバーを備えます。
- ライブラリと同じ形式の 1 行目ツールバーを使用し、検索は左側に、ページサイズと既存の
  声優フィルター操作（既定は `すべての声優`）は右側に配置されます。幅の狭いレイアウトでは、
  検索がツールバーの操作にまとめられます。ユーザータグは引き続き表示され検索もできますが、
  現時点では一覧にタグのフィルターはありません。
- お気に入り、評価、メモ、ユーザータグの状態を表示します。
- 確認済みの別名を詳細のタイトルの下に表示します。別名のレビュー、重複のマージ、マージの取り消しは
  メタデータページの **声優** ビューにあり、`metadata:sync` を持つユーザーには、
  詳細の **その他** メニューからそこへのリンクが表示されます。
- プロバイダーの声優クレジットがない作品は、`unknown` のグループにまとめます。
- 声優の詳細では、ローカルとリモートの利用可能状態バッジに続けてユーザータグを表示します。
  キャッシュは再生とフィルタリングのデータでは引き続き利用されますが、ローカルとしては
  表示されません。
- 既知の作品とリモートの作品を、ライブラリと同じレスポンシブなグリッドと共通の作品カードで
  表示します。作品カード上の DLsite タグまたは個人タグを選択すると、そのタグのローカルな
  ライブラリ検索が開きます。
- 人物の詳細、既知の作品、リモートの一致結果は、それぞれ独立して読み込まれます。リモート
  ソースの検索は並行数を制限して行われ、声優の件数とユーザータグはバッチで集計されます。
- 詳細サマリーには、お気に入り、よく使う更新操作、**その他** メニューがあります。
  **初回取得** または **更新** は、互換性のあるすべてのリモートソースにわたって、既知の作品の
  メタデータのみを対象とする声優をフォロー（Follow a voice actor）の実行をキューに追加し、
  **メタデータを再試行** は、既知の作品にまだメタデータがない間だけ表示されます。
  実行が完了するまでボタンには **更新中** と表示されます。同期状態の横の警告は、直近の処理で
  失敗したリモートソースの数を示し、クリックするとその実行がアクティビティで開きます。
  **その他** には、ソース、フィルター、メタデータ、タグの選択でこの声優を選択した状態で
  プリセットを開く **この声優をフォロー…** と、**別名を管理** があります。作品ツールバーは
  ライブラリと同様で、左側に幅が制限された検索、右側に列数、ページサイズ、利用可能状態の
  フィルター、選択がさりげないアイコン操作として並び、共通のコレクションのページ移動が
  グリッドの上下に表示されます。モバイルの作品検索は 1 行のままで、フィルター、列数、
  選択のコントロールは別のオプションシートから開きます。
- モバイルの詳細画面の戻るコントロールは、サーバーとユーザーごとに記録された最後の
  声優一覧の位置への「上へ」として動作します。詳細をライブラリやお気に入りから開いた場合も
  同様です。幅の広いレイアウトでは、ソースを考慮した履歴の戻りを維持します。

## 境界

DLsite は引き続き、既知の作品に対するメタデータプロバイダーです。Kikoto は、DLsite の
キーワードクロールを信頼できる声優カタログとしては扱いません。

## レビューの動作

別名とマージのツールは、重複した人物レコードを統合する際に、ユーザーの状態を保持し、
マージの取り消しを見える状態に保つ必要があります。
