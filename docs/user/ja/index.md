## 製品の原則

- 作品は、ローカル、キャッシュ、追跡済み、リモートの各ソースで利用可能な状態であっても、
  統合された 1 つの項目として表示されます。
- リモートソースが失敗しても、ローカルとキャッシュの状態は引き続き利用できる必要があります。
- リモートソースに対する操作は明示的に行います。同期はソースのデータを更新し、
  キャッシュはキャッシュファイルを実体化し、取得（Fetch）は選択したファイルをローカルの
  データツリーに昇格させます。
- 長時間かかる操作やレビューが必要な操作は、アクティビティに表示されます。
