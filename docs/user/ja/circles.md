# サークル

[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

サークルは制作者と公開カタログの状態を表します。

## 主要内容

- サークルを検索、フィルター、ページング付きで表示します。
- お気に入り、個人タグ、評価、メモを管理します。
- DLsite コード、カバー、同期状態、`Available N/total` を表示します。
- カタログ行は Work と分けて保存し、作品結果は Library と同じグリッドを使います。
- 詳細の **初回取得**・**サークルを更新**・**メタデータを再試行** は、フィルターとタグなしの「サークルをフォロー」の実行をキューに追加してすぐに戻ります。実行は Activity で確認できます。**その他** メニューの **このサークルをフォロー…** から、カタログ更新・フィルター・メタデータ・タグ・ソース確認を自由に組み合わせられます。既存作品のメタデータを更新するには、サークルを対象にメタデータ同期を実行します。

カタログは公開内容を説明します。Sync または Fetch がメディア位置を作成するまで再生場所は作りません。
