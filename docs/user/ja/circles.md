# サークル
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

サークルのページでは、制作者、サークル、および関連する当事者のカタログの状態を扱います。

## 現在の動作

- 既知の当事者を、サーバー側でページ分割した結果として一覧表示します。各カードにはカタログと
  利用可能状態が表示されます。
- 検索、フィルター、URL に保持されるページ移動、お気に入りの状態、ユーザータグ、評価、メモを提供します。
- 検索、ワンタップの表示チップ、ページサイズ操作を、折り返す 1 つのツールバー行に
  配置します。チップは `すべてのサークル`、`お気に入り`、`タグ付き`、`利用可能`、
  `ローカル`、`リモート`、`不足`、`要確認` で、押された状態のチップが現在の表示を示します。
  スマートフォンでは検索欄が単独で 1 行を使い、その横にページサイズが並び、
  チップはその下で横にスクロールします。
- 各サークルをカバータイルとして表示します。サークルのカバー（ない場合は `カバーなし` で
  代替表示）、カバー上のお気に入り操作、名前、最新のリリース日、個人タグを備えます。
  タイルは幅の広いレイアウトでは行を埋め、スマートフォンでは 2 列になります。
- 最新の既知の DLsite 作品のローカルにキャッシュされたカバー画像を、サークルのカバーとして
  使います。詳細の **その他** メニューにある **カバーを変更…** は、サークルの作品を検索付きで
  一覧表示し、選んだ作品のカバーをタイルと詳細サマリーでのサークルのカバーにします。同じ
  ダイアログの **最新作品** は、新作が出るたびに切り替わるカバーに戻します。この選択は
  操作したアカウントに属し、選んだ作品がサークルのカタログから外れた場合は、最新作品の
  カバーに切り替わります。
- 各サークルタイルには、同期状態、1 つの標準的な `利用可能 N/total` の件数、
  利用可能状態バーを表示します。バーは、ローカルのコピーがある作品を濃い区間、
  リモートソースにだけある作品を薄い区間、それ以外を空のトラックで示します。
- サークルの詳細は外部 ID で表示します。
- サークルのカタログ作品はサーバー側でページ分けします。カタログ総数は完全な値を保ち、検索、利用状況、シリーズの絞り込みと選んだ並び順をページ分け前に適用します。まとめて選択できるのは読み込み済みのページです。
- カタログ作品を **発売日**、**コード**、**タイトル**、**評価**、**売上** の順に、昇順または
  降順で並べ替えます。既定は発売日の新しい順です。評価または売上のない作品は、どちらの方向でも
  最後に並びます。並び順とページサイズ（24、48、96 件）は、アカウントごとにこの端末へ記憶され、
  すべてのサークルに適用されます。
- カタログの更新を、増分モードまたはフルモードで実行できます。
- カタログの行は、取り込み済みの作品とは別に保存されます。
- カタログの作品に、ローカル／キャッシュ／リモートの各ソースの利用可能状態のタグを表示します。
- 作品の結果は、ライブラリと同じレスポンシブなグリッドと作品カードで表示します。これは
  サークルの詳細とサークルのシリーズの両方に適用されます。サークル単位の一覧は独自の操作を
  維持します。作品カード上の DLsite タグまたは個人タグを選択すると、そのタグのローカルな
  ライブラリ検索が開きます。
- サークルの詳細サマリーは、カバーの色合いを帯びたパネルに、サークルの別名と個人タグとともに
  表示します。**利用可能**、**ローカル**、**リモート**、**利用不可** の各件数は利用可能状態バーの
  横に並び、下の作品がどのように絞り込まれていても、カタログ全体を表します。
  一度も取得したことのないサークルでは、ライブラリがすでに把握している作品だけが
  一覧に表示されることを示し、それ以外の場合はカタログの最終同期の時刻を表示します。
  シリーズカードにも同じ利用可能状態バーがあります。
- よく使う更新操作は詳細サマリーにまとまっています。一度も取得したことのないサークルには
  **初回取得**、続いてリモートソースも確認する **サークルを更新** が表示されます。
  **メタデータを再試行** は、カタログの作品にまだメタデータがない間だけ表示され、
  それらの作品だけを補完します。各操作は、フィルターやタグを指定しないサークルのカタログを同期
  （Sync a circle catalog）の実行をキューに追加してすぐに戻ります。実行が完了するまでボタンには
  **更新中** と表示され、実行内容はアクティビティで確認できます。
- **お気に入り** の横のベルはサークルの新作を購読し、シリーズの DLsite リンクの横のベルは
  そのシリーズを購読します。[見つける](discover.md#購読する)を参照してください。購読中のサークルの
  シリーズは、すでに含まれています。
- **その他** メニューには **カバーを変更…** と **このサークルのカタログを同期…** があります。後者は
  このサークルが入力済みのサークルのカタログを同期（Sync a circle catalog）プリセットを開き、カタログ更新、フィルター、メタデータ、
  タグ、ソース確認のそれ以外の組み合わせをすべて指定できます。サークルの作品がすでに
  持っているメタデータを更新するには、サークルのスコープでメタデータ同期を実行します。
- モバイルでは一般的な詳細操作を短縮し、アイコンのみの お気に入り、その他、DLsite の
  コントロールにも名前でアクセスできるようにして、DLsite を最後に配置します。
- 幅の広いレイアウトでは、ライブラリと同じ形式の作品ツールバーを使用します。左側には
  作品／シリーズの切り替えと幅が制限された検索、右側には現在の並び順を示す並べ替えボタン、
  表示オプション、利用可能状態のフィルター、選択が並びます。表示オプションには、
  ライブラリと共通の **カード** の選択（**フル**、**コンパクト**、**ミニ**）、列数、ページサイズが
  あり、新しく選んだカードのモードはその[プリセット](library.md#現在の動作)から始まります。
  共通のコレクションのページ移動はグリッドの上下に表示されます。
- モバイルの作品コントロールは、作品／シリーズの切り替えとその横の並べ替えボタン、検索、そして
  1 つの **カタログのオプション** 操作だけに絞られます。利用可能状態、カードの
  表示モード、モバイルの列数、ページサイズ、選択モードはそのシートの中にあり、幅の広いレイアウトでは引き続き
  インラインのコントロールが表示されます。シリーズの一覧はシリーズを一覧表示するだけで、
  並べ替えはありません。
- モバイルの詳細画面の戻るコントロールは、サーバーとユーザーごとに記録された最後の
  サークル一覧の位置への「上へ」として動作します。詳細をライブラリから開いた場合も同様です。
  幅の広いレイアウトでは、ソースを考慮した履歴の戻りラベルと遷移先を維持します。
- 古くなったカタログの行は、確認後に削除できます。

## 境界

サークルのカタログは、その当事者が何を公開してきたかを説明するものです。ソースの同期または
取得がメディアの場所を作成するまで、具体的な再生場所は作成されません。

## 更新の動作

増分更新は、新しいカタログの行を優先し、既知の行に到達した時点で停止する必要があります。
フル更新はプロバイダーのより多くのページをたどれますが、古いカタログの行を自動的に削除してはいけません。
