# 記録

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](record-library.md) · [한국어](../ko/record-library.md)

記録は個人の動画、画像、音声ファイルを扱う独立したライブラリです。`/record` マウントを使用し、音声ライブラリや作品にはファイルを追加しません。

## 設定

記録は、管理者がオンにするまでオフです。ホストのフォルダーを `/record` にマウントし、**システム → ライブラリ**の**記録**で**記録ライブラリ**をオンにして、**ルートを初期化**を選択します。Kikoto は `.kikoto-record` マーカーを書き込み、明示的な初期化後だけスキャンを開始します。記録がオフの間は、すべてのアカウントでサイドバーに表示されません。オフにしてもフォルダー、視聴位置、サムネイルは保持され、再びオンにすると利用できます。既定の本番マウントは次のとおりです。

```yaml
volumes:
  - ./record:/record
```

フォルダーの深さに制限はなく、ページでも同じツリーを閲覧できます。

## 閲覧

記録は一度に 1 つのフォルダーを表示します。上部のパスバーが現在のフォルダーを示し、それを含む任意のフォルダーへ戻れます。右端には**続きを見る**と**スキャン**（スキャン権限のないアカウントでは**更新**）があります。アドレスには開いているフォルダーが保持されるため、ブラウザーの戻る・進む・再読み込みで同じ場所に戻り、Backspace キーでも 1 つ上のフォルダーへ戻れます。

項目は名前の自然順で、サブフォルダー、動画、写真、フォルダー内のその他のファイルの順に並びます。複数の種類があるフォルダーではセクション見出しが表示されます。サブフォルダーは正方形のタイルで表示され、ポスター、ポスターがなければ背景画像、どちらもなければフォルダーのアイコンを表示します。動画は、動画のフレーム、長さ、視聴済みの割合を示すバーを付けたワイドタイルで、写真は正方形のサムネイルで表示されます。サムネイルはフォルダーが初めて表示されるときに作成されるため、大きなフォルダーでは初回に少し時間がかかることがあります。フォルダーの artwork 画像は表示されません。

**ファイル**には、フォルダー内のそれ以外のファイルが 1 行ずつ、種類とサイズとともに表示されます。音声ファイルは長さと再生済みの割合を示すバー付きで、字幕、メタデータ、その他のファイルも並びます。音声ファイルを選ぶと再生されます。

どのフォルダーからでも右上の**続きを見る**を開くと、途中まで視聴した動画と音声ファイルが新しい順に、それぞれが入っているフォルダーとともに表示されます。1 つを選ぶと止めた位置から再生され、プレーヤーを閉じると開いた元のフォルダーに戻ります。

## スキャンと artwork

パスバー右上の**スキャン**を選びます。ライブラリの書き込み権限が必要です。ボタンにポインターを合わせるとルートが最後にスキャンされた時刻を確認でき、スキャンを開始した後は、キュー済み、実行中、完了のいずれの状態かが表示されます。スキャンは永続ワークフローとしてキューに入り、実行中のスキャンと統合されます。拡張子で通常ファイルを索引し、リンクと Kikoto のトランザクションディレクトリをスキップします。ルートがオフライン、またはスキャンが一部だけ完了した場合は既存の記録を保持し、完全なスキャンだけが削除されたフォルダーとファイルを見つからない状態にします。スキャンは、新規または変更された各動画の長さとサイズ、新規または変更された各写真のサイズも読み取ります。読み取れなかったファイルは長さを持たず、変更されると再び読み取られます。

フォルダー artwork は `folder`、`poster`、`cover` をポスターに、`backdrop`、`fanart`、`background` を背景に使います。対応する動画拡張子は `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v`、`.ts`、対応する音声拡張子は `.mp3`、`.m4a`、`.aac`、`.flac`、`.wav`、`.ogg`、`.opus`、`.wma`、`.aiff`、`.mka`、画像拡張子は `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif` です。

## 動画と写真の視聴

動画を選ぶと、映像とコントロールを画面に合わせる全画面のプレーヤーで開きます。プレーヤーには、[作品の動画プレーヤー](work-detail.md#現在の動作)と同じ画面上のコントロール、タッチ操作、**字幕**メニュー、キーボードショートカットがあります。パソコンでは、上部のキーボードボタンでショートカットの一覧を表示できます。スマートフォンでは、動画は再生開始時に全画面表示に切り替わり、横長の動画は全画面表示が終わるまで画面が横向きになります。iPhone と iPad では、**全画面表示**でシステムのプレーヤーが開きます。途中まで視聴している場合、Kikoto はその位置から**続ける**か**最初から**かを尋ねます。MPEG-TS（`.ts`）の録画や、HEVC に対応しないブラウザーでの HEVC など、ブラウザーがそのまま再生できない動画は、ライブラリの動画と同じ方法で再生されます。ブラウザーが映像をデコードできる場合、サーバーは再エンコードせずにパッケージし直し、そうでない場合は変換します。動画と同じ名前の `.vtt` または `.srt` ファイルは、その動画の字幕として表示されます。`.srt` ファイルは UTF-8 である必要があります。動画に埋め込まれたテキスト字幕も選択できます。前へ・次へのボタンでフォルダー内の動画を順に切り替え、戻る操作または Esc でプレーヤーを閉じます。

ヘッドフォンボタン（**音声のみ**）を押すと、動画を音声だけで再生します。プレーヤーは音声だけを読み込み、動画のフレームまたはフォルダーのポスターを表示します。切り替えても同じ位置から続き、この端末が選択を記憶して次の動画にも適用します。音声ファイルも同じプレーヤーで開き、フォルダー内の音声ファイルを順に切り替えます。動画の音声と同様に、そのまま、または変換して再生されます。

再生位置はアカウントごとに、約 10 秒ごと、一時停止時、終了時、プレーヤーを閉じるときに保存されます。保存にはライブラリの書き込み権限が必要です。動画または音声ファイルの再生が始まるとグローバル音声プレーヤーは一時停止し、プレーヤーを閉じた後も一時停止したままです。

写真を選ぶと全画面で表示されます。矢印ボタン、矢印キー、横方向のスワイプでフォルダー内の写真を順に切り替え、戻る操作または Esc で閉じます。写真は画面に合わせて開き、クリックすると実寸で表示し、もう一度クリックすると画面に合わせます。マウスホイール、トラックパッドや 2 本指のピンチ、`+`・`-`・`0` キーで実寸の 8 倍まで任意の倍率に拡大でき、拡大した写真はドラッグでパンできます。
