# 記録

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](record-library.md) · [한국어](../ko/record-library.md)

記録は個人の動画、画像、音声ファイルを扱う独立したライブラリです。`/record` マウントを使用し、音声ライブラリや作品にはファイルを追加しません。

## 設定

記録は、管理者がオンにするまでオフです。ホストのフォルダーを `/record` にマウントし、**システム → ライブラリ**の**記録**で**記録ライブラリ**をオンにして、**ルートを初期化**を選択します。Kikoto はこのルートを示す `.kikoto-record` マーカーを書き込み、明示的な初期化後だけスキャンを開始します。別の場所で記録用に初期化済みのものを含め、別のディスクを `/record` にマウントした場合、記録はオフラインと表示され、このライブラリはそのまま保たれます。そのディスクで確認のうえ**新しいカタログを始める**を選択すると、そのディスクが記録のルートになり、ライブラリは最初からやり直しになります。以前のディスクのフォルダーと視聴位置は消去されます。フォルダーはあるのに `.kikoto-record` マーカーがなくなった場合、記録はライブラリを保持します。全員が引き続き閲覧と再生ができ、スキャンは新しいファイルを追加しますが、どれも見つからないとはしません。ファイルは削除できません。**システム → ライブラリ**の**記録**で**マーカーを復元**を選ぶと、ライブラリのフォルダーがあるディスクがマウントされていればマーカーを書き直してライブラリを保持し、確認のうえ**新しいカタログを始める**を選ぶとライブラリを破棄し、次のスキャンでフォルダーを最初から登録します。ディスクがマウントされていないときに残るような空のフォルダーでは、新しいカタログを始められません。先にディスクをマウントするか、フォルダーにファイルを追加してください。記録がオフの間は、すべてのアカウントでサイドバーに表示されません。オフにしてもフォルダー、視聴位置、サムネイルは保持され、再びオンにすると利用できます。既定の本番マウントは次のとおりです。

```yaml
volumes:
  - ./record:/record
```

フォルダーの深さに制限はなく、ページでも同じツリーを閲覧できます。

## 閲覧

記録は一度に 1 つのフォルダーを表示します。上部のパスバーが現在のフォルダーを示し、それを含む任意のフォルダーへ戻れます。右端には**続きを見る**と**スキャン**（スキャン権限のないアカウントでは**更新**）があります。アドレスには開いているフォルダーが保持されるため、ブラウザーの戻る・進む・再読み込みで同じ場所に戻り、Backspace キーでも 1 つ上のフォルダーへ戻れます。

項目は名前の自然順で、サブフォルダー、動画、写真、フォルダー内のその他のファイルの順に並びます。複数の種類があるフォルダーではセクション見出しが表示されます。サブフォルダーは正方形のタイルで表示され、ポスター、ポスターがなければ背景画像、どちらもなければフォルダーのアイコンを表示します。動画は、動画のフレーム、長さ、視聴済みの割合を示すバーを付けたワイドタイルで、写真は正方形のサムネイルで表示されます。動画の名前の横にある **音声として再生** を押すと、止めた位置からその動画の音声がグローバル音声プレーヤーで再生され、フォルダー内の他の動画が音声としてその後ろにキューされます。サムネイルはフォルダーが初めて表示されるときに作成されるため、大きなフォルダーでは初回に少し時間がかかることがあります。フォルダーの artwork 画像は表示されません。

**ファイル**には、フォルダー内のそれ以外のファイルが 1 行ずつ、種類とサイズとともに表示されます。音声ファイルは長さと再生済みの割合を示すバー付きで、字幕、メタデータ、その他のファイルも並びます。カバーアートを持つ音声ファイルは、その行にカバーアートが表示されます。音声ファイルを選ぶと、[音声を聴く](#音声を聴く)のとおりに再生されます。

どのフォルダーからでも右上の**続きを見る**を開くと、途中まで視聴した動画と音声ファイルが新しい順に、それぞれが入っているフォルダーとともに表示されます。1 つを選ぶと止めた位置から再生されます。動画はフォルダーの上に開き、プレーヤーを閉じると開いた元のフォルダーに戻ります。音声ファイルはそのフォルダーを開き、グローバル音声プレーヤーで再生されます。

## スキャンと artwork

パスバー右上の**スキャン**を選びます。ライブラリの書き込み権限が必要です。ボタンにポインターを合わせるとルートが最後にスキャンされた時刻を確認でき、スキャンを開始した後は、キュー済み、実行中（見つかったファイル数を含む）、完了のいずれの状態かが表示されます。スキャンは永続ワークフローとしてキューに入り、実行中のスキャンと統合されます。拡張子で通常ファイルを索引し、リンクと Kikoto のトランザクションディレクトリをスキップします。ルートがオフライン、またはスキャンが一部だけ完了した場合は既存の記録を保持し、完全なスキャンだけが削除されたフォルダーとファイルを見つからない状態にします。新しいファイルはスキャンが終わるとすぐに閲覧できます。

スキャンはファイルを見つけるだけです。新規または変更された各動画の長さと、新規または変更された各音声ファイルの長さおよびカバーアートの有無は、そのフォルダーを開いたときに読み取られ、数秒後に長さとカバーが表示されます。再生したファイルと、フォルダーがサムネイルを表示するファイルも、その時点で読み取られます。音声ファイルは、読み取られるとカバーが表示され、カバーがなければアイコンが表示されます。

すべてのファイルを一度に読み取るには、[ワークフロー](workflows.md#ユーザー画面)の**メディア情報**カードから**記録のメディア情報を読み取る**を実行するか、そのカードにトリガーを追加して起動時または定期的に実行します。**記録のスキャン**カードからは手動でスキャンを開始できます。実行中は、**スキャン**の横の状態に読み取り済みのファイル数が表示され、終わるとフォルダーに長さが表示されます。ほかの処理が待っているときはファイルの合間に一時停止するため、大きなライブラリでもほかのワークフローを止めません。記録フォルダーがマウントされていない間は何も読み取られません。読み取れなかったファイルは長さを持たず、変更されると再び読み取られます。

フォルダー artwork は `folder`、`poster`、`cover` をポスターに、`backdrop`、`fanart`、`background` を背景に使います。対応する動画拡張子は `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v`、`.ts`、対応する音声拡張子は `.mp3`、`.m4a`、`.aac`、`.flac`、`.wav`、`.ogg`、`.opus`、`.wma`、`.aiff`、`.mka`、画像拡張子は `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif` です。

## 動画と写真の視聴

動画を選ぶと、映像とコントロールを画面に合わせる全画面のプレーヤーで開きます。プレーヤーには、[作品の動画プレーヤー](work-detail.md#現在の動作)と同じ画面上のコントロール、タッチ操作、**字幕**メニュー、キーボードショートカットがあります。パソコンでは、上部のキーボードボタンでショートカットの一覧を表示できます。スマートフォンでは、動画は再生開始時に全画面表示に切り替わり、横長の動画は全画面表示が終わるまで画面が横向きになります。iPhone と iPad では、**全画面表示**でシステムのプレーヤーが開きます。途中まで視聴している場合、Kikoto はその位置から**続ける**か**最初から**かを尋ねます。MPEG-TS（`.ts`）の録画や、HEVC に対応しないブラウザーでの HEVC など、ブラウザーがそのまま再生できない動画は、ライブラリの動画と同じ方法で再生されます。ブラウザーが映像をデコードできる場合、サーバーは再エンコードせずにパッケージし直し、そうでない場合は変換します。動画と同じ名前の `.vtt` または `.srt` ファイルは、その動画の字幕として表示されます。`.srt` ファイルは UTF-8 である必要があります。動画に埋め込まれたテキスト字幕も選択できます。前へ・次へのボタンでフォルダー内の動画を順に切り替え、戻る操作または Esc でプレーヤーを閉じます。

動画プレーヤー右上の **音声として再生** を押すと、動画プレーヤーが閉じ、動画の音声が同じ位置からグローバル音声プレーヤーで続きます。フォルダー内の他の動画は、音声としてその後ろにキューされます。その隣の **その他の操作** に **削除** があります。

再生位置はアカウントごとに、約 10 秒ごと、一時停止時、終了時、プレーヤーを閉じるときに保存されます。動画の再生が始まるとグローバル音声プレーヤーは一時停止し、動画プレーヤーを閉じた後も一時停止したままです。グローバル音声プレーヤーが再び再生を始めると、動画は一時停止します。

写真を選ぶと全画面で表示されます。矢印ボタン、矢印キー、横方向のスワイプでフォルダー内の写真を順に切り替え、戻る操作または Esc で閉じます。写真は画面に合わせて開き、クリックすると実寸で表示し、もう一度クリックすると画面に合わせます。マウスホイール、トラックパッドや 2 本指のピンチ、`+`・`-`・`0` キーで実寸の 8 倍まで任意の倍率に拡大でき、拡大した写真はドラッグでパンできます。

## 音声を聴く

音声ファイルを選ぶと、止めた位置からグローバル音声プレーヤーで再生され、フォルダー内の他の音声ファイルが順にキューされます。プレーヤーにはそのファイル自身のカバーアートが表示され、ない場合は画像を表示しません。タイトルの下にはフォルダー名が表示され、カバーをダブルクリック（スマートフォンではダブルタップ）するとそのフォルダーが開きます。`.wma` など、ブラウザーがそのまま再生できないファイルは変換され、[互換性再生](playback.md#現在の動作)はライブラリの音声と同じように動作します。再生位置は動画と同じ方法で保存されます。記録の音声には歌詞がなく、視聴履歴にも数えられず、再読み込み後にプレーヤーが復元するキューにも含まれません。

## ファイルとフォルダーを削除する

ファイル管理の権限（`downloads:manage`）を持つアカウントは記録のファイルとフォルダーを削除できます。**削除** は **その他の操作** メニューにあります。動画プレーヤーでは右上、写真ビューアーでは上部、**ファイル** では各行の末尾、動画とフォルダーのタイルでは名前の横です。確認画面には記録ルート内でのファイルまたはフォルダーのパスと、削除されるものと残るものが表示されます。**続行**、続けて **ゴミ箱に移動** を選ぶと削除されます。ファイルを削除すると、ビューアーは次の動画や写真に進み、ない場合は閉じます。

削除したファイルやフォルダーは記録ルートの `.kikoto-trash/records` に、日時と項目にちなんだ名前のフォルダーの下へ、ルート内のフォルダー構成を保ったまま移動します。フォルダーは、記録に表示されないファイルも含めて中身ごと移動します。削除されたファイルについての全アカウントの再生位置、サムネイル、再生用キャッシュも削除され、それらのファイルはグローバル音声プレーヤーのキューからも外れます。削除したファイルの隣にある字幕などのファイルは残ります。Kikoto はゴミ箱を空にしません。元に戻すにはファイルやフォルダーを戻してスキャンし、容量を空けるにはディスクから削除してください。記録ルートがオフラインの間は何も削除されず、ルートフォルダー自体は削除できず、リンクを経由する項目の削除は拒否されます。ページに表示された後に変更された項目、たとえば別のタブで削除された項目も拒否されます。更新して、もう一度確認してください。
