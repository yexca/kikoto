# 記録

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](record-library.md) · [한국어](../ko/record-library.md)

記録は個人の動画と画像を扱う独立したライブラリです。`/record` マウントを使用し、音声ライブラリや作品にはファイルを追加しません。

## 設定

ホストのフォルダーを `/record` にマウントし、**記録**を開いて**ルートを初期化**を選択します。Kikoto は `.kikoto-record` マーカーを書き込み、明示的な初期化後だけスキャンを開始します。既定の本番マウントは次のとおりです。

```yaml
volumes:
  - ./record:/record
```

フォルダーの深さに制限はなく、ページでも同じツリーを閲覧できます。

## 閲覧

記録は一度に 1 つのフォルダーを表示します。上のパスが現在のフォルダーを示し、それを含む任意のフォルダーへ戻れます。アドレスには開いているフォルダーが保持されるため、ブラウザーの戻る・進む・再読み込みで同じ場所に戻ります。

背景 artwork のあるフォルダーは、ポスター、名前、動画と写真の数を表示するバナー付きで開きます。バナーの**再生**で最初の動画を再生でき、最後に視聴した動画があれば**…から続ける**でその位置から再開できます。背景 artwork のないフォルダーは、同じ情報を通常の見出しで表示します。

ツールバーでは**すべて**、**動画**、**写真**を切り替え、名前の昇順または降順で並べ替えます。サブフォルダーは正方形のタイルで表示され、ポスター、ポスターがなければ背景画像、どちらもなければフォルダーのアイコンを表示します。動画は、動画のフレーム、長さ、視聴済みの割合を示すバーを付けたワイドタイルで、写真は正方形のサムネイルで表示されます。サムネイルはフォルダーが初めて表示されるときに作成されるため、大きなフォルダーでは初回に少し時間がかかることがあります。字幕、メタデータ、その他のファイルは表示されず、フォルダーの artwork 画像も表示されません。**更新**でフォルダーを再読み込みします。

最上位では、**続きを見る**に途中まで視聴した動画が、新しい順に、それぞれが入っているフォルダーとともに表示されます。動画を選ぶと止めた位置から再生され、プレーヤーを閉じると最上位に戻ります。

## スキャンと artwork

ツールバーの**スキャン**を選びます。ライブラリの書き込み権限が必要です。その横には、ルートが最後にスキャンされた時刻が表示され、スキャンを開始した後は、キュー済み、実行中、完了のいずれの状態かが表示されます。スキャンは永続ワークフローとしてキューに入り、実行中のスキャンと統合されます。拡張子で通常ファイルを索引し、リンクと Kikoto のトランザクションディレクトリをスキップします。ルートがオフライン、またはスキャンが一部だけ完了した場合は既存の記録を保持し、完全なスキャンだけが削除されたフォルダーとファイルを見つからない状態にします。スキャンは、新規または変更された各動画の長さとサイズ、新規または変更された各写真のサイズも読み取ります。読み取れなかったファイルは長さを持たず、変更されると再び読み取られます。

フォルダー artwork は `folder`、`poster`、`cover` をポスターに、`backdrop`、`fanart`、`background` を背景に使います。対応する動画拡張子は `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v`、`.ts`、画像拡張子は `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif` です。

## 動画と写真の視聴

動画を選ぶと全画面のプレーヤーで開きます。途中まで視聴している場合、Kikoto はその位置から**続ける**か**最初から**かを尋ねます。動画と同じ名前の `.vtt` または `.srt` ファイルは、その動画の字幕として表示されます。`.srt` ファイルは UTF-8 である必要があります。前へ・次へのボタンでフォルダー内の動画を順に切り替え、戻る操作または Esc でプレーヤーを閉じます。再生位置はアカウントごとに、約 10 秒ごと、一時停止時、終了時、プレーヤーを閉じるときに保存されます。保存にはライブラリの書き込み権限が必要です。動画の再生が始まるとグローバル音声プレーヤーは一時停止し、プレーヤーを閉じた後も一時停止したままです。

写真を選ぶと全画面で表示されます。矢印ボタン、矢印キー、横方向のスワイプでフォルダー内の写真を順に切り替え、戻る操作または Esc で閉じます。
