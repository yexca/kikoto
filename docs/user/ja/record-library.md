# ホームビデオ

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](../zh-Hant/record-library.md) · [日本語](record-library.md) · [한국어](../ko/record-library.md)

ホームビデオは個人の動画と画像を扱う独立したライブラリです。`/record` マウントを使用し、音声ライブラリや作品にはファイルを追加しません。

## 設定

ホストのフォルダーを `/record` にマウントし、**ホームビデオ**を開いて**ルートを初期化**を選択します。Kikoto は `.kikoto-record` マーカーを書き込み、明示的な初期化後だけスキャンを開始します。既定の本番マウントは次のとおりです。

```yaml
volumes:
  - ./record:/record
```

フォルダーの深さに制限はなく、ページにはディレクトリツリーがそのまま表示されます。

## スキャンと artwork

ページから**record ライブラリをスキャン**を選びます。スキャンは永続ワークフローとしてキューに入り、実行中のスキャンと統合されます。拡張子で通常ファイルを索引し、リンクと Kikoto のトランザクションディレクトリをスキップします。ルートがオフライン、またはスキャンが一部だけ完了した場合は既存の記録を保持し、完全なスキャンだけが削除されたフォルダーとファイルを見つからない状態にします。

フォルダー artwork は `folder`、`poster`、`cover` をポスターに、`backdrop`、`fanart`、`background` を背景に使います。対応する動画拡張子は `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v`、`.ts`、画像拡張子は `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif` です。

動画を選ぶとページ内で再生できます。再生位置はアカウントごとに保存され、グローバル音声プレーヤーとは独立しています。
