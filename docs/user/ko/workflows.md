# 워크플로

[English](../en/workflows.md)

워크플로는 backend 작업을 확인 가능하게 만듭니다.

## 사용자 화면

- Workflows에서 기본 및 사용자 정의 정의와 트리거를 관리합니다.
- Activity에서 실행 중, 검토, 실패, 완료 보기를 확인합니다.

## 현재 동작

- 서클 팔로우, 시리즈 팔로우, 성우 팔로우는 프리셋 워크플로입니다. 실행 옵션은 **입력**(대상과 카탈로그 새로 고침: 증분 또는 전체), **필터**(발매일 범위와 작품 수 제한), **작업**(메타데이터 동기화, 태그 템플릿, 서클의 경우 원격 소스 확인) 세 부분으로 나뉘며 제목 오른쪽의 **Run**으로 실행합니다. 트리거 팝오버는 위의 값을 기본으로 사용하고, "실행 옵션 사용자 지정"을 켜면 개별 설정을 덮어쓸 수 있습니다. 메타데이터 동기화에는 Startup 트리거가 없습니다. 메타데이터 동기화는 메타데이터가 없는 카탈로그 작품(아직 라이브러리에 없는 작품 포함)을 대상으로 하며, 필터와 태그는 이 작품에 적용됩니다. 필터는 기본적으로 모두 꺼져 있고, 발매일 범위나 작품 수 제한이 없으면 메타데이터가 없는 카탈로그 작품을 모두 동기화합니다. 태그 템플릿도 기본적으로 꺼져 있으며, 동기화한 작품에 태그를 붙이려면 켜세요. 필터 없는 자동 실행을 저장할 때 트리거 팝오버가 필터를 켜도록 권장합니다. 메타데이터 동기화를 끄면 서클과 성우 팔로우는 카탈로그 새로 고침(과 소스 확인)만 합니다. Track과 Fetch는 더 이상 팔로우 작업이 아닙니다. 자동 실행은 증분 카탈로그 새로 고침만 지원하며 전체 새로 고침은 수동 전용입니다.
- 성우는 한 명을 고르고 선택한 원격 소스에서 카탈로그를 새로 고칩니다. 시리즈는 저장된 작품을 읽으며 카탈로그 새로 고침이 없습니다. 업그레이드하면 이전에 저장한 팔로우 트리거가 비활성화되고 다시 설정해야 한다고 표시됩니다. 트리거를 열어 실행 옵션을 확인하고 저장한 뒤 다시 켜세요. 메타데이터 동기화는 라이브러리에 있는 작품을 새로 고칩니다. 실행 옵션에서 **작품**(모든 작품, 서클 하나, 성우 한 명)과 **새로 고침 대상**(누락되었거나 오래된 항목 또는 모든 메타데이터)을 고르며, 간격 트리거도 같은 선택을 저장합니다.
- 사용자가 작성한 커스텀 워크플로, DAG 편집기, 슬래시 명령, 정의 실행 대화 상자는 제거되었습니다. 업그레이드 시 기존 사용자 정의와 트리거는 삭제되지만 실행 기록은 Activity에 남습니다.

- 로컬 스캔과 metadata sync, 원격 Sync, Cache, Fetch 및 정리는 각각 별도 실행으로 기록됩니다.
- 폴더가 사라지면 위치를 missing으로 표시하지만 파일이나 Fetch 소유권은 삭제하지 않습니다.
- 해결되지 않은 후보가 있는 실행은 Review에, 부분 완료는 Completed에 표시됩니다.
- watcher는 이벤트 후 5초를 기다리고 staging, backup, trash 및 Fetch 트리를 무시합니다.
- 큐에 있거나 실행 중인 Fetch는 canonical work마다 하나이며 반복 요청은 같은 실행을 재사용합니다.
- Fetch Activity는 전송 바이트, 측정된 전송 속도, 예상 남은 시간을 표시합니다.
- 실행 상세에는 시작·종료 시각, 소요 시간, 트리거, 단계와 기본적으로 접힌 진단 로그가 표시됩니다.

## 현재 제한

- 복구 가능하다고 선언한 워크플로만 재시도와 체크포인트 복구를 지원합니다.
- Worker는 Kikoto 프로세스 안에서 실행되며 분산 실행은 지원하지 않습니다.

Workflows 오른쪽 위의 Activity는 데스크톱 패널 또는 모바일 시트를 엽니다. 실행 중인 작업을 위에 표시하고 아래를 **Needs attention**과 **History**로 나눕니다. 미해결 후보, 메타데이터 문제, 확인하지 않은 실패가 주의 대상입니다. 기록된 메타데이터 문제가 해결되면 알림이 해제되며 다른 실패는 사용자별로 확인할 수 있습니다. History는 원래 실행 상태를 유지합니다. 메타데이터는 문제 처리와 메타데이터 설정을 모으며 동기화는 기존 워크플로 바로가기로 제공합니다.

Activity는 현재 선택한 워크플로의 실행과 개수만 표시합니다. Recent runs 또는 목록 항목을 누르면 같은 패널에서 상세 정보, 이벤트, 후보를 확인할 수 있습니다. 별도 Full Activity 페이지는 제거되었으며 기존 링크와 알림은 해당 워크플로의 Activity를 엽니다.
