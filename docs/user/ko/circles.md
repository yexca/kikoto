# 서클

[English](../en/circles.md)

서클은 제작자와 관련 카탈로그 상태를 나타냅니다.

## 현재 동작

- 알려진 서클을 서버 페이지 결과로 목록화하고 검색·필터·페이지 매김을 제공합니다.
- 즐겨찾기, 사용자 태그, 평점과 메모를 관리합니다.
- 최신 DLsite 작품 코드와 캐시 표지를 카드에 표시하며 표지가 없으면 `No cover`를 표시합니다.
- 동기화 상태와 `Available N/total` 배지를 요약합니다.
- 외부 id로 상세를 열고 incremental 또는 full 카탈로그 갱신을 지원합니다.
- 카탈로그 행은 가져온 work와 별도로 저장합니다.
- 상세 화면의 **처음 가져오기**, **서클 새로 고침**, **메타데이터 다시 시도**는 새 작품 단계를 끈 서클 팔로우 실행을 대기열에 추가하고 바로 돌아옵니다. 실행은 Activity에서 확인하며, **더 보기** 메뉴의 **이 서클 팔로우…**에서 카탈로그·메타데이터 새로 고침, 소스 확인, 새 작품을 조합할 수 있습니다.

## 경계

서클 카탈로그는 발행 목록을 설명합니다. 소스 Sync 또는 Fetch가 미디어 위치를 만들기 전에는 재생 위치를 만들지 않습니다.

## 갱신 동작

Incremental 갱신은 최신 행을 우선합니다. Full 갱신은 더 많은 provider 페이지를 조회할 수 있지만 오래된 행을 자동 삭제하지 않습니다.
