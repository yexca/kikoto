# 서클
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

서클은 제작자, 서클(circle), 그리고 관련 당사자의 카탈로그 상태를 나타냅니다.

## 현재 동작

- 알려진 당사자를 서버 페이지 단위 결과로 나열하며, 카드마다 카탈로그 상태와 사용 가능 여부를 표시합니다.
- 검색, 필터, URL에 반영되는 페이지 이동, 즐겨찾기 상태, 사용자 태그, 평점, 메모를 제공합니다.
- 검색, 한 번에 선택하는 보기 칩, 페이지 크기 동작을 줄바꿈되는 도구 모음 한 줄에 둡니다. 칩은 `모든 서클`, `즐겨찾기`, `태그됨`, `사용 가능`, `로컬`, `원격`, `누락`, `확인 필요`이며, 눌린 칩이 현재 보기를 나타냅니다. 휴대폰에서는 검색 필드가 한 줄을 차지하고 그 옆에 페이지 크기가 놓이며, 칩은 아래에서 가로로 스크롤됩니다.
- 각 서클을 표지 타일로 표시합니다. 서클의 표지(없으면 `표지 없음`으로 대체), 표지 위의 즐겨찾기 컨트롤, 이름, 최신 발매일, 개인 태그가 들어 있습니다. 타일은 넓은 레이아웃에서는 한 줄을 채우고 휴대폰에서는 두 열을 이룹니다.
- 알려진 최신 DLsite 작품의 로컬에 캐시된 표지를 서클의 표지로 사용합니다. 상세의 **더 보기** 메뉴에 있는 **커버 변경…**은 서클의 작품을 검색과 함께 나열하며, 고른 작품의 표지를 타일과 상세 요약에서 서클의 표지로 삼습니다. 같은 대화 상자의 **최신 작품**은 새 작품이 나올 때마다 바뀌는 표지로 되돌립니다. 이 선택은 선택한 계정에 속하며, 고른 작품이 서클 카탈로그에서 빠지면 최신 작품의 표지가 대신 사용됩니다.
- 각 서클 타일에 동기화 상태, 하나로 통일된 `사용 가능 N/total` 개수, 사용 가능 여부 막대를 요약해 표시합니다. 막대는 로컬 사본이 있는 작품은 채워진 구간, 원격 소스만 가진 작품은 더 연한 구간, 나머지는 빈 트랙으로 나타냅니다.
- 외부 ID로 서클 상세를 표시합니다.
- 서클 카탈로그 작품은 서버에서 페이지로 나눕니다. 카탈로그 전체 수는 유지하며 검색, 사용 가능 여부, 시리즈 필터와 선택한 정렬 순서를 페이지 분할 전에 적용합니다. 일괄 선택은 불러온 페이지에만 적용됩니다.
- 카탈로그 작품을 **출시일**, **코드**, **제목**, **평점**, **판매량** 순으로 오름차순 또는 내림차순으로 정렬하며, 기본값은 최신 발매 순입니다. 평점이나 판매량이 없는 작품은 어느 방향에서나 맨 뒤에 둡니다. 정렬 순서와 페이지 크기(24, 48, 96)는 계정별로 기기에 기억되며 모든 서클에 적용됩니다.
- 증분 또는 전체 모드의 카탈로그 새로 고침을 지원합니다.
- 카탈로그 행은 가져온 작품과 별도로 저장합니다.
- 카탈로그 작품에 로컬/캐시/원격 소스 사용 가능 태그를 표시합니다.
- 작품 결과를 라이브러리와 같은 반응형 그리드와 작품 카드로 표시합니다. 이는 서클 상세와 서클 시리즈에 모두 적용되며, 별도의 서클 엔티티 목록은 자체 컨트롤을 유지합니다. 작품 카드에서 DLsite 태그나 개인 태그를 선택하면 해당 태그의 로컬 라이브러리 검색이 열립니다.
- 서클 상세 요약을 표지 색조의 패널에 표시하며, 서클의 별칭과 개인 태그가 함께 들어 있습니다. **사용 가능**, **로컬**, **원격**, **사용 불가** 개수는 사용 가능 여부 막대 옆에 놓이며, 아래 작품에 어떤 필터가 적용되어 있든 전체 카탈로그를 나타냅니다. 한 번도 가져온 적 없는 서클에는 라이브러리가 이미 아는 작품만 나열된다고 안내하고, 그 외에는 카탈로그를 마지막으로 동기화한 시점을 표시합니다. 시리즈 카드에도 같은 사용 가능 여부 막대가 있습니다.
- 상세 요약에 자주 쓰는 새로 고침 동작을 둡니다. 한 번도 가져온 적 없는 서클에는 **처음 가져오기**가, 그다음에는 원격 소스도 함께 확인하는 **서클 새로 고침**이 표시됩니다. **메타데이터 다시 시도**는 카탈로그 작품에 아직 메타데이터가 없는 동안에만 나타나며, 해당 작품만 채웁니다. 각 동작은 필터나 태그 없이 서클 카탈로그 동기화 실행을 대기열에 넣고 즉시 반환되며, 실행이 끝날 때까지 버튼에 **새로 고치는 중**이 표시되고, 실행 내역은 활동에서 볼 수 있습니다.
- **즐겨찾기** 옆의 벨은 서클의 새 작품을 구독하고, 시리즈의 DLsite 링크 옆의 벨은 그 시리즈를 구독합니다. [구독](subscriptions.md)을 참고하세요. 구독 중인 서클의 시리즈는 이미 포함됩니다.
- **더 보기** 메뉴에는 **커버 변경…**과 **이 서클 카탈로그 동기화…**가 있습니다. 이는 이 서클이 미리 채워진 서클 카탈로그 동기화 프리셋을 열며, 카탈로그 새로 고침, 필터, 메타데이터, 태그, 소스 확인의 그 밖의 모든 조합에 사용합니다. 서클의 작품이 이미 가지고 있는 메타데이터를 새로 고치려면 서클 범위로 메타데이터 동기화를 실행하세요.
- 모바일에서는 자주 쓰는 상세 동작을 줄여 표시하고, 아이콘만 있는 즐겨찾기, 더 보기, DLsite 컨트롤도 이름으로 접근할 수 있게 유지하며, DLsite를 맨 마지막에 둡니다.
- 넓은 레이아웃에서는 라이브러리와 같은 작품 도구 모음을 사용합니다. 왼쪽에는 작품/시리즈 전환과 폭이 제한된 검색이 있고, 오른쪽에는 현재 정렬 순서를 이름으로 표시하는 정렬 버튼, 표시 옵션, 사용 가능 여부 필터, 선택이 있습니다. 표시 옵션에는 라이브러리와 공유하는 **전체**, **컴팩트**, **미니** 중에서 고르는 **카드** 선택, 열 수, 페이지 크기가 들어 있으며, 새로 고른 카드 모드는 해당 [프리셋](library.md#현재-동작)에서 시작합니다. 공통 컬렉션 페이지 이동은 그리드 위와 아래에 있습니다.
- 모바일 작품 컨트롤은 정렬 버튼이 옆에 있는 작품/시리즈 전환, 검색, 그리고 하나의 카탈로그 옵션 동작으로만 구성합니다. 사용 가능 여부, 카드 모드, 모바일 열 수, 페이지 크기, 선택 모드는 해당 시트에 있으며, 넓은 레이아웃에서는 인라인 컨트롤을 유지합니다. 시리즈 개요는 시리즈를 나열하며 정렬 순서를 제공하지 않습니다.
- 모바일 상세의 뒤로 가기 컨트롤은, 라이브러리에서 상세를 연 경우를 포함하여, 서버와 사용자 기준으로 마지막으로 본 서클 목록 위치로 올라가는 동작으로 처리합니다. 넓은 레이아웃에서는 출처를 인식하는 기록 복귀 레이블과 이동 위치를 유지합니다.
- 오래된 카탈로그 행은 확인 후 제거할 수 있습니다.

## 경계

서클 카탈로그는 당사자가 무엇을 발매했는지를 설명합니다. 소스 동기화나 가져오기로 미디어 위치가 만들어지기 전까지는 구체적인 재생 위치를 만들지 않습니다.

## 새로 고침 동작

증분 새로 고침은 최신 카탈로그 행을 우선하고, 이미 알려진 행에 도달하면 멈춰야 합니다. 전체 새로 고침은 더 많은 제공처 페이지를 따라갈 수 있지만, 이전 카탈로그 행을 자동으로 삭제해서는 안 됩니다.
