# 라이브러리
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

라이브러리는 작품을 둘러보는 기본 화면입니다.

## 현재 동작

- 로컬, 추적, 구성된 원격 소스 탭을 표시합니다.
- 큰 결과 집합에는 서버 측 페이지 이동을 사용합니다.
- 현재 페이지를 구성하기 전에 정규화된 제목, 코드, 언어 에디션 별칭, 서클, 태그, 성우 크레딧을 검색합니다. 제공처가 선언한 에디션 코드는 라이브러리 요청 중에 작품을 추가로 만들거나 원본 메타데이터 스냅숏을 스캔하지 않고도 계속 검색할 수 있습니다.
- 검색어를 문자 그대로 일치시키며 전각/반각, 대소문자, 가나 문자 종류는 구분하지 않습니다. `100%`와 `a_b`는 와일드카드가 아니고, 전각 `ＡＢＣ`는 `abc`를 찾으며, 가타카나는 히라가나로 쓴 같은 단어를 찾습니다. 검색어 앞에 `tag: 癒し`, `circle:`, `va:`, `mytag:` 같은 절을 붙이면 한 필드만 검색합니다.
- DLsite 태그는 Kikoto가 해당 태그에 대해 가져온 모든 언어의 이름과도 일치합니다. 영어로 요청한 에디션이 `癒し`로 표시되는 태그를 `Healing`으로 보고하는 경우, `tag: healing`은 둘 다 찾습니다. 태그, 제목, 서클 또는 성우 크레딧이 검색어와 정확히 같은 결과는 부분 일치보다 먼저 표시되며, 선택한 정렬이 각 그룹의 순서를 정합니다.
- 검색 필드의 `+` 버튼은 구조화된 검색 조건을 위한 떠 있는 편집기를 엽니다. 조건 배지를 선택하면 결과가 움직이지 않은 채 같은 팝오버에서 해당 조건을 편집합니다.
- 표지, 제목, 코드, 한 줄로 말줄임 처리된 서클 / 시리즈, 성우 메타데이터, 로컬 사용 가능 여부, 소스 태그, 그리고 가능한 경우 빠른 청취 표시를 보여 줍니다.
- 제공처 태그를 카드 최대 두 줄에 맞게 측정합니다. `+N` 배지는 숨겨진 태그를 팝오버로 열며, 개인 태그는 사용자 소유의 별도 줄로 유지됩니다.
- 간결한 DL 판매량과 5단계 비수치 평가 비교를 한 줄의 지표 행에 표시합니다. 저장된 커서가 있으면 재생 기록 아이콘이 나타납니다.
- 활성화된 소스를 통해 사용할 수 있는 원본(Origin)이 아닌 에디션을 데이터베이스가 알고 있을 때만 언어 아이콘을 표시합니다. 알 수 없거나 메타데이터에만 있는 언어 관계는 사용 가능함을 의미하지 않습니다.
- 정규화된 상업 메타데이터가 있으면 현재 가격을 표시하고, 가격이 0인 작품에는 무료라고 표시합니다.
- 통합 작품 카드와 상세에서 로그인한 사용자의 작품 태그를 메타데이터 태그와 별도로 표시합니다. `mytag:`는 제공처 `tag:` 검색의 의미를 바꾸지 않고 개인 태그를 필터링합니다.
- 소스 사용 가능 여부를 메타데이터 태그와 시각적으로 구분해 둡니다.
- 작품 카드의 서클 이름 옆에 알려진 연령 등급을 표시하고, 전체 연령 메타데이터는 작품 상세에 그대로 유지합니다.
- 라이브러리, 즐겨찾기, 서클 상세, 성우 상세 화면에서 작품 컬렉션에 같은 반응형 그리드를 사용합니다. 열 수 선택은 페이지마다 다시 구현하지 않고 공유합니다.
- 선택한 작품 컬렉션의 열 설정을 로컬에 저장하고 라이브러리, 즐겨찾기, 서클 작품 컬렉션, 성우 작품 컬렉션에 걸쳐 적용합니다.
- 안정적인 시드 기반 무작위 정렬을 지원합니다. 시드는 페이지 이동의 일관성을 유지하며, 다시 섞으면 순서를 뒤집는 대신 새 시드를 만듭니다.
- 새 라이브러리 보기는 기본적으로 개인화된 추천 순서를 사용하되, 기록이나 세션에서 복원된 탐색 선택은 유지합니다. 표준 URL에는 쿼리와 기본값이 아닌 청취 상태만 유지되며, 링크에 명시된 탐색 매개변수는 그대로 읽습니다. 추천 배치는 청취 의도와 선호도를 구분합니다. 듣는 중과 듣고 싶음은 앞쪽 슬롯을 받고, 미표시는 주된 탐색 풀로 남으며, 다시 듣기와 완료는 제한된 범위로 끼워 넣어지고, 보류는 예정된 상태가 소진될 때까지 기다립니다. 상태를 명시적으로 필터링하면 일치하는 모든 작품을 그대로 반환합니다. 각 상태 안에서는 제한된 선호도 점수가 즐겨찾기, 태그, 성우, 서클 신호를 사용하며, 후보 작품 자신을 취향 기록으로 취급하지 않습니다. 긍정적인 피드백이 반복되면 일치한 각 신호가 최대 다섯 개의 근거 작품까지 강화되고, 흔한 태그는 가중치가 낮아집니다. 시드 기반 탐색 부스트는 근거가 약한 작품을 우대하고, 독립적인 결과 변화는 현재 상태 내 순서에만 해당 선호도를 조정하며, 작은 제작자 다양성 조정도 순서에 영향을 줍니다. 배지와 원격 측정은 제한된 선호도 점수를 유지합니다. 다시 듣기와 즐겨찾기 기록은 긍정적인 근거이고, 완료만으로는 중립입니다. 각 브라우저 탭이나 네이티브 앱 실행은 변경되지 않는 추천 세대에 고정되므로, 탐색, 페이지 이동, 필터, 카드 변경, 도구 모음의 다시 섞기는 선호도를 다시 계산하지 않습니다. 즐겨찾기와 청취 변경은 카드에 즉시 표시되지만 배치에는 다음 클라이언트 세션부터 영향을 줍니다. 새 세션은 추천 입력이 바뀐 경우에만 세대를 다시 만들고, 그렇지 않으면 새로운 안정 시드로 현재 세대를 재사용합니다. 시드는 상태 혼합과 상태 내 다양성이 모두 페이지 이동에 안전하도록 유지하며, 도구 모음의 새로 고침 동작은 현재 세대 안에서 그 시드만 바꿉니다.
- 원격 추천 배지는 아직 가져오지 않은 작품도 알려진 현지화 태그와 제작자 별칭을 사용해 점수를 매깁니다. 배지를 켜면 원격 소스를 다시 불러오지 않고 현재 페이지를 한 번에 일괄로 점수 계산한 뒤, 배지를 점진적으로 표시합니다(모션 줄이기 설정을 존중합니다). 배지 임계값 이상인 점수만 표시됩니다. 점수 계산에 실패해도 작품은 계속 사용할 수 있으며 다시 시도를 제안합니다. 원격 점수는 동일하게 고정된 세션 선호도 프로필을 사용하며 작품을 가져오지 않습니다.
- 라이브러리 컨트롤 위에 가로로 스크롤할 수 있는 간결한 최근 재생 줄을 표시합니다. 이 줄은 각 논리적 작품 계열이 소유한 하나의 커서를 기준으로 사용자별로 정렬되며, 전체 작품 카드 그리드를 대체하지 않으면서 마지막 트랙 위치를 포함합니다. 이 줄은 접을 수 있으며, 그 설정은 브라우저에 유지됩니다.
- 로컬, 추적, 구성된 원격 소스에 걸쳐 하나의 공유 쿼리를 사용합니다. 각 소스는 자체 페이지 이동, 정렬, 스크롤 상태를 유지하고 그리드 열 설정은 공유됩니다. 사용자가 다른 곳에서 검색어를 지웠다면 소스가 오래된 검색어를 복원할 수 없습니다.
- 활성 로컬, 추적 또는 원격 소스 페이지의 페이지 크기는 첫 줄 동작 도구 모음에 두고, 상단의 간결한 페이지 이동은 결과 맥락과 페이지 탐색에 집중하도록 둡니다.
- 데이터베이스 정리는 라이브러리 밖에 둡니다. 메타데이터 -> 사용 가능한 소스 없음은 사용 가능한 소스나 미디어 위치가 없는 논리적 계열에 대해 페이지 단위 검색, 소스 확인, 확인을 거친 로컬 정보 삭제를 제공합니다.
- `/no-source` 및 `/library/no-source` 링크는 메타데이터 -> 사용 가능한 소스 없음을 열고, `/library/all` 및 `/library/remote` 링크는 라이브러리를 엽니다.
- `KIKOTO_MODE=demo`일 때 백엔드의 목록, 상세, 미디어 응답은 전 연령 대상이며 영구적으로 무료인 작품만 허용합니다. 로컬 작품은 정규화된 상업 메타데이터를 사용하며, 알 수 없는 메타데이터와 일시적인 무료 프로모션은 제외됩니다. 시뮬레이션된 Remote Kikoeru 소스는 허용된 로컬 작품만 다시 게시합니다. 데모 세션은 허용된 전체 미디어를 재생할 수 있지만 라이브러리, 설정, 워크플로 상태를 변경할 수는 없습니다.

작품 카드는 알려진 경우 성우 크레딧을 포함하여 모든 컬렉션 화면에서 같은 요약 모델을 사용합니다. 간결한 카드는 성우 이름을 최대 두 개까지 보여 주고, 추가 크레딧은 요약하여 메타데이터 때문에 카드가 무한정 커지지 않게 합니다.

즐겨찾기는 표준 URL에 엔티티/검색 의도만 유지합니다. 선택한 목록, 즐겨찾기 필터, 정렬, 시드, 페이지 이동, 선택, 작품 앵커는 현재 기록 항목에서 복원하며, 사용자 범위의 세션 폴백이 있습니다. `모든 즐겨찾기`는 빠른 표시가 있는 작품과 모든 사용자 목록에 있는 작품을 집계합니다. `표시됨`은 빠른 표시가 표시 없음이 아닌 작품만 담는 고정 시스템 목록이며, 구성원은 파생되어 목록으로 편집할 수 없습니다. 다른 목록은 사용자가 만들며 명시적인 구성원을 유지합니다. 목록을 전환해도 결과를 불러오는 동안 전체 즐겨찾기 목록 행은 안정적으로 유지되며, 보류는 마지막 청취 상태 옵션입니다. 재생 커서만으로는 작품이 즐겨찾기에 추가되지 않습니다. 소스 선택기는 소스별 작품 복사본을 만들거나 실시간 원격 새로 고침을 요청하지 않고도 즐겨찾기 작품을 선택한 여러 구성된 파일 소스 중 어느 것으로든 좁힐 수 있습니다.

넓은 화면에서는 결과 옆의 선반 레일에 모든 즐겨찾기, 표시됨, 사용자 목록, 팔로우한 서클과 성우가 개수와 함께 나열됩니다. 워크플로 및 설정 레일처럼 이름을 숨기고 아이콘만 남길 수 있으며, 그 선택은 해당 기기에 기억됩니다. 각 사용자 목록은 목록 편집에서 고른 아이콘을 표시할 수 있으며, 아이콘 레일에서 목록을 구분하는 것이 이 아이콘입니다. 목록 아이콘은 목록에 추가 메뉴에도 나타납니다. 휴대폰에서는 같은 선반을 스크롤 가능한 한 줄로 표시합니다. 열려 있는 선반에는 표지 모자이크, 개수, 완료한 작품 수, 듣는 중인 작품이 있는 머리글이 있습니다. 작품은 카드로 표시하거나 각 작품의 이어듣기 지점이 있는 더 촘촘한 목록으로 표시할 수 있습니다.

## 식별

라이브러리 카드는 소스별 복사본이 아니라 통합 작품을 나타냅니다. 원격 카드는 로컬 파일이 생기기 전에도 작품을 추적하거나 동기화할 수 있지만, 그 결과 상태는 같은 통합 작품 식별에 연결됩니다. 추적(Track)은 선택한 소스 트리도 저장하고 해당 소스를 추적됨에서 엽니다.

## 소스 탭

소스 탭은 작품을 어디에서 재생하거나 가져올 수 있는지 사용자가 알 수 있게 도와야 합니다. 별도의 메타데이터 소유권을 가진 독립된 라이브러리가 아닙니다. 로컬, 추적, 캐시, 원격의 사실은 모두 같은 작품 모델로 되돌아갑니다.
