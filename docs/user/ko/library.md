# 라이브러리
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

라이브러리는 작품을 둘러보는 기본 화면입니다.

## 현재 동작

- 로컬, 추적, 구성된 원격 소스 탭을 표시합니다.
- 큰 결과 집합에는 서버 측 페이지 이동을 사용합니다.
- 현재 페이지를 구성하기 전에 정규화된 제목, 코드, 언어 에디션 별칭, 서클, 태그, 성우 크레딧, 스태프 크레딧을 검색합니다. 제공처가 선언한 에디션 코드는 라이브러리 요청 중에 작품을 추가로 만들거나 원본 메타데이터 스냅숏을 스캔하지 않고도 계속 검색할 수 있습니다.
- 검색어를 문자 그대로 일치시키며 전각/반각, 대소문자, 가나 문자 종류는 구분하지 않습니다. `100%`와 `a_b`는 와일드카드가 아니고, 전각 `ＡＢＣ`는 `abc`를 찾으며, 가타카나는 히라가나로 쓴 같은 단어를 찾습니다. 검색어 앞에 `tag: 癒し`, `circle:`, `va:`, `mytag:` 같은 절을 붙이면 한 필드만 검색합니다. `staff:`는 DLsite의 모든 스태프 크레딧을 검색하고, `author:`, `scenario:`, `illust:`는 스태프 역할 하나를 검색하며, `creator:`는 성우를 검색합니다. `tag:`, `mytag:`, `circle:`, `va:` 또는 스태프 절 앞에 `-`를 붙이면 일치하는 작품을 제외하고, `"calm night"`이나 `circle:"Example Circle"`처럼 따옴표로 묶으면 구절 전체를 하나로 일치시킵니다.
- DLsite 태그는 Kikoto가 해당 태그에 대해 가져온 모든 언어의 이름과도 일치합니다. 영어로 요청한 에디션이 `癒し`로 표시되는 태그를 `Healing`으로 보고하는 경우, `tag: healing`은 둘 다 찾습니다. 태그, 제목, 서클, 성우 크레딧 또는 스태프 크레딧이 검색어와 정확히 같은 결과는 부분 일치보다 먼저 표시되며, 선택한 정렬이 각 그룹의 순서를 정합니다.
- 검색 필드의 `+` 버튼은 구조화된 검색 조건을 위한 떠 있는 편집기를 엽니다. 조건 배지를 선택하면 결과가 움직이지 않은 채 같은 팝오버에서 해당 조건을 편집합니다.
- 표지, 제목, 코드, 한 줄로 말줄임 처리된 서클 / 시리즈, 성우 메타데이터, 로컬 사용 가능 여부, 소스 태그, 그리고 가능한 경우 빠른 청취 표시를 보여 줍니다.
- 라이브러리와 즐겨찾기 카드에는 빠른 표시 옆에 내 평점이 있습니다. [작품 상세](work-detail.md#현재-동작)와 같은 컨트롤로, 별과 숫자를 보여 주며 평가하지 않은 작품은 빈 별로 표시합니다.
- 제공처 태그를 카드 최대 두 줄에 맞게 측정합니다. `+N` 배지는 숨겨진 태그를 팝오버로 열며, 개인 태그는 사용자 소유의 별도 줄로 유지됩니다.
- 간결한 DL 판매량과 5단계 비수치 평가 비교를 한 줄의 지표 행에 표시합니다. 저장된 커서가 있으면 재생 기록 아이콘이 나타납니다.
- 작품의 트랙에 가사가 있을 때 가사 아이콘을 표시합니다. **가사 관리**에서 지정한 가사 파일이나 이름으로 트랙과 일치한 가사 파일이 해당합니다. readme나 대본 같은 다른 텍스트 파일은 해당하지 않습니다. 자체 트랙이 없는 작품은 다른 에디션의 상태를 따릅니다.
- 정규화된 상업 메타데이터가 있으면 현재 가격을 표시하고, 가격이 0인 작품에는 무료라고 표시합니다.
- 통합 작품 카드와 상세에서 로그인한 사용자의 작품 태그를 메타데이터 태그와 별도로 표시합니다. `mytag:`는 제공처 `tag:` 검색의 의미를 바꾸지 않고 개인 태그를 필터링합니다.
- 소스 사용 가능 여부를 메타데이터 태그와 시각적으로 구분해 둡니다.
- 작품 카드의 서클 이름 옆에 알려진 연령 등급을 표시하고, 전체 연령 메타데이터는 작품 상세에 그대로 유지합니다.
- 라이브러리, 즐겨찾기, 서클 상세, 성우 상세 화면에서 작품 컬렉션에 같은 반응형 그리드를 사용합니다. 열 수 선택은 페이지마다 다시 구현하지 않고 공유합니다.
- 선택한 작품 컬렉션의 열 설정을 로컬에 저장하고 라이브러리, 즐겨찾기, 서클 작품 컬렉션, 성우 작품 컬렉션에 걸쳐 적용합니다.
- 안정적인 시드 기반 무작위 정렬을 지원합니다. 시드는 페이지 이동의 일관성을 유지하며, 다시 섞으면 순서를 뒤집는 대신 새 시드를 만듭니다.
- 새 라이브러리 보기는 추천 순서를 기본값으로 사용하며 복원한 탐색 설정을 유지합니다. 표준 URL에는 쿼리와 기본값이 아닌 청취 상태를 남기고 명시된 탐색 매개변수도 읽습니다. 듣는 중과 듣고 싶음이 앞쪽 슬롯을 받고, 미표시가 주요 탐색 풀이며, 다시 듣기와 완료는 제한된 슬롯에 삽입되고 슬롯이 없는 상태는 뒤에 나옵니다. 각 상태에서 제한된 추천 후보를 먼저 표시한 뒤 나머지 모든 일치 작품을 안정된 시드 탐색 순서로 표시합니다. 정확히 일치하는 검색은 우선하며 총수에는 모든 일치 결과가 포함되고 페이지 크기를 바꿔도 순서가 같습니다. 전체 결과를 개인 선호도순으로 정렬하는 것은 아닙니다.
- 선호도는 즐겨찾기, 태그, 성우, 서클 근거를 사용하고 후보 자신의 피드백은 제외합니다. 반복되는 긍정 근거는 즐겨찾기 다섯 개 분량까지 강화되며 흔한 태그의 가중치는 낮습니다. 내 [평점](work-detail.md#현재-동작)이 주된 근거로, 별 4개와 5개는 작품을 좋아하는 것으로, 별 1개와 2개는 싫어하는 것으로, 별 3개는 중립으로 계산합니다. 평점을 매긴 작품은 평점으로만 반영됩니다. 평점이 없는 작품은 즐겨찾기가 온전히 반영되고, 다시 듣기는 절반, 보류는 태그와 제작자에 대해 약하게 불리하게 반영되며, 완료만으로는 중립입니다. 싫어하는 작품 하나만으로도 비슷한 작품의 점수가 낮아지며, 보류한 작품은 충분히 많은 수가 일치할 때만 낮춥니다. 탐색 부스트, 변화, 제작자 다양성은 후보 순서에 영향을 주고 배지는 실제 선호도를 표시합니다. 일반 정렬에서는 현재 페이지만 점수를 계산합니다. 후보 밖의 작품도 실제 선호도를 설명하며 순서 조정은 해당 추천 쿼리 컨텍스트에서만 표시합니다. 컨텍스트가 만료되면 원래 세션의 선호도를 유지하고 순위 조정은 표시하지 않습니다.
- 각 브라우저 탭이나 네이티브 앱 실행은 선호 프로필, 청취 상태 슬롯, 공유 메타데이터 버전을 한 세대에 고정합니다. 탐색, 필터, 페이지 이동, 카드 변경, 다시 섞기는 프로필을 재사용합니다. 즐겨찾기와 청취 변경은 카드에 즉시 표시되고 새 세션의 순서에 반영됩니다. 공유 특성은 백그라운드에서 갱신되며 새 세션은 최근 완전히 게시된 버전을 사용하므로 메타데이터 편집보다 늦을 수 있습니다. 다시 섞기는 시드만 바꿉니다. 탐색 구성원과 필터는 현재 데이터를 사용하므로 작품 추가·삭제, 가용성, 권한, 개인 필터가 페이지 경계를 움직일 수 있습니다. 동일하게 보이는 데이터는 결정적인 순서로 중복이나 누락 없이 표시됩니다.
- 첫 추천 인덱싱 중에도 일반 탐색과 재생은 사용할 수 있습니다. 선택적 배지 실패는 카드를 유지하고 독립적인 다시 시도를 제공하며 추천 준비 실패는 이미 불러온 카드 옆에 다시 시도를 표시합니다. 두 실패 모두 전역 플레이어 재생을 중단하지 않습니다.
- 원격 추천 배지는 아직 가져오지 않은 작품도 알려진 현지화 태그와 제작자 별칭을 사용해 점수를 매깁니다. 배지를 켜면 원격 소스를 다시 불러오지 않고 현재 페이지를 한 번에 일괄로 점수 계산한 뒤, 배지를 점진적으로 표시합니다(모션 줄이기 설정을 존중합니다). 점수가 매겨진 모든 작품에 점수가 표시되며, 강조 임계값 이상인 점수는 강조되고 그보다 낮은 점수는 흐리게 표시됩니다. 점수 계산에 실패해도 작품은 계속 사용할 수 있으며 다시 시도를 제안합니다. 원격 점수는 동일하게 고정된 세션 선호도 프로필을 사용하며 작품을 가져오지 않습니다.
- 최근 재생한 작품을 각 논리적 작품 계열이 소유한 하나의 커서를 기준으로 사용자별로 정렬하여, 마지막 트랙 위치와 함께 제공합니다. 넓은 화면에서는 도구 모음의 기록 버튼이 목록을 엽니다. 휴대폰에서는 정렬 줄의 이어 듣기 버튼이 그 아래에 최근 재생한 작품의 표지를 가로로 스크롤하는 줄을 엽니다. 어느 페이지와 소스에서도 사용할 수 있습니다.
- 휴대폰에서는 라이브러리가 항상 표시되는 검색 필드와, 그 옆에서 현재 소스의 이름을 보여 주고 메뉴에서 모든 소스를 여는 소스 버튼으로 시작합니다. 그 아래 정렬 줄은 결과를 정하는 정렬 버튼과 표시 필터 버튼으로 시작하고, 추천 배지, 이어 듣기, 표시 옵션 같은 추가 기능과 보기 조작으로 끝납니다. 표시 필터와 이어 듣기는 각각 아래 줄을 표시하거나 숨기며, 빠른 표시 필터 칩, 이어 듣기 줄 순서로 나타납니다. 두 줄 모두 숨겨진 상태로 시작합니다. 표시 필터가 설정되어 있으면 그 버튼에 해당 표시가 나타납니다. 활성 칩을 다시 선택하면 필터가 해제됩니다.
- 정렬 버튼은 현재 정렬 순서의 이름을 보여 주고 팝오버에서 정렬 순서와 방향을 엽니다. 추천 순서와 무작위 순서에서는 그 옆에 새로 고침 버튼이 추가됩니다.
- 표시 옵션은 **카드**로 시작하며, **전체**, **컴팩트**, **미니** 중에서 선택할 수 있습니다. 이 선택은 열 설정과 함께 휴대폰과 넓은 화면에 따로 저장됩니다. **전체**가 기본값입니다. 넓은 화면의 자동 열 수는 한 줄에 전체 카드 최대 5개, 컴팩트 카드 최대 6개, 미니 카드 최대 7개가 들어가는 수이며, 창이 좁으면 그보다 적습니다. 다른 모드를 고르면 나머지 표시 옵션이 그 모드의 시작값으로 초기화되며, 이후 조정할 수 있습니다. 모든 모드에서 넓은 화면 열 수는 자동이고, **전체**와 **컴팩트**는 페이지당 작품 24개와 자동 커버 소스 표시를, **미니**는 페이지당 작품 48개와 커버 소스 표시 없음을 사용합니다. 휴대폰 열 수는 자체 설정을 유지합니다. **컴팩트**는 휴대폰 한 열에서 각 작품을 한 행으로 표시합니다. 표지 옆에 코드, 제목, 서클과 성우 이름, 평가, 판매량, 가격이 나오고, 그 아래 한 줄의 태그에는 개인 태그가 먼저 오며 마지막 청취 위치가 있으면 함께 표시됩니다. 휴대폰 두 열과 넓은 화면에서는 표지 위에 가격이 있고 태그 줄이 없는 짧은 타일로 표시됩니다. **미니**는 표지와 최대 두 줄의 제목만 표시하고 코드, 크레딧, 태그, 평가, 가격, 추천 점수, 작업 줄은 표시하지 않으며, 휴대폰의 자동 열에서는 한 줄에 표지 두 개가 들어갑니다. 커버 소스 표시는 모든 모드에서 자체 표시 옵션을 따르고, 카드는 모든 모드에서 같은 방식으로 작품을 엽니다. 이 선택은 라이브러리의 로컬, 추적됨, 원격 소스에 적용되며 원격 로딩 플레이스홀더도 포함합니다.
- 로컬, 추적, 구성된 원격 소스에 걸쳐 하나의 공유 쿼리를 사용합니다. 각 소스는 자체 페이지 이동, 정렬, 스크롤 상태를 유지하고 그리드 열 설정은 공유됩니다. 사용자가 다른 곳에서 검색어를 지웠다면 소스가 오래된 검색어를 복원할 수 없습니다.
- 활성 로컬, 추적 또는 원격 소스 페이지의 페이지 크기는 도구 모음의 표시 옵션에 둡니다. 로컬, 추적됨, 원격 소스 모두 페이지당 작품 24개, 48개, 96개를 제공합니다. 넓은 화면에서는 결과 맥락과 페이지 탐색을 담은 간결한 상단 페이지 이동을 표시합니다. 휴대폰에서는 작품 위에 결과 수와 현재 페이지를 캡션으로 표시하고, 하단 페이지 이동으로 페이지를 바꿉니다. 하단 페이지 이동에는 첫 페이지, 마지막 페이지, 현재 페이지와 그 앞뒤 페이지가 나열되며, 페이지 번호 사이의 줄임표를 누르면 입력란이 열려 입력한 페이지 번호로 이동합니다.
- 데이터베이스 정리는 라이브러리 밖에 둡니다. 메타데이터 -> DLsite 작품 -> 사용 가능한 소스 없음은 사용 가능한 소스나 미디어 위치가 없는 논리적 계열에 대해 페이지 단위 검색, 소스 확인, 확인을 거친 로컬 정보 삭제를 제공합니다.
- `/no-source` 및 `/library/no-source` 링크는 메타데이터 -> DLsite 작품 -> 사용 가능한 소스 없음을 열고, `/library/all` 및 `/library/remote` 링크는 라이브러리를 엽니다.
- `KIKOTO_MODE=demo`일 때 백엔드의 목록, 상세, 미디어 응답은 전 연령 대상이며 영구적으로 무료인 작품만 허용합니다. 로컬 작품은 정규화된 상업 메타데이터를 사용하며, 알 수 없는 메타데이터와 일시적인 무료 프로모션은 제외됩니다. 시뮬레이션된 Remote Kikoeru 소스는 허용된 로컬 작품만 다시 게시합니다. 데모 세션은 허용된 전체 미디어를 재생할 수 있지만 라이브러리, 설정, 워크플로 상태를 변경할 수는 없습니다. 추천 점수는 모의 무작위 값이며 설명에 "데모 점수, 무작위 생성"으로 표시됩니다. 같은 데모 세션에서는 작품별 점수가 안정적으로 유지되어 다시 섞어도 바뀌지 않으며 선호도 기여나 순위 조정을 표시하지 않습니다.

작품 카드는 알려진 경우 성우 크레딧을 포함하여 모든 컬렉션 화면에서 같은 요약 모델을 사용합니다. 간결한 카드는 성우 이름을 최대 두 개까지 보여 주고, 추가 크레딧은 요약하여 메타데이터 때문에 카드가 무한정 커지지 않게 합니다.

즐겨찾기는 표준 URL에 엔티티/검색 의도만 유지합니다. 선택한 목록, 즐겨찾기 필터, 정렬, 시드, 페이지 이동, 선택, 작품 앵커는 현재 기록 항목에서 복원하며, 사용자 범위의 세션 폴백이 있습니다. `모든 즐겨찾기`는 빠른 표시가 있는 작품과 어떤 목록에든 추가한 작품을 집계합니다. `표시됨`은 빠른 표시가 표시 없음이 아닌 작품만 담는 고정 시스템 목록이며, 구성원은 파생되어 목록으로 편집할 수 없습니다. 다른 목록은 사용자가 만들며 명시적인 구성원을 유지합니다. 작품 카드나 작품 상세의 **목록에 추가**는 검색 칸과 함께 목록을 보여 주며, 목록을 선택하거나 해제할 때마다 바로 저장합니다. 어떤 목록에도 없는 이름을 입력하면 그 목록을 만들고 작품을 넣을 수 있습니다. 규칙으로 작품을 담고 있는 스마트 목록은 그 사실을 표시하며, 해제하면 작품이 그 목록에서 제외됩니다. 즐겨찾기에서 선택한 작품의 **목록 변경**은 각 목록이 추가할 작품 수처럼 목록마다 생길 변경을 보여 주고 한 번에 적용합니다. 작품 일부만 담은 목록은 바꾸지 않는 한 그대로 둡니다. 휴대폰에서는 둘 다 하단 시트로 열립니다.

스마트 목록은 태그로 스스로 채워지는 목록입니다. 목록을 추가할 때 **스마트 목록**을 선택하고, 공유 메타데이터 태그와 내 태그를 세 그룹으로 나눕니다. 작품이 모두 가져야 하는 **필수 태그**, 하나 이상 가져야 하는 **하나 이상 포함할 태그**, 하나도 가지면 안 되는 **제외할 태그**입니다. 빈 그룹은 건너뛰지만, 필수 태그나 하나 이상 포함할 태그가 적어도 하나 있어야 합니다. 편집기는 조건을 바꿀 때마다 일치하는 작품 수를 보여 줍니다. 일치하는 작품은 즐겨찾기가 되지 않은 채 목록에 나타납니다. 다른 작품을 직접 추가할 수도 있으며, 이때는 다른 목록과 같이 즐겨찾기가 됩니다. 일치하는 작품을 제거하면 다시 추가할 때까지 목록에서 빠집니다. 목록은 이미 라이브러리에 있는 작품만 모읍니다. 나중에 일치하는 작품이 생기면 선반에 새 작품 수가 표시되고, **모두 확인함으로 표시**를 선택할 때까지 그 작품에 **새 작품** 표시가 붙습니다. **새 작품만**은 그 작품만 보여 줍니다. **일반 목록으로 변환**은 목록이 현재 보여 주는 작품을 일반 목록으로 남기고, 그 작품을 모두 즐겨찾기로 만들며, 규칙을 제거합니다. 나중에 숨김 처리되거나 삭제된 태그는 취소선이 그어진 채 규칙에 남고 어떤 작품과도 일치하지 않습니다.

목록을 전환해도 결과를 불러오는 동안 전체 즐겨찾기 목록 행은 안정적으로 유지되며, 보류는 마지막 청취 상태 옵션입니다. 재생 커서만으로는 작품이 즐겨찾기에 추가되지 않습니다. 리소스 필터는 즐겨찾기 작품을 카드에 표시되는 사용 가능 여부로 좁힙니다. 사용 가능(로컬, 캐시 또는 원격), 로컬, 원격, 누락 중에서 고릅니다. 파일이 다른 언어 에디션에 있는 작품은 그 에디션과 함께 판정됩니다. 필터는 저장된 사용 가능 여부를 읽으며 실시간 원격 새로 고침을 요청하지 않습니다.

넓은 화면에서는 결과 옆의 선반 레일에 모든 즐겨찾기, 표시됨, 사용자 목록, 팔로우한 서클과 성우가 개수와 함께 나열됩니다. 워크플로 및 설정 레일처럼 이름을 숨기고 아이콘만 남길 수 있으며, 그 선택은 해당 기기에 기억됩니다. 각 사용자 목록은 편집기에서 고른 아이콘을 표시할 수 있으며, 아이콘 레일에서 목록을 구분하는 것이 이 아이콘입니다. 목록 아이콘은 목록에 추가 메뉴에도 나타납니다. 열려 있는 선반에는 표지 모자이크, 개수, 완료한 작품 수, 듣는 중인 작품이 있는 머리글이 있습니다. 휴대폰에서는 같은 선반을 스크롤 가능한 한 줄로 표시하고, 그 아래에 다 들은 비율을 백분율로 보여 주는 한 줄 머리글이 이어집니다. 그 아래로 검색 필드, 현재 정렬 이름이 표시된 정렬 버튼과 그 옆의 리소스·표시·선택 버튼, 가로로 스크롤되는 칩 한 줄로 놓인 청취 상태 필터, 그리고 상단 페이지 막대 대신 결과 수와 페이지를 알려 주는 설명이 차례로 놓입니다. 표시 옵션에서 작품을 카드와 각 작품의 이어듣기 지점이 있는 더 촘촘한 목록 사이에서 전환할 수 있습니다.

선반의 **목록 추가**와 목록 선반의 **목록 편집**은 목록 하나의 편집기를 엽니다. 아이콘이 옆에 있는 이름, 선택 사항인 설명, 스마트 목록의 규칙, **목록 삭제**가 있습니다. 다른 목록이 이미 쓰는 이름은 알려 주지만 사용할 수 있습니다. **목록 관리**는 모든 목록을 보여 주며, **위로 이동**과 **아래로 이동**은 열린 선반을 벗어나지 않고 바로 순서를 바꿉니다. 거기서 목록을 열면 편집한 뒤 **뒤로**로 전체 목록에 돌아갑니다.

## 식별

라이브러리 카드는 소스별 복사본이 아니라 통합 작품을 나타냅니다. 원격 카드는 로컬 파일이 생기기 전에도 작품을 추적하거나 동기화할 수 있지만, 그 결과 상태는 같은 통합 작품 식별에 연결됩니다. 추적(Track)은 선택한 소스 트리도 저장하고 해당 소스를 추적됨에서 엽니다.

원격 소스는 한 작품의 여러 언어판을 가질 수 있습니다. 라이브러리가 그 작품의 판본 패밀리를 이미 알고 있으면, 원격 탭은 소스가 돌려준 판본을 카드 한 장으로 묶어 보여 줍니다. 카드는 판본 하나를 표시합니다. 검색에 지정한 코드의 판본, 없으면 소스에 있는 첫 번째 메타데이터 언어의 판본, 그것도 없으면 패밀리 자체 코드의 판본입니다. 카드의 코드, 제목, 표지, DLsite 링크, 추적(Track), 가져오기(Fetch)는 모두 그 판본의 것입니다. 소스가 둘 이상의 판본을 돌려주면 카드 하단의 언어 버튼이 판본 목록을 보여 주고, 고른 판본을 엽니다. 라이브러리가 아직 모르는 패밀리의 판본은 각각 별도의 카드로 표시됩니다. 한 페이지에 들어가는 결과는 카드 수를 세고, 여러 페이지에 걸친 결과는 소스의 항목 수를 셉니다.

## 소스 탭

소스 탭은 작품을 어디에서 재생하거나 가져올 수 있는지 사용자가 알 수 있게 도와야 합니다. 별도의 메타데이터 소유권을 가진 독립된 라이브러리가 아닙니다. 로컬, 추적, 캐시, 원격의 사실은 모두 같은 작품 모델로 되돌아갑니다.
