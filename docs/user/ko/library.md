# 라이브러리

[English](../en/library.md)

라이브러리는 작품을 탐색하는 기본 화면입니다.

## 현재 동작

- Local, Tracked 및 설정된 원격 소스 탭을 표시합니다.
- 대규모 결과에는 서버 측 페이지 매김을 사용합니다.
- 정규화된 제목, 코드, 언어판 별칭, 서클, 태그, 성우 크레딧을 검색합니다.
- 표지, 제목, 코드, Circle / Series, 성우 정보, 로컬 가용성, 소스 태그와 빠른 청취 상태를 카드에 표시합니다.
- 제공자 태그는 최대 두 줄로 표시하고 나머지는 `+N` 팝오버에서 보여줍니다. 개인 태그는 별도 행입니다.
- DL 판매량과 숫자가 아닌 5단계 평점 비교를 표시하며 저장된 재생 커서가 있으면 아이콘을 표시합니다.
- 활성화된 소스에서 Origin이 아닌 사용 가능한 언어판을 알고 있을 때만 언어 아이콘을 표시합니다.
- 상용 메타데이터의 현재 가격을 표시하고 가격이 0이면 Free로 표시합니다.
- 사용자 작품 태그는 메타데이터 태그와 분리하며 `mytag:`는 개인 태그만 필터링합니다.
- 소스 가용성과 메타데이터 태그를 시각적으로 분리합니다.
- 알려진 연령 등급을 서클 이름 옆에 표시하고 전체 정보는 작품 상세에 보존합니다.
- Library, Favorites, 서클 상세, 성우 상세에서 동일한 반응형 작품 그리드와 열 설정을 공유합니다.
- 시드 기반 무작위 정렬을 지원하여 페이지 매김을 안정적으로 유지합니다.
- 새 Library 화면은 개인화 추천 정렬을 기본으로 사용하되 기록과 세션 복원 선택을 보존합니다. 명시적 상태 필터는 일치하는 모든 작품을 반환합니다.
- Library 제어 위에 최근 재생 스트립을 표시하며 사용자별 최신 커서를 사용합니다. 스트립은 접을 수 있습니다.
- Local, Tracked 및 원격 소스에 하나의 검색어를 사용합니다. 각 소스의 페이지, 정렬, 스크롤 상태는 별도로 유지합니다.
- 현재 소스의 페이지 크기를 첫 행 도구 모음에 표시합니다.
- 데이터베이스 정리는 Library에서 수행하지 않습니다. Maintenance -> Work maintenance -> No available source에서 확인 후 삭제합니다.
- `KIKOTO_MODE=demo`에서는 all-ages이며 영구 무료인 작품만 응답에 포함됩니다.

작품 카드는 모든 컬렉션 화면에서 동일한 요약 모델을 사용합니다. Favorites는 Quick 표시와 사용자 목록의 작품을 집계하며 재생 커서만으로 작품이 추가되지는 않습니다.

## Identity

Library 카드는 소스별 복사본이 아니라 통합 작품을 나타냅니다. Track은 선택한 소스 트리를 저장하고 Tracked에서 열므로 두 번째 Fork가 필요하지 않습니다.

## 소스 탭

소스 탭은 작품을 어디에서 재생하거나 가져올 수 있는지 알려줍니다. 별도의 라이브러리나 메타데이터 소유권이 아닙니다.
