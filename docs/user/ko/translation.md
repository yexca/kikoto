# 번역
[English](../en/translation.md) · [简体中文](../zh-Hans/translation.md) · [繁體中文](../zh-Hant/translation.md) · [日本語](../ja/translation.md) · [한국어](../ko/translation.md)

**번역** 페이지(`/translation`)는 [AI로 번역](work-detail.md#ai로-번역)을 라이브러리 전체에 걸쳐 보여 줍니다. 실행 중이거나 대기 중인 것, 중지된 것, 완료된 항목이 기록한 것, 그리고 각 언어를 작품이 이미 얼마나 갖추었는지입니다. 라이브러리 쓰기 권한이 있는 계정의 사이드바에서 열며, 워크플로 권한은 필요하지 않습니다. 열 수 있는 모든 사용자는 모든 계정의 번역을 봅니다. 각 항목은 완료되는 즉시 적용되며, 자세한 내용은 [결과](work-detail.md#결과)에 있습니다.

이 페이지는 AI로 번역 실행과 그 항목을 보여 주는 화면입니다. [워크플로](workflows.md)의 Activity는 같은 실행을 진단 정보와 함께 나열합니다. Demo에서는 이 페이지가 읽기 전용입니다. Demo는 아무것도 번역하지 않으므로 작품을 나열하는 것은 **현황**뿐입니다.

## 진행 중

**진행 중**(`?view=running`)은 페이지가 처음 여는 보기로, 번역 중인 실행, 그다음 아직 대기 중인 실행을 작품당 카드 하나로 나열합니다. 각 대상 언어는 자체 행에 단계를 표시합니다. 대기 중, 완료된 항목 수와 함께 번역 중, 또는 완료입니다.

자신이 시작한 실행은 워크플로 권한 없이도 **취소**할 수 있으며, 워크플로 관리자는 다른 계정의 실행도 취소할 수 있습니다. 아직 보내지 않은 모든 것이 멈추고, 이미 보낸 번역 요청은 결과를 알 수 없는 상태로 남습니다. 워크플로 권한이 있는 계정은 실행의 진단 정보를 여는 **활동**도 봅니다.

## 중지됨

**중지됨**(`?view=attention`)은 실패했거나, 결과를 알 수 없거나, 만료되었거나, 콘텐츠 안전 정책이 차단한 항목을 작품, 언어, 분류별로 묶어 이유와 함께 나열합니다. **다시 전송**은 실패한 항목을 같은 실행에 다시 대기열에 추가합니다. 결과를 기록하지 못한 항목, 예를 들어 폴더가 막힌 가사는 추가 요청 없이 보관된 결과로 기록합니다. 연결 끊김, 서버 중지 또는 취소 등으로 응답을 잃은 요청은 제공자가 이미 요금을 청구했을 수 있으므로, **다시 전송**은 먼저 확인을 요청합니다. 제공자에 닿지 않은 요청, 예를 들어 연결할 수 없었던 제공자로 보낸 요청은 확인 없이 다시 전송합니다. 원본, 제공자 또는 콘텐츠 정책이 바뀐 항목은 작품에서 새 요청으로 다시 번역합니다. 기다리는 동안 파일, 폴더 또는 트랙에 해당 언어의 표시 이름이나 가사가 생긴 항목은 그 값을 유지하며 다시 전송하지 않습니다.

## 기록

**기록**(`?view=history`)은 완료된 항목이 기록한 것을 최신순으로, 작품별로 묶고 각 작품으로 가는 링크와 함께 나열합니다. 해당 언어의 제목, 설명, 태그 이름, 표시 이름, 그리고 각 가사 항목이 된 파일입니다.

## 현황

**현황**(`?view=coverage`, `&language=`와 `&missing=` 포함)은 카탈로그 작품과 사용자 지정 작품을 가리지 않고 모든 작품이 한 대상 언어로 얼마나 갖춰졌는지 보여 주며, `/metadata?view=translation` 링크가 이 보기를 엽니다. **대상 언어**는 인터페이스 언어로 시작합니다. **표시**는 기본값인 하나라도 없는 작품, 제목·설명·태그 이름·파일 이름·가사 중 특정 항목이 없는 작품, 완료된 작품, 또는 모든 작품을 나열합니다. **제목**과 **설명**은 해당 언어의 텍스트가 어디서 왔는지 알려 줍니다. 작품 원문판의 언어이면 **원문**, 작품의 해당 언어판이면 **공식판**, 해당 언어의 수동 제목이나 설명, 또는 모든 언어에 표시되는 **대체** 제목이나 설명이면 **수동**, AI 번역이면 **LLM**, 아니면 **없음**입니다. **태그**는 해당 언어의 이름이 있는 작품의 공유 태그 수를, **파일 이름**은 해당 언어의 표시 이름이 있는 로컬 파일 수를, **가사**는 해당 언어로 가사가 지정된 로컬 트랙 수를 셉니다. 대시는 셀 대상이 없다는 뜻이며, 파일 이름은 작품의 원래 언어에서는 **원문**으로 표시됩니다. 완료된 항목에는 체크 표시가 붙고, 빠진 항목은 주의 색으로 표시됩니다. 행에는 해당 언어로 진행 중인 작품의 번역도 함께 표시됩니다. 넓은 화면에서는 각 항목이 별도의 열이며, 좁은 화면에서는 제목 아래에 나열됩니다.

작품을 선택하고 헤더의 번역 버튼을 누르면, 선택한 각 작품에 없는 제목, 설명, 공유 태그 이름, 파일 및 폴더 이름을 선택한 모델로 해당 언어로 번역합니다. 분류는 선택한 작품 중 하나라도 없는 항목으로 시작합니다. 없는 것이 없는 작품은 건너뜁니다. 가사는 각 작품 자체의 AI로 번역에서 트랙별로 선택합니다. 결과는 **기록**에 표시됩니다.

페이지는 실행이 진행 중인 동안 몇 초마다 스스로 새로 고칩니다. 휴대폰에서는 보기가 옆으로 스크롤되는 한 줄로 표시됩니다.
