# 작품 상세
[English](../en/work-detail.md) · [简体中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

작품 상세는 하나의 작품에 대한 메타데이터, 에디션, 파일 트리, 소스 사용 가능 여부, 재생 동작을 보여 줍니다.

## 다국어 제목

편집기의 제목 섹션은 일본어, 중국어 간체, 중국어 번체, 영어, 한국어를 먼저, 각각 전체 너비의 행으로 나열합니다. 원래 언어에는 `origin` 배지가, 현재 표시 중인 메타데이터 언어에는 `current` 배지가 붙으며, 둘이 같은 행에 함께 나타날 수도 있습니다. **모든 언어 공통 제목**은 그 아래의 **고급 제목 옵션**에 있으며 기본적으로 접혀 있습니다. 이미 모든 언어 공통 제목이 있으면 편집하거나 지울 수 있도록 이 옵션이 자동으로 열립니다. 힌트는 모든 언어 공통 제목이 모든 언어의 제공처 제목을 재정의하지만 언어별 수동 제목이 우선하며, 에디션과 소개는 그대로 유지된다고 설명합니다. 행 자체의 수동 제목은 편집 가능한 텍스트이고, 제공처 제목과 상속된 제목은 회색 힌트로 남으며 변경 없이 저장되는 일은 없습니다. 각 행은 현재 출처를 밝히고 수동 제목이나 편집된 제목을 표시합니다. 저장하면 변경된 필드와 제목 언어만 전송합니다. 기존 수동 제목을 지우거나 그 행에서 되돌리기를 선택하면 저장할 때 해당 범위가 제거되고, 상속된 힌트를 지우는 것은 아무 변경도 만들지 않습니다. 같은 편집기가 메타데이터 → 작품에서도 열립니다.

메타데이터 언어 메뉴에는 알려진 에디션, 언어별 수동 제목 및 **LLM**으로 표시된 승인된 번역이 포함됩니다. LLM 선택은 동일 작품의 메타데이터 표시만 바꾸며 공식 에디션이나 오디오 버전을 만들지 않습니다. 원문 대체는 알 수 없는 언어를 포함하여 선언된 원래 언어를 유지합니다. [제목과 설명 우선순위](../../architecture/data-model.md#manual-overrides-and-titles)를 참고하세요.

DLsite에 작품 기록이 없어 원격 소스가 이를 채운 경우, 상세 안내에 **원격 소스로 보완됨**이 표시되고 각 소스가 채운 값이 나열됩니다. 원격 제목은 제목 순서에서 DLsite 다음, 작품 자체의 제목 앞에 옵니다. 언어를 선언하지 않으므로 언어 선택지를 추가하지 않고 텍스트도 그대로 유지하며, 제목 편집기는 그 출처를 밝힙니다.

제공처 표시에서는 작품 계열의 원본이 아닌 모든 에디션이 번역으로 취급되며, 제3자 번역도 포함됩니다. `【简体中文版】`나 `【ドイツ語版】` 같은 DLsite 언어 에디션 레이블은 그 형식에 따라 맨 앞의 하나만 제거됩니다. `【ASMR】` 같은 레이블, 중간에 있는 레이블, 수동 제목은 그대로 유지됩니다. 각 에디션 항목은 지원되지 않는 언어를 포함하여 자체 제목을 유지합니다. 원시 제공처 제목과 스냅숏은 변경되지 않습니다. 카드, 상세, 언어 선택, 검색 결과, 새 재생 대기열은 같은 표시 규칙을 공유하며, 모든 수동 제목은 계속 검색할 수 있습니다. 소개는 일반 텍스트로 그대로 렌더링되며, 수동 작품 소개로 대체되지 않는 한 선택한 에디션을 따릅니다. 일치하는 에디션이 없는 수동 언어는 원본 소개를 사용합니다.

## 메타데이터 편집

미리보기에서는 안정적인 태그 ID를 기준으로 현재 태그와 가져온 태그를 병합할 수 있습니다. DLsite 패밀리 수락은 별도 동작이며 일반 필드 저장은 같은 패밀리의 에디션을 라이브러리에 추가하지 않습니다.

**편집용 가져오기**는 현재 값, 가져온 값, 저장 예정 값의 세 열로 작품을 비교합니다. 언어 범위는 실제 에디션에서 만들어지며 원본 에디션에는 Original 표시가 붙습니다. 가져온 값을 그대로 사용하면 제공자 메타데이터로 저장되고 기존 수동 재정의가 제거됩니다. 저장 예정 값을 편집한 경우에만 수동 재정의로 저장됩니다. 미리보기는 만료되며 열어 둔 동안 작품이 변경되면 적용할 수 없습니다.

히어로 영역의 **메타데이터** 버튼은 편집기를 바로 엽니다. **메타데이터 새로 고침**은 왼쪽 아래에 있으며 일반적인 DLsite 새로 고침을 실행합니다. 활성화된 원격 소스가 메타데이터를 지원하면 옆의 화살표가 `<소스 이름>에서` 선택지를 엽니다. 하나를 선택하면 해당 소스에서 이 작품의 최신 메타데이터를 요청합니다. 수동 편집과 DLsite 값은 우선순위를 유지하고, 저장하지 않은 편집기 초안도 그대로 남습니다. 이 명시적인 새로 고침에는 자동 원격 대체가 켜져 있을 필요가 없습니다.

admin과 super_admin은 `library:write`로 작품 메타데이터를 편집할 수 있습니다. 저장하면 편집기의 초기 값에서 바뀐 필드만 전송하며, 표지만 선택해도 자동 제목, 서클, 시리즈, 성우 크레딧은 유지됩니다. 필드를 지우면 해당 필드의 재정의만 초기화됩니다. 같은 계열에서 다듬은 DLsite 제목과 정확히 일치하는 기존의 고정 제목 재정의는 업그레이드 중에 제거되며, 서클, 시리즈, 성우 재정의는 유지됩니다.

편집기는 필드를 제목, 표지, 태그, 크레디트, 메타데이터 출처 섹션으로 묶으며, 저장하지 않은 변경이 있는 섹션에는 점이 표시되고 푸터에 목록이 나타납니다. 수동 서클, 시리즈, 성우 목록이나 표지의 되돌리기, 새로 추가하거나 제거한 메타데이터 링크를 포함한 모든 변경은 저장하기 전까지 초안으로 남으므로, 섹션을 전환해도 편집 내용을 잃지 않습니다. 취소는 초안을 버리기 전에 확인을 요청합니다. 서클, 시리즈, 성우는 알려진 항목을 연결하는 제안을 제공하며, 식별자는 이름 아래에 계속 표시되고 ID 편집에서 편집할 수 있습니다. 표지는 작품의 로컬 이미지 썸네일 그리드에서 고릅니다. Ctrl+Enter로 저장합니다.

제목 섹션에는 언어별 제목 아래에 모든 언어에 공통으로 적용되는 작품 소개를 편집하는 **작품 소개** 필드가 있습니다. 작품이 현재 표시하는 소개에서 시작하며 여러 줄을 입력할 수 있습니다. 변경한 텍스트를 저장하면 수동 작품 소개가 되어 모든 에디션에서 제공처와 LLM 소개를 대체하고, 메타데이터를 새로 고쳐도 유지됩니다. 상속된 소개를 그대로 두거나 지우면 아무것도 저장되지 않습니다. 수동 작품 소개를 지우거나 되돌리기를 선택하면 저장할 때 제공처의 소개가 다시 표시됩니다. 이 필드는 **편집용 가져오기**가 필요 없으므로, 제공처 메타데이터가 없는 작품에도 작품 소개를 설정할 수 있습니다.

제목 섹션의 **연령 등급**에서는 전체 연령, R15, R18 중에서 고를 수 있고 제공처의 등급도 함께 표시됩니다. 수동 등급은 사용자 지정 작품이나 DLsite가 더 이상 게시하지 않는 상품처럼 제공처가 등급을 알려 주지 않는 작품의 등급을 채우거나, 제공처의 등급을 더 엄격하게 바꿉니다. 제공처보다 덜 엄격한 등급은 선택할 수 없습니다. 작품에는 수동 등급이 표시되고, 라이브러리에서도 그 등급으로 검색되며, [콘텐츠 안전 정책](settings.md#콘텐츠-안전-정책)에서도 그 등급으로 분류됩니다. 다만 제공처의 등급이 더 엄격하면 그 등급이 적용됩니다. 되돌리기를 선택하면 저장할 때 수동 등급이 제거됩니다.

섹션 위의 **메타데이터 언어** 탭에서 편집기가 표시할 언어를 고릅니다. **모든 언어** 다음에 일본어, 중국어 간체, 중국어 번체, 영어, 한국어가 작품에 해당 언어의 에디션이 있는지와 관계없이 나열됩니다. **더 보기**는 언어가 선언되지 않은 원본 에디션을 포함해 작품이 가진 다른 언어의 에디션을 엽니다. 하나를 고르면 그 탭이 선택되고 `더 보기 - 독일어`처럼 언어 이름이 표시됩니다. 제목과 태그 이름은 위의 다섯 언어로만 저장할 수 있으므로, 더 보기의 에디션에는 제공처의 제목과 각 태그의 기본 이름이 표시됩니다. 다섯 언어 중 하나에서는 제목 섹션에 해당 언어의 행만 표시되고, 태그 섹션에는 각 태그가 해당 언어의 이름으로 표시됩니다. 해당 언어의 이름이 없는 태그는 대신 쓰이는 이름이 회색으로 표시되며, 언어 버튼은 해당 언어의 이름과 모든 언어 공통 이름만 엽니다. 작품 패밀리 목록에는 선택한 언어의 에디션이 표시됩니다. 작품에 붙은 태그, 표지, 크레디트는 모든 언어에서 같습니다.

태그 섹션은 공유 메타데이터 태그를 검색하고 이 작품에 추가하거나 제거하며, 작품에 DLsite 메타데이터가 없어도 사용자 지정 태그를 만들 수 있습니다. DLsite 태그 복원은 작품의 태그 추가/제거를 지웁니다. 공유 이름은 수동 이름과 학습된 장르 이름을 사용하여 우선 표시할 메타데이터 언어를 따르며, 일본어 전용 작품도 알려진 중국어 태그 이름을 보여 줄 수 있습니다. 백그라운드 업데이트가 끝난 뒤에도 숨겨진 태그는 어디에서나 계속 나타나지 않습니다. 개인 "내 태그"는 계정이 소유하는 별도의 태그입니다. 데모는 편집기를 읽기 전용으로 보여 줍니다.

작품의 태그는 태그 추가 입력란 아래에 한 줄씩 목록으로 표시되며, 각 줄 아래에 다른 언어의 이름이 나열됩니다. 이 작품에 추가한 태그에는 **추가됨** 표시가 붙습니다. 각 태그의 언어 버튼은 해당 줄 안에서 모든 언어에서의 이름을 열며, 모든 언어 공통 이름과 지원되는 각 언어에 대해 별도의 행이 있습니다. 수동 이름은 편집 가능한 텍스트이고 제공처 또는 학습된 이름은 회색 힌트로 남습니다. 태그 이름은 공유되므로 이름을 바꾼 태그는 그 태그가 있는 모든 작품에서 바뀌며, 패널에는 몇 개의 작품이 이를 공유하는지 표시됩니다. 새 사용자 지정 태그는 입력한 이름을 모든 언어 공통 이름으로 유지하며, 만들기 전에 다른 언어의 이름도 받을 수 있습니다. 이름 편집은 다른 모든 변경처럼 초안이며 저장할 때 기록됩니다.

새 사용자 지정 이름은 저장이 공유 태그를 만들거나 재사용하여 하나의 트랜잭션으로 이 작품에 연결할 때까지 초안으로 남습니다. 취소하면 공유 항목이 남지 않습니다. 공백을 제거하고 대소문자를 무시했을 때 알려진 어느 언어의 이름과 일치하면 그 태그를 재사용하므로, 반복해서 클릭하거나 중복 이름을 입력해도 중복 개념이 생기지 않습니다.

메타데이터 언어를 전환하면 그 버전의 수동 또는 사전 태그 이름이 있을 때 이를 사용하고, 없으면 우선 언어로 대체합니다. 모든 버전은 원본 에디션에서 가져온 같은 태그를 보여 주므로, 전환하면 태그를 추가하거나 빼지 않고 이름만 바뀝니다. 추가, 제거, 최종 대상 숨기기, 병합 매핑은 여전히 적용됩니다. 스냅숏에만 있는 태그는 해당 프로젝션이 끝날 때까지 계속 보이며, 모든 태그를 제거하면 의도적으로 빈 표시가 됩니다.

백그라운드 **태그 이름 학습** 워크플로가 그 이름을 학습한 뒤에는 일본어 전용 작품도 우선 언어로 태그를 보여 줍니다. 그전까지 태그는 일본어 이름으로 대체됩니다. 제목은 일본어로 유지됩니다.

완성 시 병합된 이름은 최종 태그로 표시됩니다. 숨겨진 대상에 병합된 경우를 포함하여 숨겨진 일치 항목은 레이블이 붙고 추가할 수 없으므로, 먼저 메타데이터에서 숨김을 해제하세요. 이름은 [설정](settings.md)에 설명된 언어 우선순위를 따릅니다.

백그라운드 업데이트가 끝날 때까지는 메타데이터를 새로 고쳐도 작품이 마지막으로 저장된 태그 집합(빈 집합 포함)을 유지합니다. 성우 페이지의 원격 작품 목록은 수동으로 추가한 공유 태그와 함께 원격 태그를 표시합니다.

## LLM 번역

검사 방식은 [콘텐츠 안전 정책](settings.md#콘텐츠-안전-정책)을 참고하세요.

메타데이터 동기화와 라이브러리 쓰기 권한이 있는 편집자는 메타데이터 편집기의 **LLM 번역**에서 제공자와 그 모델 중 하나, 대상 언어 및 전송 필드를 선택합니다. 대상 언어는 모델이 작품의 원래 언어에서 인터페이스 언어로 번역할 수 있으면 그 언어로, 그렇지 않으면 모델이 지원하는 언어로 시작하며, 지원하지 않는 언어는 선택할 수 없음으로 표시됩니다. **전송 없이 콘텐츠 확인**은 설정한 정책 모드로 이번 요청을 분류합니다. 판정, 일치 필드와 규칙 ID를 표시하고 LLM에는 연결하지 않습니다. 규칙과 엔드포인트 경계는 [Settings → LLM](settings.md#llm-제공자)에서 설정합니다.

동기 미리보기는 15분, 백그라운드 미리보기는 24시간 유효하며 재시작 후에도 유지되고 시작 사용자와 작품에 연결됩니다. 승인 시 원문, 현재 권한, 정책 버전과 모델 설정을 재검사하고 변경이 있으면 무효화합니다. 검토에는 대기, 승인, 거부 및 만료 상태를 표시합니다. 승인된 제목과 설명은 LLM 출처를 별도로 유지하며 제공자 스냅샷과 수동 값을 덮어쓰지 않습니다. 일반 동기화는 번역을 유지하고 원문 변경은 해당 필드 번역만 만료시킵니다. **취소**는 표시에서 제거하고, **복원**은 원본 입력이 일치하는 기록만 재사용합니다.

**공유 태그 이름**은 기존 공유 태그 개념의 누락된 언어 이름을 번역하고 수동 이름, 제공자 이름 및 재사용 가능한 승인된 번역은 건너뜁니다. 승인하면 다른 작품의 공유 이름에도 반영되지만 태그 ID와 작품 연결 관계는 유지됩니다. 수동 및 제공자 이름이 우선하며 이름 변경, 숨김과 병합은 유지된 위험 정보를 지우지 않습니다.

가사는 [가사 관리 → 번역](#번역)에서 번역합니다.

**백그라운드 번역 시작**은 명시한 기존 작품 1–100개를 받습니다. 동일 제출은 영구 작업을 재사용합니다. 완료된 작업의 미리보기가 만료되거나 검토가 끝나면 다시 제출할 때 새 작업을 만들고 기존 Activity 기록을 유지합니다. Activity는 진행, 취소, 재시작 복구 및 실패를 표시합니다. 실행 시 권한, 입력, 정책과 선택한 엔드포인트를 재검사하고 완료된 청크를 유지합니다. 명확한 거부와 전송 전 실패는 같은 엔드포인트로 명시적 재시도가 가능합니다. 결과를 알 수 없는 요청은 자동 재전송을 중단하며 **결과를 알 수 없는 요청 재전송**은 추가 요금 가능성의 명시적 승인이 필요합니다. 엔드포인트, 모델, 정책 또는 입력 변경 시 이 재전송을 금지합니다. 결과는 항상 사용자의 검토를 기다립니다.

## 전사

**가사 관리 → 전사**는 구성된 [음성 인식 서비스](settings.md#음성-인식-서비스)로 로컬 트랙의 음성을 타임스탬프가 있는 가사로 바꿉니다. 이 탭은 작품의 로컬 오디오 파일을 각 파일에 가사가 있는 언어와 함께 폴더별로 나열합니다. 목록 위의 필터는 **가사 없음**(기본값)인 트랙, 작품의 원래 언어 가사가 없는 트랙(**일본어 가사 없음** 등), 또는 **전체** 트랙을 보여 줍니다. 트랙을 선택하거나 목록 맨 위에서 나열된 모든 트랙을 선택하면 하단 막대에서 **오디오 언어**, **가사 언어**, 서비스와 모델을 고를 수 있고, **전사**는 선택한 트랙마다 전사 하나를 대기열에 추가합니다. 오디오 언어는 오디오에서 말하는 언어입니다. 기본값은 작품의 원래 언어이며 힌트로 서비스에 전달됩니다. **자동 감지**는 서비스가 판단하게 합니다. 가사 언어는 결과가 저장되고 지정되는 언어입니다. **오디오 언어와 같음**은 기본값이 켜짐이며, 이때 가사 언어는 오디오 언어이고 감지된 음성은 대체 가사로 저장됩니다. 번역하는 모델(예: 일본어 음성에서 중국어 간체를 작성하는 Kikoto Helper 모델)은 자체 가사 언어로 작성합니다. 그런 모델을 선택하면 오디오 언어가 모델의 원본 언어로 설정되고, **오디오 언어와 같음**이 꺼지며, 가사 언어가 모델이 작성하는 언어로 설정됩니다. **오디오 언어와 같음**을 끄면 다른 가사 언어를 고를 수 있습니다. 선택한 모델이 그 오디오 언어에서 그 언어를 작성하지 못하는 동안에는 **전사**를 사용할 수 없으며, 막대 아래에 안내가 표시됩니다. 공유 [콘텐츠 안전 정책](settings.md#콘텐츠-안전-정책)은 작품 메타데이터와 서비스 수신 상한을 확인하며 오디오 자체는 검사하지 않습니다. 필터 옆의 **등급 확인**은 아무것도 보내지 않고 작품의 등급을 보여 주며 받을 수 없는 서비스를 표시합니다. 확인은 누를 때만 실행됩니다. 이미 전사 중인 트랙은 대기열에 중복해서 추가되지 않으며, 트랙 행에는 열려 있는 전사의 상태가 표시됩니다.

전사는 Activity 워크플로입니다. Kikoto가 트랙을 직접 디코딩하여 16 kHz 모노 오디오를 최대 5분 길이의 부분으로 나누어 보내며, 각 부분은 마지막 1분 중 가장 조용한 지점에서 잘라 단어 사이에서 끊기게 합니다. 완료된 부분은 보관되고, 워크플로는 부분 사이에 대기 중인 다른 작업에 대기열을 넘기므로 긴 트랙이 스캔이나 Fetch를 막지 않습니다. 각 부분을 보내기 전에 서비스 설정, 콘텐츠 정책, 사용자 권한, 오디오 파일이 바뀌지 않았는지 다시 확인합니다. 재시작으로 중단된 요청이나 서비스가 거부한 부분이 있으면 전사가 중지되며, Activity의 **다시 시도**는 마지막으로 완료된 부분 이후부터 이어 가고 중단된 부분을 다시 보냅니다. 실행을 취소하면 중지됩니다.

완료된 전사는 트랙 아래의 목록에서 검토를 기다립니다. **미리 보기**는 다른 가사와 같은 시간 확인으로 처음 몇 줄을 보여 줍니다. **가사에 추가**는 트랙의 작품 폴더 안 해당 언어의 가사 폴더에, 트랙 자체의 경로를 따라 WebVTT 파일로 저장하고(예: `lyrics_kikoto/ja/mp3/Track 01.vtt`) 트랙에 지정합니다. 같은 이름의 다른 파일이나 폴더가 이미 있으면 그대로 두고, 전사는 번호가 붙은 이름으로 옆에 저장합니다. 가사 폴더나 그 안의 폴더가 있어야 할 자리에 Kikoto가 만들지 않은 파일이나 폴더가 있으면 그 이름을 바꾸거나 옮기기 전까지 **가사에 추가**가 실행되지 않으며, 전사는 보관됩니다. 필요 없는 전사는 **폐기**합니다. 가사에 추가가 끝나지 않으면 결과가 보관되며 **가사에 추가**로 다시 시도합니다.

데모에서는 이 탭에 작품 트랙의 전사 예시와 예시 서비스가 표시됩니다. 오디오는 전송되지 않고 **미리 보기**에는 예시 텍스트가 표시되며, **등급 확인**, **전사**, **가사에 추가**, **폐기**는 사용할 수 없습니다.

## 번역

**가사 관리 → 번역**은 구성된 [LLM 제공자](settings.md#llm-제공자)로 로컬 트랙의 가사를 번역합니다. 이 탭은 작품의 로컬 트랙을 가사 언어에 대응시킨 표입니다. 초록색 셀은 그 언어의 가사가 있고 빨간색 셀은 없습니다. **대체** 열은 대체 가사가 번역 대상이 아니므로, 트랙에 대체 가사가 없으면 대시를 표시합니다. 오른쪽 위의 **언어**로 표시할 열을 고릅니다. 빨간색 셀을 클릭하면 그 트랙의 해당 언어를 생성 대상으로 삼고, 언어 머리글을 클릭하면 그 언어의 가사가 없는 모든 트랙을 선택합니다. 선택한 각 트랙은 작품의 원래 언어 가사, 그다음 대체 가사, 그다음 처음 나오는 다른 언어의 가사에서 번역되며 그 셀에 **번역 원본** 표시가 붙습니다. 같은 행의 다른 초록색 셀을 클릭하면 그 파일에서 대신 번역합니다. 번역이 실행 중이거나 검토를 기다리는 셀은 상태를 표시하며 다시 선택할 수 없습니다. 하단 막대에서 제공자와 모델을 고르고, **번역**은 선택한 셀마다 번역 하나를 대기열에 추가합니다. 선택한 모델이 번역할 수 없는 언어의 열은 [LLM 번역](#llm-번역)처럼 표시되며 그 셀은 선택할 수 없습니다. 트랙에는 작품 폴더 안의 로컬 파일이 있어야 하고, 번역은 그 작품 폴더에 저장됩니다. 트랙과 이름이 일치하는 원격 가사 파일은 그 트랙의 대체 가사로 취급되며 구름 표시가 붙습니다. 번역하려면 관리자의 활성화와 원격 가져오기 권한이 필요합니다. 콘텐츠 안전 정책은 [LLM 번역](#llm-번역)과 같으며, 무엇이든 보내기 전에 가사 전체를 검사합니다. **등급 확인**은 아무것도 보내지 않고 표시된 열에 있는 모든 가사 파일에 이 검사를 실행하며, 각 초록색 셀에 등급을 표시하고 등급별 개수를 세며, 선택한 번역 원본을 받을 수 없는 제공자를 표시합니다. 확인은 누를 때만 실행됩니다.

번역은 Activity 워크플로로, 가사를 크기가 제한된 부분으로 나누어 보내고 완료된 부분을 보관합니다. LRC, WebVTT, SRT, 표준 ASS Dialogue 및 일반 텍스트는 시간축과 큐 순서를 유지하며 각 줄의 텍스트만 번역합니다. 입력과 출력은 각 128 KiB, 원본은 4,000줄, 텍스트 각 줄은 4,096바이트로 제한됩니다. 제공자가 거부한 부분이나 일시적으로 사용할 수 없는 작품 폴더는 Activity에서 다시 시도할 수 있습니다. 재시작으로 중단된 요청은 결과를 알 수 없으며, **다시 보내기**는 추가 요금이 발생할 수 있음을 확인한 뒤 다시 보냅니다. 가사, 제공자 설정, 콘텐츠 정책 또는 권한이 바뀌면 번역이 중지되며 다시 시작해야 합니다.

완료된 번역은 표 아래의 목록에서 24시간 동안 검토를 기다리며 시작한 사용자에게 귀속됩니다. **미리 보기**는 다른 가사와 같은 시간 확인으로 처음 몇 줄을 보여 줍니다. **가사에 추가**는 가사 파일, 정책, 제공자를 다시 확인한 다음, 트랙의 작품 폴더 안 대상 언어의 가사 폴더에, 트랙 자체의 경로와 원본 파일의 확장자로 번역을 저장하고(예: `lyrics_kikoto/zh-hans/mp3/Track 01.lrc`) 그 언어로 트랙에 지정합니다. 원본 가사 파일은 변경되지 않습니다. 같은 이름의 다른 파일이나 폴더가 이미 있으면 그대로 두고, 번역은 번호가 붙은 이름으로 옆에 저장합니다. 가사 폴더나 그 안의 폴더가 있어야 할 자리에 Kikoto가 만들지 않은 파일이나 폴더가 있으면 그 이름을 바꾸거나 옮기기 전까지 **가사에 추가**가 실행되지 않으며, 번역은 보관됩니다. 필요 없는 번역은 **버리기**로 삭제합니다. 가사에 추가가 끝나지 않으면 결과가 보관되며 제공자에 연결하지 않고 **가사에 추가**로 다시 시도합니다.

데모에서는 이 탭에 가사가 있는 트랙의 번역 예시와 예시 제공자가 표시됩니다. 가사는 전송되지 않고 **미리 보기**에는 예시 텍스트가 표시되며, **등급 확인**, **번역**, **가사에 추가**, **버리기**, **다시 보내기**는 사용할 수 없습니다.

## 사용자 지정 작품

[사용자 지정 작품](settings.md#메타데이터)에는 제공처 메타데이터도 원격 소스도 없습니다. 상세에는 DLsite 링크, 평점, 판매량, 메타데이터 안내가 표시되지 않고, 메타데이터 새로 고침, 원격 소스 탭, 소스 확인도 제공되지 않으며, 디렉터리에는 로컬 폴더만 나열됩니다. 메타데이터 편집기에는 **편집용 가져오기**와 메타데이터 출처 섹션이 없으므로 사용자 지정 작품에는 메타데이터 링크, 구매 특전의 상위 작품, 세트 구성을 지정할 수 없습니다. 제목, 작품 소개, 연령 등급, 커버, 태그, 크레디트는 직접 편집합니다. **파일 편집**과 **가사 관리**의 **가사 파일** 탭에는 로컬 폴더와 에디션만 나열됩니다. 폴더가 없으면 디렉터리에, 폴더 이름에 `[KT00000001]`처럼 대괄호로 묶은 해당 KT 코드가 있으면 스캔이 작품을 다시 찾는다는 안내가 표시됩니다. 커버는 로컬 이미지 중에서 고르며, 커버를 초기화하면 대신 작품 코드가 표시됩니다.

## 구매 특전

조기 구매 특전(`【早期購入特典】`) 같은 구매 특전은 자체 파일을 가진 별도의 DLsite 상품이지만, DLsite는 이것이 어느 작품에 속하는지 알려 주지 않습니다. 메타데이터 동기화가 이를 상위 작품에 연결할 수 있으며([구매 특전](settings.md#구매-특전) 참고), 라이브러리 편집자는 편집기의 메타데이터 출처 섹션에 있는 **구매 특전**에서 상위 작품의 코드를 입력하거나 제거할 수 있습니다. 연결된 특전은 별도의 작품으로 유지됩니다. 자체 제목, 표지, 파일, 재생 진행 상황, 라이브러리 카드를 유지하며, 없는 태그, 성우, 시리즈는 상위 작품에서 가져옵니다. 특전의 상세에는 상위 작품과 함께 **특전 대상**이 표시되고, 상위 작품이 라이브러리에 없으면 DLsite 링크가 있는 상위 코드가 표시됩니다. 상위 작품의 상세에는 라이브러리에 있는 **구매 특전**이 나열되며, 그 계열의 다른 에디션에 연결된 특전도 포함됩니다. 상위 코드가 라이브러리 작품이 되는 일은 없습니다. 링크를 제거하면 해당 작품의 자동 감지도 중지되고, 다음 새로 고침 때 상속된 값이 사라집니다.

## 세트 작품

공식 세트는 `コンプリートパック` 같은 컴플리트 팩이나 세트처럼, 단품으로도 판매되는 작품을 담은 별도의 DLsite 상품입니다. DLsite는 일부 세트의 구성만 알려 주며, 메타데이터 동기화가 그 구성을 자동으로 나열합니다. 나머지는 라이브러리 편집자가 편집기의 메타데이터 출처 섹션에 있는 **세트 구성**에 작품을 나열합니다. 작품 코드를 입력하거나, 제목이 세트처럼 보일 때 섹션이 제안하는 세트의 DLsite 시리즈 작품 중 하나를 추가합니다(그렇지 않으면 **보기**로 제안을 펼칩니다). 변경 사항은 저장할 때 적용됩니다. 세트의 상세에는 포함된 작품과 함께 **수록 작품**이 표시되고, 각 작품의 상세에는 세트와 함께 **수록 세트**가 표시됩니다. 라이브러리에 없는 코드는 DLsite 링크와 함께 표시됩니다. 세트와 각 작품은 자체 파일, 재생 진행 상황, 라이브러리 카드를 가진 별도의 작품으로 유지되며, 세트에 속한 작품이 세트의 파일로 재생되는 일은 없습니다. 제거한 작품은 메타데이터 동기화가 다시 나열하지 않습니다. 라이브러리에서 작품 번호나 제목으로 검색하면 그 작품을 수록한 세트도 함께 찾을 수 있습니다.

## 현재 동작

- 작품 코드로 불러오며 번역된 DLsite 계열 경로를 해석합니다.
- 표지, 제목, 코드, 서클, 태그, 평점, 성우 메타데이터, DLsite 링크를 보여 줍니다.
- 논리적 작품 계열의 알려진 언어 에디션을 보여 줍니다.
- 메타데이터 언어와 디렉터리 에디션 선택기를 작품 코드 옆에 두 개의 별도 간결한 칩으로 유지합니다. 각 칩은 현재 선택을 표시하고 자체 목록을 엽니다. 원본 디렉터리 에디션은 `원본 · <언어>`로 표시됩니다. 휴대폰에서는 작품 코드와 두 칩이 한 줄에 표시되며, 칩은 언어를 코드(`JA`, `EN`, 중국어 간체는 `SC`, 중국어 번체는 `TC`, `KO`)로 나타내고 원본 디렉터리 에디션은 `원본`으로 표시됩니다. 목록에는 언어 전체 이름이 표시됩니다. 변형이 하나뿐이면 메타데이터 칩은 읽기 전용 레이블이 됩니다. 로컬 작품의 메타데이터 기본값은 우선 표시할 메타데이터 언어이고, 원격 전용 작품은 소스가 설명하는 사용자의 언어 중 첫 번째, 그다음 소스의 대체 언어가 기본값입니다. 일시적인 전환은 표시되는 제목과 태그 이름만 바꾸며 저장되지 않습니다. 구성된 기본값이 선택된 상태에서도 원본 변형이 항상 맨 앞에 나열됩니다.
- 디렉터리 에디션을 메타데이터 사용 가능 여부가 아니라 파일 사용 가능 여부로 취급합니다. 저장된 로컬 맥락에서는 접힌 선택기가 로컬 폴더나 로컬 미디어가 있는 에디션만 보여 주고, 펼치기를 누르면 알려진 모든 에디션으로 확장됩니다. 원격 형제 에디션은 그 소스가 자체 데이터베이스에서 이를 보고할 때만 선택할 수 있으며, 로컬에서 사용할 수 있는 형제 에디션은 선택한 원격 소스에 없더라도 로컬 디렉터리를 통해 계속 선택할 수 있습니다. 원격 맥락은 기본적으로 소스가 보고한 사용 가능 여부를 따릅니다.
- 메타데이터만 있는 에디션, 원격 전용 에디션, 사용할 수 없는 에디션을 로컬 재생이 가능한 것처럼 보이지 않게 표시합니다.
- 카드가 제공했거나 코드로 해석한 미리보기를 먼저 렌더링한 뒤, 기본 상세와 미디어 트리를 별도 단계로 불러옵니다.
- 카드/기록 미리보기에서 알려진 작품 ID를 유지하므로 즐겨찾기와 다른 컬렉션 경로가 라이브러리 로딩과 중복된 코드 해석 사이에서 경합하지 않습니다.
- 저장된 신원 컨트롤러와 원격 전용 신원 컨트롤러에 하나의 반응형 페이지 구성기를 사용합니다. 둘 다 원격 전용 미리보기에 저장된 상태를 부여하지 않으면서 뒤로 가기, 히어로, 모바일 정보/디렉터리, 데스크톱 디렉터리, 모달 배치를 공유합니다.
- 모바일 뒤로 가기 컨트롤은 서버와 사용자 기준으로 마지막으로 본 라이브러리 목록 위치로 올라가는 동작으로 처리하며, 넓은 레이아웃은 출처를 인식하는 기록 복귀를 유지합니다.
- 미디어 단계가 구체적인 트리를 필요로 할 때만 로컬 미디어 파일을 지연 색인합니다. 완료된 빈 스캔은 라이브러리 스캔이 그 상태를 무효화할 때까지 기억됩니다.
- 미디어가 있는 같은 작품의 동시 색인을 하나로 합치고 첫 색인 시 파일당 데이터베이스 문장 수를 줄입니다. 느린 수집 및 쓰기 단계는 진단을 위해 따로 로그에 기록됩니다.
- 백엔드의 통합 확인으로 소스 사용 가능 여부를 불러옵니다.
- 사용 가능 여부를 안 뒤에 원격 소스 트리를 지연해서 엽니다. 저장된 원격 소스 경로를 명시적으로 지정하면 통합 확인에 앞서 식별된 소스를 불러올 수 있으며, 성공적으로 불러온 경우 현재 상세에서 사용 가능으로 표시합니다.
- 공백이 없는 긴 이름을 포함한 전체 폴더 및 파일 이름을 가변 높이 디렉터리 행에서 줄바꿈하므로 페이지가 가로로 넘치지 않습니다.
- 디렉터리 이동 경로를 한 줄로 유지합니다. 모바일은 중간 상위 폴더를 메뉴로 접고, 데스크톱은 보이는 각 구간의 폭을 제한하며 현재 폴더가 보이도록 스크롤을 유지합니다. 전체 이름은 행, 상위 폴더 명령, 제목, 접근성 레이블을 통해 계속 확인할 수 있습니다.
- 히어로 동작 막대에 소스 메뉴를 하나 유지합니다. 아이콘은 로컬, 추적, 원격 맥락에 따라 바뀌고, 머리글은 선택한 소스의 이름을 표시하며, 바깥을 조작하거나 Escape를 누르거나 소스를 바꾸면 닫힙니다.
- 추적 중인 사용 가능 정보를 하나의 추적됨 탭으로 통합합니다. 작품이 둘 이상의 파일 소스에서 추적되고 있으면 탭 행에 소스 이름을 추가하지 않고 활성 추적 디렉터리를 전환하는 드롭다운이 탭에 나타납니다.
- 디렉터리 설명에 선택한 추적 소스 이름을 사용하며 선택 내용을 상세 URL에 유지합니다.
- 표지에서 색을 따온 배경의 히어로로 열립니다. 표지 옆에는 DLsite 링크와 언어 칩이 있는 작품 코드, 제목, 서클, 시리즈, CV 크레딧 줄, 태그 한 줄, 간결한 통계 줄(평점, 연령 등급, 판매량, 발매일, 재생 가능 시간. 휴대폰에서는 한 줄), 메타데이터 안내, 아래쪽에 정렬된 히어로 동작이 표시됩니다. 태그 줄은 제공처 태그를 먼저, 그다음 사용자의 개인 태그를 구분되는 강조 스타일로 나열하고 추가 또는 편집 아이콘으로 끝나며, 긴 제공처 태그 목록은 `+N` 컨트롤 뒤로 접힙니다. 제공처 태그나 개인 태그를 선택하면 상세를 연 라이브러리 검색에 `tag:` 또는 `mytag:` 절이 추가되며, 다른 페이지에서 상세를 연 뒤 선택한 개인 태그는 새 로컬 라이브러리 검색을 시작합니다. 디렉터리는 그 아래의 주 열을 채웁니다. 소스 정보와 메타데이터 업데이트 시간은 하나의 패널을 공유하며, 넓은 페이지에서는 디렉터리 옆에 있고 좁은 페이지에서는 그 뒤에 이어집니다. 소스 정보는 파일/오디오 개수, 크기와 재생 시간 범위를 보고하며, 소스 재생 시간을 조용히 대체하지 않고 메타데이터 재생 시간 대체임을 표시합니다. 그 패널 아래의 크레딧 카드에는 성우를 제외하고 DLsite가 크레딧에 올린 스태프(작가, 시나리오, 일러스트, 음악, 기타)가 나열됩니다. 작품이 크레딧에 올린 역할만 표시하며, DLsite가 스태프를 명시하지 않으면 카드가 나타나지 않습니다. 이름을 선택하면 상세를 연 라이브러리 검색에 `staff:` 절이 추가되고, 이 절은 어떤 스태프 역할에서든 그 이름을 찾습니다. 좁은 화면에서는 히어로가 정보 및 디렉터리 탭 위에 같은 크레딧 줄, 태그 줄, 통계 줄, 동작을 유지하고, 정보는 소스 패널과 크레딧 카드를 보여 주며, 표시, 목록, DLsite, 메타데이터, 소스는 아이콘으로 접힙니다.
- 디렉터리를 하나의 패널로 표시합니다. 파일 요약과 소스 확인이 있는 머리글, 상태 점이 있는 밑줄 소스 탭, 폴더 탐색기로 구성됩니다. 디렉터리 폭이 충분하고 작품에 폴더가 있으면 선택한 폴더 내용 옆에 고정 폴더 열이 나타납니다. 그렇지 않으면 폴더 버튼이 같은 탐색기를 휴대폰에서는 하단 시트로, 그 밖에서는 팝오버로 엽니다. 열 머리글의 **폴더 패널 숨기기**를 누르면 내용이 전체 폭으로 표시되고 폴더 버튼 옆에 **폴더 패널 표시**가 남으며, 이 선택은 해당 기기에 기억됩니다. 탐색기는 자연 정렬된 폴더를 재생 가능 파일 또는 이미지 개수와 함께 나열하고, 작은 트리는 완전히 열며 큰 트리는 선택한, 추천된, 재생 중인 폴더 쪽으로 열고, 하위 폴더 하나만 가진 폴더는 한 행으로 병합하며, 추천 폴더와 재생 중인 폴더를 표시합니다.
- 폴더 라우팅 규칙이 추천하는 폴더에서 열립니다. 내용 도구 모음에는 위로 이동 컨트롤과 이동 경로, 폴더의 트랙 수와 재생 시간, 추천 배지(또는 추천 폴더로 돌아가는 명령), 접힌 가사 개수, 현재 폴더의 재생 가능 파일을 위한 모두 재생 명령이 표시됩니다.
- 폴더의 내용을 하위 폴더 타일, 앨범 스타일의 트랙 목록, 이미지 갤러리, 문서, 기타 파일로 묶고, 그룹이 둘 이상이면 그룹에 레이블을 붙입니다. 하위 폴더 타일은 포함된 내용을 요약하고 재생 가능한 파일이 있으면 바로 재생 명령을 제공합니다. 트랙은 폴더 재생 순서대로 번호가 매겨지며 전체 이름 아래에 크기와 작품의 이어듣기 위치를, 끝 열에 정확한 재생 시간을 표시합니다. 마우스를 올리면 재생 표시가 나타나고, 현재 트랙은 강조 행과 실시간 아이콘으로 표시됩니다. 이어듣기 표시는 다시 불러오지 않고 재생 저장을 따라갑니다. 로컬 및 캐시 이미지는 지연 로드되는 썸네일을 표시하며, 원격 이미지는 미리볼 때만 불러옵니다.
- 일치한 같은 폴더의 가사 사이드카를 기본 디렉터리 행에서 접어 두고 일치하지 않는 텍스트는 계속 보여 줍니다. 오디오 행은 가사 선택, 미리보기, 위치 보기 동작을 제공하며, 디렉터리 컨트롤로 접힌 모든 가사를 표시할 수 있습니다. 파일 관리와 Fetch 선택은 가사를 접지 않습니다.
- 로컬 소스의 **가사 관리** 옵션은 가사 선택이 있는 모든 로컬 오디오 파일을 나열합니다. 라이브러리 쓰기 권한이 있는 사용자는 오디오와 이름이 맞지 않는 번역 가사를 포함하여 작품의 모든 로컬 가사 파일을 지정하거나, 가사 폴더를 트랙 번호(두 폴더의 파일 수가 같으면 위치)로 트랙에 맞출 수 있습니다. 각 행은 처음 몇 줄을 미리 보여 주며, 마지막 시간 지정 줄이 트랙이 끝난 뒤에 시작하면 경고합니다. 지정은 모든 청취자가 공유하며 자동 선택이 되고, 청취자 본인의 선택이 여전히 우선합니다.
- 트랙은 언어별로 지정된 가사 파일을 하나씩 가집니다. **가사 언어** 막대는 **대체**와 일본어, 중국어 간체, 중국어 번체, 영어, 한국어를 전환하며 각 언어에 가사가 있는 트랙 수를 표시합니다. **대체** 가사는 청취자의 어떤 언어에도 가사가 없을 때 사용되며, 지정이 없는 트랙이 파일 이름 일치로 대체되는 것도 이곳에서만 적용됩니다. 재생은 청취자의 메타데이터 언어 중 가사가 있는 첫 언어, 그다음 대체 가사, 그다음 다른 언어의 가사를 사용합니다. 파일의 언어는 사용자가 직접 지정하며, Kikoto는 파일에서 언어를 추측하지 않습니다.
- **가사 관리**에는 로컬 파일을 관리하는 사용자를 위한 **가사 파일** 탭이 있습니다. Kikoto는 작품 폴더 안의 `lyrics_kikoto` 폴더 하나에서 가사를 관리하며, 언어별로 언어 이름이 붙은 폴더에 둡니다: `ja`, `en`, `zh-hans`, `zh-hant`, `ko`, 그리고 대체 가사용 `fallback`입니다(예: `lyrics_kikoto/ja`). Kikoto는 자신이 만든 `lyrics_kikoto` 폴더에 자신의 것이라는 표시를 남깁니다. 작품에 포함된 가사 폴더(예: `lyrics`)는 작품 자체의 파일입니다. 그 가사는 **이 폴더의 다른 가사**에 표시되며, Kikoto는 그곳에 가사를 추가하거나 관리 중인 가사로서 삭제하지 않습니다. Kikoto가 만들지 않은 `lyrics_kikoto` 폴더나 같은 이름의 파일이 있으면 이름을 바꾸거나 옮기기 전까지 가사를 추가할 수 없습니다. 이 탭은 **파일 편집**처럼 세 열로 가사를 편집합니다. 왼쪽 열은 가사를 가져올 수 있는 위치, 가운데 열은 선택한 위치의 가사 파일, 오른쪽 열은 편집 후의 관리 중인 가사입니다. 작품에 로컬 폴더가 여러 개 있으면 오른쪽 열에서 편집할 폴더를 고릅니다.
- 위치는 다음과 같습니다. **관리 중인 가사**에서는 선택을 해제한 파일이 삭제됩니다. **이 폴더의 다른 가사**에서 선택한 파일은 가사 폴더로 복사되고 원래 자리에도 남습니다. **작품 자체의 파일**을 **lyrics_kikoto로 이동**으로 바꾸면 이동합니다. 이 선택은 관리자의 [기본값](settings.md#라이브러리)에서 시작하며, 바꾸지 않았다면 복사입니다. 작품의 다른 로컬 폴더(라이브러리의 다른 에디션 포함)의 파일은 복사되고, 설정된 원격 소스가 제공하는 에디션의 파일은 다운로드됩니다. 선택한 파일은 해당 위치의 **이 가사의 언어**에서 고른 언어의 가사 폴더로 들어갑니다. 다른 에디션의 가사는 처음에 그 에디션의 언어로 설정됩니다. Kikoto는 작품 자체 파일의 언어를 추측하지 않으므로 미리보기 전에 언어를 고릅니다. 관리 중인 가사의 언어를 바꾸려면 **이 폴더의 다른 가사**에서 **관리 중인 가사도 표시해 언어 변경**을 켜고 그곳에서 선택합니다. 이 파일들은 복사 중에도 새 언어로 이동합니다. 파일은 위치 아래의 경로를 유지하되, 이미 들어 있던 가사 폴더는 빠집니다.
- 오른쪽 열에서 결과를 미리 봅니다. 같은 내용의 파일이 이미 있으면 그대로 둡니다. 이름이 같은 다른 파일은 충돌이며 오른쪽 열에서 해결합니다: 기존 파일 유지, 교체, 둘 다 유지, 또는 들어오는 파일의 이름 변경 중 하나를 고르며 먼저 삭제할 필요가 없습니다. 방해가 되는 폴더와 파일은 **파일 편집**과 같은 방식으로 처리됩니다. **변경 사항 적용**은 파일을 삭제하기 전에 확인을 요청합니다. 라이브러리 쓰기 권한이 있으면 **추가한 가사를 일치하는 트랙에 지정**이 추가한 각 파일을 파일 이름, 다음으로 트랙 순서로 일치하는 트랙에 그 언어로 지정합니다. 해당 언어 가사가 이미 있는 트랙은 그대로 둡니다. 이동한 파일을 쓰던 지정은 파일의 언어로 함께 옮겨집니다. 복사한 파일은 별개의 파일이며, 작품 자체의 파일은 지정을 유지합니다. 읽어 온 원격 에디션은 라이브러리에 추가되지 않습니다.
- 로컬 작품의 **파일 관리**에는 작품 폴더의 다른 위치에 있는 가사를 위한 **가사로 관리**가 있습니다. `.lrc`, `.vtt`, `.srt`, `.ass`, `.ssa`, `.txt` 파일을 선택하고 이를 고르면, **이 폴더의 다른 가사**에서 그 파일들이 선택된 상태로 **가사 파일**이 열립니다.
- **가사 관리**를 사용할 수 있는 작품에서는 **파일 관리**가 Kikoto가 관리하는 가사를 기본적으로 숨깁니다. **Kikoto가 관리하는 가사** 행이 그 개수를 세어 보여 주며 **가사 관리**의 **가사 파일** 탭을 엽니다. 이 행의 **목록에 표시** 스위치를 켜면 다른 파일과 함께 나열되며 다른 파일처럼 선택할 수 있습니다. 숨겨져 있는 동안 작품 폴더 전체를 삭제 대상으로 선택하면 이 가사도 포함되고, 그보다 작은 선택은 이 가사를 그대로 둡니다.
- **가사 관리**에는 라이브러리 쓰기 및 워크플로 권한이 있는 사용자를 위해, [음성 인식 서비스](settings.md#음성-인식-서비스)가 구성되어 있으면 **전사** 탭이 있습니다. [전사](#전사)를 참고하세요. 데모에서는 예시와 함께 표시됩니다.
- **파일 관리**의 **빠른 선택**은 위치나 형식으로 파일을 선택합니다. 로컬 작품에서는 **동일한 파일 찾기**도 있습니다. 작품의 모든 에디션과 폴더에 있는 로컬 파일을 내용으로 비교하므로, 번역 에디션에서 이름이 바뀐 오디오도 원본과 같은 파일로 인식됩니다. 동일한 사본이 있는 파일에는 사본의 위치가 표시되고 두 가지 선택이 나타납니다. **다른 폴더에도 있음**은 같은 내용이 다른 곳에도 있는 나열된 파일을 선택하고, **이 폴더 안에서 중복**은 나열된 폴더 안에서 첫 번째를 제외한 모든 사본을 선택합니다. 같은 트랙을 다시 인코딩한 것처럼 서로 비슷할 뿐인 파일은 동일하지 않으므로 표시되지 않습니다. 삭제를 검토하기 전에는 아무것도 삭제되지 않습니다.
- 로컬 작품의 **파일 관리**에는 로컬 파일을 관리할 수 있는 사용자를 위한 **파일 편집**이 있습니다. 표시된 폴더를 세 열로 편집합니다. **소스**에는 **이 폴더**, 작품 각 에디션의 다른 로컬 폴더, 구성된 원격 소스가 마지막으로 제공하는 것으로 확인된 각 에디션이 나열됩니다. **원격** 옆의 **소스 확인**은 소스를 확인할 수 있는 사용자를 위한 버튼으로, 응답하는 모든 원격 소스에 작품의 각 에디션을 다시 문의하고 목록을 새로 고칩니다. **선택**에는 고른 위치의 파일이 표시되며, 이 폴더의 파일 선택을 해제하면 제거되고 다른 위치의 파일을 선택하면 추가됩니다. **최종 폴더**에는 편집 후의 폴더가 표시되고 각 파일이 유지, 제거, 이동, 복사, 다운로드, 교체됨, 이미 있음 중 하나로 표시되며, 방금 선택한 파일은 미리보기에 포함될 때까지 확인 중으로 표시됩니다. 파일 관리자처럼 정리할 수 있습니다. 파일이나 폴더를 폴더로 끌어다 놓으면 그곳으로 이동하고, 가운데 열의 파일이나 폴더를 폴더로 끌어다 놓으면 그곳에 추가되며 가운데 열은 그대로입니다. 폴더를 만들고 이름을 바꾸고 삭제하려면 **새 폴더**나 폴더의 메뉴를 사용합니다. 각 행의 메뉴에는 터치 화면과 키보드를 위한 **이동 위치**도 있습니다. 내용이 있는 폴더를 삭제하면 먼저 확인을 요청하고, 그 안에 있던 것을 한 단계 위로 옮깁니다. 파일이나 폴더가 놓이는 자리에 같은 이름이 이미 있으면 `01 (2).mp3`처럼 번호가 붙습니다. 선택을 해제한 파일은 옮겨 둔 위치를 내놓으므로, 다시 선택하면 원래 경로로 돌아갑니다. 그래도 두 파일이 같은 경로에 놓이게 되면 편집은 그 경로를 알려 주고, 둘 중 하나를 옮기거나 선택을 해제할 때까지 기다립니다. 이동한 파일은 재생 진행 상황, 가사, 그 밖의 참조를 유지합니다. 편집으로 비게 되는 폴더는 제거되고, 직접 만든 폴더는 비어 있어도 남습니다. Kikoto의 `lyrics_kikoto` 폴더는 가사 역할을 통해서만 정리되므로, 이 폴더가 포함된 선택은 끌어다 놓아도 놓이지 않습니다. 다른 로컬 폴더의 파일은 복사되며, 그 폴더에 **이 폴더로 병합**을 켜지 않으면 원본 폴더는 변경되지 않습니다. 이 스위치는 폴더의 파일을 불러온 뒤에 켤 수 있으며, 오프라인 스토리지 풀에 있는 폴더는 병합되지 않습니다. 병합하는 폴더는 아직 선택된 파일이 없으면 모든 파일을 가져오고, 이 폴더에 편집으로 복사되는 것이 모두 들어 있게 되면 병합한 폴더는 아직 담고 있는 모든 것과 함께 삭제됩니다. 원격 에디션의 파일은 다운로드되며, 여기에는 가져오기(Fetch) 권한도 필요하고 그 에디션은 라이브러리에 추가되지 않습니다. 다른 위치의 가사 파일(`.lrc`, `.vtt`, `.srt`, `.ass`, `.ssa`, `.txt`)은 원래 경로 대신 가사로 추가할 수 있습니다. 파일 이름 아래에서 언어를 고르거나, 그 위치에서 선택한 모든 가사 파일에 대해서는 **선택한 가사 파일**에서 언어를 고르면 **가사 파일**에서처럼 `lyrics_kikoto` 안의 해당 언어 폴더로 들어갑니다. 언어는 사용자가 지정하며 Kikoto는 추측하지 않습니다. 라이브러리 쓰기 권한이 있으면 **추가한 가사를 일치하는 트랙에 지정**이 추가한 각 가사 파일을 해당 언어로, 파일 이름이 일치하는 트랙에, 그다음 트랙 순서로 일치하는 트랙에 지정하며, 같은 편집에서 추가되는 트랙도 포함합니다. 해당 언어의 가사가 이미 있는 트랙은 그대로 유지됩니다. 같은 이름의 다른 파일 위에 놓이게 되는 파일은 충돌이며, 폴더의 파일 유지, 교체, 둘 다 유지, 들어오는 파일 이름 변경 중 하나로 해결합니다. 같은 이름의 폴더나 링크는 교체되지 않으므로 나머지 선택지만 제공됩니다. 들어오는 경로의 폴더가 있어야 할 자리에 파일이 있으면, 그 파일을 유지하거나 들어오는 파일을 다른 경로로 이름 변경하는 두 가지뿐입니다. 파일을 제거할 때 **변경 사항 적용**은 두 번의 삭제 확인을 요청합니다. 병합한 폴더가 있으면 먼저 병합한 폴더의 모든 파일을 편집 후의 폴더와 내용으로 비교하고, 그곳에 동일한 사본이 없어 폴더가 삭제될 때 사라지는 파일을 모두 나열하여 삭제 전에 다시 확인을 요청합니다. 원격 소스에서 다운로드한 파일은 비교하지 않습니다. 비교 후 병합할 폴더나 이 폴더가 바뀌면 편집이 적용되지 않으며 병합을 다시 검토하라는 안내가 표시됩니다. 편집은 하나의 활동 워크플로로 실행되며, 무엇이든 제거, 이동, 추가하기 전에 추가할 파일을 모두 모으고, 병합한 폴더는 마지막에, 검토에서 나열한 파일만 바뀌지 않은 채 그대로 담고 있고 검토에서 사본을 찾은 각 파일의 동일한 사본이 이 폴더에 아직 있을 때에 한해 삭제합니다. 그렇지 않으면 편집이 멈추고 병합을 다시 검토하라고 안내합니다. 멈춘 편집을 다시 시도하면 멈춘 곳부터 이어서 진행합니다. 가져오기(Fetch)가 아직 진행 중인 작품의 폴더는 병합하지 않습니다. 완료되면 디렉터리가 다시 로드됩니다.
- 스캔이 코드를 여러 로컬 폴더에서 찾은 작품은 그 폴더를 모두 유지합니다. 그러면 디렉터리에 사본마다 폴더 하나가 표시되고, **파일 관리**는 **폴더** 선택으로 한 번에 폴더 하나씩 나열하며, 작품은 폴더가 하나만 남은 뒤에야 잊을 수 있습니다. 라이브러리 쓰기 권한이 있는 사용자는 작품이 여러 폴더에 있거나 라이브러리에 다른 에디션이 있을 때 디렉터리 위에 안내를 보며, 안내의 **가사 관리**와 **파일 관리**로 가사를 한 폴더에 모으고 동일한 파일을 제거할 수 있습니다.
- 자연 정렬된 폴더를 자연 정렬된 파일보다 먼저 나열합니다. 폴더 재생은 같은 표시 순서를 따릅니다.
- 이미지와 텍스트 같은 재생 불가 파일은 사용할 수 있으면 디렉터리에 유지하며, 재생 가능 소스 지표에서는 오디오와 오디오가 포함된 비디오를 함께 집계합니다.
- 미리보기를 파일 뷰어에서 열며, 머리글 컨트롤, 화살표 키, 휴대폰의 스와이프 또는 이미지 필름스트립으로 폴더에서 같은 종류의 파일을 차례로 넘길 수 있습니다. 이미지는 창에 맞추거나 클릭한 지점을 중심으로 실제 크기를 보여 주는 어두운 무대 위에 놓이고, 끌어서 이동할 수 있으며 크기를 보고합니다. 비디오도 같은 무대를 사용합니다. 텍스트는 읽기 보기로 열리고 LRC, WebVTT, SRT 파일은 타임스탬프가 있는 줄을 표시하며, 플레이어의 가사와 같은 방식으로 파싱되고 LRC 헤더 태그와 원본 텍스트 전환이 있습니다. 뷰어는 텍스트의 복사, 로컬 및 캐시 파일의 다운로드, 로컬 이미지의 표지 설정을 제공하며, 표지 설정은 확인을 위해 한 번 더 클릭해야 하고 몇 초가 지나거나 다른 이미지로 넘어가면 초기화됩니다. 휴대폰에서는 화면을 채우고 데스크톱에서는 떠 있는 플레이어 위에 열립니다.
- 로컬, 캐시, 원격 텍스트 미리보기를 필요할 때 UTF-8로 변환하며, 바이트 순서 표시, 선언된 문자셋, 자동 레거시 인코딩 감지를 사용하고 원본 파일은 다시 쓰지 않습니다.
- 데스크톱 컴팩트 플레이어가 활성화된 동안 하단 스크롤 공간을 확보하여 마지막 대기열 동작에 계속 접근할 수 있게 합니다.

## 동작

- 고정된 재생 재개 동작 하나를 표시합니다. 완료되지 않은 양수 작품 커서가 없으면 비활성화되며, 파일을 직접 활성화하면 처음부터 시작합니다.
- 빠른 청취 상태를 업데이트합니다.
- 즐겨찾기 목록 구성원을 관리합니다. 목록 버튼에는 작품이 들어 있는 목록의 이름이 표시됩니다. 여러 목록에 들어 있으면 목록 순서상 첫 번째 목록의 이름과 나머지 개수가 표시되고, 툴팁에 모든 이름이 표시됩니다. **목록 추가**는 목록 메뉴 안에서 목록을 만들고 선택하며, **저장**은 기존 선택과 함께 구성원을 적용합니다.
- 제공처 메타데이터 태그와 별도로 개인 작품 태그를 편집합니다.
- 메타데이터를 동기화합니다.
- 호환되는 원격 소스에서 동기화/캐시/가져오기를 수행합니다.
- 가져오기(Fetch)는 수락되면 선택한 소스를 사용 가능으로 기록하고, 같은 표준 작품에 대해 이미 대기 중이거나 실행 중인 가져오기를 재사용합니다.
- 현재 방문자가 익명이면 가져오기 준비 요청에 앞서 로그인을 엽니다.
- 로컬 폴더가 있는 작품에서 원격 소스의 **가져오기(Fetch)**는 로컬 파일을 관리하고 가져오기를 할 수 있는 사용자에게 그 소스의 에디션에 맞춰 **파일 편집**을 엽니다. 이런 사용자에게 로컬 폴더가 없는 작품에서는 새 폴더로의 가져오기가 같은 세 열로 열립니다. 소스의 에디션이 먼저 나오며 모든 파일이 선택되어 있고, 작품의 다른 에디션, 소스, 로컬 폴더에서 파일을 추가할 수 있으며, 가사 파일은 **파일 편집**에서처럼 언어를 지정한 가사로 트랙 지정과 함께 추가할 수 있습니다. 그 **최종 폴더**는 **파일 편집**에서처럼 정리되지만, 파일이 없는 폴더는 만들어지지 않습니다. 에디션 자체의 파일이 하나의 가져오기입니다. 그 밖의 모든 것은 가져오기가 폴더를 게시한 뒤 **파일 편집** 워크플로로 추가되므로, 가져오기가 게시하는 파일과 같은 자리에 놓이는 파일은 먼저 해결해야 하는 충돌입니다. 대상 폴더에 검토가 필요하면 **일반 Fetch에서 검토**가 가져오기 대화상자를 엽니다. 그 밖의 사용자에게는 가져오기 대화상자가 열립니다.
- 선택한 소스의 히어로 소스 메뉴에서 소스별 추적, 분기, 가져오기, 원본, 캐시, 새로 고침, 파일 유지 관리 명령을 엽니다.
- 선택한 원격 소스를 추적하고 탐색 가능한 트리를 저장하며, 두 번째 분기 없이 통합 추적됨 맥락 안에서 해당 소스를 엽니다.
- 가능한 경우 수동 재정의를 편집합니다.
- 메타데이터 편집기에서 작품의 메타데이터를 다른 DLsite 코드에 연결합니다. 예를 들어 특전 에디션이 더 이상 판매되지 않고 일반 에디션의 코드가 다른 경우에 사용합니다. 이후 메타데이터 새로 고침은 연결된 코드를 읽어 그 메타데이터, 태그, 표지를 이 작품에 저장하며, 연결된 코드가 별도의 작품이 되지는 않습니다. 작품 자체의 코드에 기록이 없으면 사용할 수 없는 메타데이터 안내가 편집기를 바로 엽니다.

## 상세 로딩 모델

작품 상세는 알려진 로컬 데이터베이스 상태를 먼저 사용하고, 더 느린 원격 파생 상태는 별도로 불러와야 합니다.

1. 작품 카드 화면의 경로 미리보기, 또는 직접 URL을 위한 가벼운 코드 해석.
2. 기본 작품 메타데이터, 사용자 상태, 에디션, 크레딧.
3. 로컬 미디어와 디렉터리 트리.
4. 소스 사용 가능 여부 요약.
5. 사용자가 연 경우 선택한 원격 소스 트리.

이렇게 하면 원격 소스 장애가 로컬 상세 셸을 막지 않습니다. 디렉터리 단계는 디렉터리 모양의 안정적인 스켈레톤을 사용합니다. 미디어 오류는 그 스켈레톤만 대체하고 불러온 메타데이터와 동작은 그대로 둡니다. 가져오기 경로 선택과 파일 관리 트리는 해당하는 옵션 명령이 선택된 뒤에만 구성됩니다.
