# 작품 상세

[English](../en/work-detail.md)

작품 상세는 메타데이터, 판본, 파일 트리, 소스 가용성과 재생 동작을 표시합니다.

## 다국어 제목

편집기의 제목 섹션은 일본어, 중국어 간체, 중국어 번체, 영어, 한국어를 먼저 전체 너비의 한 줄씩 나열합니다. 원본 언어에는 `origin`, 현재 표시 중인 메타데이터 언어에는 `current` 배지가 붙으며 같은 줄에 둘 다 표시할 수 있습니다. 아래의 **고급 제목 옵션**은 기본적으로 접혀 있으며, 펼치면 **모든 언어 공통 제목**을 설정할 수 있습니다. 저장된 공통 제목이 있으면 수정하거나 지울 수 있도록 자동으로 펼쳐집니다. 안내는 공통 제목이 각 언어의 제공자 제목보다 우선하고 언어별 수동 제목이 있으면 그 제목을 우선한다는 점을 설명합니다. 판본과 소개는 바뀌지 않습니다. 해당 줄의 수동 제목은 직접 편집하며 제공자 제목과 상속값은 회색 힌트로만 표시됩니다. 변경하지 않은 힌트는 저장하지 않습니다. 각 줄은 현재 출처를 보여 주고 수동 제목이나 편집한 제목을 표시합니다. 변경한 필드와 제목 언어만 저장합니다. 기존 수동 제목을 비우거나 해당 줄에서 되돌리기를 선택하면 저장할 때 그 범위를 삭제하고, 상속 힌트에 입력했다가 비우면 변경하지 않습니다. 메타데이터 → 작품에서도 같은 편집기를 엽니다.

독자적인 수동 제목이나 DLsite 버전이 있는 첫 번째 선호 언어를 사용합니다. 그 언어의 수동 제목, 모든 언어의 수동 제목, 해당 버전의 제목 순으로 적용합니다. 모든 언어 제목은 문구만 바꾸며 기본 버전, 소개, 태그는 이 제목이 없을 때와 같습니다. `Origin`은 원본 버전이 선언한 언어를 사용하며 알 수 없는 언어는 추측하지 않습니다. 일치하는 항목이 없으면 원본 제목을 사용합니다. 서클, 시리즈, 성우 재정의는 모든 언어에 공통입니다. 원본 언어가 선언되지 않으면 모든 화면에서 알 수 없는 언어로 유지하며 메타데이터 요청 언어로 추측하지 않습니다. 이때 언어 표시는 **원본**만 보여 줍니다. 언어별 수동 제목은 선언된 해당 언어에 적용하거나 그 수동 언어를 명시적으로 선호 또는 선택했을 때 적용합니다. 언어 메뉴에는 실제 버전과 독자적인 수동 제목이 있는 언어만 표시합니다. 모든 언어 제목은 기존 항목에 적용하며 언어를 추가하지 않습니다.

DLsite에 기록이 없어 원격 소스로 보완된 작품은 상세 알림에 **원격 소스로 보완됨**이 표시되고 소스별로 보완한 값이 나열됩니다. 원격 제목은 제목 우선순위에서 DLsite 다음, 작품 자체 제목 앞에 옵니다. 언어를 선언하지 않으므로 언어 선택지를 추가하지 않고 문구도 그대로 표시합니다. 제목 편집기에는 그 소스 이름이 표시됩니다.

작품 계열의 원본 이외 버전은 제삼자 번역을 포함하여 번역 버전으로 취급합니다. 제공자 제목에서는 `【简体中文版】` 또는 `【ドイツ語版】` 같은 DLsite 언어 버전 표시를 형식으로 판별하고 맨 앞의 하나만 제거합니다. `【ASMR】`, 제목 중간의 표시와 수동 제목은 유지합니다. 지원하지 않는 언어도 각 버전 자체의 제목을 사용하며 제공자 원문과 스냅샷은 변경하지 않습니다. 카드, 상세, 언어 선택, 검색 결과와 새 재생 대기열은 같은 표시 규칙을 사용하고 모든 수동 제목을 검색할 수 있습니다. 소개는 일반 텍스트 그대로 표시하며 선택한 버전을 따릅니다. 대응 버전이 없는 수동 언어는 원본 소개를 사용합니다.

## 메타데이터 편집

admin과 super_admin은 `library:write` 권한으로 작품 메타데이터를 편집할 수 있습니다. 저장은 초기 값에서 바뀐 필드만 전송하므로 표지만 바꾸어도 자동 제목, 서클, 시리즈 및 성우 정보가 고정되지 않습니다. 필드를 비우면 해당 수동 재정의만 해제합니다. 업그레이드는 같은 작품 계열의 DLsite 제목과 앞뒤 공백을 제외하고 완전히 같은 제목 재정의만 삭제하며 서클, 시리즈 및 성우 재정의는 유지합니다.

편집기는 필드를 제목, 커버, 태그, 크레디트, 메타데이터 출처 섹션으로 나눕니다. 저장하지 않은 변경이 있는 섹션에는 점이 표시되고 하단에도 목록이 나옵니다. 수동 서클, 시리즈, 성우 목록, 커버의 되돌리기와 메타데이터 연결 추가·삭제를 포함해 모든 변경은 저장하기 전까지 초안으로 남으므로 섹션을 전환해도 편집이 사라지지 않습니다. 초안이 있을 때 취소하면 버릴지 먼저 묻습니다. 서클, 시리즈, 성우는 제안을 선택하면 알려진 항목과 연결되며, ID는 이름 아래에 표시되고 "ID 편집"에서 수정할 수 있습니다. 커버는 작품의 로컬 이미지 썸네일 격자에서 고릅니다. Ctrl+Enter로 저장합니다.

태그 영역에서 공유 메타데이터 태그를 검색하여 작품에 추가하거나 제거하고 사용자 정의 태그도 만들 수 있습니다. DLsite 메타데이터가 없는 작품에도 적용됩니다. DLsite 태그 복원은 이 작품의 태그 추가·제거를 해제합니다. 공유 이름은 자신의 선호 메타데이터 언어에 따라 수동 이름과 학습한 genre 이름에서 선택하므로 일본어판만 있는 작품도 알려진 중국어 태그 이름을 표시할 수 있습니다. 전체 숨김 태그는 표시되지 않습니다. 내 태그는 별도의 계정 소유 개인 태그입니다. Demo에서는 편집기를 읽기 전용으로 표시합니다.

태그의 언어 버튼을 누르면 모든 언어 공통 이름과 언어별 이름이 각각의 줄에 열립니다. 수동 이름은 직접 편집하며 제공자 이름이나 학습된 이름은 회색 힌트로 표시됩니다. 태그 이름은 공유되므로 이름을 바꾸면 그 태그가 있는 모든 작품에 적용되고, 패널에 공유하는 작품 수가 표시됩니다. 새 사용자 태그는 입력한 이름을 모든 언어 이름으로 쓰며 만들기 전에 다른 언어의 이름도 입력할 수 있습니다. 이름 변경도 다른 변경과 마찬가지로 초안이며 저장할 때 기록됩니다.

새 사용자 정의 태그 이름은 저장 전까지 초안입니다. 저장 시 공유 태그 생성 또는 재사용과 작품 추가를 같은 트랜잭션에서 처리하며 취소하면 공유 항목이 남지 않습니다. 앞뒤 공백과 대소문자를 제외하고 어느 언어의 알려진 이름과도 완전히 같으면 기존 태그를 재사용하므로 반복 클릭이나 같은 이름으로 중복을 만들지 않습니다.

메타데이터 언어를 바꾸면 해당 판본 언어의 수동 이름 또는 사전 이름을 우선 사용하고 없으면 자신의 선호 메타데이터 언어로 돌아갑니다. 추가·제거, 최종 병합 대상의 숨김, 병합 연결도 계속 적용됩니다. 모든 판본이 원작 판본의 태그를 보여 주므로 바꿔도 태그 이름만 달라지고 태그가 늘거나 줄지 않습니다. 스냅샷에만 있는 태그도 개별 투영이 완료될 때까지 보이며, 모든 태그를 직접 제거한 경우에는 빈 표시가 유지됩니다.

일본어판만 있는 작품도 백그라운드 **태그 이름 학습** 워크플로가 이름을 학습하면 태그를 선호 언어로 표시합니다. 그전까지는 일본어 태그 이름을 표시합니다. 제목은 일본어로 유지됩니다.

병합된 이름은 최종 대상 태그로 후보에 표시됩니다. 숨겨진 태그 또는 숨겨진 병합 대상과 일치하는 이름은 표시되지만 추가할 수 없습니다. 먼저 메타데이터 관리에서 숨김을 해제하세요. 이름은 [설정](settings.md)에 설명된 언어 우선순위를 따릅니다.

백그라운드 업데이트가 끝날 때까지 메타데이터를 새로고침해도 마지막으로 저장한 태그 집합을 유지하며 빈 집합도 그대로 표시합니다. 성우 페이지의 원격 작품 목록에서 원격 태그와 수동으로 추가한 공유 태그가 함께 표시됩니다.

## 현재 동작

- 작품 코드로 로드하고 번역된 DLsite 경로를 해석합니다.
- 표지, 제목, 코드, 서클, 태그, 평점, 성우 정보와 DLsite 링크를 표시합니다.
- 메타데이터 언어 선택과 디렉터리 판본 선택을 분리하며 Origin 변형은 항상 먼저 표시합니다.
- 디렉터리 판본은 파일 가용성을 뜻하고, 원격 전용 판본은 로컬 재생을 암시하지 않습니다.
- 카드 미리보기를 먼저 렌더링한 뒤 기본 상세와 미디어 트리를 별도 단계로 로드합니다.
- 로컬 미디어 트리는 필요할 때 지연 인덱싱합니다.
- 소스 가용성은 backend 집계 확인으로 로드합니다.
- 미리보기는 파일 뷰어로 열리며, 헤더 버튼·방향키·휴대폰 스와이프·이미지 필름스트립으로 같은 폴더의 같은 종류 파일을 넘겨 봅니다. 이미지는 창에 맞추거나 클릭한 위치를 중심으로 실제 크기로 보고 끌어서 이동할 수 있으며, LRC·WebVTT·SRT는 플레이어 가사와 같은 방식으로 시간 표시 행으로 보여 줍니다.
- 긴 이름도 디렉터리 행에서 전체를 표시하며 폴더를 파일보다 먼저 자연 정렬합니다.
- 디렉터리는 폴더 탐색기로 표시합니다. 넓은 화면에서는 고정된 폴더 열이 선택한 폴더 내용 옆에 있고, 좁은 화면에서는 폴더 버튼이 같은 탐색을 엽니다. 추천 폴더와 재생 중인 폴더를 표시하며, 내용은 하위 폴더, 트랙 목록, 이미지 갤러리, 문서, 기타 파일로 묶습니다. 트랙은 작품의 이어 듣기 위치를 표시합니다.
- Hero의 Source 메뉴에서 Local, Tracked 및 원격 컨텍스트 동작을 엽니다.

## 동작

- Resume은 완료되지 않은 양수 커서가 없으면 비활성화됩니다.
- 청취 상태, 즐겨찾기 목록과 개인 태그를 관리합니다.
- 메타데이터를 Sync하고 원격 소스에서 Sync/Cache/Fetch를 실행합니다.
- 선택한 원격 소스를 Track하고 Tracked 컨텍스트에서 엽니다.
- 메타데이터 편집기에서 작품의 메타데이터를 다른 DLsite 작품 번호에 연결할 수 있습니다. 특전판 판매가 끝나고 일반판이 다른 번호로 판매되는 경우 등에 사용합니다. 이후 메타데이터 새로 고침은 연결된 번호를 읽어 메타데이터, 태그, 표지를 이 작품에 저장하며 연결된 번호는 별도 작품이 되지 않습니다. 작품 자체 번호에 기록이 없으면 메타데이터를 사용할 수 없다는 안내에서 편집기를 바로 열 수 있습니다.

## 상세 로딩 모델

1. 카드 미리보기 또는 코드 확인
2. 기본 메타데이터와 사용자 상태
3. 로컬 미디어 트리
4. 소스 가용성 요약
5. 선택한 원격 소스 트리

각 단계가 독립적으로 로드되어 원격 오류가 로컬 화면을 막지 않습니다.
