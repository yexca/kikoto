# 개인 데이터

[English](../en/personal-data.md) · [简体中文](../zh-Hans/personal-data.md) · [繁體中文](../zh-Hant/personal-data.md) · [日本語](../ja/personal-data.md) · [한국어](../ko/personal-data.md)

로그인 후 '설정'의 '기록 및 추천' 탭에서 재생 기록을, '태그' 탭에서 개인 태그를, Account 맨 아래에서 '내 데이터'를 엽니다. 모바일 계정 메뉴와 빠른 작업에서는 각각 바로 엽니다. 현재 계정의 데이터만 표시합니다.

작품·서클·성우 태그와 미사용 태그를 검색합니다. 이름 변경은 모든 연결에 반영되고 병합은 연결을 옮겨 중복을 제거합니다. 태그 삭제는 작품이나 제공자 메타데이터를 지우지 않습니다. 새 작업의 기본 태그에는 날짜가 없습니다. 기존 예약 템플릿은 유지되므로 필요하면 `{date}`를 제거하세요.

청취 리포트는 30일·12개월·전체 기간으로 전환할 수 있으며 청취 시간, 재생 횟수, 일·월·연도별(UTC) 차트와 자주 듣는 작품의 커버 카드를 표시합니다. 날짜가 없는 가져온 합계는 '전체'에만 포함됩니다. 작품별 전체 기록은 카드로 그 아래에 접혀 있다가 열 때 불러옵니다. 일시 정지·버퍼링·탐색은 제외하고 배속에 따라 시간을 늘리지 않습니다. 여러 플레이어는 각각 계산하며 연결이 끊기면 일부 시간이 전송되지 않을 수 있습니다. 기록은 장기 보관되며 추천 이벤트의 90일 정리와 별개입니다. 업데이트는 남은 이벤트를 보존하지만 알 수 없는 시간을 추정하지 않습니다. 기록 지우기는 표시·목록·재개 위치를 유지하며 계정의 삭제 버전으로 지연된 이전 요청을 거부합니다.

Kikoto JSON에는 작품별 청취 상태, 개인 평점·메모, 재개 위치, 누적 통계, 작품 태그 연결, 사용자 태그 정의 및 순서가 있는 즐겨찾기 목록이 포함됩니다. 서클·성우 태그는 정의만 포함됩니다. 미디어, 소스 설정, 주소, 인증 정보, 제공자 메타데이터, 원시 세션 및 일별 통계는 제외됩니다. 음원 제목과 디스크·트랙 번호로 위치를 연결하며 로컬 경로는 내보내지 않습니다.

파일과 형식을 선택한 뒤 미리 봅니다. 기본값은 기존 작품 데이터와 동일 이름 목록을 유지합니다. 덮어쓰기는 대응 데이터와 연결 가능한 위치를 바꿉니다. 누적 통계는 큰 값을 사용하므로 중복 집계하지 않습니다. 기존 작품과 알려진 별칭만 연결하고 누락 코드를 표시합니다. 작품 생성이나 메타데이터 요청은 하지 않으며 음원이 중복되면 기존 위치를 유지합니다. 가져오기는 하나의 트랜잭션입니다.

한도: 10 MiB, 작품 20,000개, 태그 5,000개, 목록 1,000개, 목록 항목과 작품 태그 연결 각각 50,000개. Kikoeru 리뷰 배열, `reviews`, API `works` 배열을 지원합니다. 한 계정의 필요한 모든 페이지를 포함하세요. `primaryCode`/`source_id`는 작품 코드이며 숫자 `work_id`/`id`는 상품 번호이며, 유형을 ID에 넣는 파생 버전(유형 × 10¹² + 숫자)은 RJ, BJ, VJ, CC 코드로 자동 변환합니다. 상품 번호와 무관한 DB ID는 먼저 변환해야 합니다.

**Kikoeru 계정**을 고르면 설정된 가져올 곳이나 직접 입력한 API 주소에 로그인 없음, 토큰, 사용자 이름과 비밀번호 중 하나로 연결해 서버가 리뷰, 진행 상태, (지원 시) 재생목록을 읽습니다. **Kikoeru 데이터베이스 파일**은 오픈 소스 Kikoeru의 SQLite 데이터베이스(최대 512 MiB)를 업로드해 입력한 사용자 이름의 리뷰만 읽습니다. 토큰, 비밀번호, 직접 입력한 주소, 데이터베이스를 보내기 전에 위험을 설명하고 확인을 받습니다. 인증 정보는 Kikoto 서버를 거치지만 저장하거나 로그에 남기지 않고, Kikoeru에는 서버 주소에서 로그인한 것으로 보이며, 데이터베이스에는 모든 계정과 비밀번호 해시가 있고 읽은 직후 삭제됩니다. 리디렉션은 따라가지 않습니다. 직접 입력한 주소는 공개 주소만 허용하며, 관리자이거나 관리자가 **설정 → 라이브러리 → Kikoeru 계정 가져오기**에서 LAN 주소를 허용한 경우는 예외입니다.

`marked` → 듣고 싶음, `listening` → 듣는 중, `listened` → 완료, `replay` → 다시 듣기, `postponed` → 보류, 빈 값 → 미표시. 전체 사양은 [영어 문서](../en/personal-data.md)를 참고하세요.
