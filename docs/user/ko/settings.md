# 설정

[English](../en/settings.md)

설정은 서버, 사용자, 브라우저에 저장되는 동작을 관리합니다.

## 현재 동작

- 언어, 테마, 표시 밀도와 작품 컬렉션 열 수를 설정합니다.
- 재생 속도, 앞/뒤 탐색 시간, 호환 재생 범위를 저장합니다.
- 서버 연결과 로그인 세션을 관리합니다.
- 소스, 메타데이터 언어 우선순위와 원격 요청 옵션을 관리합니다.
- 폴더 스캔, watcher, Follow-up run 및 예약 트리거를 설정합니다.
- 개인 태그, 즐겨찾기 목록, 청취 상태를 사용자별로 보존합니다.

## 유지 관리

Maintenance 탭은 한 줄로 표시되며 좁은 화면에서는 가로로 스크롤할 수 있습니다. Overview는 제거되었습니다. Library에는 로컬 스캔, 원격 소스와 읽기 전용 저장 경로가 있으며 소스 관리자의 기본 화면입니다. Users에는 사용자 관리와 최고 관리자 전용 인스턴스 접근 설정이 있습니다. 사용자 관리 권한만 있으면 Users가 기본 화면입니다. 기존 Paths와 Access 링크는 각각 Library와 Users로 이동합니다.

원격 소스는 상태, 호스트, 상태 확인, 바로 저장되는 사용 스위치를 갖춘 간결한 목록입니다. **소스 추가**는 주소 하나로 시작합니다. 입력한 주소, 그 오리진, 일반적인 `api.` 하위 도메인을 차례로 확인해 API URL, 공개 사이트, 이름을 채웁니다. 감지하지 못하면 **연결 세부 정보**가 열려 직접 입력할 수 있습니다. 엔드포인트, 우선순위, 네트워크 및 저장소 옵션은 접혀 있습니다. Cache & Fetch에는 설정만 남고 캐시 내용은 **정리** 탭에서 관리합니다. 추천 설정에는 로그인한 사용자의 최근 30일 통계만 보여 주는 접힌 **내 추천 활동**이 추가되었습니다.

## 정리

**정리**는 설정에서 Proxy 다음에 있는 관리자 탭입니다(`/settings?tab=cleanup`). 캐시 부분에는 `downloads:manage`, 데이터베이스 부분에는 `sources:write` 권한이 필요합니다. 트랜스코드 캐시와 관리 미디어 캐시의 사용량 확인 및 정리, 그리고 데이터베이스 레코드 정리를 제공합니다. 대상은 디스크에 없음을 확인한 작품 폴더와 로컬 파일(이로 인해 비게 된 트랙 항목과 로컬 가용성 포함), 고아 메타데이터 스냅샷, 사용하지 않는 소스 태그, 만료된 세션, 닫은 알림, 90일이 지난 워크플로 기록과 추천 신호, 사용하지 않는 추천 스냅샷입니다. 개인 태그, 검토·Fetch 기록·메타데이터 문제가 있는 실행과 각 워크플로의 최신 실행은 유지됩니다. 정리는 확인 후 실행되고 감사 로그에 기록되며 미디어 파일은 삭제되지 않습니다. 만료된 세션과 조건에 맞는 오래된 워크플로 실행은 같은 규칙으로 하루에 한 번 자동으로도 삭제됩니다. 데이터 폴더가 없거나 비어 있으면 경로 확인을 일시 중지합니다. **소스가 없는 작품**은 메타데이터의 **사용 가능한 소스 없음**으로 연결되고, **데이터베이스 압축**은 빈 페이지를 디스크에 돌려줍니다. 압축은 활동에 표시되는 워크플로 실행으로 백그라운드에서 진행되며, 한 번에 하나만 대기하거나 실행될 수 있습니다.

## 메타데이터

**메타데이터** 레일은 **작품**(전체, 주의 필요, 메타데이터 문제, 사용 가능한 소스 없음)과 **항목**(태그, 서클, 성우)으로 나뉩니다. 넓은 화면에서는 그룹 및 보기 이름을 펼칠 수 있고 휴대폰에서는 가로로 스크롤되는 아이콘 줄입니다. 작품 표는 검색, 페이지, 선택 및 수동 새로 고침을 유지하며 연필 버튼으로 작품 상세와 같은 편집기를 엽니다. admin과 super_admin은 `library:write` 권한으로 메타데이터, 표지, 메타데이터 연결, 소스 추적 해제, 공유 태그 및 서클 식별 정보를 편집할 수 있습니다.

**태그**(`/metadata?view=tags`)는 공유 개념, 알려진 이름, 작품 수, 숨김 및 병합 상태를 보여 줍니다. 관리 대화상자에서 모든 언어 공통 또는 언어별 수동 이름, 전체 숨김, 병합 대상 및 병합 연결 취소를 설정합니다. **서클**(`?view=circles`)은 제공자 새로 고침에 덮어써지지 않는 수동 이름과 확정 별칭을 관리하며 작품, maker id, 카탈로그, 스냅샷, 시리즈 및 개인 서클 데이터를 함께 병합합니다. 가장 최근 병합부터 취소하며 관련 기록의 후속 편집을 덮어쓰지 않습니다. **성우** 별칭 및 중복 인물 관리는 계속 `metadata:sync`가 필요하고 `/metadata?view=aliases&voice=<id>` 링크도 유지됩니다. Demo에서는 화면을 둘러볼 수 있지만 변경할 수 없습니다.

항목 목록은 메타데이터 페이지와 같은 접근 조건을 사용합니다. 로그인하고 `library:write`, `metadata:sync`, `sources:write`, `system:admin` 중 하나가 필요합니다. 익명 읽기에는 관리 목록이 포함되지 않습니다. Demo는 데모 작품에 관련된 태그와 서클만 표시하고 작품 수도 그 범위에서만 계산하며, 서클 병합 기록은 표시하지 않습니다.

태그 표시 여부는 최종 병합 대상만 결정합니다. 이미 병합된 태그의 숨김 설정은 취소 후 적용되며, 숨겨진 대상에 병합하면 결과도 숨겨집니다. 원래 이름은 병합 후에도 검색되고 취소하면 원래 식별 정보와 검색 이름을 복원합니다. 숨김·병합·취소는 관련 작품만 하나의 트랜잭션에서 갱신합니다. 시간 초과 시 이전 상태를 유지하므로 다시 시도할 수 있습니다.

기존 표지 이동과 태그 보충은 기본 시작 워크플로 뒤에 독립적인 백그라운드 작업으로 실행합니다. 한 표지 파일의 오류가 다른 파일을 중단시키지 않으며, 오류를 로그에 기록하고 다음 시작에서 재시도합니다.

상단은 분류, 검색, 목록 조작을 한 줄에 모읍니다. 넓은 화면에서는 검색창이 분류 오른쪽에 놓이고, 좁은 화면에서는 오른쪽 검색 아이콘으로 접혀 누르면 줄 아래에 검색창이 열립니다. 이어서 새로 고침, 페이지당 항목 수, **메타데이터 재시도**, **소스 확인**, **메타데이터 설정** 톱니바퀴가 있습니다. 목록 위아래의 페이지 이동은 라이브러리와 같습니다. 메타데이터 설정은 팝오버로 열리며, 각 설정의 설명은 정보 아이콘에 마우스를 올리거나 포커스하면 표시됩니다. 닫아도 목록과 필터가 유지됩니다. 메타데이터 동기화는 Workflows에서 실행합니다.

작품을 선택하고 **메타데이터 재시도**를 누르면 해당 개수가 버튼에 표시됩니다. 상세 정보에서 특정 버전도 재시도할 수 있으며 이전에 사용할 수 없다고 보고된 작품도 다시 확인합니다. 실패하면 기존 정보와 수동 덮어쓰기를 유지합니다. 소스 확인은 선택한 소스 없는 작품에만 적용됩니다. 로컬 정보 삭제는 「사용 가능한 소스 없음」 화면에서만 제공하며 확인 후 서버가 소스 상태를 다시 검사하고 미디어 파일은 유지합니다.

Activity와 Workflows는 유지합니다. Activity의 문제 목록 버튼은 해당 실행의 미해결 메타데이터 문제로 필터링한 작품 유지 관리를 엽니다. 전체 대기 작품을 표시하면 실행 필터가 해제됩니다. 복구는 다른 사용자의 검토 상태를 변경하지 않습니다. 메타데이터 복구에는 `metadata:sync`, 소스 확인·삭제·소스 및 언어 설정에는 `sources:write`가 필요합니다. **메타데이터 설정** 팝오버에서 언어 우선순위, 소스 요청 언어, 카탈로그 최신성 기간을 관리합니다. 이 페이지는 동기화 워크플로의 구성이나 실행 조작을 중복하지 않습니다. 기존 Maintenance 링크도 이 페이지로 이동합니다.


공유 태그 이름은 선호 언어마다 해당 언어의 수동 이름, 모든 언어 공통 수동 이름, 제공자 이름 순서로 선택합니다. 상세 페이지의 언어 전환도 같은 순서를 따릅니다. 숨겨진 태그 또는 숨겨진 병합 대상과 일치하는 이름은 후보에 표시되며 선택하거나 새로 만들 수 없습니다. 먼저 메타데이터 관리에서 숨김을 해제하세요.

숨김, 병합, 병합 취소는 상태를 즉시 저장하고 관련 작품을 백그라운드 업데이트 대기열에 넣습니다. 각 작품은 업데이트 전까지 마지막으로 확정된 태그 집합을 표시하며, 완료 후 표시·검색·추천에 새 집합을 사용합니다. 태그 관리에 인스턴스 전체의 남은 작품 수가 표시됩니다. 목록을 새로고침하여 진행 상황을 확인할 수 있고 재시작 후에도 처리가 계속됩니다. 이전 스냅샷의 공유 태그 보완은 DLsite만 읽고 사전에 없는 이름만 추가하며 최신 이름을 덮어쓰지 않습니다. 잘못되거나 제한을 넘는 입력은 전체를 건너뛰고 정상적인 수동 편집은 저장할 수 있습니다. 원격 태그는 원격 메타데이터 대체 기능 도입 전까지 기존 스냅샷 표시를 유지합니다.

메타데이터 화면의 기본 주소는 `/metadata`입니다. 기존 `/work-management` 링크도 필터와 설정 상태를 유지해 이동합니다. 첫 동기화 실패와 미해결 메타데이터 결과는 문제 목록을 엽니다. 워크플로 권한이 없으면 실행별 필터 없이 표시합니다. 실행 진단은 Workflows의 Activity에서 확인할 수 있습니다.

Settings는 Account, Playback, '기록', '추천', '태그' 탭으로 구성되며 탭은 아이콘으로 표시됩니다. 아이콘에 마우스를 올리거나 포커스하면 이름이 보이고, 휴대폰에서는 선택한 탭의 이름도 표시됩니다. '내 데이터' 내보내기와 가져오기는 Account 맨 아래에 있습니다. '추천'은 추천 활동과 추천 설정을 표시합니다. 관리자(및 Demo)에게는 구분선 뒤에 관리 탭(Library, Cache & Fetch, Proxy, Cleanup, Users)이 표시됩니다. 넓은 화면에서는 아이콘이 설정 내용 왼쪽에 세로로 놓이고, 휴대폰에서는 가로로 스크롤되는 한 줄의 아이콘이 됩니다. 세로 열 아래의 '탭 이름 표시' 버튼으로 열을 펼치면 모든 탭 이름이 표시되며, Settings는 이 선택을 기억합니다. 폴더와 추천 환경설정은 계정별로 서버에 저장되어 기기 간에 공유됩니다. 개인 설정이 없으면 기존 인스턴스 기본값을 사용합니다. 추천 설정을 저장하면 현재 탭의 추천 세션만 갱신하며 다른 탭의 스냅샷은 유지합니다. Maintenance에는 Library, Cache & Fetch, Proxy, Users만 남고 전체 추천 통계는 Library의 접을 수 있는 영역에 있습니다. 외관 설정은 오른쪽 위 메뉴에 있으며 지구 아이콘은 브라우저 또는 기기 언어를 따릅니다. `sources:write` 권한이 있는 관리자에게는 UI 언어 바로 아래에 '우선 표시할 메타데이터 언어'도 표시됩니다. 인스턴스 전체에서 제목에 사용할 DLsite 판의 언어를 고르며 기본값은 '원본'입니다. 선택한 언어의 판이 없으면 원본을 사용합니다. 프록시는 Proxy 탭에서 우선순위대로 추가하고, '프록시 적용 범위'에서 DLsite, 원격 소스(소스별 재정의 가능), 기타 요청에 적용합니다. '이 컴퓨터' 프록시는 컨테이너가 호스트에 연결하는 주소를 보여 주기만 하고 편집할 수 없으며, 프로토콜, 포트, 선택적 인증 정보를 설정합니다. '직접 연결 대체'(기본값 꺼짐)를 켜면 모든 프록시에 연결하지 못한 요청을 프록시 없이 한 번 다시 시도합니다. Metadata 설정의 'DLsite 프록시'는 DLsite 적용 범위와 같은 스위치입니다. Demo에서는 계정 환경설정을 변경할 수 없습니다. 관리 탭(Library, Cache & Fetch, Proxy, Cleanup, Users)과 개인 데이터 화면은 둘러볼 수 있도록 표시되지만 변경할 수 없습니다.
