# 설정
[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

설정에는 계정 관리, 개인 재생, 기록, 추천, 태그 환경설정이 있으며, 관리자에게는 인스턴스 관리도 포함됩니다. 화면 모양은 헤더의 모양 메뉴에서, UI 언어와 우선 표시할 메타데이터 언어는 아바타 뒤의 계정 메뉴 또는 **로그인** 뒤에서 설정합니다.

## 탭

설정은 계정, 재생, 기록, 추천, 태그 탭을 아이콘으로 표시합니다. 아이콘 위에 마우스를 올리거나 포커스를 두면 이름이 나타나며, 휴대폰에서는 활성 탭의 이름도 함께 표시됩니다. 관리자와 데모는 구분선 뒤에 관리 탭(라이브러리, 캐시 및 가져오기, 프록시, 정리, 사용자)도 보게 되므로, 권한이 높은 범위가 따로 구분됩니다. 넓은 화면에서는 아이콘이 설정 옆에 세로 열로 표시되고, 휴대폰에서는 옆으로 스크롤되는 한 줄로 표시됩니다. 열 아래의 **탭 이름 표시** 버튼은 모든 탭의 이름을 보이도록 열을 확장하며, 설정은 이 선택을 기억합니다.

`/maintenance`, `/users`, `/cleanup`, `/history`, `/tags`, `/user-data` 링크는 해당하는 설정 탭을 엽니다.

## 계정

- 인증된 사용자의 표시 이름을 업데이트합니다.
- 계정으로 관리되는 사용자의 비밀번호는 현재 비밀번호를 확인하고 새 비밀번호를 한 번 더 확인한 뒤 변경합니다.
- 사용자 이름과 역할은 볼 수 있지만 읽기 전용입니다.
- 계정 끝의 **내 데이터**에서 개인 데이터를 내보내고 가져옵니다. [개인 데이터](personal-data.md)를 참고하세요.

비밀번호를 변경해도 현재 세션은 유지되고 해당 사용자의 다른 세션은 취소됩니다. 설정 -> 사용자에서 관리자가 비밀번호를 재설정하면 대상 사용자의 모든 세션이 취소됩니다. 역할, 활성화 상태, 사용자 이름, 사용자 수명 주기 관리는 사용자가 직접 바꾸는 계정 설정이 아닙니다.

최초 관리자를 포함한 모든 계정은 여기에서 자신의 비밀번호를 변경합니다. 예외는 환경 root 계정 모드의 root 계정이며, 이 계정의 비밀번호는 `KIKOTO_ROOT_PASSWORD`에서 가져옵니다. 잊어버린 관리자 비밀번호는 서버 호스트에서 재설정합니다. [관리자 설정 및 복구](../../operations/security.md#administrator-setup-and-recovery)를 참고하세요.

## 재생, 기록, 추천

- **재생**에는 되감기와 빨리감기 간격, **재생 소스**, **이 기기의 개인정보 보호**, **폴더 환경설정**이 있습니다. 탐색 간격의 기본값은 10초와 30초이며 1에서 300 사이의 정수 초 값을 받습니다.
- **재생 소스**: **빠른 소스 전환**은 재생 중 화면의 소스 레이블을 현재 트랙의 다른 위치를 고르는 메뉴로 바꾸고, **실패 시 다른 소스로 전환**은 실패한 위치에서 트랙의 다음 사용 가능한 위치로 이어서 재생하게 합니다. 둘 다 기본적으로 꺼져 있으며 즉시 적용됩니다.
- **이 기기의 개인정보 보호**: **시스템 미디어 컨트롤에서 트랙 정보 숨기기**는 잠금 화면, 제어 센터, 미디어 알림, 화면 가사에 트랙, 서클, 커버 대신 Kikoto만 표시하며 기본적으로 꺼져 있습니다. iOS 앱에는 기본적으로 켜져 있는 설정이 세 가지 더 있습니다. **스피커로 재생하기 전에 확인**은 헤드폰이나 다른 오디오 기기가 연결되어 있지 않으면 재생 시작을 보류하고 먼저 확인하며, 확인한 뒤에는 출력이 바뀔 때까지 스피커로 재생합니다. 잠금 화면이나 제어 센터에서 시작한 재생은 앱에서 확인할 때까지 기다립니다. **백그라운드에서 흐리게 표시**는 앱 전환기에서, 그리고 제어 센터, 알림 센터 등 시스템 화면이 Kikoto를 가릴 때 화면을 흐리게 표시합니다. **화면 녹화나 미러링 중 숨기기**는 화면 녹화, AirPlay 미러링 등 화면 캡처가 진행되는 동안 Kikoto를 가리고 화면 가사를 닫으며, 캡처가 끝날 때까지 가린 상태를 유지합니다. 모든 설정은 계정이 아닌 기기에 속하며 즉시 적용됩니다.
- **폴더 환경설정**에는 순서가 있는 폴더 일치 및 제외 규칙이 있습니다. 저장하면 플레이어를 멈추지 않고 이후의 디렉터리 선택을 갱신합니다.
- **기록**은 청취 보고서(30일, 12개월 또는 전체 기간)와 접힌 전체 청취 기록을 보여 줍니다.
- **추천**은 로그인한 사용자 본인의 최근 30일에 대한 **내 추천 활동** 보고서(노출이 열기와 재생으로 이어진 정도, 남긴 표시와 다시 섞기, 선호도 점수 분포)로 시작하며, 이어서 추천 프리셋, 배지 임계값, 변화, 탐색 부스트, 고급 점수 계산이 나옵니다. 저장하면 현재 탭에 새 추천 세션이 만들어지며, 열려 있는 다른 탭은 새 세션이 만들어질 때까지 자신의 스냅숏을 유지합니다.

폴더 환경설정과 추천 설정은 인증된 계정별로 서버에 저장되어 기기 간에 공유되며, 변경해도 다른 계정에는 영향을 주지 않습니다. 자체 값이 없는 계정과 익명 탐색은 인스턴스 기본값을 사용합니다. 저장에 실패하면 초안과 저장된 값이 모두 유지됩니다.

## 언어 및 모양

모양은 헤더 메뉴에서만, UI 언어는 헤더의 계정 메뉴에서만 사용할 수 있습니다. 지구본 옵션은 브라우저 또는 기기의 언어를 따르며, 툴팁과 접근성 이름이 자동 선택임을 알려 줍니다. 로그인한 모든 사용자는 UI 언어 바로 아래에서 **우선 표시할 메타데이터 언어**도 보게 됩니다. 이것은 개인적인 선택입니다. 해당 사용자에게 보이는 제목 에디션, 소개, 태그 이름을 결정하고, 그 제목으로 제목 정렬 순서를 정하며, Kikoto가 그 사용자를 위해 원격 소스에 질의할 때 가장 먼저 요청하는 언어입니다. 옵션은 **원본**, 일본어, 영어, 중국어 간체, 중국어 번체, 한국어입니다. 선택하지 않으면 각 작품의 원래 언어인 **원본**으로 표시되며, **원본**을 선택하면 환경설정이 지워집니다. 선택한 언어의 에디션이 없으면 `원본`으로 대체됩니다. 공유 태그 이름은 그 언어에 에디션이 있는지와 관계없이 같은 언어 우선순위로 수동 이름과 학습된 사전을 사용합니다. 태그는 원본 에디션에서 가져오므로 모든 언어가 같은 태그를 보여 줍니다. 익명 방문자는 원래 언어를 봅니다. 저장되거나 공유되는 모든 것, 즉 저장된 제목과 태그 이름, 백그라운드 동기화, 제작자 카탈로그 새로 고침, 원격 메타데이터 대체, 활동 텍스트는 항상 각 작품의 원래 언어를 사용하므로, 한 사용자의 선택이 다른 사용자에게 보이는 내용을 바꾸지 않습니다.

### 다국어 제목

Kikoto는 자체 수동 제목이나 DLsite 에디션이 있는 첫 번째 우선 메타데이터 언어를 사용합니다. 해당 언어의 수동 제목이 가장 우선하고, 그다음 모든 언어 공통 수동 제목, 그다음 그 에디션의 제목입니다. 모든 언어 공통 제목은 텍스트만 대체하며, 기본 에디션, 소개, 태그는 그 제목이 없을 때와 같게 유지됩니다. `원본`은 원본 에디션에 선언된 언어를 사용하며, 알 수 없는 언어는 추측하지 않습니다. 일치하는 것이 없으면 원래 제목을 사용합니다. 서클, 시리즈, 성우 재정의는 언어 간에 공유됩니다. 선언되지 않은 원래 언어는 메타데이터 요청 로캘과 관계없이 어디서나 알 수 없음으로 유지되며, 그 언어 레이블에는 **원본**만 표시됩니다. 특정 언어의 수동 제목은 그 선언된 언어에 대해, 또는 해당 수동 언어를 명시적으로 우선하거나 선택했을 때 적용됩니다. 언어 메뉴에는 실제로 존재하는 에디션과 자체 수동 제목이 있는 언어만 포함되며, 모든 언어 공통 제목은 언어를 추가하지 않고 기존 옵션에 적용됩니다.

## 데모 모드

데모 모드는 계정 기반 설정을 읽기 전용으로 유지합니다. 데모 신원이 관리자가 아니더라도 관리 탭, 기록, 추천, 태그 탭, 계정의 내 데이터 섹션은 검사할 수 있도록 계속 표시되지만 그 안의 모든 변경은 비활성화됩니다. 테마 모드, 스타일, 색상, 탐색 간격, 재생 소스 옵션은 브라우저 로컬 환경설정이며 데모 서버 데이터를 수정하지 않으므로, 모양과 재생 컨트롤은 계속 사용할 수 있습니다. 재생 환경설정은 서버 식별자와 인증된 사용자별로, 익명 접근이 활성화된 경우에는 익명 주체별로 분리됩니다.

## 관리

### 라이브러리

라이브러리는 라이브러리 저장소, 로컬 스캔 설정, 제작자 카탈로그, 구성된 원격 소스, 읽기 전용 저장 경로를 하나로 묶습니다.

- **라이브러리 저장소**는 라이브러리 모드(표준 또는 스토리지 풀), 온라인 또는 오프라인 배지가 붙은 각 풀, Fetch 풀을 보여 줍니다. 풀은 추가할 수 있고, 작품이 없는 동안에는 제거할 수도 있습니다. 라이브러리에 로컬 작품이 생기면 모드 자체는 고정됩니다. **다시 연결**은 운영자가 올바른 디스크가 그곳에 마운트되었음을 확인한 뒤 기존 폴더에 다시 표시를 남깁니다.
- **스캔 깊이**는 Fetch가 작품을 저장하는 수준보다 낮게 설정할 수 없습니다. 스캔은 항상 적어도 그 수준까지 도달하므로, 스캔이 그보다 위에서 멈춰 Fetch된 작품이 누락으로 보고되는 일은 없습니다.
- **크리에이터 카탈로그**에는 **카탈로그 최신 유지 일수**(1~365, 기본값 30)가 있으며, 자체 **카탈로그 설정 저장** 버튼으로 저장합니다. 서클 또는 성우 카탈로그는 마지막 새로 고침이 그보다 오래되면 확인 필요로 표시됩니다.
- 원격 소스는 상태, 호스트, 상태 확인 동작, 즉시 저장되는 활성화 스위치가 있는 간결한 목록입니다. 상태 확인 결과는 자동 프로브가 사용하는 것과 같은 소스 상태에 저장됩니다.
- **소스 추가**는 주소 하나에서 시작합니다. Kikoto는 입력한 그대로의 주소, 그 출처, 그리고 Kikoeru 호환 작품 API를 위한 관례적인 `api.` 형제 주소를 프로브한 뒤 API URL, 공개 사이트, 이름을 채웁니다. 아무것도 감지되지 않으면 수동 입력을 위해 **연결 세부 정보**가 열립니다. 엔드포인트 필드, 우선순위, 네트워크/저장소 옵션은 접힌 그룹에 있습니다.
- **대체 언어**는 소스가 모든 언어로 작품을 설명하지 않을 수 있으므로, 보는 사람의 우선 메타데이터 언어 다음에 마지막으로 요청합니다. **원본**을 유지하는 사용자, 익명 방문자, 크롤링, 다운로드, 원격 메타데이터 대체 같은 백그라운드 작업은 대체 언어로만 요청합니다. 기본값은 일본어입니다. 업스트림이 요청을 무시하거나 여러 언어가 섞인 메타데이터를 반환할 수 있습니다.
- 원격 소스는 기본적으로 호환되는 공개 저장소 호스트를 허용합니다. 소스 구성에서 **외부 호스트 제한**을 켜면 API, 공개 사이트, 대체 URL, 그리고 정확한 호스트 또는 `*.example.invalid` 형식의 공개 호스트 패턴으로 편집할 수 있는 목록만 허용할 수 있습니다.
- 저장 경로는 기본적으로 접혀 있고 읽기 전용이며, 확인된 데이터 루트, 캐시 루트, 기본 캐시/저장 미리보기, 소스별 저장 미리보기를 보여 줍니다. 원격 소스 구성은 경로 템플릿 편집기 대신 같은 확인된 예시를 보여 줍니다.

인스턴스 전체의 메타데이터 언어는 없습니다. 각 사용자의 선택은 헤더 계정 메뉴에 있고, 원격 소스의 대체 언어는 해당 소스 설정에 있습니다.

### 캐시 및 가져오기

캐시 및 가져오기에는 재생 캐시 정책, 전송 안전성, 접힌 다운로드 속도 조절 같은 구성만 있으며, 변경 후에 활성화되는 저장 동작이 하나 있습니다. 캐시 내용은 정리 탭에서 관리합니다.

- 파일당 원격 미디어 한도의 기본값은 100 GB이며, 실패하거나 취소된 Fetch 실행에서 게시되지 않은 스테이징은 기본적으로 7일 동안 보관됩니다.
- 트랜스코드 캐시 한도는 별도로 1에서 4096 GB이며 기본값은 5 GB입니다. 다시 만들 수 있는 이 캐시는 `/cache/transcodes` 아래에 있으며 관리되는 원격 미디어 캐시 한도를 바꾸지 않습니다.

### 프록시

- **프록시** 탭은 아웃바운드 프록시를 우선순위 순서로 나열합니다. 요청은 맨 위부터 시도하여 처음 연결되는 프록시를 사용합니다. **프록시 추가**에서 **이 컴퓨터** 또는 **다른 주소**를 선택합니다. 이 컴퓨터 프록시는 Kikoto가 호스팅되는 곳에서 실행됩니다. 대화상자는 서버가 이 프록시에 접속하는 주소(예: 컨테이너의 `host.docker.internal`)를 보여 주지만 편집할 수는 없으므로, 프로토콜, 포트, 선택적인 사용자 이름과 비밀번호만 설정합니다. 다른 프록시는 주소도 입력합니다. 프로토콜은 HTTP, HTTPS, SOCKS5, SOCKS5h입니다. 저장된 비밀번호는 다시 표시되지 않으며, 유지하려면 필드를 비워 두세요. 모든 변경은 즉시 저장됩니다.
- **프록시 적용 범위**는 프록시를 적용할 곳을 선택합니다. **DLsite**(메타데이터, 표지, 제작자 카탈로그), **원격 소스**(탐색, 재생, 다운로드), **기타**(업데이트 확인. 개인 Kikoeru 계정 가져오기는 항상 직접 연결합니다)가 있습니다. **전체**는 세 가지를 함께 전환합니다. 각 범위는 모든 프록시를 우선순위대로 사용하거나 선택한 프록시 하나를 사용합니다. 모든 원격 소스는 원격 소스 범위를 따르거나, 직접 연결하거나, 자체 프록시 선택을 사용할 수 있습니다.
- **직접 연결 대체**는 기본적으로 꺼져 있습니다. 꺼져 있으면 모든 프록시가 연결에 실패한 요청은 직접 연결하지 않고 실패합니다. 켜져 있으면 모든 프록시를 시도한 뒤 해당 요청을 프록시 없이 한 번 재시도합니다.

### 정리

**정리**(`/settings?tab=cleanup`)는 캐시 섹션에 `downloads:manage`, 데이터베이스 섹션에 `sources:write`가 필요합니다.

- **트랜스코드 캐시**는 한도 대비 사용량을 보여 주고 확인을 거치는 지우기 동작을 제공합니다.
- **관리되는 미디어 캐시**는 디스크상의 파일, 참조된 파일, 대상이 되는 파일, 보호된 파일을 보고하며, 고아 캐시 또는 작품별 캐시를 소스별로 묶어 정리합니다. 정리는 워크플로 실행으로 대기열에 들어가는 2단계 파괴적 동작입니다.
- **데이터베이스 레코드**는 제거할 수 있는 레코드 유형을 현재 개수와 함께 나열합니다. 디스크에 없는 것으로 확인된 누락된 작품 폴더와 로컬 파일(그로 인해 남는 빈 트랙 항목과 로컬 사용 가능 여부 포함), 고아 메타데이터 스냅숏, 사용하지 않는 소스 태그, 만료된 세션, 닫은 알림, 90일이 지난 완료된 워크플로 실행, 90일이 지난 추천 신호, 사용하지 않는 추천 스냅숏이 해당됩니다. 개인 태그, 검토/Fetch 기록/메타데이터 문제가 있는 실행, 각 워크플로의 최신 실행은 유지됩니다. 선택한 작업은 확인 후 제거되고 감사 로그에 기록되며, 미디어 파일은 절대 삭제되지 않습니다. 만료된 세션과 대상이 되는 오래된 워크플로 실행은 같은 규칙으로 하루에 한 번 자동으로도 제거됩니다.
- 데이터 폴더가 없거나 비어 있으면 경로 확인이 일시 중지되므로, 마운트되지 않은 라이브러리가 삭제된 것으로 취급되는 일은 없습니다.
- **소스가 없는 작품**은 검토와 삭제를 위해 메타데이터의 **사용 가능한 소스 없음** 보기로 연결됩니다.
- **데이터베이스 압축**은 SQLite 파일을 다시 써서 빈 페이지를 디스크에 돌려줍니다. 활동에 표시되는 워크플로 실행으로 백그라운드에서 실행되며, 한 번에 하나의 압축만 대기하거나 실행할 수 있습니다.

### 사용자

사용자는 계정을 관리합니다. 프로덕션과 개발 환경의 슈퍼 관리자는 여기에서 **인스턴스 접근**도 보게 됩니다. 익명 라이브러리 탐색과 재생은 기본적으로 비활성화되어 있으며, 스위치를 바꾸면 프로덕션 접근 경계에 적용되고 감사 항목이 만들어집니다. 개발 환경은 모든 요청을 root로 인증하므로, 익명 개발 세션을 만들지 않고도 설정이 표시되고 편집할 수 있습니다.

## 메타데이터

메타데이터는 `/metadata`를 사용하며, `/work-management` 링크는 필터나 설정 맥락과 함께 그곳으로 리디렉션됩니다.

**메타데이터** 아이콘 레일은 **작품**(전체, 주의 필요, 메타데이터 문제, 사용 가능한 소스 없음)과 **항목**(태그, 서클, 성우)을 묶습니다. 넓은 화면에서는 그룹과 보기 이름을 펼칠 수 있으며, 휴대폰에서는 스크롤 가능한 아이콘 줄을 보여 줍니다. 작품 표는 검색, 페이지 이동, 선택, 수동 새로 고침을 제공하며, 연필 아이콘은 작품 상세와 같은 편집기를 엽니다. admin과 super_admin은 메타데이터, 표지, 메타데이터 링크, 소스 추적 해제, 공유 태그 편집, 서클 식별 편집에 대한 `library:write`를 받습니다.

**태그**(`/metadata?view=tags`)는 공유 개념을 공유 태그 **ID**별로 나열하며, 목록이 언어 설정에 좌우되지 않도록 ID 순으로 정렬합니다. ID 셀에는 DLsite 장르 ID가 있으면 태그 ID 아래에 표시하고, 그 아래에는 숨겨졌거나 병합된 태그에 대해서만 **숨김** 또는 **병합됨**을 표시하며, 활성 태그에는 상태가 표시되지 않습니다. 열은 ID, 일본어, 중국어 간체, 중국어 번체, 영어, 한국어, **기타 이름**, 작품 수, 관리입니다. 각 언어 열은 해당 언어가 표시하는 이름을 보여 줍니다. 그 언어 자체의 수동 이름, 그다음 모든 언어 공통 수동 이름(흐리게 표시), 그다음 DLsite 사전 이름, 그다음 원격 소스의 이름이며, 없으면 "—"입니다. **기타 이름**은 알려진 다른 모든 이름을 한 번씩 나열합니다. 수동 이름이 대체한 이름(언어 포함), 언어가 없는 이름, 이름 레코드가 없는 저장된 이름이 해당됩니다. 검색은 원격 소스 이름을 포함한 이름과 일치하며, 숫자 쿼리는 태그 ID나 DLsite 장르 ID와도 일치합니다. 좁은 화면에서는 표가 자체 상자 안에서 옆으로 스크롤되고 관리 버튼은 오른쪽 가장자리에 고정됩니다. 관리는 모든 언어 또는 로캘별 수동 이름, 전체 숨기기, 병합 대상 선택, 병합 매핑 취소를 엽니다. **서클**(`?view=circles`)은 서클을 DLsite 메이커 ID(RG 코드)별로 코드 순으로 나열하며, 병합으로 합쳐진 메이커 ID는 기본 ID 아래에 표시되고, 원격 소스에서만 알려진 서클이 그 뒤를 따르며 Kikoto ID로 표시됩니다. 열은 코드, 이름(알려진 최신 작품의 표지 옆), 등록된 이름, 작품 수, 관리이며, 검색은 메이커 ID와도 일치합니다. 관리는 제공처 새로 고침 후에도 유지되는 수동 이름, 확인된 별칭, 작품, 메이커 ID, 카탈로그, 스냅숏, 시리즈, 개인 서클 데이터를 옮기는 검토된 병합을 지원합니다. 취소는 가장 최근 병합부터 처리하며, 영향을 받은 레코드에 대한 이후 편집을 덮어쓰기를 거부합니다. **성우**(`/metadata?view=aliases`, 한 사람을 열려면 `&voice=<id>` 추가)는 사람을 Kikoto ID별로 ID 순으로 나열하며, 열은 ID, 이름(최신 작품의 표지 옆), 별칭, 작품 수, 상태(카탈로그 동기화), 관리입니다. 별칭 및 중복 관리에는 `metadata:sync`가 필요합니다. 데모는 변경이 비활성화된 채로 검사할 수 있습니다.

항목 목록은 메타데이터 페이지에 대한 접근을 따릅니다. `library:write`, `metadata:sync`, `sources:write`, `system:admin` 중 하나 이상이 있는 계정으로 로그인하세요. 익명 읽기 접근에는 이 관리 목록이 포함되지 않습니다. 데모는 데모 작품과 관련된 태그와 서클만 표시하고, 그 작품만 집계하며, 서클 병합 기록은 노출하지 않습니다.

태그 가시성은 최종 병합 대상을 따릅니다. 이미 병합된 태그를 숨기면 취소한 뒤를 위해 그 숨김 설정을 저장하고, 숨겨진 대상에 병합하면 결과 태그가 숨겨집니다. 원래 이름은 병합된 동안에도 검색할 수 있으며, 취소하면 원래의 식별자와 검색 이름이 복원됩니다.

표지 레이아웃 마이그레이션과 태그 백필은 핵심 시작 워크플로 이후 백그라운드에서 독립적으로 실행됩니다. 표지 파일 하나가 실패해도 다른 파일은 멈추지 않습니다. 복구 실패는 로그에 기록되고 다음 시작 때 다시 시도됩니다.

헤더는 카테고리, 검색, 목록 컨트롤을 한 줄에 유지합니다. 넓은 화면에서는 검색 필드가 카테고리 옆에 있고, 좁은 화면에서는 오른쪽의 검색 아이콘으로 접혀 그 줄 아래에 필드를 엽니다. 새로 고침, 페이지당 행 수, **메타데이터 다시 시도**, **소스 확인**, **메타데이터 설정** 톱니바퀴가 그 뒤를 따릅니다. 목록 위아래의 페이지 이동은 라이브러리와 같습니다. 메타데이터 설정은 팝오버로 열리며, 정보 아이콘에 마우스를 올리거나 포커스를 두면 설정 설명이 나타나고, 닫아도 현재 목록과 필터는 유지됩니다. 메타데이터 동기화는 워크플로에서 시작하세요.

계열을 선택하고 **메타데이터 다시 시도**를 고르세요. 개수에는 대상이 되는 선택만 포함됩니다. 사용 불가로 보고된 상품을 포함하여, 영향을 받은 에디션의 세부 정보에서 그 에디션만 다시 시도할 수도 있습니다. 실패한 재시도는 기존 메타데이터와 수동 재정의를 보존합니다. **소스 확인**은 소스가 없는 선택된 계열에 적용됩니다. 로컬 정보의 삭제 확정은 **사용 가능한 소스 없음** 보기에서만 가능하며, 서버가 사용 가능 여부를 다시 확인하고 미디어 파일은 유지합니다.

활동의 **메타데이터 문제 열기**는 해당 실행의 미해결 메타데이터 문제로 필터링된 메타데이터를 열고, **모든 미처리 작품 보기**는 실행 필터를 제거합니다. 첫 동기화 실패와 보류 중인 메타데이터 결과는 메타데이터 문제를 엽니다. 워크플로 권한이 없는 운영자는 범위가 지정되지 않은 문제 목록을 봅니다. 실행 진단은 워크플로 활동에 있습니다. 복구가 다른 사용자의 활동 검토를 바꾸는 일은 없습니다. 메타데이터 복구에는 `metadata:sync`가 필요하고, 소스 확인, 삭제, 소스/언어 설정에는 `sources:write`가 필요합니다. **메타데이터 설정** 팝오버에는 설정만 있으며, 이 페이지는 동기화 워크플로의 구성이나 실행 컨트롤을 중복해서 제공하지 않습니다.

메타데이터 설정에는 **DLsite 프록시** 바로가기가 있습니다. 이는 `설정 -> 프록시 -> 프록시 적용 범위`의 DLsite 범위와 같은 스위치 및 프록시 선택이며 즉시 저장됩니다. **프록시 관리**는 프록시를 추가하거나 순서를 바꾸기 위해 해당 섹션을 엽니다. 그 아래의 **카탈로그 최신 유지 일수**는 `설정 -> 라이브러리`를 열고, **원격 메타데이터 보완**은 메타데이터 동기화 워크플로를 열며, 그곳의 **구성**에 해당 설정이 있습니다.

공유 태그 이름은 각 우선 언어를 순서대로 시도합니다. 해당 언어의 수동 이름, 모든 언어 공통 수동 이름, 그다음 제공처 이름입니다. 상세의 언어 전환도 같은 우선순위를 따릅니다.

숨기기, 병합, 취소는 상태를 즉시 저장합니다. 관련 작품은 백그라운드에서 계속 갱신되며, 태그 관리자에는 재시도를 기다리는 작품을 포함한 인스턴스 전체의 남은 작업 수가 표시됩니다. 진행 상황을 확인하려면 목록을 새로 고치세요. 실패한 작품은 다른 작품을 지연시키지 않고 자동으로 재시도되며, 재시작 후에도 업데이트가 재개됩니다.

### 우선 언어의 태그 이름

DLsite는 일본어 전용 작품에도 요청한 언어로 장르 이름을 붙입니다. 어느 사용자의 우선 메타데이터 언어가 일본어가 아니면, **태그 이름 학습** 워크플로가 백그라운드에서 누락된 태그 이름을 채웁니다. 각 언어에 대해 이름이 없는 태그를 가장 많이 포함한 작품을 DLsite에 한 번 요청하므로, 요청 횟수는 라이브러리 크기가 아니라 누락된 태그에 따라 달라집니다. 시작 후, 메타데이터 동기화 후, 언어 변경 후에 실행되며, 메타데이터 동기화와 같은 요청 속도 조절과 DLsite 프록시를 사용하고, 재시작 후에도 재개됩니다. 진행 상황, 결과, 실패는 활동에 표시됩니다. 태그 이름만 저장하며 제목이나 소개는 저장하지 않고, DLsite가 이름을 붙이지 않은 태그는 다시 요청하지 않습니다.

### 원격 메타데이터 보완

**원격 메타데이터 보완**은 DLsite 메타데이터 동기화 실행과 그 간격 트리거마다 있는 옵션으로, 기본적으로 꺼져 있습니다. 켜고 작품 메타데이터를 제공하는 활성화된 소스를 요청 순서대로 최대 16개까지 선택하세요. DLsite가 명시적으로 not-found 결과를 반환한 경우에만 대체가 시작되며, 시간 초과나 일시적인 실패는 해당하지 않습니다. 요청은 기존 작품만 설명하고 공유된 제한된 전송을 사용합니다. 채워진 메타데이터는 실행 후에도 유지됩니다. 이 선택은 저장된 원격 값의 인스턴스 전체 순서나 수동/DLsite 우선순위를 바꾸지 않습니다.

### 구매 특전

**구매 특전을 원래 작품에 연결**은 DLsite 실행 옵션으로 기본적으로 켜져 있으며 트리거에도 저장됩니다. 해당 실행의 자동 감지를 제어합니다. 감지는 먼저 저장된 작품을 확인한 뒤 최대 10개의 서클 페이지와 5개의 후보 상품을 확인합니다. 감지가 꺼져 있어도 기존 링크는 계속 적용됩니다. [구매 특전](work-detail.md#구매-특전)을 참고하세요.
