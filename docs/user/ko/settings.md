# 설정

[English](../en/settings.md)

설정은 서버, 사용자, 브라우저에 저장되는 동작을 관리합니다.

## 현재 동작

- 언어, 테마, 표시 밀도와 작품 컬렉션 열 수를 설정합니다.
- 재생 속도, 앞/뒤 탐색 시간, 호환 재생 범위를 저장합니다.
- 서버 연결과 로그인 세션을 관리합니다.
- 소스, 메타데이터 언어 우선순위와 원격 요청 옵션을 관리합니다.
- 폴더 스캔, watcher, Follow-up run 및 예약 트리거를 설정합니다.
- 개인 태그, 즐겨찾기 목록, 청취 상태를 사용자별로 보존합니다.

## 메타데이터

사이드바의 **메타데이터**는 **워크플로** 바로 아래에 있습니다. 가로 분류는 **전체**, **주의 필요**, **메타데이터 문제**, **사용 가능한 소스 없음**입니다. 전체에는 문제가 없는 저장된 작품 계열도 포함됩니다. 검색, 페이지, 표지, 선택과 해당 버전 및 제공자 상세 정보를 공유합니다.

오른쪽 위의 **메타데이터 설정**은 대화상자를 열며, 닫아도 목록과 필터가 유지됩니다. **메타데이터 동기화**는 기존 동기화 워크플로를 열어 범위를 선택하고 실행할 수 있습니다.

작품을 선택하고 **메타데이터 재시도**를 누르면 해당 개수가 버튼에 표시됩니다. 상세 정보에서 특정 버전도 재시도할 수 있으며 이전에 사용할 수 없다고 보고된 작품도 다시 확인합니다. 실패하면 기존 정보와 수동 덮어쓰기를 유지합니다. 소스 확인은 선택한 소스 없는 작품에만 적용됩니다. 로컬 정보 삭제는 「사용 가능한 소스 없음」 화면에서만 제공하며 확인 후 서버가 소스 상태를 다시 검사하고 미디어 파일은 유지합니다.

Activity와 Workflows는 유지합니다. Activity의 문제 목록 버튼은 해당 실행의 미해결 메타데이터 문제로 필터링한 작품 유지 관리를 엽니다. 전체 대기 작품을 표시하면 실행 필터가 해제됩니다. 복구는 다른 사용자의 검토 상태를 변경하지 않습니다. 메타데이터 복구에는 `metadata:sync`, 소스 확인·삭제·소스 및 언어 설정에는 `sources:write`가 필요합니다. **메타데이터 설정** 대화상자에서 언어 우선순위, 소스 요청 언어, 카탈로그 최신성 기간을 관리합니다. 동기화 바로가기는 기존 Workflows를 열며 구성을 중복하지 않습니다. 기존 Maintenance 링크도 이 페이지로 이동합니다.
