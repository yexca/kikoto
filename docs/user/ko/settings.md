# 설정

[English](../en/settings.md)

설정은 서버, 사용자, 브라우저에 저장되는 동작을 관리합니다.

## 현재 동작

- 언어, 테마, 표시 밀도와 작품 컬렉션 열 수를 설정합니다.
- 재생 속도, 앞/뒤 탐색 시간, 호환 재생 범위를 저장합니다.
- 서버 연결과 로그인 세션을 관리합니다.
- 소스, 메타데이터 언어 우선순위와 원격 요청 옵션을 관리합니다.
- 폴더 스캔, watcher, Follow-up run 및 예약 트리거를 설정합니다.
- 개인 태그, 즐겨찾기 목록, 청취 상태를 사용자별로 보존합니다.

## 유지 관리

Maintenance 탭은 한 줄로 표시되며 좁은 화면에서는 가로로 스크롤할 수 있습니다. Overview는 제거되었습니다. Library에는 로컬 스캔, 원격 소스와 읽기 전용 저장 경로가 있으며 소스 관리자의 기본 화면입니다. Users에는 사용자 관리와 최고 관리자 전용 인스턴스 접근 설정이 있습니다. 사용자 관리 권한만 있으면 Users가 기본 화면입니다. 기존 Paths와 Access 링크는 각각 Library와 Users로 이동합니다.

원격 소스는 상태, 호스트, 상태 확인, 바로 저장되는 사용 스위치를 갖춘 간결한 목록입니다. **소스 추가**는 주소 하나로 시작합니다. 입력한 주소, 그 오리진, 일반적인 `api.` 하위 도메인을 차례로 확인해 API URL, 공개 사이트, 이름을 채웁니다. 감지하지 못하면 **연결 세부 정보**가 열려 직접 입력할 수 있습니다. 엔드포인트, 우선순위, 네트워크 및 저장소 옵션은 접혀 있습니다. Cache & Fetch에는 설정만 남고 캐시 내용은 **정리** 탭에서 관리합니다. 추천 설정에는 로그인한 사용자의 최근 30일 통계만 보여 주는 접힌 **내 추천 활동**이 추가되었습니다.

## 정리

**정리**는 설정에서 Cache & Fetch 다음에 있는 관리자 탭입니다(`/settings?tab=cleanup`). 캐시 부분에는 `downloads:manage`, 데이터베이스 부분에는 `sources:write` 권한이 필요합니다. 트랜스코드 캐시와 관리 미디어 캐시의 사용량 확인 및 정리, 그리고 데이터베이스 레코드 정리를 제공합니다. 대상은 디스크에 없음을 확인한 작품 폴더와 로컬 파일(이로 인해 비게 된 트랙 항목과 로컬 가용성 포함), 고아 메타데이터 스냅샷, 사용하지 않는 소스 태그, 만료된 세션, 닫은 알림, 90일이 지난 워크플로 기록과 추천 신호, 사용하지 않는 추천 스냅샷입니다. 개인 태그, 검토·Fetch 기록·메타데이터 문제가 있는 실행과 각 워크플로의 최신 실행은 유지됩니다. 정리는 확인 후 실행되고 감사 로그에 기록되며 미디어 파일은 삭제되지 않습니다. 데이터 폴더가 없거나 비어 있으면 경로 확인을 일시 중지합니다. **소스가 없는 작품**은 메타데이터의 **사용 가능한 소스 없음**으로 연결되고, **데이터베이스 압축**은 빈 페이지를 디스크에 돌려줍니다.

## 메타데이터

사이드바의 **메타데이터**는 **워크플로** 바로 아래에 있습니다. 가로 분류는 **전체**, **주의 필요**, **메타데이터 문제**, **사용 가능한 소스 없음**입니다. 전체에는 문제가 없는 저장된 작품 계열도 포함됩니다. 검색, 페이지, 표지, 선택과 해당 버전 및 제공자 상세 정보를 공유합니다. **성우 별칭** 보기(`metadata:sync` 필요)는 성우와 확정된 별칭을 나열하며, 대화상자에서 별칭 추가·삭제, 중복 인물 병합과 병합 취소를 할 수 있습니다.

오른쪽 위의 **메타데이터 설정**은 대화상자를 열며, 닫아도 목록과 필터가 유지됩니다. **메타데이터 동기화**는 기존 동기화 워크플로를 열어 범위를 선택하고 실행할 수 있습니다.

작품을 선택하고 **메타데이터 재시도**를 누르면 해당 개수가 버튼에 표시됩니다. 상세 정보에서 특정 버전도 재시도할 수 있으며 이전에 사용할 수 없다고 보고된 작품도 다시 확인합니다. 실패하면 기존 정보와 수동 덮어쓰기를 유지합니다. 소스 확인은 선택한 소스 없는 작품에만 적용됩니다. 로컬 정보 삭제는 「사용 가능한 소스 없음」 화면에서만 제공하며 확인 후 서버가 소스 상태를 다시 검사하고 미디어 파일은 유지합니다.

Activity와 Workflows는 유지합니다. Activity의 문제 목록 버튼은 해당 실행의 미해결 메타데이터 문제로 필터링한 작품 유지 관리를 엽니다. 전체 대기 작품을 표시하면 실행 필터가 해제됩니다. 복구는 다른 사용자의 검토 상태를 변경하지 않습니다. 메타데이터 복구에는 `metadata:sync`, 소스 확인·삭제·소스 및 언어 설정에는 `sources:write`가 필요합니다. **메타데이터 설정** 대화상자에서 언어 우선순위, 소스 요청 언어, 카탈로그 최신성 기간을 관리합니다. 동기화 바로가기는 기존 Workflows를 열며 구성을 중복하지 않습니다. 기존 Maintenance 링크도 이 페이지로 이동합니다.

메타데이터 화면의 기본 주소는 `/metadata`입니다. 기존 `/work-management` 링크도 필터와 설정 상태를 유지해 이동합니다. 첫 동기화 실패와 미해결 메타데이터 결과는 문제 목록을 엽니다. 워크플로 권한이 없으면 실행별 필터 없이 표시합니다. 실행 진단은 Workflows의 Activity에서 확인할 수 있습니다.

Settings는 Account, Playback, Recommendation으로 구성됩니다. 폴더와 추천 환경설정은 계정별로 서버에 저장되어 기기 간에 공유됩니다. 개인 설정이 없으면 기존 인스턴스 기본값을 사용합니다. 추천 설정을 저장하면 현재 탭의 추천 세션만 갱신하며 다른 탭의 스냅샷은 유지합니다. Maintenance에는 Library, Cache & Fetch, Users만 남고 전체 추천 통계는 Library의 접을 수 있는 영역에 있습니다. 외관 설정은 오른쪽 위 메뉴에 있으며 지구 아이콘은 브라우저 또는 기기 언어를 따릅니다. Demo에서는 계정 환경설정을 변경할 수 없습니다.
