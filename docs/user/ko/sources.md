# 소스

[English](../en/sources.md)

소스는 작품의 파일 위치와 메타데이터 제공자를 설명합니다.

## 현재 동작

- Local은 `/data`에서 발견한 로컬 폴더와 미디어입니다.
- Tracked는 선택한 원격 파일 소스의 저장된 트리입니다.
- Cache는 원격에서 가져온 캐시 파일입니다.
- 원격 metadata source는 작품 정보와 가용성만 제공할 수 있습니다.
- 여러 소스의 정보는 하나의 통합 work에 연결되며 소스별 복사본을 만들지 않습니다.
- 소스 정책은 URL, 인증, 리디렉션, 응답 크기와 동시성을 제한합니다.

## 작업

- Sync는 메타데이터와 소스 상태를 갱신합니다.
- Track은 원격 트리를 저장하고 Tracked에서 탐색하게 합니다.
- Cache는 선택한 파일을 캐시에 materialize합니다.
- Fetch는 검토한 파일을 `/data`의 로컬 트리로 승격합니다.
- Fork는 기존 소스와 별도의 선택을 만들 때 사용합니다.
