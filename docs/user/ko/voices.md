# 성우
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

성우 페이지는 저장된 인물 및 크레딧 데이터를 보여 줍니다.

## 현재 동작

- 로컬 제공처 크레딧과 사용자가 관리하는 인물 데이터에서 성우를 나열하며, 표지 타일마다 로컬과 원격 개수 및 사용 가능 여부 막대를 표시합니다. 막대는 로컬 사본이 있는 작품은 채워진 구간, 원격 소스만 가진 작품은 더 연한 구간, 나머지는 빈 트랙으로 나타냅니다.
- 서버 페이지 단위이며 URL에 반영되는 목록 검색과 필터를 사용합니다. 각 타일에는 성우의 표지와 그 위의 즐겨찾기 컨트롤, 이름, 별칭, 최신 발매일, 동적 사용자 태그 행이 표시되며, 라이브러리와 같은 방식의 페이지 이동을 제공합니다. 타일은 넓은 레이아웃에서는 한 줄을 채우고 휴대폰에서는 두 열을 이룹니다.
- 알려진 최신 크레딧 작품의 표지를 성우의 표지로 사용합니다. 상세의 **더 보기** 메뉴에 있는 **커버 변경…**은 성우의 작품을 검색과 함께 나열하며, 고른 작품의 표지를 타일과 상세 요약에서 성우의 표지로 삼습니다. 같은 대화 상자의 **최신 작품**은 새 작품이 나올 때마다 바뀌는 표지로 되돌립니다. 이 선택은 선택한 계정에 속하며, 고른 작품이 더 이상 성우의 작품이 아니게 되면 최신 작품의 표지가 대신 사용됩니다.
- 검색, 한 번에 선택하는 보기 칩, 페이지 크기 동작을 줄바꿈되는 도구 모음 한 줄에 둡니다. 칩은 `모든 성우`, `즐겨찾기`, `태그됨`, `사용 가능`, `로컬`, `원격`, `누락`이며, 눌린 칩이 현재 보기를 나타냅니다. 휴대폰에서는 검색 필드가 한 줄을 차지하고 그 옆에 페이지 크기가 놓이며, 칩은 아래에서 가로로 스크롤됩니다. 사용자 태그는 계속 표시되고 검색할 수 있지만, 목록에서는 태그 필터를 제공하지 않습니다.
- 즐겨찾기, 평점, 메모, 사용자 태그 상태를 표시합니다.
- 상세 제목 아래에 확인된 별칭을 표시합니다. 별칭 검토, 중복 병합, 병합 취소는 메타데이터 페이지의 **성우** 보기에 있으며, `metadata:sync` 권한이 있는 사용자는 상세의 **더 보기** 메뉴에서 그곳으로 이동할 수 있습니다.
- 제공처 성우 크레딧이 없는 작품은 `알 수 없음` 그룹으로 묶습니다.
- 표지 색조의 성우 상세 요약에서 로컬과 원격 사용 가능 배지를 표시한 뒤 사용자 태그를 표시합니다. 캐시는 재생과 필터링 데이터에는 계속 사용할 수 있지만 로컬로 표시하지는 않습니다.
- 알려진 작품과 원격 작품을 라이브러리와 같은 반응형 그리드와 공통 작품 카드로 표시합니다. 작품 카드에서 DLsite 태그나 개인 태그를 선택하면 해당 태그의 로컬 라이브러리 검색이 열립니다.
- 작품을 **출시일**, **코드**, **제목**, **평점**, **판매량** 순으로 오름차순 또는 내림차순으로 정렬하며, 기본값은 최신 발매 순입니다. 선택한 기준 값이 없는 작품은 어느 방향에서나 맨 뒤에 둡니다. 정렬 순서와 페이지 크기(24, 48, 96)는 계정별로 기기에 기억되며 모든 성우에 적용됩니다.
- 성우의 작품은 서버에서 페이지로 나눕니다. 알려진 작품과 원격 카탈로그를 하나의 목록으로 합치고, 검색, 사용 가능 여부 필터와 선택한 정렬 순서를 페이지 분할 전에 적용합니다. 일괄 선택은 불러온 페이지에만 적용됩니다. 검색은 라이브러리의 일반 검색과 같이 코드, 제목, 서클, 성우, 태그, 개인 태그로 작품을 찾고, 원격 카탈로그에만 있는 작품은 코드, 제목, 서클, 태그로 찾습니다. 한 작품의 여러 에디션은 한 작품으로 세며, 어느 에디션이든 사용 가능하면 사용 가능한 것으로 봅니다. 인물 상세와 원격 소스의 카탈로그 상태는 따로 불러옵니다. 원격 소스 검색은 동시 실행 수를 제한하고, 성우 수와 사용자 태그는 일괄로 집계합니다.
- 상세 요약에 즐겨찾기, 자주 쓰는 새로 고침 동작, **더 보기** 메뉴를 둡니다. **처음 가져오기** 또는 **새로 고침**은 호환되는 모든 원격 소스에 걸쳐 알려진 작품의 메타데이터만 대상으로 하는 성우 카탈로그 동기화 실행을 대기열에 넣으며, **메타데이터 다시 시도**는 알려진 작품에 아직 메타데이터가 없는 동안에만 나타납니다. 실행이 끝날 때까지 버튼에 **새로 고치는 중**이 표시됩니다. 동기화 상태 옆의 경고는 마지막 시도에 실패한 원격 소스의 수를 보여 주며, 해당 실행을 활동에서 엽니다. **즐겨찾기** 옆의 벨은 성우의 새 작품을 구독합니다. [구독](subscriptions.md)을 참고하세요. **더 보기**에는 **커버 변경…**, 소스, 필터, 메타데이터, 태그 선택을 위해 이 성우가 선택된 프리셋을 여는 **이 성우 카탈로그 동기화…**, 그리고 **별칭 관리**가 있습니다. 작품 도구 모음은 라이브러리와 같습니다. 왼쪽에는 폭이 제한된 검색이 있고, 오른쪽에는 현재 정렬 순서를 이름으로 표시하는 정렬 버튼, 표시 옵션, 사용 가능 여부 필터, 선택이 있으며, 공통 컬렉션 페이지 이동은 그리드 위와 아래에 있습니다. 표시 옵션에는 라이브러리와 공유하는 **전체**, **컴팩트**, **미니** 중에서 고르는 **카드** 선택, 열 수, 페이지 크기가 들어 있으며, 새로 고른 카드 모드는 해당 [프리셋](library.md#현재-동작)에서 시작합니다. 휴대폰에서는 정렬 버튼을 작품 위에 두고, 검색, 필터, 카드 모드, 열 수, 페이지 크기, 선택은 별도의 옵션 시트에서 엽니다.
- 모바일 상세의 뒤로 가기 컨트롤은, 라이브러리나 즐겨찾기에서 상세를 연 경우를 포함하여, 서버와 사용자 기준으로 마지막으로 본 성우 목록 위치로 올라가는 동작으로 처리합니다. 넓은 레이아웃에서는 출처를 인식하는 기록 복귀를 유지합니다.

## 경계

DLsite는 알려진 작품에 대한 메타데이터 제공처로 남습니다. Kikoto는 DLsite 키워드 크롤링을 신뢰할 수 있는 성우 카탈로그로 취급하지 않습니다.

## 검토 동작

별칭 및 병합 도구는 중복된 인물 레코드를 통합할 때 사용자 상태를 보존하고 병합 취소를 계속 볼 수 있게 유지해야 합니다.
