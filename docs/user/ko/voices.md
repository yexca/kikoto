# 성우

[English](../en/voices.md)

성우 화면은 저장된 인물과 크레딧 정보를 표시합니다.

## 현재 동작

- 로컬 provider 크레딧과 사용자 인물 데이터를 목록화하고 Local 및 Remote 가용성 배지를 표시합니다.
- 서버 페이지 검색과 필터, 반응형 카드, 사용자 태그, 페이지 매김과 최신 작품 표지를 제공합니다.
- 즐겨찾기, 평점, 메모와 사용자 태그 상태를 표시합니다.
- 별칭 검토, 중복 병합과 병합 취소는 메타데이터 페이지의 **성우 별칭** 보기에서 제공하며, 상세 화면의 **더 보기** 메뉴에서 이동할 수 있습니다.
- 상세 화면의 **처음 가져오기**, **새로 고침**, **메타데이터 다시 시도**는 새 작품 단계를 끈 성우 팔로우 실행을 대기열에 추가합니다. **더 보기** 메뉴에는 성우 팔로우와 별칭 관리가 있습니다.
- provider 성우 크레딧이 없는 작품은 `unknown` 그룹에 넣습니다.
- Cache는 재생과 필터링에는 사용하지만 Local로 표시하지 않습니다.
- 알려진 작품과 원격 작품은 Library와 같은 카드 그리드를 사용합니다.
- 인물 상세, 알려진 작품, 원격 일치를 독립적으로 로드합니다.

## 경계

DLsite는 알려진 작품의 metadata provider입니다. Kikoto는 DLsite 키워드 크롤링을 신뢰할 수 있는 성우 카탈로그로 취급하지 않습니다.

## 검토 동작

별칭과 병합 도구는 사용자 상태를 보존하고 중복 인물을 합친 뒤에도 병합 취소를 표시해야 합니다.
