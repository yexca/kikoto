# 성우
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

성우 페이지는 저장된 인물 및 크레딧 데이터를 보여 줍니다.

## 현재 동작

- 로컬 제공처 크레딧과 사용자가 관리하는 인물 데이터에서 성우를 나열하며, 각 제작자 카드에 로컬과 원격 사용 가능 배지를 표시합니다.
- 서버 페이지 단위이며 URL에 반영되는 목록 검색과 필터를 사용하고, 더 짧은 반응형 제작자 카드, 동적 사용자 태그 행, 라이브러리와 같은 방식의 페이지 이동, 알려진 최신 크레딧 작품의 표지를 제공합니다.
- 라이브러리와 같은 방식의 첫 줄 도구 모음을 사용합니다. 검색은 왼쪽에, 페이지 크기와 기존 성우 필터 동작(기본값 `모든 성우`)은 오른쪽에 있으며, 좁은 레이아웃에서는 검색이 도구 모음 동작으로 접힙니다. 사용자 태그는 계속 표시되고 검색할 수 있지만, 목록에서는 당분간 태그 필터를 제공하지 않습니다.
- 즐겨찾기, 평점, 메모, 사용자 태그 상태를 표시합니다.
- 상세 제목 아래에 확인된 별칭을 표시합니다. 별칭 검토, 중복 병합, 병합 취소는 메타데이터 페이지의 **성우** 보기에 있으며, `metadata:sync` 권한이 있는 사용자는 상세의 **더 보기** 메뉴에서 그곳으로 이동할 수 있습니다.
- 제공처 성우 크레딧이 없는 작품은 `알 수 없음` 그룹으로 묶습니다.
- 성우 상세에서 로컬과 원격 사용 가능 배지를 표시한 뒤 사용자 태그를 표시합니다. 캐시는 재생과 필터링 데이터에는 계속 사용할 수 있지만 로컬로 표시하지는 않습니다.
- 알려진 작품과 원격 작품을 라이브러리와 같은 반응형 그리드와 공통 작품 카드로 표시합니다. 작품 카드에서 DLsite 태그나 개인 태그를 선택하면 해당 태그의 로컬 라이브러리 검색이 열립니다.
- 인물 상세, 알려진 작품, 원격 일치 항목을 각각 독립적으로 불러옵니다. 원격 소스 검색은 동시 실행 수를 제한하고, 성우 수와 사용자 태그는 일괄로 집계합니다.
- 상세 요약에 즐겨찾기, 자주 쓰는 새로 고침 동작, **더 보기** 메뉴를 둡니다. **처음 가져오기** 또는 **새로 고침**은 호환되는 모든 원격 소스에 걸쳐 알려진 작품의 메타데이터만 대상으로 하는 성우 팔로우 실행을 대기열에 넣으며, **메타데이터 다시 시도**는 알려진 작품에 아직 메타데이터가 없는 동안에만 나타납니다. 실행이 끝날 때까지 버튼에 **새로 고치는 중**이 표시됩니다. 동기화 상태 옆의 경고는 마지막 시도에 실패한 원격 소스의 수를 보여 주며, 해당 실행을 활동에서 엽니다. **더 보기**에는 소스, 필터, 메타데이터, 태그 선택을 위해 이 성우가 선택된 프리셋을 여는 **이 성우 팔로우…**와 **별칭 관리**가 있습니다. 작품 도구 모음은 라이브러리와 같습니다. 왼쪽에는 폭이 제한된 검색이 있고, 오른쪽에는 열 수, 페이지 크기, 사용 가능 여부 필터, 선택이 조용한 아이콘 동작으로 있으며, 공통 컬렉션 페이지 이동은 그리드 위와 아래에 있습니다. 모바일 작품 검색은 한 줄을 유지하고, 필터, 열, 선택 컨트롤은 별도의 옵션 시트에서 엽니다.
- 모바일 상세의 뒤로 가기 컨트롤은, 라이브러리나 즐겨찾기에서 상세를 연 경우를 포함하여, 서버와 사용자 기준으로 마지막으로 본 성우 목록 위치로 올라가는 동작으로 처리합니다. 넓은 레이아웃에서는 출처를 인식하는 기록 복귀를 유지합니다.

## 경계

DLsite는 알려진 작품에 대한 메타데이터 제공처로 남습니다. Kikoto는 DLsite 키워드 크롤링을 신뢰할 수 있는 성우 카탈로그로 취급하지 않습니다.

## 검토 동작

별칭 및 병합 도구는 중복된 인물 레코드를 통합할 때 사용자 상태를 보존하고 병합 취소를 계속 볼 수 있게 유지해야 합니다.
