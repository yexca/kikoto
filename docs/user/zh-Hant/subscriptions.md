# 訂閱
[English](../en/subscriptions.md) · [简体中文](../zh-Hans/subscriptions.md) · [繁體中文](../zh-Hant/subscriptions.md) · [日本語](../ja/subscriptions.md) · [한국어](../ko/subscriptions.md)

訂閱會收集你所訂閱的社團、系列與聲優的新作，以及可用性監視在遠端來源上找到的作品。

## 訂閱

- 社團、系列與聲優頁面在 **收藏** 旁都有一個鈴鐺。訂閱與收藏是分開的：收藏記錄的是偏好，訂閱則會把新作加入訂閱動態。訂閱屬於個人。
- 訂閱從目前的目錄狀態開始：目錄中已有的作品不會被算作新作。若目錄最近才擷取過，訂閱會立即開始。否則訂閱時會先詢問：可以同步中繼資料的帳號能 **立即擷取並訂閱**，訂閱會在該次擷取成功後開始；其他帳號，或選擇 **下次重新整理時擷取** 的帳號，則等待下一次排程的重新整理。在此之前，鈴鐺會顯示 **已訂閱，正在等待首次擷取目錄**。
- 社團的訂閱包含該社團的系列。你已訂閱社團的系列，其鈴鐺無法使用；訂閱社團時，會先列出它將取代的系列訂閱，再移除這些訂閱。
- 聲優的目錄來自遠端來源，因此訂閱聲優需要一個已啟用的相容遠端來源。
- 再次選取鈴鐺，可開啟或關閉 **監視可用性**、開啟 **管理訂閱**，或 **取消訂閱**。開啟 **監視可用性** 後，該訂閱的新作也會在你的帳號可編輯監視池時加入可用性監視。

## 新作

- **新作** 依作品進入動態的日期分組，最新的一天在前，每個作品族一張卡片。每天另起一列，標題顯示日期與當天的作品數量。每張卡片上方顯示發生了什麼，以及透過哪個訂閱。事件如下：
  - **新作**：訂閱的目錄中出現了新作品。
  - **新版本**：很久以前發售的作品出現了新的語言版本，例如翻譯版。
  - **現已可用**：可用性監視在遠端來源上找到了該作品。每個能開啟工作流程的帳號都會收到這類事件。

  有多個事件的作品族只保留一張卡片，顯示在其最新事件當天。
- 卡片與媒體庫一致。**顯示選項** 包含媒體庫與其他作品集合共用的 **卡片** 選擇（**完整**、**緊湊** 或 **極簡**）、每列的卡片數，以及每頁包含的天數：5、10（預設）或 15。沒有新作品的日子會被略過，因此每頁包含的是有作品的這麼多天。一天從 **設定 → 帳戶 → 時區** 中所選時區的午夜開始；選擇 **自動** 時使用裝置的時區。
- 當中繼資料已認得該作品時，卡片會顯示該作品；在此之前則顯示目錄中的標題、社團與代碼。開啟卡片即可前往作品、加入收藏清單、開啟 DLsite，或加入可用性監視。
- 自你上次開啟動態後新增的卡片有圓點標記。導覽會顯示其數量，開啟動態即清除該數量。重新整理若為你的動態新增了項目，也會發送一則通知。
- 發售日早於你的訂閱開始日超過 30 天的作品不會顯示，因此之後才擷取目錄中較舊的部分不會為動態新增任何內容。

## 訂閱設定

右上角的設定圖示（**訂閱設定**）會從畫面右側開啟抽屜，在手機上則開啟底部面板，內含 **訂閱** 與 **可用性監視** 兩個分頁。以 `×`、Esc 鍵或點選抽屜外側即可關閉。

- **訂閱** 列出你的社團、系列與聲優訂閱，包含其狀態（**生效中** 或 **等待首次擷取**）、目錄上次擷取的時間，以及其 **監視可用性** 選項。
- **重新整理排程** 由所有帳號共用。一次重新整理會把每個已訂閱的目錄各擷取一次、同步新作品的中繼資料、把它們加入訂閱者的動態，然後檢查可用性監視。最近六小時內已擷取過的目錄（例如由詳細資料頁面重新整理）不會再次擷取，且一次重新整理最多同步 60 個新作品；其餘的留待下一次重新整理。
- 可以同步中繼資料的帳號可以開啟或關閉 **自動重新整理**、選擇 **重新整理間隔**（1 小時到 7 天；預設 24 小時）、選擇每次重新整理是否檢查可用性監視，並 **立即重新整理**。**查看最近一次執行** 會在活動中開啟該次重新整理。

## 可用性監視

- 設定抽屜的 **可用性監視** 分頁保存共用的監視池及其設定：遠端來源、作品變為可用時的操作，以及選用的取得副檔名排除項目；監視執行如何檢查作品的作品族，請參閱[工作流程](workflows.md)。它會顯示給能開啟工作流程的帳號。
- 訂閱的重新整理會依其排程執行監視；**執行** 會立即檢查監視池。工作流程保留監視的執行歷史記錄，並連結到這裡。
