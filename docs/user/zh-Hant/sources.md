# 來源
[English](../en/sources.md) · [简体中文](../zh-Hans/sources.md) · [繁體中文](../zh-Hant/sources.md) · [日本語](../ja/sources.md) · [한국어](../ko/sources.md)

來源說明檔案從何而來。

## 來源類型

- 本機資料夾來源。
- 相容 Kikoeru 的遠端來源。
- 舊版相容 Number178 的遠端來源，僅供已遷移的既有記錄使用。

## 目前行為

- 本機掃描會偵測已設定資料根目錄下受支援的作品代碼資料夾。
- 遠端來源分頁會瀏覽已設定的來源，而不會匯入每一筆結果。
- 作品詳細資料使用後端的彙總可用性檢查。
- 遠端同步會把中繼資料與來源檔案樹匯入統一資料庫。
- 遠端快取會把選取的遠端檔案實體化到快取根目錄下。
- 遠端取得會把選取的遠端檔案提升到本機資料樹中。預設配置為 `/data/<source_code>/<code_prefix>_<code_group>/<work_code>`；舊版的 `<source_name>` 範本權杖仍可作為穩定來源代碼的別名使用。
- 使用依來源分隔之儲存範本的相容來源，會以機器標記與多語言的 `README.md` 認領其取得根目錄。該目錄中的檔案變更不會觸發本機資料夾監看器，因為取得作業會直接登錄發佈結果。既有的非空根目錄若沒有相符的標記，會顯示為阻擋性的取得審核衝突，且絕不會被自動接管。
- 較舊版本的 Kikoto 所建立、沒有標記的根目錄，可以依同一來源中作用中的 `managed_fetch` 資料夾位置，或依已成功的 `remote_work_fetch` 執行（其成功的計畫記錄了相同的來源與目標根目錄）加以辨識。Kikoto 會對照這些確切的歷史目標及其上層目錄來驗證整個根目錄，且不會走訪已證實的作品子樹。允許根目錄層級存在一般的 `README.md`，但無法解釋的項目、連結、重新分析點，以及沒有任何目標存在的過期記錄，都會讓該根目錄停留在阻擋性審核。辨識過程是唯讀的；下一次取得時才會寫入標記，並且只在尚無多語言 README 時加入它。
- 快取與本機刪除針對的是具體的檔案位置，而不是統一的作品。混合選取會以單一可復原的工作流程提交；本機刪除會保留作品進度與收聽標記。
- 遠端來源的清單與詳細資料頁面應維持為限定於該來源的檢視；它們不會取代統一的本機作品詳細資料模型。
- 相容的遠端作品回應會對應來源目前的 `price`。該值不會被保存為價格歷史，也不會被視為權威的原價。
- 示範模式絕不會連線到遠端伺服器。它唯一的遠端來源 Remote Kikoeru 是在程序內，從已收錄的本機作品中隨機挑選來模擬的，媒體庫也會在其上方顯示說明此事的通知。
- `kikoeru_compatible_number178` 為已遷移的來源保留其轉接器，但新的來源與設定種子輸入會拒絕它。歷史上的 `kikoeru_compilable_number178` 拼法會自動遷移。

## 可用性檢查

啟動時與來源變更時的批次檢查，會先驗證相關來源的健康狀態。探測優先使用 `/api/health`，對於不提供健康端點的相容來源，則退回使用只取一筆項目的清單請求。

管理員可在設定 -> 媒體庫中，以 `POST /api/file-sources/{id}/health-check` 手動執行同樣有限制的探測。回應會報告健康狀態、檢查時間與耗時，但不會回傳設定的上游位址或原始的上游錯誤。

若某個來源無法連線，Kikoto 會在該批次中將該來源標記為無法使用，並略過逐一作品的檢查。它不會把每一個候選作品都標記為遺失。

## 下載節奏

遠端下載會等待設定的延遲時間，並以退避方式重試暫時性錯誤。設定 -> 快取與取得也能設定有限制的單一檔案媒體下載大小；預設為 100 GB，可接受的範圍是 1–2048 GB。此限制適用於取得與播放快取的實體化，即使來源沒有宣告回應大小也是如此。遠端與 DLsite 封面使用另一個固定的 20 MiB 限制。DLsite 中繼資料同步對提供方的商品與封面請求，也會使用設定的基礎延遲與退避。

當來源以限流或暫時無法使用的回應作答時，Kikoto 會依其要求的時間暫停對該來源的請求，但絕不會超過設定 -> 快取與取得中的 **最大退避**。該來源的排隊工作會等待暫停結束，且不會耗用重試次數，其他來源的工作則繼續進行。

取得規劃使用已經完整持久化的中繼資料與快取的來源可用性。當所要求的代碼沒有 DLsite 快照或版本關係時，準備階段會先執行有限制的針對性系列同步，再建立審核內容。排入佇列的取得作業會重用提交時接受的遠端檔案樹，而不是立刻再次請求同一棵樹。本機登錄成功後，該次取得所提升的快取物件會被移除；未選取的快取物件仍然可用。
