# 聲優
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

聲優頁面呈現已持久化儲存的人物與參與名單資料。

## 目前行為

- 依本機提供方的參與名單與使用者維護的人物資料列出聲優，每張創作者卡片都附有本機與遠端可用性徽章。
- 使用由伺服器分頁、由網址記錄的清單搜尋與篩選，搭配較短的響應式創作者卡片、動態的使用者標籤列、媒體庫風格的分頁，以及最新已知參與作品的封面。
- 使用媒體庫風格的第一列工具列：搜尋在左側，每頁數量與既有的聲優篩選操作（預設為 `全部聲優`）在右側；窄版版面會把搜尋收進工具列操作中。使用者標籤仍然可見且可搜尋，但清單目前不提供標籤篩選。
- 顯示收藏、評分、備註與使用者標籤狀態。
- 在詳細資料標題下方顯示已確認的別名。別名審核、重複合併與合併復原都位於中繼資料頁面的 **聲優** 檢視；對具備 `metadata:sync` 的使用者，詳細資料的 **更多** 選單會連到該處。
- 將沒有任何提供方聲優參與名單的作品歸入 `unknown` 分組。
- 在聲優詳細資料中，先顯示本機與遠端可用性徽章，再顯示使用者標籤。快取仍可用於播放與篩選資料，但不會顯示為本機。
- 以與媒體庫相同的響應式網格和共用作品卡片呈現已知作品與遠端作品。在作品卡片上選取 DLsite 標籤或個人標籤，會開啟針對它的本機媒體庫搜尋。
- 獨立載入人物詳細資料、已知作品與遠端比對結果。遠端來源搜尋使用有限的並行數量，聲優數量與使用者標籤則以批次彙總。
- 在詳細資料摘要中保留收藏、常用的重新整理操作與 **更多** 選單。**首次擷取** 或 **重新整理** 會排入一次「關注聲優」執行，只針對所有相容遠端來源中已知作品的中繼資料；**重試中繼資料** 只會在已知作品仍缺少中繼資料時出現。在該次執行結束前，按鈕會顯示 **正在重新整理**。同步狀態旁的警告會統計上一輪失敗的遠端來源，並在活動中開啟該次執行。**更多** 中包含 **關注此聲優…** 與 **管理別名**：前者會開啟已選取此聲優的預製工作流程，可用於選擇來源、篩選、中繼資料與標籤。作品工具列與媒體庫一致：左側是有限寬度的搜尋，右側則以低調的圖示操作提供欄數、每頁數量、可用性篩選與選取，共用的集合分頁位於網格上方與下方。行動裝置上的作品搜尋維持單列，並從獨立的選項面板開啟篩選、欄數與選取控制項。
- 在行動裝置上，詳細資料的返回控制項會作為「上一層」，回到最後一個依伺服器與使用者分別記錄的聲優清單位置，包括從媒體庫或收藏開啟詳細資料時。寬版版面則保留會依來源而變的歷史返回。

## 邊界

DLsite 仍是已知作品的中繼資料提供方。Kikoto 不會把以關鍵字爬取 DLsite 視為可靠的聲優目錄。

## 審核行為

別名與合併工具應保留使用者狀態，並在合併重複的人物記錄時，讓合併復原保持可見。
