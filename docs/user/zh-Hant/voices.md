# 聲音
[English](../en/voices.md) · [簡體中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

語音頁面顯示持久的個人和信用資料。

## 當前行為

- 列出來自本地提供者信用和用戶維護人員的配音演員
每個創建者卡上都帶有本地和遠端可用性徽章的資料。
- 使用伺服器分頁、URL 支援的清單搜尋和過濾器，回應時間較短
創建者卡、動態使用者標籤行、庫式分頁以及最新的
已知的署名作品封面。
- 使用庫式第一行工具列，左側為搜索，右側為
頁面大小和現有語音過濾操作（預設為 `All voices`）
右邊；狹窄的佈局將搜尋折疊到工具列操作中。使用者標籤
保持可見和可搜索，但列表不公開標籤過濾器
現在。
- 顯示收藏夾、評分、註釋和使用者標籤狀態。
- 支援別名審查、重複合併和合併撤銷。
- 組在 `unknown` 儲存桶下無需提供者語音積分即可運作。
- 顯示本機和遠端可用性徽章，然後透過語音顯示使用者標籤
細節。快取仍可用於播放和過濾數據，但不再可用
呈現為本地。
- 使用相同的回應網格和共享工作來呈現已知和遠端工作
卡作為圖書館。
- 獨立加載人物詳細資料、已知作品和遠端比賽。偏僻的
來源搜尋使用有界並發，而語音計數和使用者標籤則使用有限並發。
分批匯總。
- 將 Alias 審核和來源操作放在僅圖示的行動收藏夾旁邊
控制聲音細節。每個操作都會在行動裝置上開啟一個錨定的彈出窗口，
  desktop; alias management remains permission-gated while alias viewing stays
可用的。移動工作搜尋保留一行並開啟篩選器、列和
來自單獨選項表的選擇控制項。
- 將移動詳細資訊後退控制視為“直到最後”
伺服器和用戶範圍的配音演員列表位置，包括詳細信息
從“庫”或“收藏夾”中開啟。寬佈局保持源意識
歷史回歸。

## 邊界

DLsite 仍然是已知作品的元資料提供者。 Kikoto 不處理 DLsite
關鍵字爬行作為可靠的配音演員目錄。

## 審查行為

別名和合併工具應保留使用者狀態並保持合併撤銷可見
當重複的人員記錄被合併時。
