# 聲優
[English](../en/voices.md) · [简体中文](../zh-Hans/voices.md) · [繁體中文](../zh-Hant/voices.md) · [日本語](../ja/voices.md) · [한국어](../ko/voices.md)

聲優頁面呈現已持久化儲存的人物與參與名單資料。

## 目前行為

- 依本機提供方的參與名單與使用者維護的人物資料，將聲優列為封面磚，附有本機與遠端數量及可用性長條：實心區段代表有本機副本的作品，較淺的區段代表只有遠端來源持有的作品，其餘則為空白軌道。
- 使用由伺服器分頁、由網址記錄的清單搜尋與篩選。每個磚塊顯示聲優的封面（封面上有收藏控制項）、名稱、別名、最新發行日期與動態的使用者標籤列，並搭配媒體庫風格的分頁。磚塊在寬版版面填滿整列，在手機上為兩欄。
- 以最新已知參與作品的封面作為聲優的封面。詳細資料 **更多** 選單中的 **更換封面…** 會列出該聲優的作品並提供搜尋，所選作品的封面會成為該聲優在磚塊與詳細資料摘要上的封面。同一對話框中的 **最新作品** 會恢復隨每次發行而更新的封面。此選擇屬於做出選擇的帳號；所選作品若不再是該聲優的作品，則改用最新作品的封面。
- 將搜尋、一鍵檢視晶片與每頁數量操作放在同一列可換行的工具列。晶片為 `全部聲優`、`收藏`、`已標記`、`可用`、`本機`、`遠端` 與 `缺少`，按下的晶片即為目前的檢視。在手機上，搜尋欄自成一列、每頁數量在其旁邊，晶片則在下方橫向捲動。使用者標籤仍然可見且可搜尋，但清單不提供標籤篩選。
- 顯示收藏、評分、備註與使用者標籤狀態。
- 在詳細資料標題下方顯示已確認的別名。別名審核、重複合併與合併復原都位於中繼資料頁面的 **聲優** 檢視；對具備 `metadata:sync` 的使用者，詳細資料的 **更多** 選單會連到該處。
- 聲優名稱以原版作品的 DLsite 中繼資料為準。翻譯版的寫法保留為別名，只有當媒體庫中沒有任何原版作品列名該聲優時才會成為名稱。DLsite 更改聲優名稱時，人物會改用新名稱，並將舊名稱保留為別名；手動合併時保留的名稱不會改變。DLsite 中繼資料顯示為同一創作者的聲優會合併為一人，每部作品只列名一次；與手動合併相同，可在 **合併記錄** 中復原這次合併。
- 將沒有任何提供方聲優參與名單的作品歸入 `unknown` 分組。
- 在帶有封面色調的聲優詳細資料摘要中，先顯示本機與遠端可用性徽章，再顯示使用者標籤。快取仍可用於播放與篩選資料，但不會顯示為本機。
- 以與媒體庫相同的響應式網格和共用作品卡片呈現已知作品與遠端作品。在作品卡片上選取 DLsite 標籤或個人標籤，會開啟針對它的本機媒體庫搜尋。
- 作品可依 **發行日期**、**代碼**、**標題**、**評分** 或 **銷量** 升序或降序排序，預設為最新發行的在前。沒有所選項目資料的作品在任一方向都排在最後。排序方式與每頁數量（24、48 或 96）會依帳號記錄在裝置上，並套用於每位聲優。
- 聲優的作品由伺服器分頁。已知作品與遠端目錄合併為一份清單，搜尋、可用性篩選與所選的排序都在分頁前執行；批次選取只涵蓋目前載入的頁面。搜尋與媒體庫的一般搜尋相同，依代碼、標題、社團、聲優、標籤或個人標籤比對作品；只存在於遠端目錄的作品則依其代碼、標題、社團或標籤比對。同一作品的各個版本只算作一部作品，任一版本可用即視為可用。人物詳細資料與遠端來源的目錄狀態分別載入。遠端來源搜尋使用有限的並行數量，聲優數量與使用者標籤則以批次彙總。
- 在詳細資料摘要中保留收藏、常用的重新整理操作與 **更多** 選單。**首次擷取** 或 **重新整理** 會排入一次「同步聲優目錄」執行，只針對所有相容遠端來源中已知作品的中繼資料；**重試中繼資料** 只會在已知作品仍缺少中繼資料時出現。在該次執行結束前，按鈕會顯示 **正在重新整理**。同步狀態旁的警告會統計上一輪失敗的遠端來源，並在活動中開啟該次執行。**收藏** 旁的鈴鐺會訂閱此聲優的新作；請參閱[發現](discover.md#訂閱)。**更多** 中包含 **更換封面…**、**同步此聲優的目錄…** 與 **管理別名**：**同步此聲優的目錄…** 會開啟已選取此聲優的預製工作流程，可用於選擇來源、篩選、中繼資料與標籤。作品工具列與媒體庫一致：左側是有限寬度的搜尋，右側依序是標示目前排序方式的排序按鈕、顯示選項、可用性篩選與選取，共用的集合分頁位於網格上方與下方。顯示選項包含與媒體庫共用的 **卡片** 選項（**完整**、**緊湊**、**極簡**）、欄數以及每頁數量；新選擇的卡片模式從其[預設](library.md#目前行為)開始。手機會把排序按鈕保留在作品上方，並從獨立的選項面板開啟搜尋、篩選、卡片模式、欄數、每頁數量與選取控制項。
- 在行動裝置上，詳細資料的返回控制項會作為「上一層」，回到最後一個依伺服器與使用者分別記錄的聲優清單位置，包括從媒體庫或收藏開啟詳細資料時。寬版版面則保留會依來源而變的歷史返回。

## 邊界

DLsite 仍是已知作品的中繼資料提供方。Kikoto 不會把以關鍵字爬取 DLsite 視為可靠的聲優目錄。

## 審核行為

別名與合併工具應保留使用者狀態，並在合併重複的人物記錄時，讓合併復原保持可見。
