# 個人資料

[English](../en/personal-data.md) · [简体中文](../zh-Hans/personal-data.md) · [繁體中文](../zh-Hant/personal-data.md) · [日本語](../ja/personal-data.md) · [한국어](../ko/personal-data.md)

登入後在「設定」中，收聽歷史位於「歷史」分頁，個人標籤位於「標籤」分頁，「我的資料」位於 Account 底部；行動版帳號選單和快捷操作可直接開啟它們。僅存取目前帳號的資料。

搜尋作品、社團及聲優標籤，包括未使用的標籤。重新命名更新所有關聯；合併移轉關聯並去重；刪除不影響作品及提供者中繼資料。新工作流程的預設標籤不含日期；既有排程保留原範本，可移除 `{date}` 停止產生日期標籤。

收聽報表可切換最近 30 天、12 個月或全部，顯示該範圍的收聽時間、播放次數、依日/月/年（UTC）的圖表及附封面的常聽作品卡片；沒有日期的匯入時長只計入「全部」。依最近收聽時間排列的完整歷史以卡片形式摺疊在報表下方，展開時才載入。時間不含暫停、緩衝及跳轉，倍速不會增加計時。多個播放器分別計時，斷線可能造成部分時間未回報。歷史長期儲存，推薦事件的 90 天清理不影響它。升級保留現有事件但不推算未知時長。清空歷史保留標記、列表及進度；透過帳號清空版本拒絕延遲的舊請求。

Kikoto JSON 包含作品的標記、個人評分和備註、進度、累計統計、作品標籤關聯、自訂標籤定義及有序收藏列表。社團與聲優標籤僅含定義。媒體、來源設定、地址、憑證、中繼資料、原始會話及每日統計不包含在內。音軌以標題及碟號、軌號匹配，不匯出本機路徑。

選檔後先預覽。預設保留已有作品資料與同名列表；覆寫會取代對應資料與可匹配的進度。累計統計取較大值，不重複累加。僅匹配既有作品與已知別名，列出找不到的編號，不建立作品或抓取資料。音軌缺失或無法唯一匹配時保留原進度，匯入以單一交易完成。

限制：10 MiB、20,000 部作品、5,000 個標籤、1,000 個列表、各 50,000 個列表項目或作品標籤關聯。Kikoeru 接受評價陣列、`reviews` 或 API `works` 陣列，需含單一帳號所需的全部分頁。`primaryCode`/`source_id` 為作品編號，數字 `work_id`/`id` 視為商品編號，把類型編進 ID 的分支（類型 × 10¹² + 數字）會自動解碼為 RJ、BJ、VJ、CC 編號；其他資料庫 ID 需先轉換。

也可以選擇 **Kikoeru 帳戶**：選擇已設定的來源或手動輸入 API 位址，以無登入、權杖或使用者名稱和密碼登入，由伺服器讀取你的評價、進度和播放清單（伺服器支援時）。選擇 **Kikoeru 資料庫檔案** 則上傳開源版 Kikoeru 的 SQLite 資料庫（最大 512 MiB），只讀取所填使用者名稱的評價。輸入權杖、密碼、手動位址或上傳資料庫之前，頁面會說明風險並要求確認：憑證經過 Kikoto 伺服器但不會保存或寫入日誌；Kikoeru 會看到來自伺服器位址的登入；資料庫包含所有帳號和密碼雜湊，讀取後立即刪除。請求不會跟隨重新導向。手動位址只能是公開位址，除非你是管理員，或管理員在 **設定 → 媒體庫 → Kikoeru 帳戶匯入** 中允許所有帳戶使用區域網路位址。

`marked` → 想聽、`listening` → 正在聽、`listened` → 已聽完、`replay` → 重聽、`postponed` → 擱置、空值 → 未標記。完整規格見[英文文件](../en/personal-data.md)。
