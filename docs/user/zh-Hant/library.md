# 媒體庫

[English](../en/library.md) · [簡體中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒體庫是浏览作品的主界面。

## 主要內容

- 顯示 Local、Tracked 和遠程來源標籤页。
- 遠端推薦支援尚未匯入的作品，使用既有的多語言標籤名稱和創作者別名比對偏好。啟用後批次計算目前頁面的分數，徽章依序出現，並遵循減少動態效果設定；只顯示達到個人門檻的分數。啟用推薦不會重新載入遠端清單，評分失敗可單獨重試，也不會匯入作品。
- 推薦會加強多次正向回饋的權重，並降低常見標籤權重；探索偏向證據較少的作品，排序輕微分散同一創作者。聆聽狀態配額保持一致，卡片分數與排序調整分開，同一工作階段中的偏好保持穩定。
- 支援搜尋標題、代碼、語言版本、社團、標籤和聲優。`%` 和 `_` 按字面比對，不區分全形/半形、大小寫以及片假名/平假名。可以用 `tag: 癒し` 這樣的條件限定搜尋欄位。
- DLsite 標籤也能用 Kikoto 擷取過的其他語言名稱比對：如果某個以英文請求的版本把 `癒し` 回傳為 `Healing`，`tag: healing` 就能同時找到兩者。標籤、標題、社團或聲優與搜尋詞完全一致的結果排在部分比對之前，各組內部仍依所選排序。
- 搜尋框中的 `+` 按鈕會開啟浮動編輯器以新增結構化搜尋條件；點選既有條件標籤會在同一浮層中編輯，不會推移結果清單。
- 卡片顯示封面、可用性、個人標籤和播放状态。
- Library、Favorites、社團和聲優頁面共用响应式作品網格。
- Favorites 的收藏架側欄可以像 Workflows 一樣收起名稱、只顯示圖示；自訂清單可以在「編輯清單」中選擇圖示。
- `KIKOTO_MODE=demo` 只返回全年龄且永久免费的作品。

卡片代表統一的 Work，而不是按來源複制的条目。Track 儲存來源目錄树並在 Tracked 中打开；來源標籤表示可播放或获取的位置。
