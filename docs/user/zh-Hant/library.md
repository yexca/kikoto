# 媒體庫

[English](../en/library.md) · [簡體中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒體庫是浏览作品的主界面。

## 主要內容

- 顯示 Local、Tracked 和遠程來源標籤页。
- 支援搜尋標題、代碼、語言版本、社團、標籤和聲優。
- 卡片顯示封面、可用性、個人標籤和播放状态。
- Library、Favorites、社團和聲優頁面共用响应式作品網格。
- `KIKOTO_MODE=demo` 只返回全年龄且永久免费的作品。

卡片代表統一的 Work，而不是按來源複制的条目。Track 儲存來源目錄树並在 Tracked 中打开；來源標籤表示可播放或获取的位置。
