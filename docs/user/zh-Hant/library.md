# 媒體庫
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒體庫是瀏覽作品的主要介面。

## 目前行為

- 顯示本機、已追蹤，以及已設定的遠端來源分頁。
- 對大型結果集使用伺服器端分頁。
- 在載入目前頁面的完整資料之前，先搜尋正規化後的標題、代碼、語言版本別名、社團、標籤與聲優參與名單。提供方宣告的版本代碼仍可搜尋，且在媒體庫請求期間不會建立額外作品，也不會掃描原始的中繼資料快照。
- 搜尋文字依字面比對，並忽略全形與半形、字母大小寫及假名種類：`100%` 與 `a_b` 不是萬用字元，全形的 `ＡＢＣ` 能找到 `abc`，片假名也能找到以平假名書寫的同一個詞。在詞彙前加上 `tag: 癒し`、`circle:`、`va:` 或 `mytag:` 之類的子句前綴，即可只搜尋單一欄位。
- DLsite 標籤也會比對 Kikoto 為該標籤取得的每一種語言的名稱：當以英文請求的版本把顯示為 `癒し` 的標籤回報為 `Healing` 時，`tag: healing` 兩者都能找到。標籤、標題、社團或聲優參與名單與搜尋詞完全相同的結果，會排在部分符合的結果之前，並由所選的排序決定各組內的順序。
- 搜尋欄位中的 `+` 按鈕會開啟結構化搜尋條件的浮動編輯器。選取條件徽章會在同一個彈出視窗中編輯它，結果不會移動。
- 顯示封面、標題、代碼、以單行省略顯示的社團／系列、聲優中繼資料、本機可用性、來源標籤，以及（有的話）快速聆聽標記。
- 將提供方標籤測量後排入最多兩列卡片；`+N` 徽章會在彈出視窗中開啟隱藏的標籤；個人標籤則維持為獨立的、屬於使用者的一列。
- 在同一列指標中顯示精簡的 DL 銷量與五段式的非數字評分比較。當存在持久化的游標時，會出現播放記錄圖示。
- 只有在資料庫得知透過已啟用的來源有可用的非原版版本時，才顯示語言圖示。未知或僅有中繼資料的語言關聯並不代表可用。
- 當有正規化的商業中繼資料時，顯示目前價格，並把價格為零的作品標示為免費。
- 在統一的作品卡片與詳細資料中，將已登入使用者的作品標籤與中繼資料標籤分開顯示。`mytag:` 篩選個人標籤，不會改變提供方 `tag:` 搜尋的意義。
- 讓來源可用性在視覺上與中繼資料標籤分開。
- 在作品卡片上的社團名稱旁顯示已知的年齡分級，同時在作品詳細資料中保留完整的年齡中繼資料。
- 媒體庫、收藏、社團詳細資料與聲優詳細資料這些介面，對作品集合使用同一套響應式網格。欄數選項是共用的，而不是每個頁面各自重新實作。
- 將所選的作品集合欄數設定儲存在本機，並套用到媒體庫、收藏、社團作品集合與聲優作品集合。
- 支援穩定的種子式隨機排序。種子能讓分頁保持一致；重新洗牌會產生新的種子，而不是反轉順序。
- 新的媒體庫檢視預設使用個人化推薦排序，同時保留歷史記錄／工作階段所還原的瀏覽選擇。標準網址只保留查詢與非預設的聆聽狀態；連結中明確指定的瀏覽參數仍會被讀取。推薦的安排方式把聆聽意圖與親和度分開處理：聆聽中與想聽取得前面的位置，未標記仍是主要的探索來源，重聽與已完成取得有限度的插入，已擱置則要等排程中的狀態用盡後才輪到。明確的狀態篩選仍會回傳每一個符合的作品。在每個狀態之內，有限度的親和度分數會使用收藏、標籤、聲優與社團的訊號，而不會把候選作品本身視為口味歷史。重複的正向回饋最多會對每個符合的訊號加強至五個支持作品，常見標籤的權重則較低。帶種子的探索加成偏好證據較弱的作品；獨立的結果變化只會針對目前的狀態內排序調整該親和度；少量的創作者多樣性調整也會影響排序。徽章與遙測資料保留有限度的親和度分數。重聽與收藏歷史是正向證據；僅有已完成則是中性。每個瀏覽器分頁或原生應用程式啟動，都會綁定到一個不可變的推薦世代，因此導覽、分頁、篩選、卡片異動與工具列重新洗牌都不會重新計算親和度。收藏與聆聽的變更會立即顯示在卡片上，但要到下一個用戶端工作階段才會影響排位。只有當推薦的輸入資料改變時，新的工作階段才會重建該世代；否則它會以新的穩定種子重用目前的世代。種子讓狀態混合與狀態內的多樣性在分頁時都保持安全，而工具列的重新整理操作只會在目前世代內改變該種子。
- 遠端推薦徽章也會為尚未匯入的作品評分，所用的是已知的在地化標籤與創作者別名。開啟徽章時，會在不重新載入遠端來源的情況下一次批次為目前頁面評分，然後逐步顯示徽章（並尊重減少動態效果的設定）。只會顯示達到你的徽章門檻的分數。評分失敗時，作品仍然可用，並提供重試。遠端評分使用相同的凍結工作階段偏好設定檔，且不會匯入任何作品。
- 在媒體庫控制項上方顯示精簡、可水平捲動的最近播放列。它依每位使用者排序，來源是每個邏輯作品系列所擁有的那一個游標，並包含最新的音軌位置，但不會取代完整的作品卡片網格。該列可以收合，這項偏好設定會保存在瀏覽器中。
- 在本機、已追蹤與已設定的遠端來源之間使用同一個共用查詢。每個來源各自保留自己的分頁、排序與捲動狀態，而網格欄數設定仍然共用。當使用者在別處清除查詢後，來源不能還原過期的查詢文字。
- 將目前本機、已追蹤或遠端來源的每頁數量放在第一列的操作工具列中，並讓頂部精簡的分頁專注於結果脈絡與頁面導覽。
- 資料庫清理不放在媒體庫中。中繼資料 -> 無可用來源，為沒有可用來源或媒體位置的邏輯系列，提供分頁搜尋、來源檢查，以及經確認的本機資訊刪除。
- `/no-source` 與 `/library/no-source` 連結會開啟中繼資料 -> 無可用來源；`/library/all` 與 `/library/remote` 連結則開啟媒體庫。
- 當 `KIKOTO_MODE=demo` 時，後端的清單、詳細資料與媒體回應只收錄全年齡且永久免費的作品。本機作品使用正規化的商業中繼資料，未知的中繼資料與暫時性的限時免費都會被排除。模擬的 Remote Kikoeru 來源只會重新發佈已收錄的本機作品。示範工作階段可以播放已收錄的完整媒體，但不能更動媒體庫、設定或工作流程狀態。

作品卡片在每個集合介面上都使用同一套摘要模型，已知時也包含聲優參與名單。精簡卡片最多顯示兩個聲優名稱，並摘要其餘的參與名單，不會讓中繼資料無限制地撐大卡片。

收藏只在標準網址中保留實體／搜尋意圖。所選清單、收藏篩選、排序、種子、分頁、選取與作品錨點，會從目前的歷史項目還原，並以依使用者區分的工作階段作為後備。**全部收藏** 彙整帶有快速標記的作品，以及位於任何使用者清單中的作品。**已標記** 是固定的系統清單，只包含快速標記不是未標記的作品；其成員由推導而來，無法作為清單編輯。其他清單由使用者建立，並保留明確的成員資格。切換清單時，完整的收藏清單列在結果載入期間保持穩定，且已擱置是聆聽狀態選項中的最後一項。僅有播放游標絕不會把作品加入收藏。來源選擇器可以把收藏的作品限縮到任意多個所選的已設定檔案來源，而不會建立每個來源各自的作品副本，也不會請求即時的遠端重新整理。

在寬螢幕上，結果旁的書架側欄會列出全部收藏、已標記、你的清單，以及已關注的社團與聲優及其數量。和工作流程與設定的側欄一樣，它可以隱藏名稱而只保留圖示，這項選擇會記在該裝置上。每個使用者清單都可以顯示在編輯清單中選擇的圖示，這就是在圖示側欄中區分各清單的依據；清單圖示也會出現在加入清單的選單中。手機則將相同的書架顯示為一列可捲動的列。展開的書架有標頭，內含封面拼貼、其數量、已完成的作品數，以及你正在聆聽的作品。作品可以顯示為卡片，也可以顯示為較密集、附有各作品續播點的清單。

## 身分

媒體庫卡片代表統一的作品，而不是每個來源各自的副本。遠端卡片可以在作品尚無本機檔案之前就追蹤或同步它，但產生的狀態會附加到同一個統一的作品身分上。追蹤也會保存所選的來源檔案樹，並在已追蹤中開啟該來源。

## 來源分頁

來源分頁應協助使用者回答一個作品可以從哪裡播放或取得。它們不是擁有各自中繼資料所有權的獨立媒體庫。本機、已追蹤、快取與遠端的事實，全都指向同一個作品模型。
