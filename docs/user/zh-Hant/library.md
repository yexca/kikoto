# 媒體庫
[English](../en/library.md) · [简体中文](../zh-Hans/library.md) · [繁體中文](../zh-Hant/library.md) · [日本語](../ja/library.md) · [한국어](../ko/library.md)

媒體庫是瀏覽作品的主要介面。

## 目前行為

- 顯示本機、已追蹤，以及已設定的遠端來源分頁。
- 對大型結果集使用伺服器端分頁。
- 在載入目前頁面的完整資料之前，先搜尋正規化後的標題、代碼、語言版本別名、社團、標籤與聲優參與名單。提供方宣告的版本代碼仍可搜尋，且在媒體庫請求期間不會建立額外作品，也不會掃描原始的中繼資料快照。
- 搜尋文字依字面比對，並忽略全形與半形、字母大小寫及假名種類：`100%` 與 `a_b` 不是萬用字元，全形的 `ＡＢＣ` 能找到 `abc`，片假名也能找到以平假名書寫的同一個詞。在詞彙前加上 `tag: 癒し`、`circle:`、`va:` 或 `mytag:` 之類的子句前綴，即可只搜尋單一欄位。在 `tag:`、`mytag:`、`circle:` 或 `va:` 前加上 `-` 可排除符合的作品；以引號括住詞組（例如 `"calm night"` 或 `circle:"Example Circle"`）則會比對整個詞組。
- DLsite 標籤也會比對 Kikoto 為該標籤取得的每一種語言的名稱：當以英文請求的版本把顯示為 `癒し` 的標籤回報為 `Healing` 時，`tag: healing` 兩者都能找到。標籤、標題、社團或聲優參與名單與搜尋詞完全相同的結果，會排在部分符合的結果之前，並由所選的排序決定各組內的順序。
- 搜尋欄位中的 `+` 按鈕會開啟結構化搜尋條件的浮動編輯器。選取條件徽章會在同一個彈出視窗中編輯它，結果不會移動。
- 顯示封面、標題、代碼、以單行省略顯示的社團／系列、聲優中繼資料、本機可用性、來源標籤，以及（有的話）快速聆聽標記。
- 將提供方標籤測量後排入最多兩列卡片；`+N` 徽章會在彈出視窗中開啟隱藏的標籤；個人標籤則維持為獨立的、屬於使用者的一列。
- 在同一列指標中顯示精簡的 DL 銷量與五段式的非數字評分比較。當存在持久化的游標時，會出現播放記錄圖示。
- 作品的音軌有歌詞時顯示歌詞圖示：在 **管理歌詞** 中指派的歌詞檔案，或依名稱比對到音軌的歌詞檔案。其他文字檔案（例如 readme 或台本）不計入。本身沒有音軌的作品沿用其他版本的狀態。
- 當有正規化的商業中繼資料時，顯示目前價格，並把價格為零的作品標示為免費。
- 在統一的作品卡片與詳細資料中，將已登入使用者的作品標籤與中繼資料標籤分開顯示。`mytag:` 篩選個人標籤，不會改變提供方 `tag:` 搜尋的意義。
- 讓來源可用性在視覺上與中繼資料標籤分開。
- 在作品卡片上的社團名稱旁顯示已知的年齡分級，同時在作品詳細資料中保留完整的年齡中繼資料。
- 媒體庫、收藏、社團詳細資料與聲優詳細資料這些介面，對作品集合使用同一套響應式網格。欄數選項是共用的，而不是每個頁面各自重新實作。
- 將所選的作品集合欄數設定儲存在本機，並套用到媒體庫、收藏、社團作品集合與聲優作品集合。
- 支援穩定的種子式隨機排序。種子能讓分頁保持一致；重新洗牌會產生新的種子，而不是反轉順序。
- 新的媒體庫檢視預設使用個人化推薦排序，並保留還原的瀏覽選擇。標準網址保留查詢及非預設聆聽狀態，也讀取明確的瀏覽參數。聆聽中與想聽優先，未標記為主要探索來源，重聽與已完成有限度插入，零槽位狀態後置。每種狀態先顯示有界推薦候選，再依穩定的種子探索順序顯示其餘所有符合的作品。精確搜尋仍優先，總數包含全部符合項目，變更每頁數量不改變順序。此順序不表示全部結果嚴格依個人親和度排列。
- 親和度使用收藏、標籤、聲優及社團證據，扣除候選自身的回饋；正向證據最多強化至五部支持作品，常見標籤權重較低。收藏與重聽是正向證據，僅已完成是中性。探索加成、變化及創作者多樣性影響候選排序，徽章保留真實親和度。一般排序只為目前頁面評分；候選外作品的說明也顯示真實親和度，排序調整僅在適用的推薦查詢情境中顯示。情境過期時，說明保留原工作階段的親和度，省略排序調整。
- 每個瀏覽器分頁或原生應用程式啟動，將偏好設定檔、聆聽狀態槽位及共用中繼資料版本凍結在一個推薦世代。導覽、篩選、分頁、卡片變更及重新洗牌重用設定檔。即時收藏與聆聽變更立即顯示於卡片，並在新工作階段影響排序。共用特徵由背景更新，新工作階段使用最新完整發布版本，可能稍晚於中繼資料編輯。重新洗牌只變更種子。可瀏覽成員及篩選仍是即時的：作品新增刪除、可用性、權限及個人篩選可能移動頁面邊界，相同可見資料的順序保持確定且完整。
- 首次推薦索引期間，一般瀏覽與播放保持可用。選用徽章失敗時保留卡片並提供獨立重試；推薦準備失敗時在已載入卡片旁提供重試。這些失敗不會中斷全域播放器。
- 遠端推薦徽章也會為尚未匯入的作品評分，所用的是已知的在地化標籤與創作者別名。開啟徽章時，會在不重新載入遠端來源的情況下一次批次為目前頁面評分，然後逐步顯示徽章（並尊重減少動態效果的設定）。每部已評分的作品都會顯示分數；達到你的醒目提示門檻的分數會醒目顯示，較低的分數以淡化樣式顯示。評分失敗時，作品仍然可用，並提供重試。遠端評分使用相同的凍結工作階段偏好設定檔，且不會匯入任何作品。
- 提供最近播放的作品，依每位使用者排序，來源是每個邏輯作品系列所擁有的那一個游標，並包含最新的音軌位置。寬螢幕上，工具列中的歷史按鈕會開啟該清單。手機上，在本機或已追蹤的第一頁且未設定搜尋或標記篩選時，來源按鈕下方會顯示「繼續收聽」列。該列可水平捲動，預設收合，展開狀態會保存在瀏覽器中。
- 手機上的媒體庫最上方是始終可見的搜尋欄位，接著是一列可捲動的來源按鈕、一個標示目前排序方式並在彈出視窗中開啟排序方式與方向的排序按鈕，以及一列快速標記篩選按鈕。再次點選目前選取的按鈕會清除該篩選。
- 在寬螢幕上，工具列的排序按鈕同樣標示目前排序方式，並在彈出視窗中開啟排序方式與方向。「推薦」與「隨機」排序會在它旁邊加上一個重新整理按鈕。
- 顯示選項以 **卡片** 開頭，可在 **完整**、**緊湊** 和 **極簡** 中選擇，該選擇與欄數設定一同保存，手機與寬螢幕分別保存。**完整** 為預設值。寬螢幕的自動欄數在一列中最多容納 5 張完整卡片、6 張緊湊卡片或 7 張極簡卡片，視窗較窄時更少。選擇其他模式會把其餘顯示選項重設為該模式的起始值，之後可以再調整：每種模式都使用自動的寬螢幕欄數，**完整** 與 **緊湊** 使用每頁 24 部作品與自動的封面來源標記，**極簡** 使用每頁 48 部作品，不顯示封面來源標記。手機欄數保留自己的設定。**緊湊** 在手機單欄時將每部作品顯示為一列：封面位於代碼、標題、社團與聲優名稱、評分、銷售量及價格旁，其下是一列標籤，個人標籤優先，並在有的話顯示上次聆聽位置。手機雙欄與寬螢幕則顯示簡短的圖塊，價格位於封面上，且沒有標籤列。**極簡** 只顯示封面和最多兩行標題，不顯示代碼、參與人員、標籤、評分、價格、推薦分數或操作列，手機上的自動欄數每列顯示兩個封面。封面來源標記在每種模式下都遵循各自的顯示選項，卡片在每種模式下開啟作品的方式都相同。該選擇適用於媒體庫中的本機、已追蹤與遠端來源，包括遠端載入時的預留位置。
- 在本機、已追蹤與已設定的遠端來源之間使用同一個共用查詢。每個來源各自保留自己的分頁、排序與捲動狀態，而網格欄數設定仍然共用。當使用者在別處清除查詢後，來源不能還原過期的查詢文字。
- 將目前本機、已追蹤或遠端來源的每頁數量放在工具列的顯示選項中。本機、已追蹤與遠端來源每頁都可選 24、48 或 96 部作品。寬螢幕顯示精簡的頂部分頁，包含結果脈絡與頁面導覽。手機上，作品上方以說明文字顯示結果數量與目前頁碼，並透過底部分頁切換頁面。底部分頁列出第一頁、最後一頁、目前頁面及其相鄰頁面；頁碼之間的省略號可開啟輸入欄位，輸入頁碼後跳至該頁。
- 資料庫清理不放在媒體庫中。中繼資料 -> 無可用來源，為沒有可用來源或媒體位置的邏輯系列，提供分頁搜尋、來源檢查，以及經確認的本機資訊刪除。
- `/no-source` 與 `/library/no-source` 連結會開啟中繼資料 -> 無可用來源；`/library/all` 與 `/library/remote` 連結則開啟媒體庫。
- 當 `KIKOTO_MODE=demo` 時，後端的清單、詳細資料與媒體回應只收錄全年齡且永久免費的作品。本機作品使用正規化的商業中繼資料，未知的中繼資料與暫時性的限時免費都會被排除。模擬的 Remote Kikoeru 來源只會重新發佈已收錄的本機作品。示範工作階段可以播放已收錄的完整媒體，但不能更動媒體庫、設定或工作流程狀態。推薦分數是模擬隨機值，說明標示「示範分數，隨機產生」。每部作品的分數在同一示範工作階段中保持穩定，重新洗牌不改變分數，也不顯示偏好貢獻或排序調整。

作品卡片在每個集合介面上都使用同一套摘要模型，已知時也包含聲優參與名單。精簡卡片最多顯示兩個聲優名稱，並摘要其餘的參與名單，不會讓中繼資料無限制地撐大卡片。

收藏只在標準網址中保留實體／搜尋意圖。所選清單、收藏篩選、排序、種子、分頁、選取與作品錨點，會從目前的歷史項目還原，並以依使用者區分的工作階段作為後備。**全部收藏** 彙整帶有快速標記的作品，以及你加入任一清單的作品。**已標記** 是固定的系統清單，只包含快速標記不是未標記的作品；其成員由推導而來，無法作為清單編輯。其他清單由使用者建立，並保留明確的成員資格。作品卡片或作品詳情上的「新增至清單」附搜尋欄列出你的清單，每勾選或取消一個清單都會立即儲存；輸入尚無清單使用的名稱，即可建立該清單並把作品加入其中。依規則包含該作品的動態清單會註明這一點，取消勾選則把作品排除在該清單之外。在收藏中選取作品後的「變更清單」會顯示每個清單將產生的變化（例如會加入多少部作品），並一次套用；只包含部分作品的清單除非你變更，否則保持不變。在手機上兩者都以底部面板開啟。

動態清單會依標籤自動收錄作品。新增清單時選擇 **動態清單**，再把共用的中繼資料標籤與你自己的標籤分成三組：作品必須全部帶有的 **必須包含**、至少帶有其中一個的 **至少包含其一**，以及一個都不能帶有的 **排除**。空的分組會被略過，但「必須包含」或「至少包含其一」中至少要有一個標籤；編輯器會隨著你的選擇顯示符合的作品數量。符合的作品會出現在清單中，但不會因此成為收藏。你仍可手動加入其他作品，它們會像在任何清單中一樣成為收藏；移除某個符合的作品後，它會一直被排除在清單之外，直到你再次加入。清單只會收錄媒體庫中已有的作品。之後有作品開始符合時，書架會顯示新作品的數量，並在這些作品上標示 **新**，直到你選擇 **全部標為已看**；**只看新作品** 則只顯示這些作品。**轉為一般清單** 會把清單目前顯示的作品保留為一般清單，將它們全部設為收藏，並移除規則。之後被隱藏或刪除的標籤會加上刪除線保留在規則中，不再符合任何作品。

切換清單時，完整的收藏清單列在結果載入期間保持穩定，且已擱置是聆聽狀態選項中的最後一項。僅有播放游標絕不會把作品加入收藏。資源篩選依卡片上顯示的可用狀態限縮收藏的作品：「可用」（本機、快取或遠端）、「本機」、「遠端」或「缺少」。檔案屬於其他語言版本的作品，會連同該版本一起判定。篩選讀取已儲存的可用狀態，不會請求即時的遠端重新整理。

在寬螢幕上，結果旁的書架側欄會列出全部收藏、已標記、你的清單，以及已關注的社團與聲優及其數量。和工作流程與設定的側欄一樣，它可以隱藏名稱而只保留圖示，這項選擇會記在該裝置上。每個使用者清單都可以顯示在其編輯器中選擇的圖示，這就是在圖示側欄中區分各清單的依據；清單圖示也會出現在新增至清單的選單中。手機則將相同的書架顯示為一列可捲動的列。展開的書架有標頭，內含封面拼貼、其數量、已完成的作品數，以及你正在聆聽的作品。顯示選項可以讓作品在卡片與較密集、附有各作品續播點的清單之間切換。

書架中的「加入清單」和清單書架上的「編輯清單」會開啟單一清單的編輯器：附圖示的名稱、選填的說明、動態清單的規則，以及「刪除清單」。與其他清單同名時會提示，但仍可儲存。「管理清單」顯示所有清單；「上移」與「下移」會立即調整順序，且不會離開目前開啟的書架；在那裡開啟某個清單編輯後，可用「返回」回到所有清單。

## 身分

媒體庫卡片代表統一的作品，而不是每個來源各自的副本。遠端卡片可以在作品尚無本機檔案之前就追蹤或同步它，但產生的狀態會附加到同一個統一的作品身分上。追蹤也會保存所選的來源檔案樹，並在已追蹤中開啟該來源。

## 來源分頁

來源分頁應協助使用者回答一個作品可以從哪裡播放或取得。它們不是擁有各自中繼資料所有權的獨立媒體庫。本機、已追蹤、快取與遠端的事實，全都指向同一個作品模型。
