# 工作流程
[English](../en/workflows.md) · [簡體中文](../zh-Hans/workflows.md) · [繁體中文](../zh-Hant/workflows.md) · [日本語](../ja/workflows.md) · [한국어](../ko/workflows.md)

工作流程使後端操作變得可檢查。

## 使用者介面

- 工作流程：內建定義（含預製的關注工作流程）及其觸發器在
選定的定義中管理，不再提供自訂工作流程編輯器。
- 活動：互斥的運作、審核、失敗和已完成視圖。
- **Fetch** 的執行選項可輸入一個作品 code 並選擇已啟用的相容遠端來源。在 **篩選** 中勾選要排除的副檔名，或用逗號分隔輸入其他副檔名，預設不排除任何類型。點擊 **Run** 開啟 Fetch 預覽，確認檔案與儲存位置後點擊 **發佈 Fetch** 提交執行。切換語言版本時也會沿用排除條件。Fetch 僅手動執行，沒有自動觸發器。

## 當前行為

- 關注社團、關注系列、關注聲優是預製工作流程。執行選項分為三部分：**輸入**（目標與目錄重新整理：增量或完整）、**篩選**（發售日期範圍與作品上限）和**動作**（同步中繼資料、標籤範本，社團還可檢查遠端來源），寬螢幕時三部分並排成三欄；點擊執行選項底部的 **Run** 即可執行；觸發器彈出框預設使用上方的值，啟用「自訂執行選項」後可單獨覆寫。元資料同步沒有 Startup 觸發器。同步中繼資料針對缺少中繼資料的目錄作品（包括尚未入庫的作品），篩選和標籤會套用到這些作品。所有篩選預設關閉；沒有發售日期範圍或作品上限時，每次執行會同步所有缺少中繼資料的目錄作品。標籤範本同樣預設關閉，開啟後才會為同步的作品加上標籤。儲存沒有篩選的自動執行時，觸發器彈出框會提示並建議開啟篩選。關閉同步中繼資料後，關注社團和關注聲優只重新整理目錄（以及檢查來源）。Track 和 Fetch 不再是關注的動作。自動執行只支援增量目錄重新整理，完整重新整理僅限手動。

- 本地掃描記錄資料夾發現和本地來源存在，無需等待
對於元資料提供者。元資料同步、來源可用性、遠端同步、
快取、取得、清理、循環刷新和批次遠端操作單獨記錄
工作流程運作。
- 對於明確的本機工作，掃描會標記舊的本機檔案位置遺失
當資料夾消失或其儲存的路徑不再屬於
  detected folder. It does not delete files or change Fetch ownership. A moved
資料夾開啟時會延遲索引；重複程式碼資料夾保留在「審閱」中。
- 節點運行公開步驟級進度。
- 候選人公開可審查的結果。
- 審核包含終端運行，其中未解決的候選者需要用戶
決定。常規部分或跳過的結果保留在“已完成”中並保留
它們的警告狀態、摘要和供檢查的事件。
- 頂部通知中心分為「動態」（你的已完成或失敗的工作流程結果，例如獲取）
與工作流程操作者可見的「需要處理」執行，最新的執行中工作顯示在兩者上方。
獲取通知開啟本地作品詳情，可為登入使用者獨立解除；「開啟活動」開啟完整面板。
- 定義列以固定順序列出內建工作流程，預製的關注工作流程排在收集器之後；
頁面上無法新增、編輯或刪除定義。
- 內建本地掃描、元資料同步、遠端流行、DLsite流行
工作流程支援可編輯的間隔觸發器；本地掃描和兩個熱門
收集器也支援啟動觸發器。元資料同步沒有啟動觸發器，
避免和掃描後續執行競爭。本地掃描船
使用預設啟動觸發器，並且不檢查遠端可用性或
同步元資料。手動、啟動和間隔掃描會暴露
預設停用 `Follow-up run`；啟用它排隊一個獨立的
掃描完成後運行元資料。
- 本地掃描還附帶一個固定的、啟用的資料夾觀察器。可以暫停，
已恢復，或在增量和完整之間切換，但無法創建，
複製、轉換、重新命名或刪除。增量是預設值。這
觀察者註冊發現目錄和下面的每個後代目錄
一個已識別的工作根目錄，然後動態註冊新的目錄樹。它
在最近觀察到的事件後等待五秒，忽略 Kikoto 的
暫存、備份、垃圾和按源獲取樹，並協調
影響工作根源。刪除的檔案和資料夾變成`missing`；資料庫
記錄被保留。觀察者錯誤、事件批次過大、根
失效和重複根自動使用完整掃描。拿來
直接註冊自己發布的位置；手動、啟動和間隔
掃描總是檢查完整的資料樹。主動運行期間的變化
最多產生一次後續掃描。暫停的事件被丟棄；離線
更改依賴預設的啟動掃描。
- **重新整理本機作品檔案**排在本地掃描之後（第二個）。它為掃描已發現的本機作品資料夾索引其中的媒體檔案，避免開啟作品時才臨時索引大型資料夾。**增量**（預設）只處理從未索引過檔案的資料夾；**完整**會重新索引所有可用的本機作品。同一時間只有一個排隊或執行中的工作，再次啟動會傳回目前的工作。支援儲存模式的啟動和間隔觸發器，預設沒有觸發器。
- 遠端和DLsite流行的集合表面編輯標籤模板
目前值預覽、完整的工作流程特定變數清單以及
當呈現的標籤超過 40 個字元時明確警告。手動運行
根據要求擴展模板；自動觸發器將其存儲不變並且
在調度時將其擴展。遠端自動收集僅跟踪，因此
無法繞過取得大小和磁碟保留保護措施。
- 有執行參數的工作流程會在摘要下方顯示 **執行選項**，直接顯示輸入與標籤預覽，無需開啟對話框；選項只套用於下一次手動執行。表單底部的列中有 `Run`，無法執行時會在旁邊說明原因（例如缺少必填項目）。表單較長時，這一列會停留在螢幕底部，位於手機導覽列和播放器上方。本地掃描在此顯示後續同步選項；沒有執行參數的內建工作流程將 `Run` 放在標題右側。可用性監視在相同位置顯示已儲存的設定，`Configure` 位於 `Run` 旁邊。表單之後依序是最近一次執行的階段與記錄、觸發器和最近執行。
- 聲優目標為選定的一位聲優，並在勾選的遠端來源中重新整理其目錄。系列讀取已儲存的作品，沒有目錄重新整理。升級後，先前儲存的關注觸發器會被停用並提示需要重新設定；開啟觸發器、確認執行選項並儲存，然後重新開啟即可。元資料同步重新整理媒體庫中已有的作品：執行選項可選擇**作品**（所有作品、某個社團、某位聲優）和**重新整理內容**（缺少或過期，或所有中繼資料），間隔觸發器也儲存同樣的選擇。擁有 `sources:write` 的管理員還會在 **執行** 旁看到 **設定**：它設定整個執行個體的[遠端中繼資料備援](settings.md#遠端中繼資料備援)和[購買特典關聯](settings.md#購買特典)，且只儲存這些設定。
- 使用者自建的自訂工作流程、DAG 編輯器、斜線指令與定義執行對話框已移除。
升級時會刪除既有的使用者定義及其觸發器，其執行紀錄仍保留在 Activity 歷史中。
- DLsite熱門合輯支援24小時、7天、30天、全年語音
排名。近期可限於30天內發布的作品；
年度運行選擇一個明確的年份並預設為包含以下內容的模板
`{year}`。運行同步元資料並附加預覽的使用者標籤，無需
替換現有的用戶標籤。
- 排隊或正在運行的 Fetch 對於每個規範工作都是唯一的。重複獲取
請求重複使用運行的內容，而不是下載相同的作品兩次，並且每次
請求用戶收到共享運作的終端通知。
- Fetch 的 Activity 顯示位元組層級的遠端傳輸進度、實測傳輸速度與預估剩餘時間。
  尺寸未知的檔案會明確標示，在實際尺寸確定前不顯示百分比與剩餘時間。
- Fetch 執行詳情列出其檔案：正在下載的檔案置頂並帶有獨立進度條，完整清單標示已完成、等待中，以及執行失敗或暫停時所在的檔案。
- 工作流程清單依類別、以固定順序列出所有工作流程：基礎（本地掃描、本地檔案、中繼資料同步）、收集（熱門收集）、關注（預製關注工作流程）與遠端（Availability Watch 與 Fetch 記錄）。每一項顯示最近一次執行的狀態與時間，小圖示標出已啟用的啟動觸發器、排程或資料夾監看。寬螢幕時清單位於所選工作流程旁邊，清單下方的「收合分頁名稱」可將其收合為圖示，每個圖示仍以小圓點標出最近一次執行的狀態，「展開分頁名稱」可再次展開，此頁面會記住此選擇；行動版先顯示清單，點選工作流程即開啟，可用頂欄返回按鈕或瀏覽器上一頁回到清單。
- 所選工作流程彙整最近 20 次執行：上次執行、已完成執行的成功率、典型（中位數）耗時，以及下次自動執行的時機（排程、下次服務啟動、資料夾變更或僅手動）。下方的長條圖依舊到新顯示這些執行的耗時；一般成功以中性色呈現，失敗與部分完成會特別突顯。將游標移到長條上可查看詳情，點選即可開啟該執行。

## 當前限制

- 重試和檢查點恢復僅適用於明確
宣布他們的工作可以恢復；任意失敗的節點無法在
隔離.
- 工作人員在 Kikoto 進程內運行，因此排隊的作業只有在
該進程正在運行。分散式或多執行個體執行不是
支持。
- 正常停止服務時，執行中的可恢復作業會回到佇列，不消耗重試預算。當機、強制終止或租約過期後的恢復受每個作業的重試預算的限制。
手動陳舊運行恢復標記已中斷的不可恢復工作失敗
檢查。

頁面頂部的狀態列顯示正在執行的工作與進度、需要處理的執行數量，以及下一次排程執行。點選前兩格或狀態列右端的 Activity 會開啟桌面面板或手機底部面板；點選下一次排程則會選取該工作流程。執行中的工作顯示在上方，下方分為 **Needs attention** 和 **History**。待處理候選項、中繼資料問題與未確認失敗進入前者；已解決的中繼資料執行提示會解除，其他失敗可由各使用者確認。History 保留原始執行狀態。中繼資料集中處理作品問題與 DLsite 代理捷徑，並提供同步捷徑。

Activity 顯示所有工作流程的工作與計數，切換流程不會改變它。每筆紀錄顯示狀態、執行編號、觸發方式與耗時。點擊 Recent runs 或紀錄即可在同一面板查看開始與結束時間、耗時、步驟、候選項，以及預設收合的診斷日誌。獨立 Full Activity 頁面已移除，舊連結與通知會開啟所屬流程的 Activity。
