## 產品原則

- 即使一個作品同時具有本機、快取、已追蹤與遠端來源的可用狀態，它也只會顯示為一個統一的項目。
- 遠端來源失敗時，本機與快取的狀態仍應保持可用。
- 遠端來源的操作應該是明確的：同步會更新來源資料，快取會將快取檔案實體化，取得則會把選取的檔案提升到本機資料樹中。
- 長時間執行或需要審核的操作，應該在活動中可見。
