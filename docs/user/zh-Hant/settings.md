# 設定
[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定包含帳戶控制、個人的播放、歷史、推薦與標籤偏好，並為管理員提供執行個體管理。外觀位於頁首的外觀選單；介面語言與優先展示的中繼資料語言，則位於頭像後方的帳戶選單，或位於 **登入** 之後。

## 分頁

設定使用帳戶、播放、歷史、推薦與標籤分頁，以圖示顯示：將游標移到圖示上或使其取得焦點即可看到名稱，手機也會標示目前作用中的分頁。管理員與示範模式也會在分隔線之後看到管理分頁（媒體庫、快取與取得、代理、清理與使用者），讓提升權限的範圍保持獨立。寬螢幕會把圖示排成設定旁的一欄；手機則顯示為可橫向捲動的一列。欄下方的 **展開分頁名稱** 按鈕會展開並顯示每個分頁的名稱，設定會記住這項選擇。

`/maintenance`、`/users`、`/cleanup`、`/history`、`/tags` 與 `/user-data` 連結會開啟對應的設定分頁。

## 帳戶

- 更新已驗證使用者的顯示名稱。
- 在驗證目前密碼並確認新密碼後，變更由帳戶自行管理的使用者的密碼。
- 使用者名稱與角色可見，但為唯讀。
- 帳戶最後的 **我的資料** 可匯出與匯入個人資料；請參閱[個人資料](personal-data.md)。

變更密碼會保留目前的工作階段，並撤銷該使用者的其他工作階段。管理員從設定 -> 使用者重設密碼，會撤銷目標使用者的所有工作階段。角色、啟用狀態、使用者名稱與使用者生命週期管理，不屬於可自行操作的帳戶設定。

每個帳戶（包括最初的管理員）都在此處變更自己的密碼。例外是環境 root 帳戶模式下的 root 帳戶，其密碼來自 `KIKOTO_ROOT_PASSWORD`。忘記的管理員密碼要從伺服器主機重設；請參閱[管理員初始設定與復原](../../operations/security.md#administrator-setup-and-recovery)。

## 播放、歷史與推薦

- **播放** 包含倒退與快轉的跳轉間隔、**播放來源** 與 **目錄偏好**。跳轉間隔預設為 10 秒與 30 秒，接受 1 到 300 的整數秒數。Android 與 iOS 應用程式還會顯示 **本裝置隱私**，說明請參閱[睡眠與耳機隱私](playback.md#睡眠與耳機隱私)。
- **播放來源**：**快速切換來源** 會讓正在播放的來源標籤變成選單，可用來選擇目前音軌的另一個位置；**失敗時切換其他來源** 則讓失敗的位置改由該音軌的下一個可用位置繼續。兩者預設皆為關閉，並立即生效。
- **目錄偏好** 保存有順序的資料夾比對與排除規則。儲存後會更新之後的目錄選擇，而不會停止播放器。
- **歷史** 顯示收聽報告（30 天、12 個月或全部時間）以及收合起來的完整收聽歷史。
- **推薦** 一開始是 **我的推薦活動** 報告，涵蓋已登入使用者自己最近 30 天的資料（曝光如何轉為開啟與播放、給出的標記與重新洗牌，以及親和度分數的分布），接著是推薦預設值、徽章門檻、變化、探索加成與進階評分。儲存會為目前的分頁建立新的推薦工作階段；其他開啟中的分頁會保留它們的快照，直到建立新的工作階段。

目錄偏好與推薦設定依每個已驗證的帳戶儲存在伺服器上，並跨裝置共用；變更它們絕不會改變其他帳戶。沒有自己數值的帳戶與匿名瀏覽，使用執行個體的預設值。儲存失敗時會保留草稿與已持久化的值。

## 語言與外觀

外觀只能從頁首選單使用，介面語言則從頁首的帳戶選單使用。地球選項會跟隨瀏覽器或裝置的語言；其提示文字與無障礙名稱會標明這是自動選擇。每位已登入的使用者還會在介面語言正下方看到 **優先展示 metadata 語言**。這是個人的選擇：它決定該使用者看到哪個標題版本、簡介與標籤名稱，依這些標題排序標題，並且在 Kikoto 為該使用者查詢遠端來源時最先詢問。選項有 **原版**、日文、英文、簡體中文、繁體中文與韓文。未做選擇時顯示 **原版**，也就是每個作品的原始語言，選擇 **原版** 會清除該偏好；沒有所選語言的版本會退回 `原版`。共用的標籤名稱使用手動名稱與已學習的詞典，採用相同的語言優先順序，與該語言是否有對應版本無關。每種語言顯示的標籤都相同：它們來自原始版本。匿名訪客看到原始語言。所有儲存或共用的內容，例如已儲存的標題與標籤名稱、背景同步、創作者目錄重新整理、遠端中繼資料備援與活動文字，一律使用每個作品的原始語言，因此一位使用者的選擇絕不會改變其他人看到的內容。

### 多語言標題

Kikoto 使用第一個具有自己的手動標題或 DLsite 版本的優先中繼資料語言。其語言專屬的手動標題優先，其次是全語言手動標題，再其次是該版本的標題。全語言標題只會取代文字：預設版本、簡介與標籤維持與沒有它時相同。`原版` 使用原始版本所宣告的語言；未知的語言不會被猜測。若沒有任何符合，就使用原始標題。社團、系列與聲優的覆寫在各語言之間共用。未宣告的原始語言在任何地方都保持未知，與中繼資料請求的語系無關；其語言標籤只顯示 **原始**。語言專屬的手動標題，會在該宣告語言，或該手動語言被明確設為偏好或選取時生效。語言選單只包含既有的版本，以及具有自己手動標題的語言；全語言標題套用於既有的選項，而不會新增語言。

## 示範模式

示範模式會讓以帳戶為基礎的設定維持唯讀。管理分頁、歷史、推薦與標籤分頁，以及帳戶中的我的資料區段，即使示範身分不是管理員，仍然保持可見以供檢視，且其中的每項變更都已停用。外觀與播放控制項仍可使用，因為主題模式、樣式、顏色、跳轉間隔與播放來源選項，是瀏覽器本機的偏好設定，不會修改示範伺服器的資料。播放偏好設定依伺服器身分與已驗證的使用者隔離，啟用匿名存取時則依匿名主體隔離。

## 管理

### 媒體庫

媒體庫整合了媒體庫儲存、本機掃描設定、創作者目錄、已設定的遠端來源，以及唯讀的儲存路徑。

- **媒體庫儲存** 顯示媒體庫模式（一般或儲存池）、每個儲存池及其線上或離線徽章，以及 Fetch 池。可以新增儲存池，或在儲存池不含任何作品時移除；媒體庫一旦含有本機作品，模式本身就固定不變。**重新連線** 會在操作人員確認正確的磁碟已掛載於該處之後，再次標記既有的資料夾。
- **掃描深度** 不能設定得低於取得儲存作品的層級；掃描一律至少會到達該層級，因此取得的作品絕不會因為掃描停在它們之上而被回報為遺失。
- **創作者目錄** 包含 **目錄新鮮度天數**（1 到 365，預設 30），以自己的 **儲存目錄設定** 按鈕儲存。社團或聲優目錄一旦距離上次重新整理超過該天數，就會被標示為需要注意。
- 遠端來源是精簡的清單：健康狀態、主機、健康檢查操作，以及會立即儲存的啟用開關。健康檢查結果會透過與自動探測相同的來源健康狀態持久化。
- **新增來源** 從單一位址開始。Kikoto 會探測輸入的位址、其來源，以及相容 Kikoeru 作品 API 慣用的 `api.` 同層網域，然後填入 API URL、公開網站與名稱。若什麼都沒有偵測到，會開啟 **連線詳細資料** 供手動輸入。端點欄位、優先順序，以及網路／儲存選項，都留在收合的群組中。
- **備援語言** 最後才詢問，排在檢視者的優先中繼資料語言之後，因為來源不一定以每種語言描述作品。保留 **原版** 的檢視者、匿名訪客，以及爬取、下載與遠端中繼資料備援等背景工作，只會以備援語言詢問。預設為日文。上游仍可能忽略該請求，或回傳混合語言的中繼資料。
- 遠端來源預設使用相容的公開儲存主機。來源設定可以啟用 **限制輸出主機**，只允許 API、公開網站、備援，以及一份可編輯的、由完全比對或 `*.example.invalid` 形式的公開主機模式組成的清單。
- 儲存路徑預設為收合、唯讀，並顯示解析後的資料根目錄、快取根目錄、預設的快取／儲存預覽，以及各來源的儲存預覽。遠端來源設定會顯示同樣解析後的範例，而不是路徑範本編輯器。

沒有執行個體層級的中繼資料語言：每位使用者自己的選擇在頁首的帳戶選單中，而遠端來源的備援語言則在其來源設定中。

### 快取與取得

快取與取得只包含設定：播放快取原則、傳輸安全，以及收合的下載節奏，並有一個在變更後才會啟用的儲存操作。快取內容在清理分頁中管理。

- 單一檔案的遠端媒體限制預設為 100 GB，而失敗或已取消的取得執行所遺留、尚未發佈的暫存，預設保留七天。
- 轉碼快取限制是獨立的，範圍從 1 到 4096 GB，預設為 5 GB。這個可重建的快取位於 `/cache/transcodes` 之下，不會改變託管的遠端媒體快取限制。

### 代理

- **代理** 分頁依優先順序列出輸出代理。請求會從最上面開始嘗試，並使用第一個能連線的代理。**新增代理** 可選擇 **本機** 或 **其他位址**。本機代理執行於 Kikoto 所在的主機上：對話方塊會顯示伺服器連到它所用的位址（例如容器中的 `host.docker.internal`），但不允許編輯，因此只需設定協定、連接埠，以及選用的使用者名稱與密碼。其他代理還要填寫位址。協定有 HTTP、HTTPS、SOCKS5 與 SOCKS5h。已儲存的密碼不會再次顯示；將欄位留空即可保留原密碼。每項變更都會立即儲存。
- **代理適用範圍** 選擇代理套用的位置：**DLsite**（中繼資料、封面與創作者目錄）、**遠端來源**（瀏覽、播放與下載），以及 **其他**（更新檢查；個人的 Kikoeru 帳戶匯入一律直接連線）。**全部** 會同時切換這三者。每個範圍可依優先順序使用所有代理，或使用其中選定的一個。每個遠端來源可以跟隨遠端來源範圍、直接連線，或使用自己的代理選擇。
- **保底直連** 預設為關閉。關閉時，所有代理都無法連線的請求會失敗，而不是直接連線。開啟時，在每個代理都嘗試過之後，該請求會不經代理重試一次。

### 清理

**清理**（`/settings?tab=cleanup`）的快取區段需要 `downloads:manage`，資料庫區段則需要 `sources:write`。

- **轉碼快取** 顯示用量與其限制，並提供需確認的清除操作。
- **託管媒體快取** 報告磁碟上的檔案、被引用的檔案、符合資格的檔案與受保護的檔案，並清理依來源分組的孤立快取或各作品快取。清理是兩步驟的破壞性操作，以工作流程執行的形式排入佇列。
- **資料庫記錄** 列出可以移除的記錄類型，每一項都附有目前的數量：遺失的作品資料夾，以及已確認在磁碟上不存在的本機檔案（連同它們留下的空音軌項目與本機可用性）、孤立的中繼資料快照、未使用的來源標籤、過期的工作階段、已關閉的通知、超過 90 天的已結束工作流程執行、超過 90 天的推薦訊號，以及未使用的推薦快照。個人標籤、帶有審核、取得記錄或中繼資料問題的執行，以及每個工作流程最新的一次執行，都會保留。選取的工作會在確認後移除，並記錄在稽核日誌中；媒體檔案絕不會被刪除。過期的工作階段與符合資格的舊工作流程執行，也會以相同的規則每天自動移除一次。
- 資料資料夾遺失或為空時，路徑檢查會暫停，因此未掛載的媒體庫絕不會被視為已刪除。
- **沒有任何來源的作品** 連結到中繼資料的 **無可用來源** 檢視，以供審核與刪除。
- **壓縮資料庫** 會重寫 SQLite 檔案，把閒置的頁面還給磁碟。它以顯示在活動中的工作流程執行形式於背景執行，同一時間只能有一次壓縮在排隊或進行中。

### 使用者

使用者用來管理帳戶。正式環境與開發環境中的超級管理員，也會在此看到 **執行個體存取權**。匿名的媒體庫瀏覽與播放預設為停用；變更此開關會套用到正式環境的存取邊界，並建立一筆稽核記錄。開發環境會把每個請求都以 root 驗證，因此該設定在那裡可見且可編輯，而不會建立匿名的開發工作階段。

## 中繼資料

中繼資料使用 `/metadata`；`/work-management` 連結會連同其篩選或設定脈絡重新導向到那裡。

**中繼資料** 圖示側欄將 **作品**（全部、需要注意、中繼資料問題、無可用來源）與 **條目**（標籤、社團、聲優）分組。寬螢幕可以展開群組與檢視的名稱；手機則顯示可捲動的圖示列。作品表格提供搜尋、分頁、選取與手動重新整理，而鉛筆會開啟與作品詳細資料相同的編輯器。admin 與 super_admin 擁有 `library:write`，可處理中繼資料、封面、中繼資料連結、來源取消追蹤、共用標籤編輯與社團身分編輯。

**標籤**（`/metadata?view=tags`）依共用標籤的 **ID** 列出共用概念，並依 ID 排序，因此清單絕不依賴語言設定。ID 儲存格在有 DLsite 類型 ID 時，會在標籤 ID 下方顯示它，再下方只有在標籤為隱藏或已合併時才顯示 **已隱藏** 或 **已合併**；作用中的標籤不顯示狀態。欄位有 ID、日文、簡體中文、繁體中文、英文、韓文、**其他名稱**、作品與管理。每個語言欄位顯示該語言所顯示的名稱：先是它自己的手動名稱，其次是全語言手動名稱（以淡色顯示），再來是 DLsite 詞典名稱，然後是遠端來源的名稱，什麼都沒有時顯示「—」。**其他名稱** 會將其他每個已知名稱各列一次：被手動名稱取代的名稱（附其語言）、沒有語言的名稱，以及沒有名稱記錄的已儲存名稱。搜尋會比對名稱（包括遠端來源的名稱），數字查詢也會比對標籤 ID 或 DLsite 類型 ID。在窄螢幕上，表格會在自己的方框內橫向捲動，而管理按鈕固定在其右緣。管理可開啟所有語言或單一語系的手動名稱、全域隱藏、合併目標選擇，以及合併對應的復原。**社團**（`?view=circles`）依 DLsite 製作方 ID（RG 代碼）列出社團，並依代碼排序；合併帶入的製作方 ID 顯示在主要 ID 之下，而只在遠端來源中已知的社團則接在後面，以其 Kikoto ID 顯示。欄位有代碼、名稱（位於最新已知作品封面旁）、已知名稱、作品與管理，搜尋也會比對製作方 ID。管理支援能在提供方重新整理後保留的手動名稱、已確認的別名，以及會移動作品、製作方 ID、目錄、快照、系列與個人社團資料的已審核合併。復原會先處理最新的合併，並拒絕取代之後對受影響記錄所做的編輯。**聲優**（`/metadata?view=aliases`，以 `&voice=<id>` 開啟單一人物）依 Kikoto ID 列出人物並依 ID 排序，欄位有 ID、名稱（位於最新作品封面旁）、別名、作品、狀態（目錄同步）與管理；別名與重複項管理需要 `metadata:sync`。示範模式允許檢視，變更則維持停用。

條目清單遵循中繼資料頁面的存取權：需以至少具備 `library:write`、`metadata:sync`、`sources:write` 或 `system:admin` 其中之一的身分登入。匿名的讀取存取不包含這些管理清單。示範模式只顯示與示範作品相關的標籤與社團，只計算那些作品，且不公開社團合併歷史。

標籤的可見性跟隨最終的合併目標。隱藏已合併的標籤，會儲存其隱藏設定以供復原後使用；合併到隱藏的目標，則會隱藏合併後產生的標籤。原始名稱在合併期間仍可搜尋，而復原會還原原始身分與搜尋名稱。

封面配置遷移與標籤回填，會在核心啟動工作流程之後，於背景獨立執行。單一封面檔案失敗不會中止其他檔案。修復失敗會寫入日誌，並在下次啟動時重試。

頁首把類別、搜尋與清單控制項放在同一列。在寬螢幕上，搜尋欄位位於類別旁；在較窄的螢幕上，它會收合成右側的搜尋圖示，並在該列下方開啟欄位。接下來是重新整理、每頁列數、**重試中繼資料**、**檢查來源** 與 **中繼資料設定** 齒輪。清單上下的分頁與媒體庫一致。中繼資料設定在彈出視窗中開啟；將游標移到資訊圖示上或使其取得焦點，即可看到某項設定的說明，關閉它會保留目前的清單與篩選。請從工作流程啟動中繼資料同步。

選取系列並選擇 **重試中繼資料**；其數量只包含符合資格的選取項目。你也可以從詳細資料重試受影響的版本，包括被回報為無法使用的商品。重試失敗會保留既有的中繼資料與手動覆寫。**檢查來源** 適用於沒有來源的選取系列。經確認的本機資訊刪除，只能在 **無可用來源** 檢視中進行；伺服器會重新檢查可用性，並保留媒體檔案。

活動中的 **前往中繼資料待處理清單** 會開啟依該次執行未解決的中繼資料問題篩選的中繼資料；**顯示全部待處理作品** 則移除該次執行的篩選。首次同步失敗與待處理的中繼資料結果會開啟中繼資料問題；沒有工作流程權限的操作人員，看到的是不限範圍的問題清單。執行診斷位於工作流程的活動中。復原絕不會改變其他使用者的活動審核。中繼資料復原需要 `metadata:sync`，而來源檢查、刪除與來源／語言設定需要 `sources:write`。**中繼資料設定** 彈出視窗只包含設定；本頁不會重複同步工作流程的設定或執行控制項。

中繼資料設定有 **DLsite 代理** 捷徑：與 `設定 -> 代理 -> 代理適用範圍` 中 DLsite 範圍相同的開關與代理選擇，並立即儲存。**管理代理** 會開啟該區段以新增代理或重新排序。其下方的 **目錄新鮮度** 會開啟 `設定 -> 媒體庫`，而 **遠端中繼資料備援** 會開啟中繼資料同步工作流程，由其 **設定** 保存該設定。

共用的標籤名稱會依序嘗試每個優先語言：該語言的手動名稱、全語言手動名稱，然後是提供方名稱。詳細資料的語言切換遵循相同的優先順序。

隱藏、合併與復原會立即儲存其狀態。相關作品會在背景持續更新；標籤管理器會顯示整個執行個體剩餘的工作數量，包括等待重試的作品。重新整理清單即可查看進度。失敗的作品會自動重試而不延誤其他作品，重新啟動後更新會繼續進行。

### 以偏好語言顯示標籤名稱

即使是僅有日文的作品，DLsite 也會以所請求的語言命名類型。當任何使用者的優先中繼資料語言不是日文時，**學習標籤名稱** 工作流程會在背景補上缺少的標籤名稱：針對每種語言，它會向 DLsite 詢問一次涵蓋最多尚未命名標籤的那個作品，因此請求次數取決於缺少的標籤，而不是媒體庫的大小。它會在啟動、中繼資料同步與語言變更之後執行，使用與中繼資料同步相同的請求節奏和 DLsite 代理，並在重新啟動後繼續進行。進度、結果與失敗會顯示在活動中。它只儲存標籤名稱，絕不儲存標題或簡介，也不會對 DLsite 沒有命名的標籤再次詢問。

### 遠端中繼資料備援

**遠端中繼資料備援** 是每次 DLsite 中繼資料同步執行及其間隔觸發器的選項，預設為關閉。啟用後，依請求順序選擇最多 16 個提供作品中繼資料的已啟用來源。只有 DLsite 明確的找不到結果才會觸發備援；逾時與暫時性失敗不會。請求只描述既有的作品，並使用共用的有限制傳輸。補上的中繼資料會在執行結束後保留。這些選擇不會改變已儲存遠端值的執行個體層級排序，也不會改變手動／DLsite 的優先順序。

### 購買特典

**將購買特典關聯到原作品** 是 DLsite 的執行選項，預設為開啟，也會儲存在觸發器中。它控制該次執行的自動偵測。偵測會先檢查已儲存的作品，然後最多檢查 10 個社團頁面與 5 個候選商品。偵測關閉時，既有的關聯仍然適用；請參閱[購買特典](work-detail.md#購買特典)。
