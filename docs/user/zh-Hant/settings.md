# 設定
[English](../en/settings.md) · [簡體中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定公開每個使用者的帳戶控制和瀏覽器本地外觀以及
播放首選項。實例和使用者管理仍處於維護階段。

## 目前設定

- 更新經過驗證的使用者的顯示名稱。
- 驗證目前密碼後更改帳戶管理使用者的密碼
密碼並確認更換。
- 保持使用者名稱和角色可見但唯讀。
- 淺色、深色和系統外觀首選項。
- Anthropic、OpenAI、Apple 和 Google Material Design 風格偏好。
- 原色、石墨色、鈷色和虹膜顏色偏好。
- 向後和向前搜尋間隔。它們預設為 10 和 30 秒，
分別接受從 1 到 300 的整秒值。

## 帳戶邊界

更改密碼會保留目前會話並撤銷使用者的其他會話
會議。從維護中重置管理員密碼會撤銷每個
目標使用者的會話。角色、啟用狀態、使用者名稱和使用者生命週期
管理不是自助帳號設定。

配置的 root 帳戶無法在「設定」中變更其密碼。它是
憑證由`KIKOTO_ROOT_PASSWORD`管理；改變那個環境
值並重新啟動 Kikoto 會替換儲存的 root 密碼並撤銷其
現有會話。其他超級管理員仍然受帳戶管理，並且可以
正常更改自己的密碼。

演示模式使帳戶支援的設定保持唯讀狀態。外觀及播放
控制項仍然可用，因為主題模式、樣式、顏色和搜尋間隔
是瀏覽器本機首選項，不會修改演示伺服器資料。回放
首選項由伺服器身份和經過身份驗證的使用者隔離，或由
啟用匿名存取時的匿名主體。

## 維護組織

- 維護以簡潔的管理描述打開，而不是
重複可編輯的配置值作為摘要統計資料。詳細資料選項卡
僅保留操作指標，例如來源健康狀況、推薦
遙測和託管快取使用情況。
- 庫結合了本地掃描設定和配置的遠端來源。
- 元資料設定允許管理員選擇和重新排序受支援的 DLsite
標題/標籤語言。 `Origin` 始終保留作為最終後備。每個
相容的遠端來源在此標籤上也有其請求語言提示；這
上游可能會忽略它、回退或傳回混合語言元資料。
- 生產和開發中的超級管理員可以看到存取權限。
  Anonymous Library browsing and playback default to disabled; changing the
開關應用於生產訪問邊界並建立審核條目。
開發仍然以 root 身份驗證每個請求，因此設定仍然保留
在那裡可見和可編輯，無需建立匿名開發會話。
- 未連結的作品是邏輯工作系列的專用分頁維護選項卡
沒有可用的來源或媒體位置。它支援源重新檢查和
確認刪除本地資料庫訊息，同時保留媒體檔案。
- 每個啟用的遠端來源都有明確的運作狀況檢查操作。結果是
透過自動探測器使用的相同來源健康狀態持續存在。
- 遠端來源預設為相容的公共儲存主機。來源
配置可以啟用**限制出站主機**以僅允許API，
公共站點、後備以及精確或 `*.example.invalid` 的可編輯列表
公共主機模式。
- 路由規則是有序的偏好。他們的時間軸位置決定了
內部優先權；停用和數位權重控制不會公開。
- 建議從命名的通用設定檔開始，公開結果變化
和發現提升，並保持狀態混合槽、親和力基線，
高級評分下的權重和上限。
- 快取和取得首先呈現可編輯策略，然後是託管媒體使用
和清理控制。它的配置是一個垂直列表；已解決保存
路徑是路徑擁有的唯讀預覽。
- 快取和取得包括每個檔案的遠端媒體限制和保留期限
用於因失敗或取消的 Fetch 運行而未發布的暫存。預設值是
每個媒體檔案 100 GB，暫存保留期為 7 天。
- Cache & Fetch 提供獨立的轉碼快取限制，從 1 到
4096 GB。預設為 5 GB，包含準備完成的音訊和 HLS 片段使用量，以及可用
配額，並提供確認的明確行動。這個可重建的快取仍然有效
在 `/Cache/transcodes` 下並且不會更改託管遠端媒體緩存
限制。
- 託管媒體快取清理按來源範圍分組。團體可以是
折疊並作為一個單元選擇，而有界列表獨立滾動
對於大型圖書館。清理仍然是一個兩步驟破壞性行動。
- 路徑是唯讀的，顯示已解析的資料根、快取根、預設值
快取/保存預覽，以及按來源儲存預覽。遠端來源配置
顯示相同的已解決範例，而不是公開路徑範本編輯器。
