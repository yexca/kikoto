# 設定
[English](../en/settings.md) · [簡體中文](../zh-Hans/settings.md) · [繁體中文](../zh-Hant/settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

設定公開每個使用者的帳戶控制和瀏覽器本地外觀以及
播放首選項。實例和使用者管理仍處於維護階段。

## 多語言標題

使用第一個擁有專屬手動標題或 DLsite 版本的偏好中繼資料語言，依序採用該語言手動標題、全語言手動標題、該版本的標題。全語言標題只替換標題文字，預設版本、簡介和標籤與沒有這個標題時相同。`Origin` 對應原版明確宣告的語言；語言不明時不推測。均不符合時使用原版標題。社團、系列和聲優的手動覆寫仍為全語言共用。未宣告的原版語言始終視為未知，不根據中繼資料請求語言推測；此時語言標籤只顯示**原始**。語言專屬手動標題用於明確宣告的對應語言，或在該手動語言明確列為偏好、手動選取時生效。語言選單只列實際版本和擁有專屬手動標題的語言；全語言標題套用至既有選項，不會新增語言。

## 目前設定

- 更新經過驗證的使用者的顯示名稱。
- 驗證目前密碼後更改帳戶管理使用者的密碼
密碼並確認更換。
- 保持使用者名稱和角色可見但唯讀。
- 淺色、深色和系統外觀首選項。
- Anthropic、OpenAI、Apple 和 Google Material Design 風格偏好。
- 原色、石墨色、鈷色和虹膜顏色偏好。
- 向後和向前搜尋間隔。它們預設為 10 和 30 秒，
分別接受從 1 到 300 的整秒值。

## 帳戶邊界

更改密碼會保留目前會話並撤銷使用者的其他會話
會議。從維護中重置管理員密碼會撤銷每個
目標使用者的會話。角色、啟用狀態、使用者名稱和使用者生命週期
管理不是自助帳號設定。

所有帳戶（包括初始管理員）都在此變更自己的密碼；例外是環境變數管理模式下的 root 帳戶，其密碼來自 `KIKOTO_ROOT_PASSWORD`。忘記管理員密碼時，請在伺服器主機上重設，參見[管理員初始化與復原](../../operations/security.md#administrator-setup-and-recovery)。

演示模式使帳戶支援的設定保持唯讀狀態。外觀及播放
控制項仍然可用，因為主題模式、樣式、顏色和搜尋間隔
是瀏覽器本機首選項，不會修改演示伺服器資料。回放
首選項由伺服器身份和經過身份驗證的使用者隔離，或由
啟用匿名存取時的匿名主體。

## 維護組織

維護分頁採單行橫向排列，窄螢幕可橫向捲動。已移除 Overview；來源管理員預設進入 Library，僅有使用者管理權限時進入 Users。舊 Paths、Access 連結分別轉到 Library、Users。

- 維護以簡潔的管理描述打開，而不是
重複可編輯的配置值作為摘要統計資料。詳細資料選項卡
僅保留操作指標，例如來源健康狀況、推薦
遙測和託管快取使用情況。
- Library 整合本地掃描設定、遠端來源和唯讀儲存路徑。
- 生產和開發中的超級管理員可在 Users 內管理執行個體存取權限。
  Anonymous Library browsing and playback default to disabled; changing the
開關應用於生產訪問邊界並建立審核條目。
開發仍然以 root 身份驗證每個請求，因此設定仍然保留
在那裡可見和可編輯，無需建立匿名開發會話。
- 每個啟用的遠端來源都有明確的運作狀況檢查操作。結果是
透過自動探測器使用的相同來源健康狀態持續存在。
- 遠端來源預設為相容的公共儲存主機。來源
配置可以啟用**限制出站主機**以僅允許API，
公共站點、後備以及精確或 `*.example.invalid` 的可編輯列表
公共主機模式。
- 目錄規則和推薦偏好已移至 Settings，依帳號儲存。推薦分頁中摺疊的 **我的推薦活動** 只統計目前使用者過去 30 天的資料。
- 遠端來源以精簡清單呈現健康狀態、主機、健康檢查與立即儲存的啟用開關。**新增來源** 只需輸入一個位址：Kikoto 會依序探測原位址、其來源網域與常見的 `api.` 子網域，自動填入 API URL、公開網站與名稱；未偵測到時會展開 **連線詳細資料** 供手動填寫。
- Library 中的 **創作者目錄** 包含 **目錄新鮮度天數**（1 到 365，預設 30），透過獨立的 **儲存目錄設定** 按鈕儲存：社團或聲優目錄距上次重新整理超過該天數後會標示為需要注意。舊的 `/settings?tab=metadata` 連結會開啟 Library。執行個體不再設定中繼資料語言：每位使用者自己的選擇在右上角外觀選單中，遠端來源的備援語言在其來源設定中。
- Cache & Fetch 只保留設定：播放快取策略、傳輸安全與摺疊的下載節奏，變更後才可儲存。每個檔案的遠端媒體上限預設 100 GB，失敗或取消的 Fetch 暫存保留 7 天，轉碼快取上限預設 5 GB。快取內容改在 **清理** 分頁管理。
- Library 中的儲存路徑預設摺疊，是唯讀的，顯示已解析的資料根、快取根、預設值
快取/保存預覽，以及按來源儲存預覽。遠端來源配置
顯示相同的已解決範例，而不是公開路徑範本編輯器。



## 清理

**清理** 是設定中位於 Proxy 之後的管理員分頁（`/settings?tab=cleanup`）；快取部分需要 `downloads:manage`，資料庫部分需要 `sources:write`。頁面包含轉碼快取與託管媒體快取的用量與清理，以及資料庫記錄清理：磁碟上已確認不存在的作品資料夾與本機檔案（連同因此變空的曲目項目與本機可用狀態）、孤立中繼資料快照、未使用的來源標籤、過期工作階段、已關閉通知、超過 90 天的工作流程歷史與推薦訊號、不再使用的推薦快照。個人標籤、含審閱、Fetch 記錄或中繼資料問題的執行，以及每個工作流程的最新執行都會保留；清理需要確認並寫入稽核記錄，不會刪除媒體檔案。過期工作階段與符合條件的舊工作流程執行也會依相同規則每天自動刪除一次。資料資料夾遺失或為空時會暫停路徑檢查。**沒有任何來源的作品** 連到中繼資料的 **無可用來源** 檢視；**壓縮資料庫** 會把閒置頁還給磁碟；它會作為顯示在活動中的工作流程執行在背景進行，同一時間只能有一個壓縮在排隊或執行。

## 中繼資料

**中繼資料** 左欄分為 **作品**（全部、需要注意、中繼資料問題、無可用來源）與 **條目**（標籤、社團、聲優）。寬螢幕可以展開分組與檢視名稱，手機為可橫向捲動的圖示行。作品表格保留搜尋、分頁、選取和手動重新整理，鉛筆按鈕開啟與作品詳情相同的編輯器。admin 與 super_admin 擁有 `library:write`，可編輯中繼資料、封面、中繼資料連結、取消追蹤來源，並管理共享標籤和社團身分。

**標籤**（`/metadata?view=tags`）每列以共享標籤 **ID** 為準，依 ID 排序，因此清單不受任何語言設定影響。ID 儲存格在標籤 ID 下方顯示 DLsite 類型 ID（如有），僅當標籤已隱藏或已合併時再於其下顯示 **已隱藏** 或 **已合併**；正常標籤不顯示狀態。欄位依序為 ID、日文、簡體中文、繁體中文、英文、韓文、**其他名稱**、作品數、管理。每個語言欄顯示該語言實際顯示的名稱，優先順序為：該語言的手動名稱、全語言手動名稱（以淡化樣式顯示）、DLsite 詞典名稱、遠端來源的名稱；都沒有時顯示「—」。**其他名稱** 將其餘已知名稱各列出一次：被手動名稱取代的名稱（附語言）、沒有語言的名稱，以及沒有名稱紀錄的已儲存名稱。搜尋比對名稱（包括遠端來源的名稱），純數字查詢也會比對標籤 ID 或 DLsite 類型 ID。窄螢幕時表格在自己的框內橫向捲動，管理按鈕始終固定在右側。管理對話框可設定通用或各語言手動名稱、全域隱藏、選取合併目標並取消合併對應。**社團**（`?view=circles`）支援不會被來源更新覆蓋的手動名稱、已確認別名，以及可審閱的合併：作品、maker id、目錄、快照、系列和個人社團資料一起移轉。復原依最近合併優先，受影響資料有後續編輯時會拒絕覆蓋。**聲優** 的別名與重複人物管理仍要求 `metadata:sync`，保留 `/metadata?view=aliases&voice=<id>` 深連結。Demo 可查看這些介面，修改控制項停用。

條目清單和中繼資料頁面使用相同的存取條件：登入並擁有 `library:write`、`metadata:sync`、`sources:write` 或 `system:admin` 中至少一項權限。匿名唯讀存取不包含這些管理清單。Demo 只顯示與示範作品相關的標籤和社團，作品數也只計算這個範圍，並且不公開社團合併紀錄。

標籤是否顯示只看最終合併目標。隱藏已經合併的標籤，是保留它取消合併後的隱藏設定；合併到隱藏目標會隱藏最終標籤。合併後原名稱仍可搜尋，取消合併會還原原身分和搜尋名稱。

舊封面遷移和標籤回填在核心啟動工作流程之後獨立於背景執行。單一封面失敗不會阻止其他檔案，失敗會記入日誌並在下次啟動重試。

頂部將分類、搜尋與清單操作放在同一列。寬螢幕時搜尋框位於分類右側；窄螢幕時收合為右側的搜尋圖示，點擊後在該列下方展開搜尋框。其後依序為重新整理、每頁數量、**重試中繼資料**、**檢查來源** 與 **中繼資料設定** 齒輪。清單上下的分頁與媒體庫一致。中繼資料設定以浮動框開啟，將滑鼠停留或聚焦在資訊圖示上即可查看各項說明，關閉後保留清單與篩選條件。中繼資料同步請在 Workflows 中執行。

選取作品後點擊**重試中繼資料**，按鈕顯示適用數量；也可在詳情中重試指定版本，包括先前被回報為不可用的作品。失敗時保留既有資料與人工覆寫內容。**檢查來源**只處理所選無來源作品；**刪除本地資訊**僅在「無可用來源」篩選中提供，需要確認，伺服器重新檢查來源狀態並保留媒體檔案。

Activity 和 Workflows 保留原有功能。待處理按鈕會開啟作品維護並篩選該次執行尚未解決的中繼資料問題，可顯示全部待處理作品以取消執行篩選。復原不會修改其他使用者的 Activity 審核。中繼資料處理需要 `metadata:sync`；來源檢查、刪除以及來源和語言設定需要 `sources:write`。**中繼資料設定** 浮動框提供 **DLsite 代理** 捷徑：與 `設定 -> 代理 -> 代理適用範圍` 中 DLsite 的開關與代理選擇相同，變更會立即儲存；**管理代理** 會開啟該處以新增代理或調整順序。其下的 **目錄新鮮度** 開啟 `設定 -> Library`，**遠端中繼資料備援** 開啟中繼資料同步工作流程，該設定位於其 **設定** 中。此頁面不重複同步工作流程的設定與執行操作。舊 Maintenance 連結會重新導向此頁。

共享標籤名稱逐一嘗試偏好語言：該語言的手動名稱 > 所有語言手動名稱 > 提供方名稱。詳情頁的語言切換也遵循此順序。

隱藏、合併和取消合併會立即儲存狀態，相關作品在背景持續更新。標籤管理顯示整個實例剩餘的待更新作品數，包括等待重試的作品；重新整理列表可查看進度。失敗作品會自動重試，不阻塞其他作品，重新啟動後繼續處理。

### 偏好語言的標籤名稱

偏好中繼資料語言由每位登入的使用者在外觀選單中選擇。未選擇的使用者與匿名訪客看到每部作品的原語言（**原版**）；儲存的標題和標籤名稱、背景同步、目錄重新整理、遠端中繼資料備援和活動文字也一律使用每部作品的原語言。任何語言下標籤都來自原作版本，依標題排序則依循顯示的標題。要求遠端來源時先使用檢視者的語言，最後使用來源設定中的 **備援語言**；保持 **原版** 的使用者、匿名訪客以及抓取、下載、備援查詢等背景工作只使用備援語言。

即使作品只有日文版，DLsite 也會依請求的語言回傳類型名稱。任一使用者的偏好中繼資料語言不是日語時，**學習標籤名稱** 工作流程會在背景補全缺少的標籤名稱：每種語言都挑一個包含最多缺少標籤的作品請求一次，因此請求數取決於缺少的標籤數量，而不是作品庫的大小。它在啟動時、中繼資料同步後和變更語言後執行，使用與中繼資料同步相同的請求間隔和 DLsite 代理，重新啟動後會接著進行。進度、結果和失敗顯示在活動中。它只儲存標籤名稱，不使用標題或簡介；DLsite 沒有提供名稱的標籤不會反覆請求。

### 遠端中繼資料備援

**遠端中繼資料備援** 在中繼資料同步工作流程（`工作流程 -> 同步作品中繼資料`）的 **設定** 中設定，擁有 `sources:write` 的管理員會在 **執行** 旁看到該按鈕；預設關閉。開啟後，重新整理作品中繼資料時若 DLsite 明確回報找不到作品，會依清單順序查詢所選遠端來源；逾時等暫時性的 DLsite 錯誤不會觸發查詢。清單只顯示在來源設定中開啟 **提供作品中繼資料** 的來源。每個來源只請求一次，第一個回傳該作品的來源會補全標題、發售日、社團、標籤和封面（僅在沒有封面時）。備援不會新建作品，也不會補全 DLsite 缺少的語言。開啟期間，沒有 DLsite 資料的作品標籤會併入共享標籤，與既有標籤相符的遠端標籤會沿用該標籤。之後一旦有 DLsite 資料，一律改用 DLsite。

即使開關關閉，清單順序也決定多個遠端來源描述同一作品時採用哪個來源的值。關閉開關後不再發起新的查詢，遠端標籤會移出共享標籤；已補全的標題、日期、社團和封面會保留，直到被 DLsite 或手動值取代。中繼資料待處理清單會註明補全 DLsite 缺少作品的來源。

中繼資料頁面的正式位址為 `/metadata`。舊 `/work-management` 連結仍可使用，並保留篩選或設定情境。首次同步失敗及存在待處理中繼資料問題的結果入口會開啟問題清單；沒有工作流程權限的使用者進入不限定執行的清單。執行診斷仍可在 Workflows 的 Activity 中查看。

Settings 包含 Account、Playback、「歷史」「推薦」「標籤」分頁，以圖示顯示：游標停留或聚焦圖示可查看名稱，手機上還會標出目前分頁的名稱。「我的資料」的匯出與匯入位於 Account 底部；「推薦」顯示推薦活動與推薦設定。管理員（以及 Demo）還會在分隔線之後看到管理分頁（Library、Cache & Fetch、Proxy、Cleanup、Users）。寬螢幕時圖示以直欄顯示在設定內容左側；手機上則是一列可橫向捲動的圖示。直欄下方的「展開分頁名稱」按鈕可展開直欄，顯示每個分頁的名稱，Settings 會記住此選擇。Playback 內的目錄偏好與推薦設定按帳號儲存於伺服器，跨裝置共用；未自訂時沿用現有執行個體預設值。儲存推薦設定會更新目前頁面的推薦工作階段，其他已開啟頁面保留原快照。Maintenance 包含 Library、Cache & Fetch、Proxy、Cleanup、Users，全站推薦統計位於 Library 的摺疊區域。外觀設定僅保留右上角入口，地球圖示表示跟隨瀏覽器或裝置語言。每位登入使用者還會在 UI 語言下方看到「優先展示 metadata 語言」。這是個人選擇，決定該使用者看到的標題版本、簡介與標籤名稱；選項為「原版」、日文、英文、簡體中文、繁體中文、韓文；未選擇時顯示「原版」，即每部作品的原語言，選擇「原版」會清除此偏好；沒有所選語言版本時退回原版。代理在 Proxy 分頁中依優先順序新增，並在「代理適用範圍」中套用到 DLsite、遠端來源（可依來源個別設定）與其他要求。「本機」代理只顯示容器連到主機所用的位址且無法修改，只需設定通訊協定、連接埠與選填的帳號密碼。開啟「保底直連」（預設關閉）後，所有代理都無法連線的要求會不使用代理再重試一次。Metadata 設定中的「DLsite 代理」與 DLsite 適用範圍是同一個開關。Demo 模式不能修改帳號偏好；管理分頁（Library、Cache & Fetch、Proxy、Cleanup、Users）和個人資料頁面仍可檢視，但無法修改。
