# 記錄

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](record-library.md) · [日本語](../ja/record-library.md) · [한국어](../ko/record-library.md)

記錄是用於個人影片和圖片的獨立媒體庫。它使用 `/record` 掛載點，不會將檔案加入音訊媒體庫或任何作品。

## 設定

將主機資料夾掛載到 `/record`，開啟**記錄**，然後選擇**初始化根目錄**。Kikoto 會寫入 `.kikoto-record` 標記；只有明確初始化後才會開始掃描。正式環境的預設掛載如下：

```yaml
volumes:
  - ./record:/record
```

資料夾可以使用任意深度，頁面瀏覽的是同一棵資料夾樹：

```text
record/
├── artist1/
│   ├── folder-a/
│   └── folder-b/
└── artist2/
    └── folder-c/
```

## 瀏覽

記錄一次顯示一個資料夾。上方的路徑會標示目前的資料夾，並可返回任何包含它的資料夾。網址會保留目前開啟的資料夾，因此瀏覽器的上一頁、下一頁和重新載入都會回到同一個位置。

有背景 artwork 的資料夾會以橫幅開啟，顯示其海報、名稱以及影片和照片的數量，並提供**播放**以播放第一部影片，或**從 … 繼續**（顯示該時間）以接續你上次觀看的影片停下的時間。其他資料夾則以一般標題顯示相同資訊。

工具列提供**全部**、**影片**或**照片**的顯示切換，並可依名稱正向或反向排序。子資料夾以海報顯示，沒有海報時以資料夾圖示顯示；影片以寬幅圖塊顯示，圖塊含影片的一個畫面、長度，以及表示你已觀看比例的進度列；照片以方形縮圖顯示。縮圖會在資料夾第一次顯示時產生，因此較大的資料夾第一次開啟可能需要稍候。字幕、中繼資料和其他檔案不會顯示，資料夾的 artwork 圖片也不會顯示。**重新整理**會重新讀取該資料夾。

在最上層，**繼續觀看**會列出你看到一半就停止的影片，最近觀看的在前，並標示每部影片所在的資料夾。選擇其中一部會從你停止的位置開始播放，關閉播放器後會回到最上層。

## 掃描和 artwork

在工具列中選擇**掃描**，這需要媒體庫寫入權限。旁邊的頁面會顯示根目錄上次掃描的時間，開始掃描後則顯示掃描是已排入佇列、執行中或已完成。掃描會作為持久工作流程排隊，並與正在執行的掃描合併。它按副檔名索引一般檔案，跳過連結和 Kikoto 交易目錄；根目錄離線或掃描只完成部分時會保留既有記錄。只有完整掃描才會將已移除的資料夾和檔案標記為遺失。掃描也會讀取每個新增或變更的影片的長度和大小，以及每張新增或變更的照片的大小；無法讀取的檔案不會記錄長度，並會在檔案變更後重新讀取。

資料夾 artwork 使用以下圖片名稱：`folder`、`poster` 或 `cover` 作為海報，`backdrop`、`fanart` 或 `background` 作為背景。支援的影片副檔名包括 `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v` 和 `.ts`；支援的圖片副檔名包括 `.jpg`、`.jpeg`、`.png`、`.webp` 和 `.avif`。

## 觀看影片和照片

選擇影片即可在全螢幕播放器中開啟。如果你上次看到一半就停止，Kikoto 會詢問要從該時間繼續還是從頭開始。與影片同名的 `.vtt` 或 `.srt` 檔案會作為該影片的字幕顯示；`.srt` 檔案必須是 UTF-8。上一部和下一部按鈕可在該資料夾的影片間切換，返回或 Esc 會關閉播放器。播放位置按帳戶保存，約每十秒一次，並在暫停、播放結束和關閉播放器時保存；保存播放位置需要媒體庫寫入權限。影片開始播放時會暫停全域音訊播放器，關閉播放器後音訊仍保持暫停。

選擇照片即可全螢幕檢視。可使用方向按鈕、方向鍵或左右滑動在該資料夾的照片間切換，並以返回或 Esc 關閉。
