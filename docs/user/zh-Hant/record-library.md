# 記錄

[English](../en/record-library.md) · [简体中文](../zh-Hans/record-library.md) · [繁體中文](record-library.md) · [日本語](../ja/record-library.md) · [한국어](../ko/record-library.md)

記錄是用於個人影片、圖片和音訊檔案的獨立媒體庫。它使用 `/record` 掛載點，不會將檔案加入音訊媒體庫或任何作品。

## 設定

記錄預設為關閉，需由管理員開啟。將主機資料夾掛載到 `/record`，然後在**系統 → 媒體庫**的**記錄**之下開啟**記錄媒體庫**，並選擇**初始化根目錄**。Kikoto 會寫入 `.kikoto-record` 標記，用來標明這個根目錄；只有明確初始化後才會開始掃描。掛載在 `/record` 的另一個磁碟，即使已在別處為記錄初始化過，也會讓記錄顯示為離線，並保持此媒體庫原樣。對那個磁碟選擇**開始新的目錄**並確認後，它會成為記錄的根目錄，媒體庫從頭開始：先前那個磁碟的資料夾與觀看位置都會被清除。資料夾仍在但其 `.kikoto-record` 標記已遺失時，記錄會保留媒體庫：所有人仍可瀏覽和播放，掃描會加入新檔案但不會將任何檔案標為缺少，且無法刪除檔案。在**系統 → 媒體庫**的**記錄**中，**還原標記**會在存放媒體庫資料夾的磁碟已掛載時重新寫入標記並保留媒體庫；確認後，**開始新的目錄**會忘記媒體庫，並在下次掃描時重新為該資料夾編入索引。磁碟未掛載時留下的那種空資料夾無法開始新的目錄：請先掛載磁碟，或在該資料夾中加入檔案。記錄關閉時，側邊欄不會對任何帳戶顯示它；關閉記錄會保留其資料夾、觀看位置與縮圖，重新開啟後即可繼續使用。正式環境的預設掛載如下：

```yaml
volumes:
  - ./record:/record
```

資料夾可以使用任意深度，頁面瀏覽的是同一棵資料夾樹：

```text
record/
├── artist1/
│   ├── folder-a/
│   └── folder-b/
└── artist2/
    └── folder-c/
```

## 瀏覽

記錄一次顯示一個資料夾。上方的路徑列標示目前的資料夾並可返回任何包含它的資料夾，右側提供**繼續觀看**與**掃描**（沒有掃描權限的帳戶則顯示**重新整理**）。網址會保留目前開啟的資料夾，因此瀏覽器的上一頁、下一頁和重新載入都會回到同一個位置；按 Backspace 鍵也可返回上一層。

項目會依名稱自然排序，依序為子資料夾、影片、照片，最後是資料夾中的其他檔案；當資料夾內包含多種項目時會顯示分組標題。子資料夾以方形圖塊顯示，呈現其海報；沒有海報時呈現背景圖，兩者都沒有時顯示資料夾圖示；影片以寬幅圖塊顯示，圖塊含影片的一個畫面、長度，以及表示你已觀看比例的進度列；照片以方形縮圖顯示。影片名稱旁的 **以音訊播放** 會從你停止的位置在全域音訊播放器中播放影片的聲音，資料夾中的其他影片以聲音形式排在其後。縮圖會在資料夾第一次顯示時產生，因此較大的資料夾第一次開啟可能需要稍候。資料夾的 artwork 圖片不會顯示。

**檔案**列出資料夾中的其他所有內容，每項一列，顯示其類型和大小：音訊檔案附有長度和表示收聽進度的進度列，另外還有字幕、中繼資料及任何其他檔案。帶有封面圖的音訊檔案會在其列中顯示封面。選擇音訊檔案即可播放，詳見[收聽音訊](#收聽音訊)。

在任意資料夾中點開右上角的**繼續觀看**，都會列出你看到一半就停止的影片和音訊檔案，最近觀看的在前，並標示每部影片所在的資料夾。選擇其中一部會從你停止的位置開始播放。影片會在其資料夾上方開啟，關閉播放器後會回到開啟時的資料夾；音訊檔案則會開啟其資料夾，並在全域音訊播放器中播放。

## 掃描和 artwork

選擇路徑列右上角的**掃描**，這需要媒體庫寫入權限。將游標移到按鈕上可查看根目錄上次掃描的時間，開始掃描後則顯示掃描是已排入佇列、執行中或已完成。掃描會作為持久工作流程排隊，並與正在執行的掃描合併。它按副檔名索引一般檔案，跳過連結和 Kikoto 交易目錄；根目錄離線或掃描只完成部分時會保留既有記錄。只有完整掃描才會將已移除的資料夾和檔案標記為遺失。掃描也會讀取每個新增或變更的影片的長度和大小，每個新增或變更的音訊檔案的長度及是否帶有封面圖，以及每張新增或變更的照片的大小；無法讀取的檔案不會記錄長度，並會在檔案變更後重新讀取。

資料夾 artwork 使用以下圖片名稱：`folder`、`poster` 或 `cover` 作為海報，`backdrop`、`fanart` 或 `background` 作為背景。支援的影片副檔名包括 `.mp4`、`.mkv`、`.webm`、`.mov`、`.avi`、`.m4v` 和 `.ts`；支援的音訊副檔名包括 `.mp3`、`.m4a`、`.aac`、`.flac`、`.wav`、`.ogg`、`.opus`、`.wma`、`.aiff` 和 `.mka`；支援的圖片副檔名包括 `.jpg`、`.jpeg`、`.png`、`.webp` 和 `.avif`。

## 觀看影片和照片

選擇影片即可在全螢幕播放器中開啟，播放器會讓畫面及其控制項適應螢幕，並提供與[作品的影片播放器](work-detail.md#目前行為)相同的螢幕控制項、觸控手勢、**字幕**選單和鍵盤快速鍵；在電腦上，頂部的鍵盤按鈕會列出這些快速鍵。在手機上，影片開始播放時會切換為全螢幕，寬度大於高度的影片會讓螢幕轉為橫向，直到結束全螢幕；在 iPhone 和 iPad 上，**全螢幕**會開啟系統播放器。如果你上次看到一半就停止，Kikoto 會詢問要從該時間繼續還是從頭開始。瀏覽器無法直接播放的影片，例如 MPEG-TS（`.ts`）錄影，或在不支援 HEVC 的瀏覽器中的 HEVC 影片，會依媒體庫中影片的方式播放：瀏覽器能解碼其畫面時，伺服器無需重新編碼即可重新封裝，否則會轉換。與影片同名的 `.vtt` 或 `.srt` 檔案會作為該影片的字幕顯示；`.srt` 檔案必須是 UTF-8。影片內嵌的文字字幕同樣可供選擇。上一部和下一部按鈕可在該資料夾的影片間切換，返回或 Esc 會關閉播放器。

影片播放器右上角的 **以音訊播放** 會關閉影片播放器，並在全域音訊播放器中從同一時刻繼續播放影片的聲音，資料夾中的其他影片以聲音形式排在其後。旁邊的 **更多操作** 中有 **刪除**。

播放位置按帳戶保存，約每十秒一次，並在暫停、播放結束和關閉播放器時保存。影片開始播放時會暫停全域音訊播放器，關閉影片播放器後音訊仍保持暫停；全域音訊播放器再次開始播放時，影片會暫停。

選擇照片即可全螢幕檢視。可使用方向按鈕、方向鍵或左右滑動在該資料夾的照片間切換，並以返回或 Esc 關閉。照片開啟時適應螢幕，點擊顯示實際大小，再點一次恢復適應螢幕；滑鼠滾輪、觸控板或雙指捏合，以及 `+`、`-`、`0` 鍵可縮放到實際大小 8 倍以內的任意比例，放大後拖曳可以平移。

## 收聽音訊

選擇音訊檔案後，會在全域音訊播放器中從你停止的位置開始播放，該資料夾的其他音訊檔案會依序排入佇列。播放器顯示該檔案自身的封面圖，檔案沒有封面圖時則不顯示圖片，並在標題下方標示資料夾名稱；按兩下封面，或在手機上輕點兩下，即可開啟該資料夾。瀏覽器無法直接播放的檔案，例如 `.wma`，會經轉換後播放，[相容性播放](playback.md#目前行為)的運作方式與媒體庫音訊相同。播放位置的保存方式與影片相同。記錄的音訊沒有歌詞，不計入收聽歷史，也不會出現在重新載入後還原的佇列中。

## 刪除檔案和資料夾

擁有檔案管理權限（`downloads:manage`）的帳戶可以刪除記錄中的檔案和資料夾。**刪除** 位於 **更多操作** 選單中：影片播放器中在右上角，照片檢視器中在頂端，**檔案** 中在每一列末端，影片和資料夾磚中在名稱旁邊。確認畫面會列出檔案或資料夾在記錄根目錄中的路徑，以及將刪除和保留的內容；選擇 **繼續**，再選擇 **移到回收區** 即可刪除。刪除檔案後，檢視器會前往下一部影片或下一張照片，沒有時則關閉。

刪除的檔案或資料夾會移到記錄根目錄下的 `.kikoto-trash/records`，放在以時間和該項目命名的資料夾中，並保留它在根目錄內的資料夾結構。資料夾會連同其中所有內容一起移動，包括記錄不列出的檔案。所有帳戶在被刪除檔案上的播放進度、它們的縮圖和播放快取也會刪除，這些檔案也會從全域音訊播放器的佇列中移除。被刪除檔案旁邊的檔案（例如字幕）會保留。Kikoto 從不清空回收區：要還原，請把檔案或資料夾移回原處並掃描；要釋放空間，請從磁碟上刪除它。記錄根目錄離線時不會刪除任何內容，根資料夾本身不能刪除，經由連結存取的項目會被拒絕刪除。自頁面顯示後已發生變更的項目，例如在另一個分頁中已被刪除的項目，同樣會被拒絕；請重新整理後再次確認。
