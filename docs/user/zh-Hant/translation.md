# 翻譯


**翻譯** 頁面（`/translation`）在整個媒體庫範圍追蹤 [AI 翻譯](work-detail.md#ai-翻譯)：哪些內容正在進行或在排隊、哪些已停止、已完成的翻譯寫入了什麼，以及各語言已涵蓋多少作品。具備媒體庫寫入權限的帳戶可從側邊欄開啟，不需要工作流程權限。所有能開啟它的人都會看到每個帳戶的翻譯。每個項目一完成就會生效，詳見[結果](work-detail.md#結果)。

此頁面是 AI 翻譯執行及其項目的檢視。[工作流程](workflows.md)中的活動會列出相同的執行及其診斷資訊。Demo 中此頁面為唯讀：Demo 不翻譯任何內容，因此只有 **覆蓋** 會列出作品。

## 進行中

**進行中**（`?view=running`，頁面預設開啟的檢視）列出正在翻譯的執行，其後是仍在排隊的執行，每個作品一張卡片，每個目標語言各占一列，並顯示其階段：已排隊、翻譯中並顯示已完成多少項，或已完成。

你可以**取消**自己發起的執行，不需要工作流程權限；工作流程管理員也可以取消其他帳戶的執行。尚未送出的內容都會停止，已送出的翻譯請求會保留結果未知狀態。具備工作流程權限的帳戶還會看到 **活動**，它會開啟該執行的診斷資訊。

## 已停止

**已停止**（`?view=attention`）列出失敗、結果未知、已過期，或被內容安全政策攔截的項目，依作品、語言與類別分組，並各附原因。**重新傳送** 會在同一次執行中，把失敗的項目重新加入佇列。結果無法寫入的項目（例如歌詞資料夾被佔用的歌詞）會直接從保留的結果寫入，不需再次請求。請求因連線中斷、伺服器停止或取消等原因遺失回應時，可能已被服務商計費，因此 **重新傳送** 會先要求你確認；從未送達服務商的請求（例如送往無法連線的服務商的請求）會直接重新傳送，不需確認。來源、服務商或內容政策已變更的項目，由作品的新請求重新翻譯。等待期間檔案、資料夾或音軌已有該語言顯示名稱或歌詞的項目，會保留這些內容，不再重新傳送。

## 歷史

**歷史**（`?view=history`）列出已完成項目寫入的內容，最新的在前，依作品分組並附各作品的連結：該語言的標題、簡介、標籤名稱或顯示名稱，以及各歌詞項目成為的檔案。

## 覆蓋

**覆蓋**（`?view=coverage`，可帶 `&language=` 與 `&missing=`）顯示每個作品（目錄作品與自訂作品皆然）在一種目標語言下已有多少內容；`/metadata?view=translation` 連結會開啟它。**目標語言** 預設為介面語言。**顯示** 可列出缺少任一項的作品（預設）、缺少標題、簡介、標籤名、檔案名或歌詞的作品、已完整的作品，或全部作品。**標題** 與 **簡介** 標示該語言文字的來源：**原文** 表示它是作品原始版本的語言，**官方版本** 表示作品的語言版本，**手動** 表示該語言的手動標題或簡介，或在所有語言中顯示的 **備援** 標題或簡介，**LLM** 表示 AI 翻譯，**缺少** 表示沒有。**標籤** 計算作品中在該語言有名稱的共享標籤，**檔案名** 計算其本機檔案中在該語言有顯示名稱的檔案，**歌詞** 計算其本機音軌中已指派該語言歌詞的音軌；破折號表示作品沒有可計算的項目，檔案名在作品的原始語言下顯示 **原文**。勾號標示已完整的部分，缺少的部分使用注意色。每一列還會顯示作品在該語言下正在執行的翻譯。寬螢幕為每個部分提供獨立欄位，較窄的螢幕則把它們列在標題下方。

選取作品並按標頭的翻譯按鈕，即可以所選的模型翻譯每個作品在該語言下缺少的內容：標題、簡介、共享標籤名稱，以及檔案和資料夾名稱。各類別預設為所選作品中有任一缺少的部分。沒有缺少內容的作品會被略過。歌詞則在各作品自己的 AI 翻譯中逐條音軌選擇。結果會顯示在 **歷史** 中。

此頁面在有執行進行時會每隔幾秒自動重新整理。在手機上，各檢視排成可橫向捲動的一列。
