# 工作細節
[English](../en/work-detail.md) · [簡體中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

工作細節呈現元資料、版本、檔案樹、來源可用性和
一件作品的播放動作。

## 當前行為

- 按工作程式碼載入並解析翻譯後的 DLsite 系列路由。
- 顯示封面、標題、程式碼、圓圈、標籤、評分、語音元資料和 DLsite
關聯。
- 顯示邏輯工作系列的已知語言版本。
- 元資料語言與目錄版本是作品代碼旁兩個獨立的小標籤，各自顯示目前的選擇並開啟自己的清單；
  原始目錄版本顯示為「Origin · 語言」。元資料只有一種語言時，標籤只顯示文字。
元資料預設為本地作品配置的語言優先級
僅遠端工作的來源請求語言提示；使用者臨時切換
更改顯示的標題和提供者標籤而不保留。這
原始變體始終首先列出，同時保留配置的預設值
已選擇。
- 將目錄版本視為檔案可用性，而不是元資料可用性。
在持久的本地上下文中，折疊的選擇器僅顯示帶有以下內容的版本
本機資料夾或本機媒體；該公開內容將其擴展到所有已知版本。
只有當該來源在其自己的報告中報告遠端同級時，才可以選擇該遠端同級
資料庫;本地可用的同級仍可透過其本地選擇
即使選定的遠端來源不包含該目錄，也是如此。偏僻的
上下文預設為來源報告的可用性。
- 顯示僅元資料、僅遠端和不可用版本，但不暗示
本地播放。
- 首先渲染卡片提供的或程式碼解析的預覽，然後載入基本細節
和媒體樹作為單獨的階段。
- 在卡片/歷史預覽中保留已知的工作 ID，以便收藏夾和其他內容
收集路線不能與冗餘程式碼競爭庫加載
解決。
- 使用一個響應式頁面編輯器來實現持久且僅限遠端的身份
控制器。兩者共享返回、英雄、行動資訊/目錄、桌面目錄、
和模態放置，而不授予僅遠端預覽持久狀態。
- 將移動後退控制視為直到最後一個伺服器和使用者範圍
  Library list location, while wide layouts retain the source-aware history
返回。
- 僅當媒體階段需要具體時才延遲索引本地媒體文件
樹。已完成的空掃描會被記住，直到庫掃描失效為止
那個狀態。
- 合併相同媒體承載工作的並發索引並減少
每個檔案的第一個索引資料庫語句。緩慢的收集和寫入階段
單獨記錄以供診斷。
- 透過後端聚合檢查載入來源可用性。
- 在知道可用性後延遲開啟遠端來源樹。明確的
持久的遠端來源路由可以在
聚合 檢查並標記當前詳細資料中可用的成功載入。
- 目錄列以可變高度完整換行顯示資料夾與檔案名稱，包括沒有空格的長名稱，頁面不會水平溢出。
- 目錄路徑列保持一行。手機將中間的上層資料夾收進選單；桌面限制每段寬度並讓目前資料夾保持在可見範圍內。
  完整名稱仍可透過列、上層資料夾命令、標題與無障礙標籤取得。
- 在英雄操作列中保留一個來源選單。它的圖標更改為本地，
追蹤和遠端上下文，其標頭命名選定的來源，並且它
關閉外部互動、逃逸或來源變更。
- 將追蹤的狀態聚合到一個「追蹤」標籤中。當作品被追蹤時
如果有多個文件來源，此選項卡會顯示一個下拉列表，用於切換
活動追蹤目錄，無需將來源名稱新增至選項卡行。
- 在目錄描述中使用選定的追蹤來源名稱並保留
詳細 URL 中的選擇。
- 頁首 Hero 以封面色調為背景。封面旁依序顯示作品代碼、DLsite 連結與語言標籤、標題、
  社團與系列、CV 聲優列、一行標籤、精簡數據列（評分、年齡分級、銷量、發售日、可播放時長；
  手機上保持一行）、元資料提示，以及置於底部的 Hero 操作。標籤列先列出來源標籤，再以
  不同的強調樣式列出使用者的個人標籤，最後是新增或編輯圖示；來源標籤過多時收合為
  「+N」。目錄佔據下方主欄。來源資訊與元資料更新時間位於同一個面板，寬版時固定在
  目錄旁，較窄時接在目錄之後。來源資訊報告檔案／音訊數量、大小與時長的覆蓋範圍，
  並標示元資料時長的後備值，而不是默默取代來源時長。在窄螢幕上，Hero 在「資訊／目錄」
  分頁上方保留相同的聲優列、標籤列、數據列與操作，「資訊」分頁顯示來源面板，標記、
  清單、DLsite、元資料與來源則收合為圖示。
- 目錄以資料夾瀏覽器呈現：目錄夠寬且作品含資料夾時，固定的資料夾欄位於所選資料夾內容旁；
  否則以「資料夾」按鈕開啟同一個導覽（手機為底部面板，其他為彈出視窗）。導覽列出自然排序的資料夾及其可播放或圖片數量，
  小型樹完整展開、大型樹僅展開通往所選、推薦與播放中資料夾的路徑，只含單一子資料夾的資料夾會合併為一列，
  並標示推薦資料夾與正在播放的資料夾。
- 預設開啟資料夾路由規則推薦的資料夾。內容工具列顯示上層按鈕與路徑、資料夾的音軌數與時長、
  「推薦」標記（或返回推薦資料夾的命令）、折疊歌詞數量，以及播放目前資料夾可播放檔案的「全部播放」。
- 資料夾內容分組為子資料夾卡片、專輯式音軌清單、圖片集、文件與其他檔案，有多個分組時顯示分組標題。
  子資料夾卡片摘要其內容，含可播放檔案時提供直接播放。音軌依資料夾播放順序編號，完整名稱下方顯示大小與作品的續播位置，
  精確時長位於右側欄；滑鼠懸停顯示播放提示，目前音軌以強調列與動態圖示標示。續播標記會隨播放儲存即時更新。
  本機與快取圖片延遲載入縮圖；遠端圖片僅在預覽時載入。
- 將相符的同資料夾歌詞邊車折出預設的目錄
列，同時保持不匹配的文字可見。音訊行暴露歌詞選擇，
預覽和顯示操作，並且目錄控制項可以顯示所有折疊的
歌詞。文件管理和Fetch選擇繼續顯示完整
未過濾的樹。
- 預覽以檔案檢視器開啟，可用標題列按鈕、方向鍵、手機滑動或圖片縮圖列切換同一資料夾內的同類檔案。
  圖片置於深色舞台，可符合視窗或以點擊位置為中心顯示實際尺寸並拖曳平移，並顯示尺寸；影片使用相同舞台。
  文字以閱讀檢視開啟，LRC、WebVTT 與 SRT 以帶時間戳的行顯示（含 LRC 標頭標籤與「原始文字」切換），解析方式與播放器歌詞相同。
  檢視器提供文字複製、本機與快取檔案下載及本機圖片設為封面（需再次點擊確認，幾秒後或切換圖片時取消），在手機上全螢幕顯示，並位於桌面浮動播放器之上。
- 自然排序的資料夾列在自然排序的檔案之前。資料夾播放遵循相同的可見順序。
- 在目錄中保留可用的不可播放文件，例如圖像和文字
在可播放源下一起計算音頻和音頻視頻
公制。
- 使用位元組順序按需將本機和遠端文字預覽轉換為 UTF-8
標記、聲明的字元集和自動遺留編碼偵測，無需
重寫原始檔。
- 在桌面緊湊型播放器處於活動狀態時保留底部滾動空間，以便
最終隊列操作仍然可達。

## 行動

- 顯示一個固定的恢復操作。沒有積極未完成就被禁用
工作遊標；直接文件啟動從頭開始。
- Update quick listening status.
- 管理收藏清單會員資格。
- 與提供者元資料標籤分開編輯個人工作標籤。
- 同步元資料。
- 從相容的遠端來源同步/快取/取得。
- 當選定的來源被接受並重複使用時，取得記錄為可用
  an existing queued or running Fetch for the same canonical work.
- 當目前訪客處於任何獲取準備請求之前開啟登入
匿名的。
- 開源特定的 Track、Fork、Fetch、Origin、快取、刷新和文件
所選來源的「英雄來源」選單中的維護指令。
- 追蹤選定的遠端來源，保留其可瀏覽樹，然後開啟
聚合追蹤上下文中的相應來源，無需
第二個叉子。
- 編輯可用的手動覆蓋。
- 可以在中繼資料編輯器中將作品的中繼資料關聯到另一個 DLsite 編號，例如特典版停售後一般版以新編號販售時。之後重新整理中繼資料會讀取關聯編號，並將其中繼資料、標籤和封面儲存到目前作品；關聯編號不會成為獨立作品。作品本身的編號沒有記錄時，中繼資料無法使用的提示會直接開啟編輯器。

## 詳細載入模型

工作細節應該先選擇已知的本機資料庫狀態，然後載入速度較慢
分別遠端導出狀態：

1.從任何工作卡表面進行路線預覽，或輕量級程式碼解析
直接網址。
2. 基本作品元資料、使用者狀態、版本和製作人員。
3.本地媒體和目錄樹。
4. 來源可用性摘要。
5. 選擇遠端原始碼樹（如果使用者開啟一棵）。

這可以防止遠端來源故障阻塞本機詳細 shell。
目錄階段使用穩定的目錄狀骨架。媒體錯誤
僅替換該骨架，並保持已載入的元資料和操作不變。
取得路徑選擇和檔案管理樹僅在它們之後派生
選擇相應的選項命令。
