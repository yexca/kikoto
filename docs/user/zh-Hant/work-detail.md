# 工作細節
[English](../en/work-detail.md) · [簡體中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

工作細節呈現元資料、版本、檔案樹、來源可用性和
一件作品的播放動作。

## 當前行為

- 按工作程式碼載入並解析翻譯後的 DLsite 系列路由。
- 顯示封面、標題、程式碼、圓圈、標籤、評分、語音元資料和 DLsite
關聯。
- 顯示邏輯工作系列的已知語言版本。
- 將元資料語言選擇器與目錄版本選擇器分開。
元資料預設為本地作品配置的語言優先級
僅遠端工作的來源請求語言提示；使用者臨時切換
更改顯示的標題和提供者標籤而不保留。這
原始變體始終首先列出，同時保留配置的預設值
已選擇。
- 將目錄版本視為檔案可用性，而不是元資料可用性。
在持久的本地上下文中，折疊的選擇器僅顯示帶有以下內容的版本
本機資料夾或本機媒體；該公開內容將其擴展到所有已知版本。
只有當該來源在其自己的報告中報告遠端同級時，才可以選擇該遠端同級
資料庫;本地可用的同級仍可透過其本地選擇
即使選定的遠端來源不包含該目錄，也是如此。偏僻的
上下文預設為來源報告的可用性。
- 顯示僅元資料、僅遠端和不可用版本，但不暗示
本地播放。
- 首先渲染卡片提供的或程式碼解析的預覽，然後載入基本細節
和媒體樹作為單獨的階段。
- 在卡片/歷史預覽中保留已知的工作 ID，以便收藏夾和其他內容
收集路線不能與冗餘程式碼競爭庫加載
解決。
- 使用一個響應式頁面編輯器來實現持久且僅限遠端的身份
控制器。兩者共享返回、英雄、行動資訊/目錄、桌面目錄、
和模態放置，而不授予僅遠端預覽持久狀態。
- 將移動後退控制視為直到最後一個伺服器和使用者範圍
  Library list location, while wide layouts retain the source-aware history
返回。
- 僅當媒體階段需要具體時才延遲索引本地媒體文件
樹。已完成的空掃描會被記住，直到庫掃描失效為止
那個狀態。
- 合併相同媒體承載工作的並發索引並減少
每個檔案的第一個索引資料庫語句。緩慢的收集和寫入階段
單獨記錄以供診斷。
- 透過後端聚合檢查載入來源可用性。
- 在知道可用性後延遲開啟遠端來源樹。明確的
持久的遠端來源路由可以在
聚合 檢查並標記當前詳細資料中可用的成功載入。
- 將完整的資料夾和檔案名稱包裝在可變高度的瀏覽和樹行中，
包括沒有空格的長名稱，沒有水平頁面溢出。
- 將瀏覽麵包屑保持在一行。移動崩潰了中間祖先
進入選單，而桌面限制每個可見部分；保留完整姓名
透過行、祖先命令、標題和可存取標籤可用。
- 在英雄操作列中保留一個來源選單。它的圖標更改為本地，
追蹤和遠端上下文，其標頭命名選定的來源，並且它
關閉外部互動、逃逸或來源變更。
- 將追蹤的狀態聚合到一個「追蹤」標籤中。當作品被追蹤時
如果有多個文件來源，此選項卡會顯示一個下拉列表，用於切換
活動追蹤目錄，無需將來源名稱新增至選項卡行。
- 在目錄描述中使用選定的追蹤來源名稱並保留
詳細 URL 中的選擇。
- 將工作代碼和 DLsite 連結、標題、圈子和系列放在一個文件中
封面和元資料上方的全角桌面標題。中等寬度細節
頁面使用兩個獨立的列，包含語音、標籤和個人標籤
  flowing directly below the cover and source facts, version controls, and Hero
從第二列頂部流出的操作。
寬詳細資訊頁面使用三列作為封面、身分元資料和
源元資料。通知和版本控制跨越兩個元資料列
緊接在其內容下方，英雄動作直接位於其下方；
蓋子高度不會將這些控制向下推。來源資訊報告
檔案/音訊計數、大小和持續時間覆蓋範圍，並標記元資料持續時間
回退而不是默默地替換來源持續時間。在緊湊的螢幕上，
語音製作人員在主要操作上方仍可見，而標記、列出、
DLsite、元資料和來源折疊為圖示。
- 對行動裝置和桌面上的每種目錄檔案類型使用一行兩行，
將完整名稱放在類型、精確音訊持續時間和大小之上。
- 將相符的同資料夾歌詞邊車折出預設的瀏覽和樹
行，同時保持不匹配的文字可見。音訊行暴露歌詞選擇，
預覽和顯示操作，並且目錄控制項可以顯示所有折疊的
歌詞。文件管理和Fetch選擇繼續顯示完整
未過濾的樹。
- 在樹中自然排序的文件之前列出自然排序的資料夾和
瀏覽。資料夾播放遵循相同的可見順序。
- 在目錄中保留可用的不可播放文件，例如圖像和文字
在可播放源下一起計算音頻和音頻視頻
公制。
- 使用位元組順序按需將本機和遠端文字預覽轉換為 UTF-8
標記、聲明的字元集和自動遺留編碼偵測，無需
重寫原始檔。
- 在桌面緊湊型播放器處於活動狀態時保留底部滾動空間，以便
最終隊列操作仍然可達。

## 行動

- 顯示一個固定的恢復操作。沒有積極未完成就被禁用
工作遊標；直接文件啟動從頭開始。
- Update quick listening status.
- 管理收藏清單會員資格。
- 與提供者元資料標籤分開編輯個人工作標籤。
- 同步元資料。
- 從相容的遠端來源同步/快取/取得。
- 當選定的來源被接受並重複使用時，取得記錄為可用
  an existing queued or running Fetch for the same canonical work.
- 當目前訪客處於任何獲取準備請求之前開啟登入
匿名的。
- 開源特定的 Track、Fork、Fetch、Origin、快取、刷新和文件
所選來源的「英雄來源」選單中的維護指令。
- 追蹤選定的遠端來源，保留其可瀏覽樹，然後開啟
聚合追蹤上下文中的相應來源，無需
第二個叉子。
- 編輯可用的手動覆蓋。

## 詳細載入模型

工作細節應該先選擇已知的本機資料庫狀態，然後載入速度較慢
分別遠端導出狀態：

1.從任何工作卡表面進行路線預覽，或輕量級程式碼解析
直接網址。
2. 基本作品元資料、使用者狀態、版本和製作人員。
3.本地媒體和目錄樹。
4. 來源可用性摘要。
5. 選擇遠端原始碼樹（如果使用者開啟一棵）。

這可以防止遠端來源故障阻塞本機詳細 shell。
目錄階段使用穩定的目錄狀骨架。媒體錯誤
僅替換該骨架，並保持已載入的元資料和操作不變。
取得路徑選擇和檔案管理樹僅在它們之後派生
選擇相應的選項命令。
