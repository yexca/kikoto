# 工作細節
[English](../en/work-detail.md) · [簡體中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

工作細節呈現元資料、版本、檔案樹、來源可用性和
一件作品的播放動作。

## 多語言標題

標題編輯器可選擇 **全語言**、日語、簡體中文、繁體中文、英語和韓語。目前範圍自己的手動標題可直接編輯；提供方標題與繼承值僅顯示為灰色提示，不會因儲存而固定。來源區分目前語言手動標題與全語言手動標題。切換語言保留草稿；儲存只提交變更的欄位與標題語言。清空既有手動標題會移除該範圍；在繼承提示處輸入後清空則不提交變更。重設僅清除選定範圍，編輯器保持開啟並保留其他語言與欄位草稿。中繼資料 → 作品開啟的是同一個編輯器。

按偏好中繼資料語言逐一嘗試：該語言手動標題、全語言手動標題、該語言的 DLsite 版本。`Origin` 對應原版明確宣告的語言；語言不明時不推測。均不符合時使用原版標題。社團、系列和聲優的手動覆寫仍為全語言共用。 未宣告的原版語言始終顯示為未知，不根據中繼資料請求語言推測。語言專屬手動標題用於明確宣告的對應語言，或在該手動語言明確列為偏好、手動選取時生效。語言選單只列實際版本和擁有專屬手動標題的語言；全語言標題套用至既有選項，不會新增語言。

作品家族中所有非原版版本皆視為翻譯版，包括第三方翻譯。提供方標題依格式僅移除一個開頭的 DLsite 語言版本標記，例如 `【简体中文版】` 或 `【ドイツ語版】`。`【ASMR】`、標題中間的標記與所有手動標題保持原樣。每個版本項目使用自己的標題，包括偏好設定不支援的語言；提供方原文和快照不變。卡片、詳情、語言選項、搜尋結果與新加入的播放佇列共用此顯示規則，全部手動標題均可搜尋。簡介以純文字原樣顯示，並隨所選版本切換；只有手動標題而無對應版本的語言使用原版簡介。

## 編輯中繼資料

admin 與 super_admin 擁有 `library:write`，可以編輯作品中繼資料。儲存只提交相對初始值變更的欄位；只換封面不會固定自動標題、社團、系列或聲優。清空欄位只重設該欄位的手動覆寫。升級會刪除與同一作品系列某個 DLsite 標題去掉首尾空白後完全相同的固定標題覆寫，社團、系列和聲優覆寫保留。

標籤區可以搜尋共享中繼資料標籤，為目前作品新增或移除，也能建立自訂標籤；沒有 DLsite 中繼資料的作品也可使用。還原 DLsite 標籤會清除目前作品的標籤增刪。共享名稱依設定的中繼資料語言優先順序選取手動名稱和已學到的 genre 名稱，因此只有日文版的作品也能顯示已知的中文標籤名。背景更新完成後，全域隱藏的標籤不會出現。「我的標籤」仍是獨立的個人標籤。Demo 中編輯器僅供查看。

新建的自訂標籤名稱先保留為草稿，儲存時才在同一交易中建立或重用共享標籤並關聯目前作品。取消編輯不會留下共享條目。去掉首尾空白、忽略大小寫後，與任一語言的已知名稱完全相同時會重用既有標籤，重複點擊或同名輸入不會建立重複概念。

切換中繼資料語言版本時，優先使用該版本語言的手動名稱或字典名稱，沒有時依設定的語言優先順序回退；手動增刪、最終目標的隱藏狀態和合併關係繼續生效。預設版本選擇與作品投影使用相同的來源版本。只有快照標籤的作品，在自身投影完成前保留標籤顯示；手動移除全部標籤後則維持空白。

補全建議將已合併的舊名稱顯示為最終目標標籤。名稱符合隱藏標籤（包括合併到隱藏目標）時會標示並禁止新增；請先在中繼資料管理中取消隱藏。標籤名稱遵循[設定](settings.md)中說明的語言優先順序。

背景更新完成前，作品保留上次儲存的標籤集合，包括空集合，重新整理中繼資料也不會讓已移除的標籤重新出現。聲優頁的遠端作品列表同時顯示遠端標籤與手動新增的共享標籤。

- 顯示一個固定的恢復操作。沒有積極未完成就被禁用
工作遊標；直接文件啟動從頭開始。
- Update quick listening status.
- 管理收藏清單會員資格。
- 與提供者元資料標籤分開編輯個人工作標籤。
- 同步元資料。
- 從相容的遠端來源同步/快取/取得。
- 當選定的來源被接受並重複使用時，取得記錄為可用
  an existing queued or running Fetch for the same canonical work.
- 當目前訪客處於任何獲取準備請求之前開啟登入
匿名的。
- 開源特定的 Track、Fork、Fetch、Origin、快取、刷新和文件
所選來源的「英雄來源」選單中的維護指令。
- 追蹤選定的遠端來源，保留其可瀏覽樹，然後開啟
聚合追蹤上下文中的相應來源，無需
第二個叉子。
- 編輯可用的手動覆蓋。

## 詳細載入模型

工作細節應該先選擇已知的本機資料庫狀態，然後載入速度較慢
分別遠端導出狀態：

1.從任何工作卡表面進行路線預覽，或輕量級程式碼解析
直接網址。
2. 基本作品元資料、使用者狀態、版本和製作人員。
3.本地媒體和目錄樹。
4. 來源可用性摘要。
5. 選擇遠端原始碼樹（如果使用者開啟一棵）。

這可以防止遠端來源故障阻塞本機詳細 shell。
目錄階段使用穩定的目錄狀骨架。媒體錯誤
僅替換該骨架，並保持已載入的元資料和操作不變。
取得路徑選擇和檔案管理樹僅在它們之後派生
選擇相應的選項命令。
