# 作品詳細資料
[English](../en/work-detail.md) · [简体中文](../zh-Hans/work-detail.md) · [繁體中文](../zh-Hant/work-detail.md) · [日本語](../ja/work-detail.md) · [한국어](../ko/work-detail.md)

作品詳細資料呈現單一作品的中繼資料、版本、檔案樹、來源可用性與播放操作。

## 多語言標題

編輯器的標題區段會先列出日文、簡體中文、正體中文、英文與韓文，每一種語言各佔一整列。原始語言帶有 `origin` 徽章，目前顯示的中繼資料語言則帶有 `current` 徽章；兩者可以同時出現在同一列。**跨語言通用標題** 位於它們下方的 **進階標題選項** 之下，預設為收合。既有的通用標題會自動展開這些選項，以便編輯或清除。提示文字說明，通用標題會覆寫每種語言的提供方標題，而各語言的手動標題則優先；版本與簡介維持不變。某一列自己的手動標題是可編輯的文字；提供方與繼承而來的標題則是灰色提示，絕不會原樣儲存。每一列都會標明其目前的來源，並標示手動或已編輯的標題。儲存時只會送出變更過的欄位與標題語言；清除既有的手動標題，或在其列上選擇還原，會在儲存時移除該範圍，而清除繼承而來的提示則不會有任何變更。同樣的編輯器也能從中繼資料 → 作品開啟。

中繼資料語言選單包含已知版本、按語言設定的人工標題，以及標為 **LLM** 的已接受翻譯。LLM 選項只改變同一作品的中繼資料呈現，不增加官方版本或媒體版本。原文回退保留提供方宣告的原始語言，包括未知語言。優先順序見[標題與描述規則](../../architecture/data-model.md#manual-overrides-and-titles)。

當 DLsite 沒有某個作品的記錄，而由遠端來源補全時，詳細資料通知會顯示 **已由遠端來源補全**，並列出各來源補全了哪些值。遠端標題在標題順序中排在 DLsite 之後、作品自己的標題之前。它不宣告任何語言，因此不會新增語言選項，其文字也保持不變；標題編輯器會標明它的來源。

就提供方的顯示而言，作品系列中任何非原始版本都屬於翻譯，包括第三方翻譯。只有一個位於開頭的 DLsite 語言版本標籤（例如 `【简体中文版】` 或 `【ドイツ語版】`）會依其格式被移除。`【ASMR】` 之類的標籤、位於中間的標籤與手動標題都維持原樣。每個版本項目保留自己的標題，包括不支援的語言。原始的提供方標題與快照維持不變。卡片、詳細資料、語言選項、搜尋結果與新的播放佇列，共用同一套顯示規則；所有手動標題都仍可搜尋。簡介以純文字逐字呈現，除非被手動簡介取代，否則跟隨所選的版本。沒有對應版本的手動語言，使用原始簡介。

## 編輯中繼資料

預覽也能依穩定的標籤 ID 合併目前與拉取的標籤；接受 DLsite family 需要獨立操作，普通欄位儲存不會把同族版本加入媒體庫。

**拉取以編輯**會為目前作品開啟目前值、拉取值與預計儲存三欄的私人比較；語言範圍依實際版本顯示，原始版本標記為 Original。直接使用拉取值會接受提供方中繼資料並清除舊的手動覆寫；修改預計儲存值才會儲存為手動覆寫。預覽會過期，作品在此期間變更時也無法套用。

頂部橫幅的 **中繼資料** 按鈕會直接開啟編輯器。**重新整理中繼資料** 位於左下方，執行一般的 DLsite 重新整理。當已啟用的遠端來源支援中繼資料時，旁邊的箭頭會開啟 `來自 <source name>` 選項。選取其中一個，會向該來源請求這個作品的最新中繼資料；手動編輯與 DLsite 的值保持其優先順序，編輯器中未儲存的草稿也會保留。這項明確的重新整理不需要啟用自動遠端備援。

admin 與 super_admin 可以憑 `library:write` 編輯作品中繼資料。儲存時只會送出與編輯器初始值相比有變更的欄位；單獨選擇封面會保留自動產生的標題、社團、系列與聲優參與名單。清除欄位只會重設它自己的覆寫。與同一系列中去除空白後的 DLsite 標題完全相符的既有凍結標題覆寫，會在升級時移除；社團、系列與聲優的覆寫則會保留。

編輯器把欄位分成標題、封面、標籤、參與名單與中繼資料來源區段；圓點會標示有未儲存變更的區段，頁尾則會列出它們。每項變更在儲存之前都只是草稿，包括還原手動的社團、系列、聲優清單或封面，以及新增或移除的中繼資料連結，因此切換區段絕不會遺失編輯內容。取消會在捨棄草稿之前詢問。社團、系列與聲優提供能連結到已知條目的建議；它們的識別碼顯示在名稱下方，並可在編輯 ID 之下繼續編輯。封面從該作品本機圖片的縮圖網格中挑選。Ctrl+Enter 可儲存。

標題分區在各語言標題下方提供 **作品簡介** 欄位，用來編輯所有語言共用的作品簡介。它從作品目前顯示的簡介開始，可以輸入多行。儲存修改後的文字會成為手動簡介，在所有版本中取代提供方和 LLM 的簡介，並在中繼資料重新整理後保留；保留或清空繼承的簡介不會儲存任何內容。清空手動簡介或選擇其還原，會在儲存時恢復提供方的簡介。此欄位不需要 **拉取以編輯**，因此沒有提供方中繼資料的作品也能設定簡介。

標題分區的 **年齡分級** 可選擇全年齡、R15 或 R18，並顯示提供方的分級。手動分級可以補上提供方沒有給出的分級（例如自訂作品或 DLsite 已不再列出的商品），也可以讓分級比提供方的更嚴格；不能選擇比提供方寬鬆的分級。作品會顯示其手動分級，在媒體庫中依它被搜尋，並依它接受[內容安全政策](settings.md#內容安全政策)的判定，除非提供方的分級更嚴格。選擇還原會在儲存時移除手動分級。

各區段上方的**中繼資料語言**標籤列用來選擇編輯器顯示的語言：**所有語言**，接著是日文、簡體中文、正體中文、英文與韓文，無論作品是否有對應語言的版本。**更多**會展開作品在其他語言中的版本，包括未宣告語言的原始版本；選取其中一項後，該分頁會被選取並顯示所選語言，例如 `更多 - 德文`。標題與標籤名稱只能儲存為上述五種語言，因此「更多」之下的版本顯示來源提供的標題與各標籤的預設名稱。在五種語言之一下，標題區段只顯示該語言的一列，標籤區段以該語言的名稱顯示每個標籤；沒有該語言名稱的標籤會以灰色顯示回退後的名稱，其語言按鈕只開啟該語言的名稱與所有語言通用的名稱。作品族清單顯示所選語言的版本。作品擁有哪些標籤、封面與參與名單在所有語言中都相同。

標籤區段可搜尋共用的中繼資料標籤，為這個作品新增或移除它們，並且即使作品沒有 DLsite 中繼資料，也能建立自訂標籤。還原 DLsite 標籤會清除該作品的標籤新增與移除。共用名稱依你的優先中繼資料語言顯示，使用手動名稱與已學習的類型名稱；僅有日文的作品可以顯示已知的中文標籤名稱。背景更新完成後，隱藏的標籤在各處都維持不出現。個人的「我的標籤」是另外屬於帳戶的標籤。示範模式以唯讀方式顯示編輯器。

作品的標籤以清單形式顯示在「新增標籤」輸入框下方，每個標籤佔一列，下方列出它在其他語言中的名稱；新增至本作品的標籤帶有**已新增**標記。每個標籤的語言按鈕會在該列內開啟其各語言的名稱，其中全語言名稱與每個支援的語言各佔一列：手動名稱是可編輯的文字，提供方或已學習的名稱則是灰色提示。標籤名稱是共用的，因此重新命名的標籤會在每個擁有它的作品上改變；面板會顯示有多少作品共用它。新的自訂標籤會把輸入的名稱保留為其全語言名稱，並可在建立之前接收其他語言的名稱。名稱編輯和其他所有變更一樣是草稿，會在你儲存時寫入。

新的自訂名稱在儲存之前都只是草稿；儲存會在單一交易中建立或重用共用標籤，並將它附加到這個作品。取消不會留下任何共用條目。去除空白並忽略大小寫後，與任何已知語言的名稱相符的名稱，會重用該標籤，因此重複點擊與重複的名稱不會建立重複的概念。

切換中繼資料語言時，會優先使用該版本的手動或詞典標籤名稱（若有），否則退回你的優先語言。每個版本顯示的標籤都相同，取自原始版本，因此切換只會重新命名標籤，而不會新增或移除任何標籤。新增、移除、最終目標的隱藏與合併對應仍然適用。僅存在於快照中的標籤，在其自己的投影完成之前仍然可見；移除每個標籤會產生刻意留空的顯示。

僅有日文的作品，在背景的 **學習標籤名稱** 工作流程學會這些名稱之後，就會以優先語言顯示其標籤；在那之前，標籤會退回其日文名稱。它的標題仍然是日文。

完成時，合併後的名稱會顯示為其最終標籤。隱藏的符合項目（包括合併到隱藏目標）會被標示且無法新增；請先在中繼資料中取消隱藏。名稱遵循[設定](settings.md)中所述的語言優先順序。

在背景更新完成之前，作品會保留它最後儲存的標籤集合（包括空集合），即使中繼資料已重新整理也是如此。聲優頁面的遠端作品清單，會將遠端標籤與手動加入的共用標籤一起顯示。

## LLM 翻譯

評估方式見[內容安全政策](settings.md#內容安全政策)。

具備中繼資料同步和作品寫入權限的編輯者可從編輯器開啟 **LLM 翻譯**，選擇提供方及其中一個模型、目標語言和傳送欄位。模型支援從作品原始語言譯入介面語言時，目標語言預設為介面語言，否則為模型支援的語言；模型不支援的語言顯示為無法使用。**僅預檢，不傳送內容**依設定的政策模式評估本次請求。結果顯示分級、命中欄位與規則身分，不聯絡 LLM。規則及端點邊界在 [Settings → LLM](settings.md#大型語言模型服務商) 設定。

同步預覽有效期為 15 分鐘，背景預覽為 24 小時；預覽跨重新啟動保留，並綁定發起使用者與作品。接受時重新檢查來源內容、目前權限、策略版本與模型設定；發生變化時預覽失效。審核清單顯示待確認、已接受、已拒絕與已過期狀態。確認的標題和描述獨立保留 LLM 出處，不覆寫提供方快照或人工值。一般同步保留譯文；原始欄位變化時僅使對應譯文失效。**撤銷**從呈現中移除譯文，**恢復**僅在來源輸入仍一致時重用記錄。

**共享標籤名稱**只翻譯既有共享標籤概念缺少的語言名稱，跳過已有人工名稱、提供方名稱和可重用的已接受譯名。確認會影響其他作品中的共享名稱，但不改變標籤 ID 或作品成員關係。人工和提供方名稱優先；名稱修改、隱藏和合併不會抹去保留的風險證據。

歌詞在 [管理歌詞 → 翻譯](#翻譯) 中翻譯。

**提交背景翻譯**接受 1–100 個明確填寫的既有作品。相同提交重用持久化工作；已完成工作的預覽過期或審核結束後，再次提交會建立新工作並保留原 Activity 記錄。Activity 顯示進度、取消、重新啟動恢復及失敗。執行時重新檢查權限、輸入、策略與指定端點，保留完成的分塊。明確拒絕及傳送前失敗可明確重試同一端點。上游結果不確定時停止自動傳送；**重新傳送結果不確定的請求**要求明確接受可能重複計費。端點、模型、策略或內容變更後禁止此種重新傳送。結果始終等待人工審核。

## 轉寫

**管理歌詞 → 轉寫** 用已設定的[語音辨識服務](settings.md#語音辨識服務)，把本機音軌中的語音轉為帶時間軸的歌詞。此分頁依資料夾分組，列出作品的本機音訊檔案，以及每個檔案已有歌詞的語言。清單上方的篩選器可顯示 **無歌詞** 的音軌（預設）、沒有作品原始語言歌詞的音軌，或 **全部** 音軌。選擇音軌，或在清單頂端選取所有列出的音軌，再在底部工具列中選擇 **音訊語言**、服務與模型；**轉寫** 會為每個所選音軌加入一次轉寫。音訊語言是音訊中所說的語言，預設為作品的原始語言，會作為提示傳送給服務，結果以該語言儲存並指派；**自動偵測** 由服務自行判斷，結果儲存為備用歌詞。共享的[內容安全政策](settings.md#內容安全政策)根據作品中繼資料檢查服務的接收上限，不檢查音訊本身。**檢測分級** 位於篩選器旁，不傳送任何內容，顯示作品的分級，並標出不能接收的服務；只有點擊時才會檢測。正在轉寫的音軌不會被重複加入佇列，音軌所在列會顯示其未完成轉寫的狀態。

轉寫是 Activity 工作流程。Kikoto 自行解碼音軌，並把 16 kHz 單聲道音訊分成每段最長五分鐘傳送；每段在其最後一分鐘內最安靜的位置切開，使切點落在詞與詞之間。每個完成的部分都會保留，工作流程會在各部分之間把佇列讓給其他等待的工作，因此長音軌不會阻塞掃描或取得。傳送每個部分之前，Kikoto 都會再次檢查服務設定、內容政策、你的權限與音訊檔案是否未變更。重新啟動中斷的請求，或服務拒絕的部分，會使轉寫停止；在 Activity 中點擊 **重試** 會從最後完成的部分之後繼續，並重新傳送被中斷的部分。取消執行會使其停止。

完成的轉寫在音軌下方的清單中等待審核。**預覽** 以與其他歌詞相同的時間檢查顯示開頭幾行。**加入歌詞** 會把它儲存為 WebVTT 檔案，放在音軌所在作品資料夾內該語言的歌詞資料夾中，沿用音軌自身的路徑，例如 `lyrics_kikoto/ja/mp3/Track 01.vtt`，並指派給該音軌。同名位置已有不同的檔案或資料夾時，該檔案或資料夾會保留，轉寫則以帶編號的名稱儲存在旁邊。歌詞資料夾或其中的資料夾應在的位置上有一個不是 Kikoto 建立的檔案或資料夾時，在重新命名或移走它之前，**加入歌詞** 無法使用，轉寫會保留。**捨棄** 會放棄不需要的轉寫。如果加入歌詞未能完成，結果會保留，再次點擊 **加入歌詞** 即可重試。

Demo 中，此分頁顯示作品音軌的範例轉寫與範例服務。不會傳送任何音訊，**預覽** 顯示範例文字，**檢測分級**、**轉寫**、**加入歌詞** 與 **捨棄** 無法使用。

## 翻譯

**管理歌詞 → 翻譯** 用已設定的 [LLM 提供方](settings.md#大型語言模型服務商)翻譯本機音軌的歌詞。此分頁是作品本機音軌與歌詞語言構成的表格。綠色儲存格表示該語言已有歌詞，紅色儲存格表示沒有；音軌沒有備用歌詞時，**備用** 欄顯示短橫線，因為備用歌詞不是翻譯目標。右上角的 **語言** 用於選擇顯示哪些欄。點擊紅色儲存格會為該音軌建立該語言，點擊某種語言的表頭會選取所有缺少該語言的音軌。每個所選音軌依序從作品原始語言的歌詞、其備用歌詞、其第一個其他語言的歌詞翻譯，該儲存格會標為翻譯來源；點擊同一列中的另一個綠色儲存格，則改為從該檔案翻譯。翻譯正在執行或等待審閱的儲存格會顯示其狀態，不能再次選取。底部工具列用於選擇提供方與模型，**翻譯** 會為每個所選儲存格加入一次翻譯。所選模型無法翻譯成的語言欄會被標出，如 [LLM 翻譯](#llm-翻譯) 所述，其儲存格不能選取。該音軌必須在作品資料夾中有本機檔案，譯文儲存到該作品資料夾。依名稱比對某個音軌的遠端歌詞檔案算作該音軌的備用歌詞，並標有雲朵圖示；翻譯它要求管理員啟用及遠端取得權限。內容安全政策與 [LLM 翻譯](#llm-翻譯) 相同，並在傳送任何內容之前檢查完整歌詞。**檢測分級** 不傳送任何內容，對所顯示欄中的每個歌詞檔案執行這項檢查，用分級標記每個綠色儲存格並統計各分級的數量，同時標出不能接收所選來源的提供方；只有點擊時才會檢測。

翻譯是 Activity 工作流程，把歌詞分成有大小限制的部分傳送，並保留每個完成的部分。LRC、WebVTT、SRT、標準 ASS 對話和純文字保留時間軸與字幕順序，只翻譯每行文字。輸入和輸出各限 128 KiB，來源檔案最多 4,000 行，每個文字行最多 4,096 位元組。提供方拒絕的部分，或暫時無法使用的作品資料夾，可在 Activity 中重試。重新啟動中斷的請求結果未知；確認可能重複計費後，**重新傳送** 會再次傳送。歌詞、提供方設定、內容政策或你的權限發生變化會使翻譯停止，需要重新開始。

完成的翻譯在表格下方的清單中等待 24 小時，歸發起人所有。**預覽** 以與其他歌詞相同的時間檢查顯示開頭幾行。**加入歌詞** 會再次檢查歌詞檔案、政策和提供方，然後把譯文儲存到音軌所在作品資料夾內目標語言的歌詞資料夾中，沿用音軌自身的路徑和原檔案的副檔名，例如 `lyrics_kikoto/zh-hans/mp3/Track 01.lrc`，並以該語言指派給該音軌。原歌詞檔案不會被修改。同名位置已有不同的檔案或資料夾時，該檔案或資料夾會保留，譯文則以帶編號的名稱儲存在旁邊。歌詞資料夾或其中的資料夾應在的位置上有一個不是 Kikoto 建立的檔案或資料夾時，在重新命名或移走它之前，**加入歌詞** 無法使用，譯文會保留。**捨棄** 會放棄不需要的譯文。如果加入歌詞未能完成，結果會保留，再次點擊 **加入歌詞** 即可重試，且不會聯絡提供方。

Demo 中，此分頁顯示有歌詞音軌的範例翻譯與範例提供方。不會傳送任何歌詞，**預覽** 顯示範例文字，**檢測分級**、**翻譯**、**加入歌詞**、**捨棄** 與 **重新傳送** 無法使用。

## 自訂作品

[自訂作品](settings.md#中繼資料)沒有提供方中繼資料，也沒有遠端來源。其詳細資料不顯示 DLsite 連結、評分、銷量或中繼資料通知，也不提供中繼資料重新整理、遠端來源分頁或來源檢查；目錄只列出其本機資料夾。中繼資料編輯器沒有 **拉取以編輯**，也沒有「中繼資料來源」區段，因此自訂作品不能設定中繼資料連結、購買特典的原作品或合集內容；其標題、簡介、年齡分級、封面、標籤與製作資訊都以手動編輯。**編輯檔案** 與 **管理歌詞** 的 **歌詞檔案** 分頁只列出本機資料夾與版本。當它的資料夾遺失時，目錄會說明：只要某個資料夾的名稱以其 KT 代碼結尾，掃描就會重新找到該作品。封面從其本機圖片中選擇；重設封面後改為顯示作品編號。

## 購買特典

購買特典（例如早期購入特典 `【早期購入特典】`）是自己的 DLsite 商品，有自己的檔案，但 DLsite 並未說明它屬於哪個作品。中繼資料同步可以把它關聯到該原作品（請參閱[購買特典](settings.md#購買特典)），而媒體庫編輯者可以在編輯器中繼資料來源區段的 **購買特典** 之下，輸入或移除原作品的代碼。已關聯的特典仍是獨立的作品：它保留自己的標題、封面、檔案、播放進度與媒體庫卡片，並從原作品取得它所缺少的標籤、聲優與系列。其詳細資料會顯示 **特典所屬** 與原作品；當原作品不在媒體庫中時，則顯示原作品代碼及 DLsite 連結。而原作品的詳細資料會列出其位於媒體庫中的 **購買特典**，包括關聯到其系列另一個版本的特典。原作品代碼絕不會變成媒體庫作品。移除關聯也會停止對該作品的自動偵測，而下次重新整理會捨棄繼承而來的值。

## 合集

官方合集，例如完整包（`コンプリートパック`）或套裝，是有自己檔案的獨立 DLsite 商品，其中收錄的作品也單獨販售。DLsite 只會說明部分合集的內容，中繼資料同步會自動列出這些內容。其他合集則由媒體庫編輯者在編輯器中繼資料來源區段的 **合集內容** 之下列出其中的作品：輸入作品代碼，或加入該區段在標題看起來像合集時建議的、來自合集 DLsite 系列的某個作品（否則按 **顯示** 即可展開建議）。變更會在儲存時套用。合集的詳細資料會在 **收錄作品** 之下列出其中的作品，各作品的詳細資料則會在 **收錄於** 之下顯示所屬合集；不在媒體庫中的代碼會附上 DLsite 連結顯示。合集與其中每個作品仍是各自獨立的作品，擁有自己的檔案、播放進度與媒體庫卡片，合集中的作品絕不會使用合集的檔案播放。你移除的作品不會再被中繼資料同步列出。在媒體庫中搜尋某部作品的編號或標題時，也會找到收錄它的合集。

## 目前行為

- 依作品代碼載入，並解析已翻譯的 DLsite 系列路由。
- 顯示封面、標題、代碼、社團、標籤、評分、聲優中繼資料與 DLsite 連結。
- 顯示邏輯作品系列已知的語言版本。
- 將中繼資料語言與目錄版本選擇器保持為作品代碼旁兩個獨立的精簡標籤。每個標籤都標明其目前的選擇，並開啟自己的清單；原版目錄版本顯示為 `原版 · <language>`。在手機上，作品代碼與兩個標籤保持在同一行：標籤以代碼表示語言（`JA`、`EN`、簡體中文為 `SC`、正體中文為 `TC`、`KO`），原版目錄版本顯示為 `原版`。清單中仍顯示完整的語言名稱。當只有一個變體時，中繼資料標籤會變成唯讀標籤。對於本機作品，中繼資料預設為你的優先中繼資料語言；對於僅有遠端的作品，則預設為來源所描述的你的語言中的第一個，再其次是來源的備援語言。暫時切換會改變顯示的標題與標籤名稱，但不會被持久化。原版變體一律列在最前面，同時已設定的預設仍維持選取。
- 把目錄版本視為檔案可用性，而不是中繼資料可用性。在持久化的本機脈絡中，收合的選擇器只顯示具有本機資料夾或本機媒體的版本；展開鈕則會展開為所有已知版本。只有當遠端同層版本由該來源在自己的資料庫中回報時才可選取；本機可用的同層版本，即使所選的遠端來源不包含它，仍可透過其本機目錄選取。遠端脈絡則預設改用來源回報的可用性。
- 顯示僅有中繼資料、僅有遠端與無法使用的版本，而不暗示可在本機播放。
- 先繪製由卡片提供或由代碼解析出的預覽，然後將基本詳細資料與媒體樹作為獨立階段載入。
- 在卡片／歷史預覽中保留已知的作品 ID，使收藏與其他集合路由不會讓媒體庫載入與多餘的代碼解析互相競爭。
- 為持久化與僅有遠端的身分控制器使用同一個響應式頁面組合器。兩者共用返回、頂部橫幅、行動版資訊／目錄、桌面版目錄與強制回應視窗的位置，而不會讓僅有遠端的預覽取得持久化的狀態。
- 把行動版的返回控制項視為回到最後一個依伺服器與使用者分別記錄的媒體庫清單位置的「上一層」，而寬版版面則保留會依來源而變的歷史返回。
- 只有在媒體階段需要具體的檔案樹時，才延遲為本機媒體檔案建立索引。已完成的空掃描會被記住，直到媒體庫掃描使該狀態失效。
- 合併同一個含媒體作品的並行索引，並減少每個檔案首次建立索引的資料庫陳述式。緩慢的收集與寫入階段會分別記錄日誌以供診斷。
- 透過後端的彙總檢查載入來源可用性。
- 在得知可用性之後，才延遲開啟遠端來源檔案樹。明確的持久化遠端來源路由，可以在彙總檢查之前載入它所指明的來源，並在目前的詳細資料中將成功的載入標記為可用。
- 在高度可變的目錄列中換行顯示完整的資料夾與檔案名稱，包括沒有空格的長名稱，且頁面不會水平溢出。
- 讓目錄導覽路徑保持在單一行。行動版會把中間的上層收進選單，桌面版則限制每個可見片段的寬度，並讓目前的資料夾捲動到可見位置；完整名稱仍可透過列、上層指令、標題與無障礙標籤取得。
- 在頂部橫幅的操作列中保留一個來源選單。其圖示會依本機、已追蹤與遠端脈絡而變，標頭標明所選的來源，並會在點擊外部、按 Escape 或變更來源時關閉。
- 將已追蹤的存在狀態彙整為單一已追蹤分頁。當作品被多個檔案來源追蹤時，該分頁會提供一個下拉選單，用來切換作用中的已追蹤目錄，而不必把來源名稱加進分頁列。
- 在目錄說明中使用所選的已追蹤來源名稱，並把這項選擇保留在詳細資料網址中。
- 開啟時顯示一個背景以封面著色的頂部橫幅。封面旁邊會顯示：作品代碼與 DLsite 連結及語言標籤、標題、社團與系列、一行 CV 參與名單、一列標籤、精簡的統計列（評分、年齡分級、銷量、發售日與可播放長度；手機上為一列）、任何中繼資料通知，以及靠底部對齊的頂部橫幅操作。標籤列先列出提供方標籤，再以獨特的強調樣式列出使用者的個人標籤，並以新增或編輯圖示作結；過長的提供方標籤清單會收合到 `+N` 控制項之後。選取提供方標籤或個人標籤，會在詳細資料所由開啟的媒體庫搜尋中加入 `tag:` 或 `mytag:` 子句；從另一個頁面開啟詳細資料後選取個人標籤，則會開始新的本機媒體庫搜尋。目錄填滿其下方的主欄。來源資訊與中繼資料更新時間共用一個面板，在寬頁面上位於目錄旁，在較窄的頁面上則接在目錄之後。來源資訊會報告檔案／音訊數量、大小與長度的涵蓋範圍，並標示中繼資料長度的後備值，而不是悄悄取代來源長度。該面板下方的「製作人員」卡片列出 DLsite 在聲優之外署名的製作人員：作者、劇本、插畫、音樂與其他。卡片只顯示作品署名的角色，DLsite 未列出製作人員時則不會出現。選取某個名字，會在詳細資料所由開啟的媒體庫搜尋中加入 `staff:` 子句，該子句可在任一製作人員角色中找到這個名字。在小螢幕上，頂部橫幅會在資訊與目錄分頁之上保留同樣的參與名單行、標籤列、統計列與操作，資訊顯示來源面板與「製作人員」卡片，而標記、清單、DLsite、中繼資料與來源會收合為圖示。
- 將目錄呈現為單一面板：包含檔案摘要與來源檢查的標頭、帶有狀態圓點的底線來源分頁，以及資料夾瀏覽器。當目錄夠寬且作品有資料夾時，一個固定的資料夾欄會位於所選資料夾內容旁；否則，資料夾按鈕會在手機上以底部面板、在其他裝置上以彈出視窗開啟相同的導覽器。該欄標頭中的**隱藏資料夾面板**會讓內容佔滿整個寬度，並在資料夾按鈕旁留下**顯示資料夾面板**；此選擇會記在該裝置上。導覽器列出依自然排序的資料夾及其可播放或圖片數量，完整展開小型樹狀結構，而較大的則朝向所選、推薦與正在播放的資料夾展開；將只含一個子資料夾的資料夾合併為單一列，並標示推薦的資料夾與正在播放的資料夾。
- 開啟時會停在資料夾路由規則所推薦的資料夾。內容工具列顯示上一層控制項與導覽路徑、資料夾的音軌數量與長度、推薦徽章（或回到推薦資料夾的指令）、已摺疊的歌詞數量，以及針對目前資料夾可播放檔案的全部播放指令。
- 將資料夾內容分組為子資料夾磚、專輯式音軌清單、圖片圖庫、文件與其他檔案，並在存在多個群組時標示各群組。子資料夾磚會摘要其內容，並在含有可播放檔案時提供直接播放指令。音軌依資料夾播放順序編號，完整名稱位於大小與作品續播位置之上，精確長度位於尾端欄位；它們在游標移上時顯示播放提示，並以強調色的列與動態圖示標示目前的音軌。續播標記會隨播放儲存而更新，無需重新載入。本機與快取的圖片顯示延遲載入的縮圖；遠端圖片只在預覽時載入。
- 將已比對的同資料夾歌詞附屬檔案，從預設的目錄列中摺疊起來，同時保留未比對的文字可見。音訊列提供歌詞選擇、預覽與顯示位置操作，而目錄控制項可以顯示所有被摺疊的歌詞。檔案管理與取得選擇不會摺疊歌詞。
- 本機來源的 **管理歌詞** 選項，會列出每個附有歌詞選擇的本機音訊檔案。具有媒體庫寫入權限的使用者，可以指派該作品的任何本機歌詞檔案，包括名稱與音訊不相符的翻譯歌詞，或依音軌編號（或兩個資料夾的檔案數量相同時依位置）將歌詞資料夾對齊到音軌。每一列都會預覽前幾行，並在最後一行有時間的歌詞開始於音軌結束之後時發出警告。指派由所有聆聽者共用，並成為自動選項；聆聽者自己的選擇仍然優先。
- 一首音軌每種語言各保留一個指派的歌詞檔案。**歌詞語言** 列可在 **備用** 與日文、簡體中文、正體中文、英文、韓文之間切換，並顯示每種語言有歌詞的音軌數量。聆聽者的所有語言都沒有歌詞時，會使用 **備用** 歌詞，而且只有在那裡，沒有指派的音軌才會退回依檔名比對。播放時先使用聆聽者的中繼資料語言中第一個有歌詞的語言，其次是備用歌詞，最後是其他語言。檔案的語言由你自行宣告；Kikoto 不會從檔案猜測。
- **管理歌詞** 為管理本機檔案的使用者提供 **歌詞檔案** 分頁。Kikoto 會管理作品資料夾內一個 `lyrics_kikoto` 資料夾中的歌詞，依語言放在以語言命名的資料夾裡：`ja`、`en`、`zh-hans`、`zh-hant`、`ko`，以及用於備用歌詞的 `fallback`，例如 `lyrics_kikoto/ja`。Kikoto 會把自己建立的 `lyrics_kikoto` 資料夾標記為自己所有。作品自帶的歌詞資料夾（例如 `lyrics`）屬於作品本身的檔案：其中的歌詞列在 **此資料夾中的其他歌詞** 下，Kikoto 不會在其中加入歌詞，也不會把其中的檔案當作受管理歌詞刪除。不是 Kikoto 建立的 `lyrics_kikoto` 資料夾或同名檔案會阻止加入歌詞，直到你重新命名或移走它。此分頁像 **編輯檔案** 一樣分三欄編輯這些歌詞：左欄是歌詞可以來自的位置，中欄是所選位置的歌詞檔案，右欄是編輯後的受管理歌詞。作品有多個本機資料夾時，在右欄選擇要編輯的資料夾。
- 位置包括：**受管理的歌詞**，取消勾選檔案即刪除它；**此資料夾中的其他歌詞**，選取的檔案會複製到歌詞資料夾並留在原處，把 **作品本身的檔案** 設為 **移動到 lyrics_kikoto** 時則會移入，該選擇從管理員的[預設值](settings.md#媒體庫)開始，未變更時為複製；作品的其他本機資料夾（包括媒體庫中的其他版本），其檔案會被複製；以及已設定的遠端來源提供的版本，其檔案會被下載。選取的檔案會放入為其所在位置在 **這些歌詞的語言** 中選擇的語言的歌詞資料夾。其他版本的歌詞預設使用該版本的語言；Kikoto 不會猜測作品本身檔案的語言，因此需要先選擇語言才會產生預覽。要變更受管理歌詞的語言，請在 **此資料夾中的其他歌詞** 中開啟 **同時列出受管理的歌詞，以變更其語言**，再在那裡選取它們；即使在複製時，它們也會移到新語言。檔案會保留其在所在位置下的路徑，但去掉它可能已在的歌詞資料夾。
- 右欄預覽結果。內容相同的檔案已在那裡時保持不變。同名的不同檔案是一個衝突，直接在右欄處理：保留現有檔案、取代它、兩者都保留，或重新命名新檔案；不需要先刪除。擋路的資料夾和檔案依 **編輯檔案** 中的方式處理。**套用變更** 在刪除檔案前會要求確認。擁有媒體庫寫入權限時，**將新增的歌詞指派給相符的音軌** 會先依檔名、再依音軌順序，把每個新增檔案以其語言指派給相符的音軌；已有該語言歌詞的音軌保持不變。已使用被移動檔案的指派會隨檔案一起轉到其語言；複製的檔案是一個新檔案，作品本身的檔案保留其指派。讀取過的遠端版本不會被加入媒體庫。
- 本機作品的 **管理檔案** 提供 **作為歌詞管理**，適用於位在作品資料夾其他位置的歌詞。選取 `.lrc`、`.vtt`、`.srt`、`.ass` 或 `.txt` 檔案後選擇它，會開啟 **歌詞檔案**，並在 **此資料夾中的其他歌詞** 下選取這些檔案。
- 當作品可使用 **管理歌詞** 時，**管理檔案** 預設會隱藏 Kikoto 所管理的歌詞。**由 Kikoto 管理的歌詞** 列會統計它們的數量，並開啟 **管理歌詞** 的 **歌詞檔案** 分頁。開啟其中的 **在清單中顯示** 開關後，它們會與其他檔案一起列出，並可像任何檔案一樣選取。隱藏期間，選取整個作品資料夾進行刪除時會包含它們；任何較小的選取範圍則會將它們留在原處。
- **管理歌詞** 對具備媒體庫寫入與工作流程權限的使用者，在已設定[語音辨識服務](settings.md#語音辨識服務)時提供 **轉寫** 分頁。詳見[轉寫](#轉寫)。Demo 中會以範例顯示。
- **管理檔案** 中的 **快速選取** 可依位置或格式選取檔案。本機作品還可在其中 **尋找相同檔案**。它會依內容比對此作品每個版本與資料夾的本機檔案，因此翻譯版本中改過名稱的音訊，也會被認定與原版相同。有相同副本的檔案會標出副本所在的位置，並出現兩個選取項目：**其他資料夾中也有** 會選取所列檔案中在別處有相同內容的檔案，**在此資料夾內重複** 則會選取所列資料夾內除了第一份之外的每一份副本。只是相似的檔案（例如同一首音軌重新編碼）並不相同，也不會被標記。在你檢查刪除之前，不會刪除任何東西。
- 本機作品的 **管理檔案** 提供 **編輯檔案**，供可以管理本機檔案的使用者使用。它以三欄編輯目前列出的資料夾。**來源** 列出 **此資料夾**、作品各版本的其他本機資料夾，以及已設定的遠端來源最近一次被發現提供的每個版本。**遠端** 旁的 **檢查來源** 供可以檢查來源的使用者使用，會再次向每個有回應的遠端來源詢問該作品的各個版本，並重新整理清單。**選擇** 顯示所選位置的檔案：取消勾選此資料夾的檔案會將其移除，勾選其他位置的檔案會將其加入。**最終目錄** 顯示編輯後的資料夾，並把每個檔案標記為保留、移除、移動、複製、下載、被取代或已存在；剛選取的檔案在預覽包含它之前顯示為檢查中。它像檔案管理員一樣排列：把檔案或資料夾拖到某個資料夾上即可移到那裡，把中間一欄的檔案或資料夾拖到某個資料夾上即可加入那裡，中間一欄保持不變，並可用 **新增資料夾** 或資料夾的選單來建立、重新命名和刪除資料夾。每一列的選單中還有供觸控螢幕和鍵盤使用的 **移動到**。刪除一個有內容的資料夾時會先詢問，然後把其中的內容上移一層。檔案或資料夾落點處的名稱已被佔用時，會加上編號，例如 `01 (2).mp3`。被移動的檔案保留其播放進度、歌詞和其他參照。編輯後變空的資料夾會被移除，你建立的資料夾即使為空也會保留。Kikoto 的 `lyrics_kikoto` 資料夾只透過歌詞角色來排列。來自其他本機資料夾的檔案會被複製，除非為該資料夾開啟了 **合併到此資料夾**，否則該資料夾保持不變。被合併的資料夾在尚未選取任何檔案時會帶入它的所有檔案，一旦此資料夾包含了編輯所複製的內容，被合併的資料夾就會連同其中仍有的所有內容一起被刪除。來自遠端版本的檔案會被下載，這還需要取得（Fetch）權限，且該版本不會加入媒體庫。來自其他位置的歌詞檔案（`.lrc`、`.vtt`、`.srt`、`.ass` 或 `.txt`）可以作為歌詞加入，而不是放在它自己的路徑：在檔名下選擇語言，或對該位置所有選取的歌詞檔案在 **所選歌詞檔案** 下選擇語言，檔案會像在 **歌詞檔案** 中一樣放入 `lyrics_kikoto` 內該語言的資料夾。語言由你指定，Kikoto 不會猜測。有媒體庫寫入權限時，**將新增的歌詞指派給相符的音軌** 會把每個新增的歌詞檔案依其語言，先依檔名、再依音軌順序，指派給與之相符的音軌，也包括同一次編輯新增的音軌；該語言已有歌詞的音軌會保留原歌詞。如果檔案會落在同名的不同檔案上，就是一個衝突：保留資料夾中的檔案、取代它、兩者都保留，或重新命名傳入的檔案。已在該名稱處的資料夾或連結絕不會被取代，因此只提供其他選擇。傳入路徑的某個資料夾應在的位置上有一個檔案時，只能選擇保留該檔案，或把傳入的檔案重新命名到另一個路徑。移除檔案時，**套用變更** 會要求兩次刪除確認。有被合併的資料夾時，它會先把被合併資料夾的每個檔案與編輯後的資料夾依內容比較，列出在那裡沒有相同副本、會隨資料夾刪除而遺失的每個檔案，並在刪除前再次確認；從遠端來源下載的檔案不參與比較。編輯作為一個活動工作流程執行，在移除、移動或加入任何內容之前先收集好所有要加入的檔案，並最後刪除被合併的資料夾，且僅當它仍恰好包含檢閱所列出的檔案時才刪除。完成後目錄會重新載入。
- 掃描在多個本機資料夾中找到同一個代碼的作品，會保留所有這些資料夾。目錄接著會為每一份副本顯示一個資料夾，**管理檔案** 一次列出一個資料夾並提供 **資料夾** 選擇，而且只有在剩下單一資料夾時，才能忘記該作品。作品位於多個資料夾，或媒體庫中有它的另一個版本時，管理媒體庫的使用者會在目錄上方看到通知，其中的 **管理歌詞** 與 **管理檔案** 可將歌詞整合到一個資料夾，並移除相同的檔案。
- 先列出依自然排序的資料夾，再列出依自然排序的檔案。資料夾播放遵循同一個可見的順序。
- 讓圖片與文字等可用的不可播放檔案保留在目錄中，同時把音訊與含音訊的影片合併計入可播放來源指標。
- 在檔案檢視器中開啟預覽，可用標頭控制項、方向鍵、手機上的滑動，或圖片幻燈片列，逐一瀏覽資料夾中同類型的檔案。圖片位於深色舞台上，可適應視窗大小，或以點擊處為中心顯示實際大小並支援拖曳平移，同時報告其尺寸；影片使用同樣的舞台。文字會開啟閱讀檢視，LRC、WebVTT 與 SRT 檔案則顯示帶時間戳記的行，並有 LRC 標頭標籤與原始文字切換，其解析方式與播放器的歌詞相同。檢視器提供文字的複製、本機與快取檔案的下載，以及本機圖片的設定封面，後者需要再點一次確認，並在數秒後或換一張圖片時重設。它在手機上填滿螢幕，並在桌面的浮動播放器上方開啟。
- 依需要將本機、快取與遠端的文字預覽轉換為 UTF-8，使用位元組順序標記、宣告的字元集與自動的舊版編碼偵測，而不會改寫來源檔案。
- 桌面版精簡播放器作用中時，預留底部捲動空間，使最後的佇列操作仍可觸及。

## 操作

- 顯示一個固定的繼續播放操作。沒有大於零且未完成的作品游標時，它會停用；直接啟動檔案則從頭開始。
- 更新快速聆聽狀態。
- 管理收藏清單的成員資格。清單按鈕會顯示作品所在清單的名稱；作品在多個清單中時，顯示依清單順序排在最前的一個並標出其餘數量，懸停提示會列出全部名稱。**加入清單** 會在清單選單中建立一個清單並選取它；**儲存** 會把成員資格連同既有的選擇一起套用。
- 與提供方中繼資料標籤分開編輯個人作品標籤。
- 同步中繼資料。
- 從相容的遠端來源同步／快取／取得。
- 取得被接受時，會將所選來源記錄為可用，並重用同一標準作品已在排隊或進行中的取得。
- 當目前的訪客是匿名時，在任何取得準備請求之前先開啟登入。
- 對已有本機資料夾的作品，在遠端來源上使用 **取得（Fetch）** 會開啟 **編輯檔案** 並定位到該來源的版本，供可以管理本機檔案並執行取得的使用者使用。對這些使用者，沒有本機資料夾的作品會以同樣的三欄開啟一個取得（Fetch）到新資料夾的介面：該來源的版本排在最前且所有檔案都已選取，作品的其他版本、來源和本機資料夾可以加入檔案，歌詞檔案可以像在 **編輯檔案** 中一樣作為某種語言的歌詞加入並指派音軌。其 **最終目錄** 與 **編輯檔案** 中一樣排列，只是不含任何檔案的資料夾不會被建立。該版本自己的檔案是一次取得，其餘所有內容都在取得發佈資料夾之後由 **編輯檔案** 工作流程加入，因此會落在取得所發佈檔案上的檔案是需要先解決的衝突。目標資料夾需要檢閱時，**在標準 Fetch 中檢閱** 會開啟取得對話框。其他使用者會得到取得對話框。
- 從所選來源的頂部橫幅來源選單，開啟該來源專屬的追蹤、分支、取得、來源頁面、快取、重新整理與檔案維護指令。
- 追蹤所選的遠端來源，持久化其可瀏覽的樹狀結構，並在彙整的已追蹤脈絡中開啟對應的來源，而不需要再次分支。
- 可用時編輯手動覆寫。
- 在中繼資料編輯器中，將作品的中繼資料連結到另一個 DLsite 代碼，例如當特典版本不再販售，而一般版本有不同的代碼時。之後中繼資料重新整理會讀取所連結的代碼，並將其中繼資料、標籤與封面儲存到這個作品上；所連結的代碼不會變成獨立的作品。當作品自己的代碼沒有記錄時，無法使用中繼資料的通知會直接開啟編輯器。

## 詳細資料載入模型

作品詳細資料應優先採用已知的本機資料庫狀態，再獨立載入較慢、源自遠端的狀態：

1. 來自任何作品卡片介面的路由預覽，或針對直接網址的輕量代碼解析。
2. 基本的作品中繼資料、使用者狀態、版本與參與名單。
3. 本機媒體與目錄樹。
4. 來源可用性摘要。
5. 所選的遠端來源樹（若使用者開啟了一個）。

這可以避免遠端來源失敗阻擋本機的詳細資料外殼。目錄階段使用穩定、呈目錄形狀的骨架。媒體錯誤只會取代該骨架，並讓已載入的中繼資料與操作維持完整。取得路徑選擇與檔案管理樹，只有在選取其對應的選項指令後才會推導出來。
