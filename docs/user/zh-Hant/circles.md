# 社團
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社團代表製作者、社團及相關製作方的目錄狀態。

## 目前行為

- 以伺服器分頁的結果列出已知的製作方，每張卡片都附有目錄與可用狀態。
- 提供搜尋、篩選、由網址記錄的分頁、收藏狀態、使用者標籤、評分與備註。
- 將搜尋、一鍵檢視晶片與每頁數量操作放在同一列可換行的工具列。晶片為 `全部社團`、`收藏`、`已標記`、`可用`、`本機`、`遠端`、`缺少` 與 `需要注意`，按下的晶片即為目前的檢視。在手機上，搜尋欄自成一列、每頁數量在其旁邊，晶片則在下方橫向捲動。
- 將每個社團顯示為封面磚：社團的封面（以 `無封面` 作為後備顯示）、封面上的收藏控制項、名稱、最新發行日期與個人標籤。磚塊在寬版版面填滿整列，在手機上為兩欄。
- 以最新已知 DLsite 作品的本機快取封面作為社團的封面。詳細資料 **更多** 選單中的 **更換封面…** 會列出該社團的作品並提供搜尋，所選作品的封面會成為該社團在磚塊與詳細資料摘要上的封面。同一對話框中的 **最新作品** 會恢復隨每次發行而更新的封面。此選擇屬於做出選擇的帳號；所選作品若離開該社團的目錄，則改用最新作品的封面。
- 每個社團磚都會摘要其同步狀態、單一標準的 `可用 N/總數` 數量與可用性長條：實心區段代表有本機副本的作品，較淺的區段代表只有遠端來源持有的作品，其餘則為空白軌道。
- 依外部 ID 顯示社團詳細資料。
- 社團目錄作品由伺服器分頁。目錄總數保持完整，搜尋、可用性和系列篩選與所選的排序都在分頁前執行；批次選取只涵蓋目前載入的頁面。
- 目錄作品可依 **發行日期**、**代碼**、**標題**、**評分** 或 **銷量** 升序或降序排序，預設為最新發行的在前。沒有評分或銷量的作品在任一方向都排在最後。排序方式與每頁數量（24、48 或 96）會依帳號記錄在裝置上，並套用於每個社團。
- 支援以增量或完整模式重新整理目錄。
- 目錄資料列與匯入的作品分開儲存。
- 為目錄中的作品顯示本機／快取／遠端來源的可用標籤。
- 以與媒體庫相同的響應式網格和作品卡片呈現作品結果。這同時適用於社團詳細資料與社團系列；獨立的社團實體清單則保留自己的控制項。在作品卡片上選取 DLsite 標籤或個人標籤，會開啟針對它的本機媒體庫搜尋。
- 在帶有封面色調的面板上顯示社團詳細資料摘要，包含社團的別名與個人標籤。其 **可用**、**本機**、**遠端** 與 **無法使用** 數量位於可用性長條旁，涵蓋整個目錄，不受下方作品篩選條件影響。從未擷取過的社團會說明只列出本庫已知的作品；否則摘要會顯示目錄上次同步的時間。系列卡片帶有相同的可用性長條。
- 將常用的重新整理操作放在詳細資料摘要中：從未擷取過的社團顯示 **首次擷取**，其後是 **重新整理社團**，後者也會檢查遠端來源。**重試中繼資料** 只會在目錄作品仍缺少中繼資料時出現，並且只補齊這些作品。每個操作都會排入一次不帶篩選或標籤的「同步社團目錄」執行並立即返回；在該次執行結束前，按鈕會顯示 **正在重新整理**，且可在活動中看到這次執行。
- **收藏** 旁的鈴鐺會訂閱此社團的新作，系列的 DLsite 連結旁的鈴鐺則訂閱該系列；請參閱[訂閱](subscriptions.md)。已訂閱社團的系列已包含在內。
- **更多**選單包含 **更換封面…** 與 **同步此社團的目錄…**，後者是已填入此社團的「同步社團目錄」預製工作流程，可用於目錄重新整理、篩選、中繼資料、標籤與來源檢查的其他所有組合。若要更新該社團作品已有的中繼資料，請以該社團為範圍執行中繼資料同步。
- 在行動裝置上縮短常用的詳細資料操作，讓僅有圖示的收藏、更多與 DLsite 控制項仍可依名稱存取，並把 DLsite 放在最後。
- 在寬版版面使用媒體庫風格的作品工具列：左側是作品／系列切換與有限寬度的搜尋，右側依序是標示目前排序方式的排序按鈕、顯示選項、可用性篩選與選取。顯示選項包含與媒體庫共用的 **卡片** 選項（**完整**、**緊湊**、**極簡**）、欄數以及每頁數量；新選擇的卡片模式從其[預設](library.md#目前行為)開始。共用的集合分頁位於網格上方與下方。
- 在行動裝置上，作品控制項僅保留作品／系列切換（旁邊是排序按鈕）、搜尋與一個目錄選項操作。可用性、卡片模式、行動裝置欄數、每頁數量與選取模式都放在該面板中；寬版版面則保留行內控制項。系列總覽列出系列，不提供排序。
- 在行動裝置上，詳細資料的返回控制項會作為「上一層」，回到最後一個依伺服器與使用者分別記錄的社團清單位置，包括從媒體庫開啟詳細資料時。寬版版面則保留會依來源而變的歷史返回標籤與目的地。
- 允許在確認後移除過期的目錄資料列。

## 邊界

社團目錄說明某個製作方發行過什麼。在來源同步或取得作業建立媒體位置之前，它們不會建立具體的播放位置。

## 重新整理行為

增量重新整理應優先處理最新的目錄資料列，並在遇到已知資料列時停止。完整重新整理可以走訪更多提供方頁面，但不應自動刪除舊的目錄資料列。
