# 社團

[English](../en/circles.md) · [簡體中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社團頁面表示创作者及其目錄状态。

## 主要內容

- 支援搜尋、筛选和分页浏览社團。
- 管理收藏、個人標籤、评分和备注。
- 顯示 DLsite 代碼、封面、同步状态和 `Available N/total`。
- 目錄行與 Work 分开儲存，作品结果使用與 Library 相同的網格。

目錄说明社團發布过什么；只有 Sync 或 Fetch 创建媒體位置后才有可播放位置。
