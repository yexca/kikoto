# 社團
[English](../en/circles.md) · [简体中文](../zh-Hans/circles.md) · [繁體中文](../zh-Hant/circles.md) · [日本語](../ja/circles.md) · [한국어](../ko/circles.md)

社團代表製作者、社團及相關製作方的目錄狀態。

## 目前行為

- 以伺服器分頁的結果列出已知的製作方，每張卡片都附有目錄與可用狀態。
- 提供搜尋、篩選、由網址記錄的分頁、收藏狀態、使用者標籤、評分與備註。
- 使用與媒體庫相同風格的第一列工具列：搜尋留在左側，每頁數量與社團篩選操作（預設為 `全部社團`）留在右側；窄版版面會把搜尋收進工具列操作中。
- 在精簡的響應式創作者卡片中，顯示最新已知的 DLsite 作品代碼與本機快取的封面，並以 `無封面` 作為後備顯示。
- 每張社團卡片都會摘要其同步狀態，並以單一標準的 `可用 N/總數` 徽章取代分開的本機與遠端數量。
- 依外部 ID 顯示社團詳細資料。
- 支援以增量或完整模式重新整理目錄。
- 目錄資料列與匯入的作品分開儲存。
- 為目錄中的作品顯示本機／快取／遠端來源的可用標籤。
- 以與媒體庫相同的響應式網格和作品卡片呈現作品結果。這同時適用於社團詳細資料與社團系列；獨立的社團實體清單則保留自己的控制項。在作品卡片上選取 DLsite 標籤或個人標籤，會開啟針對它的本機媒體庫搜尋。
- 在社團詳細資料中，於使用者定義的標籤旁顯示一個 `可用 N` 徽章。重複的統計方塊與社團別名不會出現在社團介面中。
- 將常用的重新整理操作放在詳細資料摘要中：從未擷取過的社團顯示 **首次擷取**，其後是 **重新整理社團**，後者也會檢查遠端來源。**重試中繼資料** 只會在目錄作品仍缺少中繼資料時出現，並且只補齊這些作品。每個操作都會排入一次不帶篩選或標籤的「關注社團」執行並立即返回；在該次執行結束前，按鈕會顯示 **正在重新整理**，且可在活動中看到這次執行。
- **更多**選單會開啟 **關注此社團…**，也就是已填入此社團的「關注社團」預製工作流程，可用於目錄重新整理、篩選、中繼資料、標籤與來源檢查的其他所有組合。若要更新該社團作品已有的中繼資料，請以該社團為範圍執行中繼資料同步。
- 在行動裝置上縮短常用的詳細資料操作，讓僅有圖示的收藏、更多與 DLsite 控制項仍可依名稱存取，並把 DLsite 放在最後。
- 在寬版版面使用媒體庫風格的作品工具列：左側是作品／系列切換與有限寬度的搜尋，右側則以低調的圖示操作提供欄數、每頁數量、可用性篩選與選取。共用的集合分頁位於網格上方與下方。
- 在行動裝置上，作品控制項僅保留作品／系列切換、搜尋與一個目錄選項操作。可用性、行動裝置欄數與選取模式都放在該面板中；寬版版面則保留行內控制項。
- 在行動裝置上，詳細資料的返回控制項會作為「上一層」，回到最後一個依伺服器與使用者分別記錄的社團清單位置，包括從媒體庫開啟詳細資料時。寬版版面則保留會依來源而變的歷史返回標籤與目的地。
- 允許在確認後移除過期的目錄資料列。

## 邊界

社團目錄說明某個製作方發行過什麼。在來源同步或取得作業建立媒體位置之前，它們不會建立具體的播放位置。

## 重新整理行為

增量重新整理應優先處理最新的目錄資料列，並在遇到已知資料列時停止。完整重新整理可以走訪更多提供方頁面，但不應自動刪除舊的目錄資料列。
